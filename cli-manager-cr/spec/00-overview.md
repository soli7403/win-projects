# 제품 개요 (TermGo)

> 작성 방식: 기존 앱 사용 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**.

## 1. 한 줄 설명
Windows 에서 쓰는 **터미널 접속 관리 앱**. 여러 서버(SSH·텔넷·시리얼)와 이 PC 의 셸을 탭·분할 화면으로 열고, 접속 정보(계정·키)를 마스터 비밀번호로 암호화한 볼트에 저장하며, SFTP 파일 탐색·이미지 붙여넣기 업로드·git 동기화를 제공한다.

## 3. 대상 환경
- **Windows 10/11 (1차)**. macOS·Linux 전용 동작(키체인·Touch ID, 맥 단축키, ssh config 중심 문구)은 1차 범위 밖(결정 D5). 코드는 운영체제에 따라 동작이 갈라지는 부분(경로, 줄바꿈, 권한, 셸, OS 보호 API)을 분리해 다른 OS 로 확장할 수 있게 한다.
- 화면 기술: 웹 기술 기반 데스크톱 창(Wails + WebView2), 프런트는 React, 터미널은 xterm.js(WebGL 렌더러 우선).
- 언어: 화면 문구는 **한국어**.

## 4. 용어
| 용어 | 뜻 |
|---|---|
| 서버 | 저장된 접속 대상(프로토콜, 주소, 계정 연결, 환경 등) |
| 폴더 | 서버를 묶는 계층 |
| 환경 | 운영(prod)·성능테스트·기능테스트·개발·장비·일반 — 색과 위험 가드에 영향 |
| 세션 | 열려 있는 접속 하나(터미널 화면 하나) |
| 칸(pane) | 탭 안에서 세션 하나를 보이는 영역, 빈 칸 가능 |
| 볼트 | 계정 비밀을 암호화해 담는 `vault.json` |
| 계정 | 볼트 항목(비밀번호 또는 개인 키) |
| 즉석 접속 | 저장하지 않고 연 접속(빠른 접속의 "바로 연결") |
| 세션 유지 | 원격(또는 WSL)의 tmux 세션에 붙어 창을 닫아도 프로그램이 계속 실행되게 하는 기능 |

## 5. 비목표 (이 명세에서 다루지 않음)
- 광고 배너 기능, 원본 앱의 이미지·로고·이름(새 로고·이름 사용).
- 설치 프로그램·자동 업데이트 설치(새 버전 **확인**만 있고 내려받기 페이지를 여는 것까지).
- macOS·Linux 빌드(1차).

## 6. 구현 순서 제안 (B/C 단계)
1. 백엔드: 데이터 폴더·store·vault·IPC 틀 → 세션(로컬 셸부터) → SSH → SFTP → 텔넷·시리얼 → 가져오기 → 동기화·업데이트
2. 프런트: 외형 토큰·셸 → 잠금 화면 → 사이드바·서버 편집 → 탭·분할·터미널 → 빠른 접속 → SFTP·스니펫 → 설정 → 나머지
3. 화면마다 acceptance/ 시나리오로 확인
