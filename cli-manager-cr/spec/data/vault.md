# 데이터 형식 — 볼트 (자격 증명 보관)

> 작성 방식: 기존 앱의 볼트 파일 형식·암호 절차 열람 (호환에 필요한 사실만). 작성일 2026-11-10. 상태: **draft**.
> 암호 매개변수는 **기존 vault 파일과 호환**하기 위한 사실이다. 이 형식을 따르는 한 같은 마스터 비밀번호로 양쪽 앱이 같은 파일을 열 수 있다.

## 1. 파일

데이터 폴더의 `vault.json` (JSON 객체 하나). 저장은 임시 파일에 쓰고 이름을 바꾸는 방식이며 이전 내용은 `.bak` 으로 남기고 권한은 소유자 전용(0600)이다. 읽을 때 본 파일이 깨져 있으면 `.bak` 을 시도한다. 파일이 없으면 "미초기화" 상태.

| 필드 | 설명 |
|---|---|
| version | 숫자, 현재 1 |
| kdf | 마스터 비밀번호용 키 파생 매개변수 (§2) |
| wrapped | 마스터 비밀번호로 감싼 **볼트 키** (§3) |
| recoveryKdf, recoveryWrapped | 복구 코드용 (§5). 없을 수 있음 |
| osWrapped | 문자열. 다른 앱(Electron safeStorage) 값 — **읽기·보존만, 사용하지 않음** |
| osWrappedWin | 문자열. Windows DPAPI 로 감싼 볼트 키(base64). OS 잠금 해제용 (§7) |
| items | 항목 배열 (§4) |

## 2. 키 파생 (kdf / recoveryKdf)

객체: `alg`=`scrypt`, `N`=131072(2^17), `r`=8, `p`=1, `salt`=무작위 16바이트(base64). 출력 32바이트.
입력 문자열은 **유니코드 NFKC 로 정규화**한 뒤 UTF-8 바이트로 쓴다. 새로 만들 때마다 새 salt.

## 3. 암호화 형식 (공통)

AES-256-GCM, 12바이트 무작위 nonce. 결과는 객체 `{iv, tag, ct}` 이며 세 값 모두 base64. `ct` 는 암호문(태그 제외), `tag` 는 16바이트 인증 태그. 복호화 시 `ct`+`tag` 를 이어 검증한다. 추가 인증 데이터(AAD)가 지정되면 그 문자열의 UTF-8 바이트를 쓴다.

- **볼트 키**: 무작위 32바이트. `wrapped` = 볼트 키를 (마스터 비밀번호에서 파생한 키로) 암호화, AAD=`vault-key`.
- **복구 `recoveryWrapped`**: 같은 볼트 키를 복구 코드에서 파생한 키로 암호화, AAD=`vault-key`.

## 4. 항목 (items[])

| 필드 | 설명 |
|---|---|
| id | UUID v4 |
| name | 표시 이름 (평문) |
| kind | `password` / `key` (평문) |
| username | 사용자 이름 (평문, 비면 생략) |
| updatedAt | 밀리초 타임스탬프 |
| iv, tag, ct | 비밀의 암호화 결과 — 볼트 키로 암호화, **AAD = 항목 id** |

암호화되는 비밀은 JSON 객체 `{username, password, privateKey, passphrase}` 이며 **비어 있는 값은 생략**한다.

## 5. 복구 코드

- 형식: 알파벳 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`(32글자: I, O, 0, 1 제외)에서 무작위로 **24글자**를 뽑아 4글자씩 하이픈으로 구분(`XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`).
- 복구 키 파생에는 **하이픈을 뺀 24글자** 문자열을 쓴다. 입력받을 때는 대문자로 바꾸고 하이픈·공백·탭을 모두 제거한 뒤 사용한다.

## 6. 동작

| 동작 | 규칙 |
|---|---|
| 설정(Setup) | 이미 있으면 오류 "이미 볼트가 설정되어 있습니다". 비밀번호가 **8자(문자 수) 미만**이면 오류 "마스터 비밀번호는 8자 이상이어야 합니다". 볼트 키를 새로 만들고 kdf·recoveryKdf 를 새로 만들어 두 가지로 감싸 저장. 복구 코드를 돌려준다. **설정 직후 볼트는 열린 상태**지만 "잠금 변경" 알림은 보내지 않는다(복구 코드 화면 유지를 위해). |
| 잠금 해제 | 비밀번호에서 키를 파생해 `wrapped` 를 복호화. 성공하면 볼트 키를 메모리에 두고 "열림" 알림. 실패하면 false(상태 변화 없음). |
| 복구 | (새 비밀번호 8자 검사는 비밀번호 변경과 같다.) 복구 코드로 볼트 키를 복호화. 성공하면 새 비밀번호로 **새 kdf**를 만들어 `wrapped` 를 다시 감싸고 저장, 볼트 키를 메모리에 두고 "열림" 알림. 복구 정보 자체(recovery*)는 바꾸지 않는다 — 복구 코드는 계속 유효. |
| 비밀번호 변경 | (새 비밀번호의 길이는 화면이 검사한다 — 8자 미만이면 거절. **백엔드가 같은 8자 검사를 추가해도 된다**, 오류 문구는 설정과 같은 "마스터 비밀번호는 8자 이상이어야 합니다".) 이전 비밀번호로 볼트 키를 복호화하고 새 비밀번호의 **새 kdf**로 다시 감싸 저장. 항목은 다시 암호화하지 않는다. 열림 상태는 바꾸지 않는다. 실패하면 false. |
| 잠금 | 메모리의 볼트 키를 0 으로 덮어쓰고 비운다. **이미 잠겨 있어도 항상** "잠김" 알림을 보낸다(상태 전이와 무관). |
| 목록 | 잠겨 있어도 가능. 이름·종류·사용자 이름·갱신 시각만 돌려줌(비밀 없음). |
| 조회(Get) | 잠겨 있으면 오류 "볼트가 잠겨 있습니다". 항목이 없으면 없음(null). |
| 저장(Save) | 잠겨 있으면 같은 오류. 볼트가 없으면 오류 "볼트 없음". id 가 없으면 새 UUID. **각 필드는 "지정 안 함"(요청에서 빠졌거나 null)이면 기존 값을 유지하고, 빈 문자열 `""` 을 명시하면 그 값을 빈 값으로 바꾼다(지우기).** 대상 필드: 사용자 이름·비밀번호·개인 키·키 암호 각각. 항목의 **평문 사용자 이름은 저장 시점의 비밀 객체 사용자 이름과 항상 같은 값**으로 쓴다(두 값이 다르게 저장된 파일을 읽을 때는 **비밀 객체의 값이 우선**). 갱신 시각=지금. 같은 id 의 항목을 교체(없으면 추가, 목록 맨 뒤로 이동). 저장 후 "항목 변경" 알림(동기화 예약용). |
| 삭제 | 항목 제거 후 저장, "항목 변경" 알림. |
| 백업용 내보내기 | 파일 구조 전체. |
| 백업에서 가져오기 | 파일을 통째로 교체. **osWrapped, osWrappedWin 은 비운다**(다른 PC 의 OS 보호 값). 볼트는 잠긴 상태가 되고 "잠김" 알림. |

## 7. OS 잠금 해제 (Windows)

- 가능 여부: Windows 에서 DPAPI 를 쓸 수 있을 때.
- 켜기: 볼트가 열려 있어야 하며(아니면 오류 "볼트가 잠겨 있습니다"), 볼트 키를 **현재 Windows 사용자 계정의 DPAPI** 로 보호한 결과를 base64 로 `osWrappedWin` 에 저장. 끄기: 값을 비운다.
- 해제: `osWrappedWin` 을 풀어 32바이트 볼트 키를 얻는다. **항목이 하나 이상이면 첫 항목을 그 키로 복호화해 보고** 실패하면 해제 실패. 성공하면 "열림" 알림.
- 상태 값의 종류 이름(`osUnlockKind`): **Windows 에서는 OS 잠금 해제 가능 여부와 상관없이 항상 `windows`**. OS 잠금 해제를 지원하지 않는 빌드(다른 OS)에서는 이 필드를 생략한다. 화면은 `osUnlockAvailable` 로 토글 표시 여부를 정한다.

## 8. 동기화 지원 (data/sync-backup.md 에서 사용)

- **임의 데이터 암호화/복호화**: 열린 볼트 키로 AES-256-GCM, 호출자가 AAD 문자열을 지정.
- **헤더(Header)**: 파일 구조에서 `items`, `osWrapped`, `osWrappedWin` 을 비운 복사본 — 다른 PC 가 같은 마스터 비밀번호로 열 수 있게 하는 최소 정보.
- **항목 목록 교체**: 병합 결과를 항목 전체로 교체(저장).
- **원격 볼트 받기(AdoptRemote)**: 저장소의 헤더 + 항목 + 마스터 비밀번호를 받아, 비밀번호로 `wrapped` 가 열리면 이 PC 볼트를 헤더+항목으로 교체(OS 값은 비움)하고 **열린 상태**로 만들며 "열림" 알림. 비밀번호가 맞지 않으면 아무것도 바꾸지 않고 false.
