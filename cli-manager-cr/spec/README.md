# 명세 인덱스 (구현자의 유일한 기준)

> **화면 문구 용어 (D60, 2026-11-13 / D67, 2026-11-14: "보관함" → 앱 잠금 용어 — 잠금 해제됨·앱 잠김·앱 잠그기·암호화해 저장 / D68, 2026-11-14: 마스터 비밀번호 → 앱 잠금 비밀번호)**: 화면에 보이는 문구는 [../docs/wording-proposal.md](../docs/wording-proposal.md) 의 용어로 바뀌었다(볼트→보관함, 스니펫→명령 모음, 동시 입력→일괄 입력, 칸·패널→창, 분할→나누기 등). 각 문서의 따옴표 안 문구는 바뀐 말이고, 설명 문장의 개념어(칸·분할 등)는 같은 뜻으로 읽는다.

> 작성자: 명세 작성자 / 구현자는 이 폴더 밖의 기존 코드를 보지 않는다 ([../CLAUDE.md](../CLAUDE.md) clean-room 규칙).
> 문서 상태: `todo` 아직 없음 · `draft` 작성 중 · `ready` 구현 가능 · `verified` 대조 완료.
