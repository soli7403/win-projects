## 1. 모양
- **언어**(맨 위, 목록 선택, D75): 도움말 "화면과 안내 문구의 언어입니다. 바꾸면 바로 적용됩니다." 목록은 behavior/i18n.md §1 의 10개(그 언어로 쓴 이름). 지금 화면 언어가 골라져 있다.
- **앱 테마**(세그먼트 다크/라이트). 바꾸면 터미널 테마도 짝에 맞춰 바뀐다: 라이트로 바꿀 때 현재 터미널 테마가 `DariTerm Dark` 이면 `DariTerm Light` 로, 다크로 바꿀 때 `DariTerm Light` 이면 `DariTerm Dark` 로. 다른 테마를 쓰고 있으면 그대로 둔다.
- **터미널 색 테마**: 3열 격자. 테마 카드마다 그 테마의 배경색·글자색으로 칠하고, 이름 아래에 샘플 한 줄 `user@host:~$ ls err`(user@host=초록, ~=파랑, ls=노랑, err=빨강, 현재 설정 글꼴 12px). 선택된 카드는 강조색 테두리(2px), 아니면 기본 테두리. 누르면 선택. 테마 목록과 색은 ui/tokens.md.
- 3열: **글꼴**(도움말 "설치된 고정폭 글꼴 이름 (예: D2Coding, Cascadia Mono)", 문자열) / **글자 크기**(숫자. **8~32 로 제한**: 범위를 벗어나면 가까운 경계값으로 — 예 100 → 32, 3 → 8 — 그리고 **비어 있거나 숫자가 아니면 14**) / **줄 간격**(숫자, 입력 단계 0.05·힌트 1~2, **값을 강제로 자르지는 않고** 비어 있거나 숫자가 아니면 1.15).
- 2열 격자:
  - 토글 **창 크기·위치 기억**(설명 "다음 실행 때 마지막 크기·위치·최대화 상태로 엽니다. 모니터 구성이 바뀌어 화면 밖이면 가운데로 엽니다")
  - 필드 **창 크기**: 버튼 [기본 크기로] → 창을 기본 크기로 되돌림
  - **커서 모양**(세그먼트 블록/막대/밑줄)
  - **스크롤백 (줄)**(숫자, 500~200000으로 제한, 비면 10000)
  - **최대 화면 분할 (상하)**(세그먼트 1·2·3·4·5, 기본 3, 도움말 "한 탭에서 위아래로 나눌 수 있는 최대 창 수입니다. 도달하면 [아래로 나누기] 버튼이 비활성화됩니다.") — 2026-11-12 추가, ui/panes.md §2
- 카드: 토글 **커서 깜빡임**, 토글 **벨 소리**.

(아래 "키워드 강조" 항목은 2026-11-27 D140 에 **"출력 규칙" 구역(§2b)으로 옮겼다**. 항목의 모양은 그대로다.)

- **키워드 강조**(2026-11-23, D113, 동작은 behavior/terminal.md §9): 도움말 "터미널 출력에서 이 글자가 나오면 색으로 표시합니다. 위에 있는 규칙이 우선입니다. 화면 표시만 바꾸며 복사한 글자와 로그에는 영향이 없습니다. vim 같은 전체 화면 프로그램 안에서는 표시하지 않습니다." 규칙마다 한 줄: 사용 스위치 / "찾을 글자" 입력(고정폭, 틀린 정규식이면 빨간 테두리) / 색 6개(빨강 `#ef4444`·주황 `#f97316`·노랑 `#eab308`·초록 `#22c55e`·파랑 `#3b82f6`·보라 `#a855f7`, 18px 원, 고른 색에 테두리) / 체크 "바탕 칠하기" / 체크 "정규식" / 체크 "대소문자 구분" / [삭제](휴지통). 아래에 [+ 규칙 추가](30개면 비활성): 새 규칙은 빈 글자, 빨강, 체크 모두 꺼짐, 사용 켜짐. 스위치·색·체크·삭제·추가는 누르는 즉시 저장하고, 찾을 글자는 입력 칸을 벗어날 때 저장한다.

## 2. 입력·붙여넣기
카드 안 토글(설명 포함):
1. **선택하면 자동 복사** — "드래그로 선택하면 즉시 클립보드에 복사합니다 (PuTTY 방식)"
   - (2026-11-23, D120-1) 마우스로 선택을 끝냈을 때(끌기·두 번/세 번 클릭 뒤 왼쪽 버튼을 뗄 때) 한 번 복사하고, 칸 메뉴의 "모두 선택"도 복사한다. 앱이 코드로 바꾼 선택(찾기의 현재 항목)은 복사하지 않는다.
2. **오른쪽 클릭으로 붙여넣기** — "끄면 오른쪽 클릭에 메뉴가 뜹니다. 켜져 있어도 Shift+오른쪽 클릭은 메뉴입니다"
3. **Ctrl+V로 붙여넣기** (Windows 에서만 표시) — "끄면 Ctrl+V 는 그대로 서버로 보내고, 붙여넣기는 Ctrl+Shift+V 로 합니다"
4. **Shift+Enter 로 줄바꿈** — "실행하지 않고 줄만 바꿉니다. Claude Code 같은 CLI의 여러 줄 입력용입니다 (Alt+Enter 와 같은 값 전송)"
5. **원격 복사 허용 (OSC 52)** — "서버 쪽 tmux·vim·Claude Code 등의 클립보드 쓰기 요청을 이 PC 클립보드에 반영합니다. 읽기 요청은 항상 거부합니다"
6. **여러 줄 붙여넣기 확인** — "두 줄 이상 붙여넣을 때 실행 전에 확인합니다"
7. **운영 서버 위험 명령 확인** — "환경이 '운영'인 서버에서 아래 패턴(정규식)에 맞는 명령을 실행하거나 붙여넣으면 먼저 확인합니다"

그 아래: 필드 **위험 명령 패턴 (정규식, 한 줄에 하나)** — 7줄 여러 줄 입력. 입력을 줄 단위로 나눠 앞뒤 공백 제거·빈 줄 제거 후 목록으로 저장. 버튼 [기본값으로] → 기본 패턴 목록(data/store.md §4)으로 복원.

## 2a. 단축키
(2026-11-25, D126. 동작은 behavior/shortcuts.md §5.)
- 카드 토글 **단축키 사용**(기본 켜짐) — "끄면 아래 앱 단축키가 모두 동작하지 않고, 그 키는 터미널(서버)로 그대로 갑니다. vi·tmux 처럼 같은 키를 쓰는 프로그램과 겹칠 때 끕니다. 하나만 겹치면 그 단축키만 바꾸거나 지우세요" — 값은 `shortcutsEnabled`.
- 소제목 **앱 단축키** + 오른쪽에 작은 버튼 [모두 기본값으로](바꾼 것이 없으면 누를 수 없다). 아래 도움말 "키 칸을 누른 뒤 쓸 키를 누르세요. Esc 는 취소입니다. 다른 동작이 쓰던 키를 고르면 그 동작의 키는 비워집니다".
- 목록(테두리 상자, 한 줄에 명령 하나, behavior/shortcuts.md §5 의 34개·그 순서): **이름** · **키 칸**(지금 키, 없으면 흐린 "없음") · [키 지우기](× 아이콘, 키가 없으면 누를 수 없다) · [기본값으로](되돌리기 아이콘, 지금 키가 기본 키면 누를 수 없다, 툴팁에 기본 키).
  - 키 칸을 누르면 강조색 테두리의 "키를 누르세요…" 로 바뀌고 다음에 누른 조합을 받는다. Ctrl·Shift·Alt 만 누른 것은 기다린다. Esc·다른 곳 누르기·창이 포커스를 잃으면 취소(그동안의 Esc 는 설정 창을 닫지 않는다).
  - 고를 수 없는 조합이면 오류 토스트를 내고 계속 기다린다: "Ctrl 또는 Alt 와 함께 누르는 키나 F1~F12 만 쓸 수 있습니다" / "{키} 는 터미널의 복사·붙여넣기에 쓰는 키라 고를 수 없습니다".
  - 다른 명령이 쓰던 조합을 고르면 그대로 저장하고, 먼저 쓰던 명령은 "없음"이 되며 정보 토스트 '{키} 를 쓰던 "{이름}"의 단축키를 비웠습니다'.
  - "단축키 사용"이 꺼져 있으면 목록의 이름·키가 흐리게 보인다(바꾸는 것은 된다).
- 소제목 **터미널 안에서 쓰는 키** + 도움말 '바꿀 수 없고, "단축키 사용"을 꺼도 동작합니다. Ctrl+V 붙여넣기는 설정 > 입력에서 끌 수 있습니다' + 표 3줄: 붙여넣기 (이미지·파일 자동 업로드) Ctrl+V · 클립보드 이미지 → 서버 Ctrl+Alt+V · 복사 Ctrl+Shift+C / 선택.

## 2b. 출력 규칙
(2026-11-27, D140. 터미널 출력에 반응하는 규칙을 한곳에 둔다.)

위에서 아래로 **키워드 강조**(§1 끝에 적힌 항목 그대로)와 **출력 트리거** 두 항목.

- **출력 트리거**(동작은 behavior/terminal.md §10): 도움말 "터미널 출력의 한 줄에 이 글자가 나오면 알림·소리·자동 응답을 실행합니다. 열려 있는 모든 연결에 적용되고, 보이지 않는 탭의 출력도 살핍니다. 한 줄에서 규칙마다 한 번, 같은 규칙은 1초에 한 번만 실행합니다. vim 같은 전체 화면 프로그램 안에서와 직접 입력하는 줄에서는 실행하지 않습니다. 자동 응답은 그 글자가 나온 연결에 곧바로 입력되므로 조심해서 쓰세요. 운영 서버에는 보내지 않고(입력 > 운영 서버 위험 명령 확인이 켜져 있을 때), 10초에 5번 넘게 반복되면 그 연결에서는 꺼집니다."
  - 목록 위에 토글 한 줄 **"앱이 뒤에 있으면 Windows 알림도 띄우기"**(`triggerOsNotify`, 기본 켬, 누르는 즉시 저장), 설명 "알림을 켠 규칙이 맞았을 때 DariTerm 창이 앞에 있지 않으면 Windows 알림 센터에도 띄웁니다. 한 번에 맞은 줄은 알림 하나로 묶습니다." (2026-11-27, D145)
  - 목록 아래 도움말(D149): "특정 서버에서만 쓸 규칙은 서버 편집 > 자동화 탭의 "이 서버의 출력 트리거"에 넣습니다. 여기 규칙은 모든 연결에 씁니다."
  - 규칙마다 테두리 상자 하나, 두 줄.
    - 첫 줄: 사용 스위치 / "찾을 글자" 입력(고정폭, 틀린 정규식이면 빨간 테두리) / 체크 "정규식" / 체크 "대소문자 구분" / [삭제](휴지통).
    - 둘째 줄(스위치 폭만큼 들여 씀): 체크 "알림" / 체크 "소리" / 체크 "자동 응답". 자동 응답을 켜면 그 오른쪽에 "응답으로 입력할 글자" 입력(고정폭)과 체크 "Enter 붙이기"가 나타난다.
  - [+ 규칙 추가](30개면 비활성): 새 규칙은 빈 글자, 알림만 켜짐, 자동 응답 꺼짐(Enter 붙이기는 켜진 채), 사용 켜짐.
  - 스위치·체크·삭제·추가는 누르는 즉시 저장하고, 글자 칸은 벗어날 때 저장한다.

## 3. 이미지·파일 전송
- 안내 박스(이미지 아이콘): "SSH 터미널에서 **Ctrl+V**로 이미지(캡처)를 붙여넣거나 파일을 터미널로 끌어다 놓으면, 서버의 업로드 폴더로 전송한 뒤 그 **경로를 터미널에 입력**합니다. 서버에서 실행 중인 **Claude Code** 등 CLI는 이 경로로 이미지를 읽을 수 있습니다. 예: `이 화면의 오류 원인 알려줘` 입력 후 Ctrl+V."
- **서버 업로드 폴더**(고정폭 문자열, 도움말 "업로드 파일을 둘 서버 경로입니다. ~ 는 홈 디렉터리이며, 없으면 만듭니다.")
- **오래된 업로드 자동 삭제 (일)**(숫자, 0 이상, 도움말 "이 일수보다 오래된 업로드를 지웁니다. DariTerm이 올린 파일(dt- 접두어)만 대상이며, 0이면 끕니다.") — 이 앱이 올리는 파일 이름은 접두어 `dt-` 로 시작해야 하며 자동 삭제는 이 접두어 파일만 대상으로 한다(clean-room 선택, 원본의 접두어와 다름)
- 카드 토글 **공백이 있는 경로는 따옴표로 감싸기**
- 같은 카드의 토글 **ZMODEM 파일 전송 (sz · rz)**(2026-11-23, D114, 기본 켜짐) — "SSH·시리얼 터미널에서 sz 파일 을 실행하면 이 PC로 받고, rz 를 실행하면 고른 파일을 보냅니다. 경유 서버 뒤나 SFTP가 없는 장비에서 씁니다. 전송 중에는 Ctrl+C로 취소합니다."

## 6. 보안·계정
- 필드 **자동 잠금 (분)**(숫자, 0 이상, 비면 0). 도움말 "이 시간 동안 입력이 없거나 Windows 잠금·절전 시 앱을 잠급니다. 연결된 세션은 유지됩니다. 0이면 끕니다"
- **OS 잠금 해제** 카드 — 이 PC가 지원할 때만 표시. 토글 "Windows 로그인으로 열기", 설명 "앱 잠금 비밀번호 대신 현재 Windows 계정(DPAPI)으로 잠금을 해제합니다". 켜고 끌 때 볼트 상태를 새로 읽고, 실패하면 오류 토스트.
- 소제목 **앱 잠금 비밀번호 변경**: 3열 입력(플레이스홀더 "현재 비밀번호", "새 비밀번호", "새 비밀번호 확인") + [변경] 버튼 + 결과 문구. 검사: 새 비밀번호 8자 미만 "새 비밀번호는 8자 이상", 불일치 "새 비밀번호가 일치하지 않습니다". 성공 "변경했습니다"(세 칸을 비움), 현재 비밀번호 틀림 "현재 비밀번호가 틀립니다"(세 칸을 비움).
- 소제목 **저장된 계정 ({개수})**: 카드. 없으면 "저장된 계정이 없습니다". 행마다: 이름 + (사용자 이름이 있으면 흐린 `(사용자)`) + 알약("키" 또는 "비밀번호"), 아래 작은 글씨 "사용 중: {서버 표시 이름 최대 4개}" + 4개를 넘으면 " 외 {나머지}", 사용하는 서버가 없으면 "사용하는 서버 없음". 오른쪽 버튼 [이름](입력 대화상자 "계정 이름" → 비어 있지 않으면 항목 이름 변경) 과 [삭제](휴지통 아이콘).
  - 삭제 확인: 제목 "계정 삭제", 본문 `"{이름}" 계정을 삭제할까요?` + (사용 서버가 있으면 ` {n}개 서버가 연결할 때 비밀번호를 다시 묻게 됩니다.`), 확인 "삭제", 위험. 삭제하면 그 계정을 쓰던 서버의 계정 연결을 모두 끊는다.
