## 1. 모양
- **언어**(맨 위, 목록 선택, D75): 도움말 "화면과 안내 문구의 언어입니다. 바꾸면 바로 적용됩니다." 목록은 behavior/i18n.md §1 의 10개(그 언어로 쓴 이름). 지금 화면 언어가 골라져 있다.
- **앱 테마**(세그먼트 다크/라이트). 바꾸면 터미널 테마도 짝에 맞춰 바뀐다: 라이트로 바꿀 때 현재 터미널 테마가 `DariTerm Dark` 이면 `DariTerm Light` 로, 다크로 바꿀 때 `DariTerm Light` 이면 `DariTerm Dark` 로. 다른 테마를 쓰고 있으면 그대로 둔다.
- **터미널 색 테마**: 3열 격자. 테마 카드마다 그 테마의 배경색·글자색으로 칠하고, 이름 아래에 샘플 한 줄 `user@host:~$ ls err`(user@host=초록, ~=파랑, ls=노랑, err=빨강, 현재 설정 글꼴 12px). 선택된 카드는 강조색 테두리(2px), 아니면 기본 테두리. 누르면 선택. 테마 목록과 색은 ui/tokens.md.
- 3열: **글꼴**(도움말 "설치된 고정폭 글꼴 이름 (예: D2Coding, Cascadia Mono)", 문자열) / **글자 크기**(숫자. **8~32 로 제한**: 범위를 벗어나면 가까운 경계값으로 — 예 100 → 32, 3 → 8 — 그리고 **비어 있거나 숫자가 아니면 14**) / **줄 간격**(숫자, 입력 단계 0.05·힌트 1~2, **값을 강제로 자르지는 않고** 비어 있거나 숫자가 아니면 1.15).
- 2열 격자:
  - 토글 **창 크기·위치 기억**(설명 "다음 실행 때 마지막 크기·위치·최대화 상태로 엽니다. 모니터 구성이 바뀌어 화면 밖이면 가운데로 엽니다")
  - 필드 **창 크기**: 버튼 [기본 크기로] → 창을 기본 크기로 되돌림
  - **커서 모양**(세그먼트 블록/막대/밑줄)
  - **스크롤백 (줄)**(숫자, 500~200000으로 제한, 비면 10000)
  - **최대 화면 분할 (상하)**(세그먼트 1·2·3·4·5, 기본 3, 도움말 "한 탭에서 위아래로 나눌 수 있는 최대 창 수입니다. 도달하면 [아래로 나누기] 버튼이 비활성화됩니다.") — 2026-11-12 추가, ui/panes.md §2
- 카드: 토글 **커서 깜빡임**, 토글 **벨 소리**.

## 2. 입력·붙여넣기
카드 안 토글(설명 포함):
1. **선택하면 자동 복사** — "드래그로 선택하면 즉시 클립보드에 복사합니다 (PuTTY 방식)"
2. **오른쪽 클릭으로 붙여넣기** — "끄면 오른쪽 클릭에 메뉴가 뜹니다. 켜져 있어도 Shift+오른쪽 클릭은 메뉴입니다"
3. **Ctrl+V로 붙여넣기** (Windows 에서만 표시) — "끄면 Ctrl+V 는 그대로 서버로 보내고, 붙여넣기는 Ctrl+Shift+V 로 합니다"
4. **Shift+Enter 로 줄바꿈** — "실행하지 않고 줄만 바꿉니다. Claude Code 같은 CLI의 여러 줄 입력용입니다 (Alt+Enter 와 같은 값 전송)"
5. **원격 복사 허용 (OSC 52)** — "서버 쪽 tmux·vim·Claude Code 등의 클립보드 쓰기 요청을 이 PC 클립보드에 반영합니다. 읽기 요청은 항상 거부합니다"
6. **여러 줄 붙여넣기 확인** — "두 줄 이상 붙여넣을 때 실행 전에 확인합니다"
7. **운영 서버 위험 명령 확인** — "환경이 '운영'인 서버에서 아래 패턴(정규식)에 맞는 명령을 실행하거나 붙여넣으면 먼저 확인합니다"

그 아래: 필드 **위험 명령 패턴 (정규식, 한 줄에 하나)** — 7줄 여러 줄 입력. 입력을 줄 단위로 나눠 앞뒤 공백 제거·빈 줄 제거 후 목록으로 저장. 버튼 [기본값으로] → 기본 패턴 목록(data/store.md §4)으로 복원.

## 3. 이미지·파일 전송
- 안내 박스(이미지 아이콘): "SSH 터미널에서 **Ctrl+V**로 이미지(캡처)를 붙여넣거나 파일을 터미널로 끌어다 놓으면, 서버의 업로드 폴더로 전송한 뒤 그 **경로를 터미널에 입력**합니다. 서버에서 실행 중인 **Claude Code** 등 CLI는 이 경로로 이미지를 읽을 수 있습니다. 예: `이 화면의 오류 원인 알려줘` 입력 후 Ctrl+V."
- **서버 업로드 폴더**(고정폭 문자열, 도움말 "업로드 파일을 둘 서버 경로입니다. ~ 는 홈 디렉터리이며, 없으면 만듭니다.")
- **오래된 업로드 자동 삭제 (일)**(숫자, 0 이상, 도움말 "이 일수보다 오래된 업로드를 지웁니다. DariTerm이 올린 파일(dt- 접두어)만 대상이며, 0이면 끕니다.") — 이 앱이 올리는 파일 이름은 접두어 `dt-` 로 시작해야 하며 자동 삭제는 이 접두어 파일만 대상으로 한다(clean-room 선택, 원본의 접두어와 다름)
- 카드 토글 **공백이 있는 경로는 따옴표로 감싸기**

## 4. 연결
- 카드 토글:
  1. **끊기면 자동 재접속** — "연결이 끊기면 2·4·8·16·30초로 간격을 늘리며 최대 5번 재연결합니다"
  2. **탭·분할 레이아웃 복원** — "종료할 때 열린 탭과 창 배치를 저장하고, 다음 실행 때 같은 서버로 다시 연결합니다. 비밀번호·화면 내용은 저장하지 않으며, 목록에 없는 일회성 SSH 연결은 복원하지 않습니다"
  3. **세션 로그 저장** — "터미널 출력을 텍스트 파일로 남깁니다 (켠 뒤 새로 여는 연결부터)"
- 버튼 [로그 폴더 열기](폴더 아이콘) → 로그 폴더를 탐색기로 연다.

## 6. 보안·계정
- 필드 **자동 잠금 (분)**(숫자, 0 이상, 비면 0). 도움말 "이 시간 동안 입력이 없거나 Windows 잠금·절전 시 앱을 잠급니다. 연결된 세션은 유지됩니다. 0이면 끕니다"
- **OS 잠금 해제** 카드 — 이 PC가 지원할 때만 표시. 토글 "Windows 로그인으로 열기", 설명 "앱 잠금 비밀번호 대신 현재 Windows 계정(DPAPI)으로 잠금을 해제합니다". 켜고 끌 때 볼트 상태를 새로 읽고, 실패하면 오류 토스트.
- 소제목 **앱 잠금 비밀번호 변경**: 3열 입력(플레이스홀더 "현재 비밀번호", "새 비밀번호", "새 비밀번호 확인") + [변경] 버튼 + 결과 문구. 검사: 새 비밀번호 8자 미만 "새 비밀번호는 8자 이상", 불일치 "새 비밀번호가 일치하지 않습니다". 성공 "변경했습니다"(세 칸을 비움), 현재 비밀번호 틀림 "현재 비밀번호가 틀립니다"(세 칸을 비움).
- 소제목 **저장된 계정 ({개수})**: 카드. 없으면 "저장된 계정이 없습니다". 행마다: 이름 + (사용자 이름이 있으면 흐린 `(사용자)`) + 알약("키" 또는 "비밀번호"), 아래 작은 글씨 "사용 중: {서버 표시 이름 최대 4개}" + 4개를 넘으면 " 외 {나머지}", 사용하는 서버가 없으면 "사용하는 서버 없음". 오른쪽 버튼 [이름](입력 대화상자 "계정 이름" → 비어 있지 않으면 항목 이름 변경) 과 [삭제](휴지통 아이콘).
  - 삭제 확인: 제목 "계정 삭제", 본문 `"{이름}" 계정을 삭제할까요?` + (사용 서버가 있으면 ` {n}개 서버가 연결할 때 비밀번호를 다시 묻게 됩니다.`), 확인 "삭제", 위험. 삭제하면 그 계정을 쓰던 서버의 계정 연결을 모두 끊는다.

## 7. 백업
- 안내 박스: "백업 파일 하나에 서버 목록·설정·명령 모음과 **암호화된** 계정 정보가 담깁니다. 다른 PC에서 가져온 뒤 같은 앱 잠금 비밀번호로 엽니다."
- 버튼 [백업 내보내기](주 버튼): 저장 위치를 고르는 대화상자 후 저장. 성공하면 토스트 "백업 저장: {경로}"(취소하면 없음), 실패하면 오류 토스트.
- 버튼 [백업 가져오기]: 확인 대화상자(제목 "백업 가져오기", 본문 "현재 서버 목록과 계정 정보가 백업 파일 내용으로 바뀝니다. 계속할까요?", 확인 "가져오기", 위험) → 파일 선택 → 성공하면 저장 데이터·볼트 상태를 새로 읽고 토스트 "백업을 가져왔습니다. 백업한 PC의 앱 잠금 비밀번호로 잠금을 해제하세요." 실패하면 오류 토스트.
