# 서버 편집 / 폴더 편집 대화상자

> 작성 방식: 기존 앱 실행 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**. 데이터 필드는 data/store.md, 볼트 저장은 data/vault.md.

## 1. 서버 편집 (기본 크기 모달)

- 제목: 새 서버면 "서버 추가", 편집이면 "서버 편집 · {표시 이름}".
- 바닥(왼쪽에 오류 메시지가 있으면 빨간 글씨로, 오른쪽에 버튼): [취소] [저장] [저장하고 연결](주 버튼).
- 본문 위에 **탭 막대**: 기본 · 인증 · 고급 · 포트 포워딩. **프로토콜이 SSH 가 아니면 "로그인"과 "포트 포워딩" 탭은 숨긴다.** 본문 최소 높이 380px.
- 열릴 때: 새 서버는 기본값으로 초기화(데이터 명세 §3; 폴더는 호출한 곳이 지정한 폴더 또는 최상위), 편집은 원본을 복사해 편집한다. 편집 중 변경은 [저장]을 눌러야 반영된다.

### 1.1 "일반" 탭 (위→아래)

1. **프로토콜** (세그먼트): SSH / Telnet / 시리얼 (COM/RS-485) / 로컬 (이 PC). 전환 규칙:
   - Telnet 으로 바꿀 때 포트가 22 이면 23 으로, SSH 로 바꿀 때 포트가 23 이면 22 로
   - 시리얼로 바꾸면 시리얼 옵션이 없을 때 기본값(§1.6)을 채우고, 환경이 비어 있거나 `none` 이면 `device`(장비)로
   - 로컬이 아닌 것으로 바꿀 때 포트가 0 이면 Telnet 23 / 그 외 22
2. **별칭 (탭·목록에 표시될 이름)** — 플레이스홀더 "예: 운영-WEB01". 열릴 때 포커스.
3. 프로토콜별 영역:
   - **로컬**: 2열 — "시작 폴더"(고정폭 입력 + [폴더 선택] 버튼(아이콘, 툴팁 "폴더 선택"), 도움말 "비워 두면 홈 폴더에서 열립니다", 플레이스홀더 `C:\Work\프로젝트`) / "셸"(드롭다운: 첫 항목 "기본 ({기본 셸 이름})" = 값 없음, 이어서 이 PC에서 찾은 셸 목록)
   - **SSH / Telnet**: 3열 — "주소 (IP 또는 도메인)"(플레이스홀더 "10.0.0.11  또는  user@host:22") / "포트"(숫자) / "사용자 이름"(플레이스홀더 "root"). **호스트 칸에 `사용자@호스트[:포트]` 를 입력하면 자동으로 사용자·호스트·포트 칸으로 나눠 채운다.**
   - **시리얼**: 2열 — "포트"(장치 경로 입력 + 이 PC의 장치 목록 자동완성(항목에 설명 라벨), 라벨 옆 [새로고침] 링크, 플레이스홀더 "COM3") / "속도 (baud)"(드롭다운 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600). 2열 — "데이터 / 패리티 / 정지 비트"(드롭다운 3개: 8·7·6·5 / none·even·odd·mark·space / 1·1.5·2), "흐름 제어 / Enter 전송값"(드롭다운 2개: 없음·RTS/CTS·XON/XOFF / CR·LF·CRLF). 토글 "입력 글자 표시 (로컬 에코)"(설명 "장비가 입력한 글자를 돌려주지 않을 때 켜세요"). 프로토콜을 시리얼로 고르면 장치 목록을 조회한다.
4. 2열 — "폴더"(드롭다운: "(최상위)" + 모든 폴더를 `상위 / 하위` 경로 형식으로 이름순 정렬) / "태그 (쉼표로 구분)"(쉼표로 나눠 공백 제거·빈 항목 제거, 플레이스홀더 "web, nginx").
5. **환경**(세그먼트: 일반·개발·기능테스트·성능테스트·운영·장비, 각 옵션 앞에 해당 색 점; 순서는 none, dev, stage, perf, prod, device). 도움말 "운영 서버는 빨간 테두리로 표시되고 위험 명령 실행 전에 확인을 받습니다".
6. **색상 (지정하지 않으면 환경/폴더 색을 따름)** — 색 선택(데이터 명세 §6).
7. **메모** — 2줄 여러 줄 입력.

### 1.2 "로그인" 탭 (SSH 만)
- 볼트가 잠겨 있으면 맨 위 경고 박스(자물쇠 아이콘) "보관함이 잠겨 있습니다. 비밀번호나 키를 저장하려면 먼저 잠금을 해제하세요."
- **인증 방식**(세그먼트): 비밀번호 / 개인 키(열쇠 아이콘) / SSH 에이전트 (Pageant) / 매번 묻기
- 인증 방식이 비밀번호·개인 키일 때 **계정 저장 방식**(세그먼트): "이 서버에만 저장" / "저장된 계정 사용".
  - **공유 계정 선택**: 드롭다운 "저장된 계정"(첫 항목 "선택하세요", 항목은 `이름 (사용자) · 키|비밀번호`), 도움말 "같은 계정을 쓰는 서버 여러 대가 하나의 비밀번호를 공유합니다. 비밀번호를 바꾸면 모두 적용됩니다."
  - 편집으로 열 때 이 서버가 쓰는 계정이 있고 **계정 이름이 이 서버 별칭과 다르며 같은 계정을 쓰는 서버가 2개 이상**이면 처음부터 "저장된 계정 사용"으로 시작한다.
  - **이 서버 전용 + 비밀번호**: 입력창 "비밀번호"(가려짐). 저장된 계정이 있으면 플레이스홀더 "••••••••  (저장됨)" 과 도움말 "저장된 비밀번호가 있습니다. 바꾸려면 새로 입력하세요.", 없으면 플레이스홀더 "비밀번호" 와 도움말 "비워 두면 처음 연결할 때 묻고, 저장 여부를 선택할 수 있습니다."
  - **이 서버 전용 + 개인 키**: [키 파일 선택] 버튼 + 선택한 경로(없으면 저장된 키가 있을 때 "저장된 키 사용 중", 아니면 "선택된 키 없음") / "또는 키 내용 붙여넣기"(4줄 입력, 플레이스홀더 `-----BEGIN OPENSSH PRIVATE KEY-----`) / "키 암호 (있으면)". 도움말 "OpenSSH(id_ed25519, id_rsa), PEM, PuTTY PPK v2 지원. 키 내용은 보관함에 암호화되어 저장됩니다." 불러온 키 내용이 PuTTY PPK **v3** 이면 오류 메시지 "PPK v3 키는 PuTTYgen → Conversions → Export OpenSSH key 로 변환해 주세요".
  - **SSH 에이전트**: 안내 박스 "Windows에서는 Pageant, 그 외에는 SSH_AUTH_SOCK 에이전트를 사용합니다. 에이전트 인증이 실패하면 비밀번호를 묻습니다."
  - **매번 묻기**: 안내 박스 "연결할 때마다 비밀번호를 묻습니다. 입력 창에서 "저장"을 선택하면 다음부터 자동으로 로그인됩니다."

### 1.3 "고급" 탭
1. **점프 호스트 (배스천 경유)** — SSH 만. 드롭다운: "없음" / "직접 입력…" / (자기 자신 제외 다른 SSH 서버들 `표시 이름 (주소)`). 도움말 "이 서버에 연결하기 전에 먼저 거쳐 갈 서버입니다 (ProxyJump)."
2. **직접 입력**을 고르면 카드가 나타난다: 
   - "경유 서버 주소"(고정폭, 플레이스홀더 `ec2-user@203.0.113.10:22`, 도움말 "user@host:port 형식으로 넣으면 사용자·호스트·포트로 나뉩니다"): `[사용자@]호스트[:포트]`(IPv6 는 대괄호) 형식이면 칸을 나눠 채우고(사용자나 포트가 있을 때만), 아니면 입력을 그대로 호스트로 둔다.
   - "포트"(비우면 22), "사용자", "인증 방식"(비밀번호 / 개인 키)
   - 비밀번호: 입력창, 저장된 것이 있으면 도움말 "저장됨 — 바꾸려면 새로 입력"과 플레이스홀더 "••••••••  (저장됨)", 없으면 도움말 `보관함에 암호화해 저장 ("{표시 이름} 경유 서버")`
   - 개인 키: [키 파일 선택] 버튼 + 상태 문구("키를 불러왔습니다" / "저장됨"), "키 암호 (있으면)"
3. **세션 유지 (tmux)** 카드 — 표시 조건: SSH, 또는 로컬이면서 (Windows 가 아니거나 선택한 셸이 WSL 인 경우). 제목 "연결 유지 (tmux)", 설명 "창이나 앱을 닫아도 tmux 안의 프로그램은 계속 실행되고, 다시 열면 그 화면에 그대로 붙습니다. " + (로컬이고 Windows 면 "Windows 로컬은 WSL 셸일 때만 지원합니다." 아니면 "대상에 tmux 가 있어야 합니다."), 오른쪽 스위치. **새 로컬 터미널을 만들 때 tmux 가 있으면 이 스위치를 기본으로 켠다**(값이 아직 정해지지 않았을 때만).
   - 스위치가 켜져 있으면 필드 "tmux 세션 이름"(고정폭, 도움말 "비워 두면 서버 표시 이름(또는 로컬 폴더 이름)으로 만듭니다", 플레이스홀더 별칭 또는 "termgo").
4. **접속 후 자동 실행 명령**(로컬이면 "시작할 때 실행할 명령") — 고정폭 입력. 도움말 로컬 "예: claude --continue", 그 외 "예: cd /var/www && sudo -i"(플레이스홀더도 같음). 세션 유지가 켜져 있으면 줄바꿈 후 "세션을 처음 만들 때만 실행됩니다 (이미 있는 세션에 다시 붙을 때는 실행되지 않음)".
5. 로컬: "터미널 종류" 한 칸. 그 외: 3열 — "문자 인코딩"(옵션 4개: "UTF-8"(utf-8), "CP949 / EUC-KR (구형 장비)"(cp949), "Shift_JIS"(shift_jis), "Latin-1"(latin1). 저장 데이터에 `euc-kr` 값이 있어도 읽을 수 있어야 한다) / "터미널 종류" / "연결 확인 간격 (초)"(숫자, 비면 0).

### 1.4 "포트 포워딩" 탭 (SSH 만)
- 안내 박스: "L: 내 PC의 포트 → 서버에서 접근 가능한 주소 (예: 로컬 3307 → DB 3306). R: 서버의 포트 → 내 PC 쪽 주소."
- 표: 머리 종류 · 바인드 주소 · 포트 · 대상 호스트 · 대상 포트 · (삭제). 행마다 종류 드롭다운(L/R), 바인드 주소(고정폭), 포트(숫자), 대상 호스트(고정폭), 대상 포트(숫자), [삭제](휴지통 아이콘).
- [포워딩 추가] 버튼: 새 행 기본값 종류 L, 바인드 주소 `127.0.0.1`, 포트 8080, 대상 호스트 `localhost`, 대상 포트 80.

### 1.5 저장 동작 (검사·정규화·볼트 저장)

1. 오류 메시지를 지운다.
2. **별칭 보정**: 별칭이 비면 시리얼은 장치 경로(없으면 "Serial"), 로컬은 시작 폴더의 마지막 폴더 이름(없으면 "로컬 터미널"), 그 외는 호스트 주소를 쓴다. 호스트·사용자 이름은 앞뒤 공백 제거.
3. **로컬 정규화**: 호스트 빈 값, 포트 0, 사용자 빈 값, 인증 `ask`, 계정 없음, 경유 서버 없음, 포워딩 없음, 인코딩 `utf-8`, 로컬 옵션은 셸·시작 폴더(공백 제거, 비면 지정 안 함)만 남긴다.
4. **검사**(실패하면 해당 탭으로 이동하고 오류 메시지): SSH/Telnet 인데 호스트가 비면 "호스트 주소를 입력하세요"(기본 탭). 시리얼인데 포트 경로가 비면 "시리얼 포트를 선택하세요"(기본 탭).
5. **계정 저장**(이 서버 전용 + 비밀번호 입력 또는 키 내용 있음): 볼트가 잠겨 있으면 오류 "보관함이 잠겨 있어 비밀번호를 저장할 수 없습니다". 아니면 볼트에 항목을 저장한다. 항목 이름=서버 별칭, 종류=키/비밀번호, 사용자 이름=서버 사용자. **기존 계정을 이 서버만 쓰고 있으면 같은 항목을 갱신, 다른 서버와 공유 중이면 새 항목을 만든다.** 서버의 계정 연결을 저장된 항목으로 바꾼다. 저장 후 계정 목록을 새로 읽는다.
6. 인증 방식이 `ask` 또는 `agent` 이고 "이 서버 전용"이면: `ask` 는 계정 연결을 끊고, `agent` 는 기존 연결을 유지한다.
7. **점프 호스트 직접 입력**(SSH): 주소가 비면 "고급" 탭으로 이동하고 오류 "경유 서버 주소를 입력하세요". 베스천 비밀/키가 입력되었으면: 볼트가 잠겨 있으면 오류 "보관함이 잠겨 있어 경유 서버 자격 증명을 저장할 수 없습니다". 아니면 **대상 서버 계정과 별개 항목**으로 저장(이름 `{표시 이름} 경유 서버`; 이미 베스천 계정이 있으면 갱신). 직접 입력이 아니면 직접 입력 정보를 지운다.
8. 저장 성공: 서버를 목록에 반영(새로 만들었으면 추가, 아니면 교체), 대화상자 닫기. **[저장하고 연결]이면 닫은 뒤 새 탭으로 연결**. 어느 단계든 예외가 나면 오류 메시지를 표시하고 닫지 않는다.

### 1.5.1 시리얼·로컬 서버의 저장 값 보충
- **시리얼**: 장치 경로는 `serial.path` 에 둔다. `host` 는 화면에서 만든 서버는 빈 문자열, 가져오기로 만든 서버는 장치 경로와 같은 값이며 **어느 쪽이든 동작에 영향이 없다**(목록 부제와 대상 문자열은 `serial.path` 를 쓴다). `authType` 과 계정 연결은 시리얼에서 쓰이지 않으므로 값은 무관하다(새 서버 기본값 `password` 를 그대로 둬도, `ask` 로 둬도 된다). 시리얼·텔넷에서는 포트 포워딩 데이터를 비운다.
- **세션 유지 카드의 "Windows 인지" 판정**: 백엔드의 `app.info` 가 돌려주는 `platform` 값을 쓰는 것이 원칙이다(조회 전·알 수 없을 때는 Windows 로 가정). 브라우저 사용자 에이전트 문자열로 대신해도 결과가 같으면 허용.
- **인코딩 목록**: 저장 데이터에 `euc-kr` 값이 있으면 목록에 "CP949 / EUC-KR (구형 장비)" 항목이 이미 있으므로 그 항목으로 보여 주고 값은 보존한다.

### 1.6 시리얼 기본값
포트 `COM1`, 속도 9600, 데이터 비트 8, 패리티 none, 정지 비트 1, 흐름 제어 없음, Enter 전송값 CR, 로컬 에코 꺼짐.

## 2. 폴더 편집 (작은 모달)

- 제목: 새 폴더면 "새 폴더", 편집이면 "폴더 수정".
- 필드: "이름"(플레이스홀더 "예: 헤펠레코리아", 열릴 때 포커스, Enter=저장), "상위 폴더"(드롭다운: "(최상위)" + 자기 자신을 뺀 모든 폴더 경로), "환경"(도움말 "폴더 안의 서버가 이 환경 색을 물려받습니다", 세그먼트는 서버 편집과 같음), "색상"(색 선택).
- 새 폴더 기본값: 상위=호출한 곳이 지정한 폴더 또는 최상위, 환경 `none`, 정렬 키=현재 폴더 수.
- 버튼 [취소] [저장]. **이름이 비어 있으면 [저장] 비활성** 및 Enter 무시. 저장 시 이름의 앞뒤 공백을 제거.
- 상위 폴더 선택 목록이 자기 하위 폴더를 걸러 주지는 않는다(사이드바 끌어 놓기에서만 순환을 막는다 — 알려진 한계).
