# 대화상자와 공통 요소

> 작성 방식: 기존 앱 관찰 + 열람. 작성일 2026-11-10. 상태: **draft** — 이번 라운드 범위: 공통 모달/메뉴, 빠른 접속, 위치 선택, 인증 요청, 가져오기, 동기화 패널. **서버 편집·폴더 편집 대화상자는 다음 라운드**(미작성).

## 1. 공통 모달

- 어두운 오버레이 위 가운데 카드. 크기 3종: 작게(sm), 기본, 크게(lg).
- 머리: (선택 아이콘) 제목, 오른쪽 닫기(X) 버튼. 바닥: 선택적으로 버튼 줄.
- **Esc** 로 닫는다(다른 처리보다 먼저 가로채며 아래로 전달하지 않음). 모달이 겹쳐 있으면 **맨 위 겹만** 닫는다 — 다음 Esc 가 그 아래 모달을 닫는다(2026-11-27 D159). 겹친 순서는 연 순서이고, 다시 그려져도 바뀌지 않는다. 카드에 크기·클래스를 따로 줄 수 있다(도움말 창의 크기 조절). **오버레이(카드 바깥) 클릭**으로도 닫는다. 카드 안 클릭은 닫지 않는다.
- 닫히면 포커스를 터미널로 되돌린다.

### 1.1 확인 대화상자
- 작은 크기. 제목, 본문(줄 간격 넉넉히), 선택적 상세(고정폭 박스), 버튼 [취소] [확인 문구, 기본 "확인"].
- **위험한 확인**이면 확인 버튼이 위험색이고 초기 포커스가 [취소]에 있다(Enter 를 실수로 쳐도 실행되지 않게). 아니면 초기 포커스가 확인 버튼.
- 결과는 예/아니오(Esc·X·바깥 클릭=아니오).

### 1.2 입력 대화상자
- 작은 크기. 제목, (선택 라벨) 한 줄 입력창, 버튼 [취소] [확인]. 열리면 입력창에 포커스하고 **전체 선택**. Enter=확인. 취소·Esc=취소(결과 없음). 빈 문자열 확인은 빈 문자열로 전달.

### 1.3 컨텍스트 메뉴
- 마우스 위치에 뜬다. 화면 오른쪽·아래로 넘치면 화면 안쪽(가장자리에서 8px)으로 당긴다.
- 항목: 라벨, (선택) 오른쪽 단축키 표기, 위험색 항목, 비활성 항목, 구분선.
- 닫힘: 메뉴 밖 마우스 누름, 창 포커스 잃음, Esc, 항목 선택. 항목을 고르면 먼저 닫고 동작 실행.

### 1.4 공통 입력 요소
- **필드**: 라벨(선택) + 입력 + 도움말(선택, 작은 글씨).
- **스위치**: 켜짐/꺼짐 토글 버튼. **토글 행**: 왼쪽에 라벨과 작은 설명, 오른쪽에 스위치.
- **세그먼트**: 여러 옵션 중 하나를 고르는 붙은 버튼 줄(선택된 것이 강조).
- **색 선택**: 데이터 명세 §6 팔레트. 맨 앞 "자동(환경/폴더 색)" 항목.

### 1.5 표시 형식
- 바이트: 1024 미만 `n B`, 1MB 미만 `x.x KB`, 1GB 미만 `x.x MB`, 그 이상 `x.xx GB`.
- 날짜(SFTP 등): 올해이면 `MM-DD HH:mm`, 아니면 `YYYY-MM-DD`, 값이 0 이면 빈 칸.

## 2. 빠른 접속 (팔레트)

가운데 위쪽에 뜨는 검색 팔레트. 입력창(번개 아이콘, 플레이스홀더 "서버 이름·IP·user@host:port 를 입력 (> 로 명령)"), 결과 목록, 바닥 안내줄.

### 2.1 입력에 따른 결과

**(a) `>` 로 시작 — 명령 모드.** `>` 뒤 글자로 아래 명령 중 **이름에 그 글자가 포함된** 것만 보여 준다(대소문자 무시). 명령 목록(순서):
1. 새 로컬 터미널 — 새 탭(Shift+Enter 로 실행하면 아래 분할, Ctrl+Enter 면 오른쪽 분할)
2. 새 서버 등록 — 서버 편집 대화상자(최상위)
3. 새 폴더 — 폴더 편집 대화상자(최상위)
4. PuTTY / SSH config 가져오기 — 가져오기 대화상자
5. 설정 열기
6. 테마 전환 (현재가 다크면 "라이트", 라이트면 "다크"를 괄호에 표시) — 앱 테마와 터미널 테마를 함께 바꾼다(다크↔`DariTerm Dark`/라이트↔`DariTerm Light`)
7. 매크로 녹화 시작 / 매크로 녹화 정지 (녹화 중이면 "정지") — behavior/terminal.md §11 (2026-11-27, D141)
8. 앱 잠그기

("모든 탭을 그리드로 모으기" 명령은 2026-11-23 에 없앴다 — D116, ui/panes.md §6.)

**(b) 직접 접속 주소처럼 보이는 입력**: `[ssh://|telnet://][사용자@]호스트[:포트]` 형식이면서 `@`가 있거나, IPv4 모양이거나, 점(.)이 있거나, `ssh`/`telnet`으로 시작할 때, 목록 맨 위에 "바로 연결: {입력}" 항목(부제 "저장하지 않고 한 번만 연결")을 둔다. 프로토콜 기본값은 ssh, 포트 생략 시 기본 포트.

**(c) 로컬 터미널 항목**: 입력이 "로컬", "local", "터미널", "term", "shell", "셸" 로 **시작**하면 목록 위쪽(직접 접속 항목 다음)에 "새 로컬 터미널"(부제 "이 PC의 셸 · Ctrl+Alt+T")을 둔다. **입력이 비어 있으면 목록 맨 아래**에 둔다(Ctrl+K → Enter 의 기본 동작이 첫 서버가 되도록).

**(d) 저장된 서버 검색**: 입력을 공백으로 나눈 낱말마다 다음 우선순위로 점수를 더하고, **어느 한 낱말이라도 맞지 않으면 제외**한다. 우선순위(높음→낮음): 이름이 낱말로 시작 > 이름에 포함 > 주소에 포함 > 폴더 이름·태그에 포함 > 사용자명에 포함 > 이름에 글자가 순서대로 흩어져 포함(퍼지). 입력이 비면 모든 서버가 같은 점수. 정렬: 점수 내림차순 → 최근 사용 시각 내림차순 → 이름 오름차순. **최대 50개**.
- 서버 항목 표시: 프로토콜 아이콘, 색 막대(서버/폴더/환경 색), 굵은 이름, 부제 = 대상 문자열(ssh/telnet 이고 기본 22가 아닌 포트면 `:포트` 덧붙임) + (폴더가 있으면 ` · 폴더이름`).

결과가 없으면 "일치하는 서버가 없습니다. **user@host** 형식으로 입력하면 바로 연결할 수 있습니다."

### 2.2 조작
- ↑/↓: 선택 이동(끝에서 멈춤, 선택 항목이 보이도록 스크롤). 마우스를 올려도 선택이 따라간다. 입력이 바뀌면 선택은 맨 위로.
- **Enter: 새 탭에서 열기 / Ctrl+Enter: 오른쪽 분할 / Shift+Enter: 아래 분할.** 항목을 마우스로 클릭할 때도 같은 보조키 규칙.
  - 화면이 나뉘어 있을 때 어느 그룹에 여는가: 탭 막대의 + 버튼으로 띄웠으면 **그 버튼이 속한 그룹**(새 탭은 그 그룹에, 나누기는 그 그룹에서 선택된 탭의 포커스 칸), 그 밖(단축키·시작 화면 버튼)에는 포커스 그룹 (ui/shell.md §2.3, D119). 명령 모드의 "새 로컬 터미널"도 같다.
- Esc 또는 바깥 클릭: 닫기. 실행하면 대부분 닫힌다(새 서버 등록·새 폴더·가져오기·설정은 다른 대화상자로 바뀜).
- 선택된 항목 오른쪽에 `Enter` 키 표시.
- 바닥 안내줄: `Enter 새 탭` · `Ctrl+Enter 오른쪽 나누기` · `Shift+Enter 아래 나누기` · `> 명령`

## 3. 위치 골라서 연결 (위치 선택)

> **2026-11-23 삭제 (D117)**: 이 대화상자와 서버 우클릭 메뉴의 "열 위치 선택…" 항목을 **없앴다.** 이 화면은 열린 탭의 아무 창이나 상·하·좌·우로 나눠 열 수 있었는데, 탭의 창 수 한도(ui/panes.md §2.1 6번, 설정 `maxVerticalSplits`)를 보지 않았다 — 바둑판 배열(D116)과 같은 문제다. 아래 설명은 기록으로만 남긴다. **구현하지 않는다.** 서버를 여는 위치는 우클릭 메뉴의 "새 탭으로 열기"·"오른쪽 화면에 열기"·"아래 창으로 열기"로 고른다(셋 다 한도를 지킨다).

서버 우클릭 메뉴의 "열 위치 선택…"에서 열린다. 크게 보기. 제목 "위치 골라서 연결 — {서버 이름}".
- 위쪽 버튼 [새 탭으로 열기]
- 열린 탭이 없으면 "열린 탭이 없습니다. 새 탭으로 여세요."
- 열린 탭마다 **축소 그림**: 탭 제목(없으면 첫 칸 세션 제목, 없으면 "탭 N") 아래에 그 탭의 분할 구조를 비율대로 그린다.
  - 세션이 있는 칸: 세션 제목 + 위/아래/왼쪽/오른쪽 방향 화살표 버튼(툴팁 "이 방향으로 나눠 열기"). 화살표를 누르면 그 칸을 그 방향으로 쪼개 새 세션을 연다.
  - 빈 칸: "여기에" 버튼(툴팁 "이 빈 창에서 열기") — 그 칸에 새 세션을 채운다.
- 어느 쪽이든 선택하면 대화상자가 닫히고 연결을 시작한다.

## 4. 인증·확인 요청 (연결 중 백엔드가 요청)

요청은 **순서대로 한 번에 하나씩** 보인다(큐). 응답하면 다음 요청이 나온다. 응답 후 포커스는 터미널로. 닫기(X/Esc/바깥)는 "취소"로 처리한다(호스트 키 요청은 거부, 나머지는 입력 없음).

### 4.1 호스트 키
- **처음 접속하는 서버**: 제목 "처음 연결하는 서버입니다"(질문 방패 아이콘, 강조색). 본문 "[세션 제목] **host:port** 서버의 신원을 아직 확인하지 않았습니다. 아래 지문이 서버 관리자가 알려준 값과 같은지 확인하세요." 필드 라벨 "{키 종류} 키 지문" + 지문 값(고정폭). 버튼 [연결 취소] [믿고 연결](주 버튼, 초기 포커스).
- **키가 바뀜**: 제목 "경고: 서버의 호스트 키가 바뀌었습니다"(경고 방패 아이콘, 위험색). 위험 안내 박스 "[세션 제목] host:port의 호스트 키가 이전에 저장한 키와 다릅니다. 서버를 재설치했거나 IP가 바뀐 경우가 아니라면 **중간자 공격**일 수 있습니다. 확실하지 않으면 연결하지 마세요." 지문 필드 + 이전 지문 필드("이전에 저장된 지문", 흐리게). 버튼 [연결 취소] [위험을 알고 새 키로 연결](위험색, 초기 포커스 없음).
- 결과: 신뢰=예/아니오.

### 4.2 비밀번호 / 키 암호 / 사용자 이름 (작게)
- 제목: 비밀번호 입력 / 개인 키 암호 입력 / 사용자 이름 입력. 아이콘: 사용자 이름은 사람, 나머지는 열쇠.
- 본문: 세션 제목(흐리게), (비밀번호이고 직전 시도가 실패했으면 오류 "비밀번호가 틀렸거나 인증에 실패했습니다. 다시 입력하세요."), 필드(라벨: 비밀번호는 서버가 준 안내 문구, 키 암호는 "키 파일이 암호로 보호되어 있습니다", 사용자 이름은 "연결할 계정"). 입력창은 사용자 이름만 일반 글자, 나머지는 가려진 글자. 열릴 때 포커스.
- 비밀번호 요청이고 저장 허용(allowSave)이면 체크박스 "암호화해 저장하고 다음부터 자동 로그인". 기본 체크 상태는 볼트가 열려 있으면 켜짐. **볼트가 잠겨 있으면** 체크박스는 흐리게 비활성이며 문구 끝에 "(앱 잠김)"을 붙이고 저장하지 않는다.
- 버튼 [취소] [확인], Enter=확인. 결과: 비밀번호=`{입력값, 저장 여부}`, 그 외=입력 문자열, 취소=없음.

### 4.3 추가 인증 (keyboard-interactive)
- 제목: 서버가 준 이름, 없으면 "추가 인증". 열쇠 아이콘. 본문: 세션 제목(흐리게), 서버 안내문(있으면), 서버가 준 프롬프트마다 필드(라벨=프롬프트). 입력을 에코하라는 프롬프트면 일반 글자, 아니면 가려진 글자. 첫 입력창에 포커스. 버튼 [취소] [확인]. 결과: 입력 문자열 배열(프롬프트 순서, 비면 빈 문자열).

## 5. 서버 가져오기

크게 보기. 제목 "서버 가져오기"(다운로드 아이콘). 바닥: 왼쪽에 "{선택}/{전체}개 선택", 오른쪽 [취소] [{n}개 가져오기](주 버튼, 선택이 0이거나 진행 중이면 비활성, 진행 중 문구 "가져오는 중...").

본문 위에서 아래:
1. **안내 박스**: "PuTTY 저장 세션(레지스트리), SecureCRT 세션 폴더, ~/.ssh/config를 읽어 옵니다. 호스트·포트·사용자·키 파일·포트 포워딩·시리얼 설정·인코딩이 옮겨집니다. 비밀번호는 옮기지 않으므로 처음 연결할 때 한 번 입력하면 저장됩니다." 볼트가 잠겨 있으면 문장 끝에 " (앱이 잠겨 있으면 키 파일은 저장되지 않습니다)" 추가.
2. **AWS EC2 불러오기** 버튼(구름 아이콘, 진행 중 "AWS 전 리전 조회 중...") + 설명 "aws CLI 자격 증명으로 인스턴스를 읽습니다. 사설 IP 서버는 같은 VPC 의 경유 서버를 경유 서버로 잇고, 키는 ~/.ssh/<키 이름>.pem 에서 찾습니다."
   - **SecureCRT 폴더 선택** 버튼(폴더 아이콘, 진행 중 "SecureCRT 폴더 읽는 중...") + 설명 "다른 위치(다른 PC에서 복사한 Config 폴더 등)의 SecureCRT 세션을 읽습니다. 폴더 구조는 넣을 폴더 아래에 그대로 만들어집니다." (신규 기능, D66)
   - **Xshell 내보내기 파일 선택** 버튼(압축 파일 아이콘, 진행 중 "Xshell 파일 읽는 중...") + 설명 "Xshell 의 [파일 > 내보내기]로 만든 .xts 파일이나 세션 파일(.xsh) 하나에서 세션을 읽습니다. 폴더 구조와 포트 포워딩은 그대로 옮겨집니다. 비밀번호·사용자 키·프록시 설정은 옮기지 않습니다." (신규 기능, 2026-11-25, D128. 포트 포워딩·세션 파일 하나는 D129)
3. 후보 검색 중이면 "검색 중...". 후보가 없으면 "가져올 세션을 찾지 못했습니다." 줄바꿈 "PuTTY·SecureCRT에 저장된 세션이 없거나 ~/.ssh/config가 없습니다."
4. 후보가 있으면:
   - 필드 "넣을 폴더 이름"(기본값 "PuTTY 가져오기", 단 자동 검색 결과에 PuTTY 후보가 없고 SecureCRT 후보가 있으면 "SecureCRT", PuTTY·SecureCRT 후보가 없고 Xshell 후보가 있으면 "Xshell"), 도움말 "이름이 prod-/stg-/dev- 로 시작하면 운영/검증/개발 환경이 자동 지정됩니다. 비우면 최상위에 넣습니다. SecureCRT 폴더 구조는 이 폴더 아래에 만들어집니다."
   - 표(머리: 전체 선택 체크박스, 이름, 주소, 종류, 출처). 행마다 체크박스, 굵은 이름(`folderPath` 가 있으면 이름 앞에 흐린 글씨로 `폴더/폴더/`), 주소(`사용자@호스트:포트`, 시리얼은 `경로 @ 속도`, 키 파일이 있으면 열쇠 표시), 종류(프로토콜 대문자, 기본 SSH), 출처(`PuTTY` / `SecureCRT` / `Xshell` / `ssh config` / AWS 는 `AWS`에 경유 서버 경유 시 ` · 배스천 경유`, 키 파일 없음 메모가 있으면 경고 표시; 툴팁에 메모).
   - **초기 선택**: 이미 같은 호스트·포트·사용자의 서버가 있는 후보는 선택하지 않고, 나머지는 모두 선택.

동작:
- 대화상자가 열리면 후보를 자동 검색한다.
- AWS 조회: 결과가 없으면 정보 토스트 "AWS 에서 가져올 인스턴스를 찾지 못했습니다". 결과가 있으면 기존 AWS 후보를 대체하고(다른 출처 후보는 유지) 새 후보를 선택(중복 제외)하며 폴더 이름을 "AWS"로 바꾼다. 실패하면 오류 토스트 "AWS 조회 실패: {오류} — 터미널에서 aws configure 로 자격 증명을 확인하세요".
- SecureCRT 폴더 선택: 폴더 선택을 취소하면 아무것도 안 함. 결과가 없으면 정보 토스트 "선택한 폴더에서 SecureCRT 세션을 찾지 못했습니다". 결과가 있으면 기존 SecureCRT 후보를 대체하고(다른 출처 후보는 유지) 새 후보를 선택(중복 제외)하며 폴더 이름을 "SecureCRT"로 바꾼다. 실패하면 오류 토스트 "SecureCRT 폴더를 읽지 못했습니다: {오류}".
- Xshell 내보내기 파일 선택(2026-11-25, D128): 파일 선택을 취소하면 아무것도 안 함. 결과가 없으면 정보 토스트 "선택한 파일에서 Xshell 세션을 찾지 못했습니다". 결과가 있으면 기존 Xshell 후보를 대체하고(다른 출처 후보는 유지) 새 후보를 선택(중복 제외)하며 폴더 이름을 "Xshell"로 바꾼다. 실패하면 오류 토스트 "Xshell 파일을 읽지 못했습니다: {오류}". 이 PC 에 Xshell 이 설치돼 있으면 그 세션은 대화상자를 열 때의 자동 검색에 이미 들어 있다.
- 가져오기 실행: 선택된 후보를 폴더 이름과 함께 백엔드에 적용 → 저장 데이터를 다시 읽고 → 성공 토스트 "{n}개 서버를 가져왔습니다"(키를 볼트에 저장했으면 " (키 {k}개 암호화해 저장)" 덧붙임) → 건너뛴 항목이 있으면 오류 토스트에 줄바꿈으로 나열 → 닫기. 실패하면 오류 토스트.

## 6. 동기화(git) 패널 — 설정 화면의 한 구역

- 설명: "여러 PC의 서버 목록을 맞춥니다. 비공개 git 저장소에는 **앱 잠금 비밀번호로 암호화한 파일 하나**만 올라가며 평문 정보는 남지 않습니다. 다른 PC에서는 같은 앱 잠금 비밀번호로 엽니다. 저장소 인증은 이 PC의 git 설정(SSH 키, credential helper)을 그대로 쓰고, 앱은 git 자격 증명을 저장하지 않습니다."
- 필드 "저장소 주소"(도움말 "예: git@github.com:me/dariterm-sync.git — URL에 비밀번호·토큰을 넣지 마세요", 입력은 고정폭, 플레이스홀더 `https://github.com/me/dariterm-sync.git`). 입력창을 벗어나면(blur) 값을 설정에 저장한다. 옆에 [지금 동기화] 버튼(주소가 비었거나 볼트가 잠겼거나 진행 중이면 비활성, 진행 중 아이콘 회전). 누르면 주소를 저장하고 동기화 실행.
- 카드: 토글 "자동 동기화" — 설명 "잠금을 해제할 때, 변경 후 약 20초 뒤, 그리고 10분마다 동기화합니다"
- "마지막 동기화: {로컬 형식 날짜시간}", 없으면 "아직 동기화한 적 없음"
- git 이 없으면 오류 "이 PC 에 git 이 설치되어 있지 않습니다." 볼트가 잠겨 있으면 "잠금을 해제해야 동기화할 수 있습니다." 마지막 상태가 오류면 그 메시지 표시.
- **저장소 볼트 불일치 상태**일 때 카드 표시: 굵은 제목 "저장소의 암호화 데이터가 이 PC 와 다릅니다", 설명 "처음 연결하는 새 PC 라면 "저장소 데이터 받기"를 선택하세요. 이 PC 의 데이터를 저장소의 기준으로 삼으려면 "이 PC 데이터로 덮어쓰기"를 선택하세요 (저장소의 기존 내용이 대체됩니다).", 버튼 [저장소 데이터 받기](주 버튼) [이 PC 데이터로 덮어쓰기](위험색). 덮어쓰기는 확인 대화상자(제목 "이 PC 데이터로 덮어쓰기", 본문 "저장소의 기존 동기화 내용이 이 PC 의 데이터로 대체됩니다. 다른 PC 는 새 앱 잠금 비밀번호로 다시 받아야 합니다.", 확인 문구 "덮어쓰기", 위험)을 거친다.
- 동기화 결과 토스트: 성공 "동기화했습니다"(다른 PC 변경을 받았으면 "동기화했습니다 (다른 PC 의 변경을 받았습니다)"), 오류·git 없음·잠김은 오류 토스트(메시지 없으면 "동기화하지 못했습니다").
- 상태 변화 이벤트를 받으면 마지막 상태 표시를 즉시 갱신한다.

## 7. 포트 포워딩 정보 창 (기본 크기, 2026-11-27, D137)

창 머리글의 포트 포워딩 버튼 또는 칸 우클릭 메뉴로 연다(ui/panes.md §2.6). 지금 연결의 포워딩 결과(behavior/session.md §1 `forwards`)를 보인다. 읽기 전용이다.

- 제목: `포트 포워딩 · {세션 제목}`, 좌우 화살표 아이콘.
- 본문 첫 줄(흐린 작은 글씨): `{접속 대상} · {개수}개 설정됨`, 실패가 있으면 `{개수}개 설정됨, {실패 수}개 실패`. 이어져 있는 연결이 하나라도 있으면 뒤에 ` · 연결 {모든 포워딩의 합}개`. 오간 바이트가 있으면 그 뒤에 ` · ↑ {보낸 합} · ↓ {받은 합}`(D151).
- 표(포워딩마다 한 줄, 설정한 순서): 머리 **종류 · 듣는 주소 · 대상 · 상태 · 전송량**(전송량 열은 2026-11-27 D151).
  - 전송량: 작은 고정폭 흐린 글씨 `↑ {up} · ↓ {down}`(바이트 표기는 §1.5), 실패한 줄은 비운다. 연결 수와 같이 창을 열 때·[새로고침] 때 읽는다.
  - 종류: 굵은 글자 `L`/`R`/`D` + 흐린 이름(로컬 / 원격 / 동적).
  - 듣는 주소·대상: 고정폭, 글자를 선택해 복사할 수 있다. D 의 대상은 흐린 글씨 "SOCKS 프록시".
  - 상태: 성공이면 초록 **"동작 중"**(2026-11-27 사용자 지시, D142 — 처음의 "대기 중"은 아직 준비가 안 된 것으로 읽혔다). 그 포워딩으로 지금 이어져 있는 연결이 있으면 `동작 중 · 연결 {n}개`(뒷부분 굵게), 0 이면 "동작 중"만. 실패면 빨강 `실패: {오류}`(실패한 줄은 주소 글자가 흐리다).
  - **연결 수 읽기**: 창을 **열 때 한 번** `session.forwards` 를 물어 표를 그린다(빈 배열·오류가 오면 세션 정보의 목록을 그대로 둔다). **주기적으로 다시 묻지 않는다**(2026-11-27 사용자 지시). 다시 보려면 [새로고침]. 창 머리글의 버튼에는 연결 수를 보이지 않는다.
- 표 아래 도움말: "L: 이 PC의 듣는 주소로 접속하면 서버를 거쳐 대상으로 갑니다. R: 서버의 듣는 주소로 접속하면 이 PC를 거쳐 대상으로 갑니다. D: 듣는 주소가 SOCKS 프록시입니다. 바꾸려면 서버 편집 > 포트 포워딩에서 고친 뒤 다시 연결하세요."
- 버튼 [새로고침](왼쪽 끝, 연결 수를 다시 읽는다) [복사] [닫기](주 버튼). [복사]는 목록을 글자로 클립보드에 넣고(한 줄에 하나, 듣는 주소 폭을 맞춤 — 터미널 안내의 줄 모양에서 들여쓰기만 뺀 것) 성공 토스트 "포워딩 목록을 복사했습니다".
