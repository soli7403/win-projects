# 도움말 창

> 작성 방식: 새 기능 명세(원본 앱에 없던 기능). 작성일 2026-11-27. 결정 D155(창·검색), D156(목록 정렬), D157(질문 카드), D158(그림), D159(크기 조절·그림 보기). 상태: **ready**.

## 1. 여는 곳
- 왼쪽 아이콘 묶음(ui/shell.md §2.0)의 **설정 오른쪽**에 도움말 버튼(물음표 동그라미, 툴팁 "도움말"). 누르면 첫 항목(또는 마지막으로 정해진 항목)으로 연다.
- 설정 화면 왼쪽 아래 **"이 구역 도움말"**(§3).
- 잠금 화면이 덮여 있으면 열지 않는다. 단축키는 두지 않는다(F1 은 터미널 프로그램이 쓴다).

## 2. 창 모양
- 공통 모달(ui/dialogs.md §1), 제목 "도움말", 크게 보기. 기본 크기 820 × 화면 높이의 80%.
- **크기 조절**(D159): 카드 오른쪽 아래 손잡이(툴팁·이름 "끌어서 창 크기 조절 (두 번 누르면 원래 크기)"). 끌면 너비는 움직인 거리의 2배(카드가 가운데 정렬이라), 높이는 그대로 바뀐다. 최소 600 × 380, 최대 (창 너비 − 40) × (창 높이의 92% − 16). 놓을 때 화면 저장소(`dariterm.helpSize`)에 저장하고 다음에 연 때 그 크기로 연다. 두 번 누르면 기본 크기로 돌아가고 저장값을 지운다. 손잡이에 포커스가 있으면 방향키 20px, Shift+방향키 60px.
- 왼쪽(250px): 검색 칸(플레이스홀더 "도움말 검색 (예: 매크로, 프록시 명령)"), 그 아래 검색어가 없으면 **목록 순서** 단추(§5), 검색 중이면 결과 줄 "{n}개 항목"(없으면 `"{검색어}" 에 맞는 항목이 없습니다`), 그 아래 항목 목록(지금 항목 강조, 검색 중에는 항목마다 미리 보기 두 줄).
- 오른쪽: 본문 언어가 화면 언어와 다르면 안내 "이 언어의 도움말이 아직 없어 영어로 보여 드립니다.", 그 아래 고른 항목의 제목·본문. 본문 글자는 선택해 복사할 수 있다.

## 3. 설정과의 연결
- 설정 화면 왼쪽 열의 구역 목록 **아래**(목록 밖)에 "이 구역 도움말". 누르면 설정을 닫고 도움말을 그 구역의 항목으로 연다. 도움말을 닫으면 설정이 같은 구역으로 다시 열린다(모달 둘을 겹쳐 띄우지 않는다).
- 구역 → 항목: 화면 → settings, 입력 → terminal, 단축키 → shortcuts, 출력 규칙 → triggers, 파일 전송 → sftp, 연결 → connect, 로그 → log, git 동기화 → sync, 보안 → vault, 백업 → sync, 정보 → license.

## 4. 검색
- 검색어를 공백으로 나눈 낱말이 **모두** 든 항목만(대소문자 무시, 꾸밈 기호 `**`·`` ` `` 를 뺀 제목+본문에서). 점수: 낱말마다 제목에 있으면 100 + 본문에 나온 횟수. 높은 순, 같으면 원래 순서.
- 미리 보기: 첫 낱말이 처음 나온 곳 앞 30자부터 90자.
- 제목·목록·본문(표·목록·코드 포함)에서 맞은 낱말을 경고색 바탕으로 강조한다.
- 검색 칸에서 Enter 는 첫 결과를 고른다. 고른 항목이 결과에 없으면 첫 결과를 보인다.

## 5. 목록 순서 (D156)
- 단추 두 개: **기능 순서**(본문 파일 순서) · **이름순**(문구: ko 가나다순 · en/de/fr/es/pt A–Z · ru А–Я · ja 名前順 · zh 按名称 · tw 依名稱). 검색어가 있을 때는 보이지 않는다(결과는 맞은 정도 순).
- 이름순은 **보이는 본문의 언어**로 꾸밈 기호를 뺀 제목을 비교한다(숫자는 수로, 대소문자·악센트 무시). 앱 언어 `tw` 는 `zh-TW`, 쓸 수 없는 언어 코드는 기본 비교.
- 고른 값은 화면 저장소 `dariterm.helpSort`(`feature`/`name`)에 둔다. 읽지 못하면 기능 순서.

## 6. 본문 형식
- `locales/help/<언어>.md` — 지금은 ko·en. 그 밖의 언어는 en 을 쓴다(en 도 없으면 ko). 맨 앞의 `<!-- -->` 주석은 버린다.
- `## 제목 {#id}` 하나가 항목 하나. id 는 언어마다 같고 같은 순서(start, screen, servers, connect, auth, vault, terminal, tabs, jump, proxy, forward, agent, tmux, serial, sftp, zmodem, snippets, macros, login-script, highlight, triggers, log, import, sync, shortcuts, settings, license, faq).
- 꾸밈: `### 소제목`, 문단, `- ` 목록, `1. ` 번호 목록(두 칸 이상 들여 쓴 줄은 바로 위 항목의 하위), 표(`| a | b |`, 둘째 줄 구분선), `> ` 안내 상자, 코드 블록(```), 글자 안의 `**굵게**`·`` `코드` ``. HTML 은 그리지 않는다.
- **질문 카드**(D157): `Q: 질문` 줄과 그 아래 줄들(빈 줄·다음 `Q:`·항목 제목 전까지)이 한 묶음. 테두리·바탕 있는 카드에 파란 `Q` + 굵은 질문, 회색 `A` + 답.
- **그림**(D158): 한 줄 전체가 `![설명](파일)`, 파일 이름은 소문자·숫자·하이픈과 `.png`·`.webp`·`.jpg` 만(경로 불가). 그림은 `locales/help/img/<언어>/<파일>`, 그 언어 → en → ko 순으로 찾고 없으면 그리지 않는다. 빌드할 때 실행 파일에 함께 묶인다. 본문 안에서는 본문 폭·높이 360px 안으로 줄여 보이고 아래에 흐린 설명, 툴팁 "눌러서 크게 보기".

## 7. 그림 보기 (D159)
- 본문의 그림을 누르면 앱 창 전체를 덮는 어두운 화면에 그 그림을 띄운다(이름 = 그림 설명). 위 줄: 설명, [실제 크기] ↔ [화면에 맞추기] 단추, [닫기](X).
- 처음에는 그림 전체가 보이게 맞춘다. 단추나 그림을 누르면 실제 크기(넘치면 스크롤) ↔ 맞추기.
- **Esc** 는 그림 보기만 닫는다(도움말은 그대로). 어두운 곳을 눌러도 닫힌다.

## 8. 그림 자동 캡처 (개발용)
- `frontend` 에서 `npm run help:capture` — vite 개발 서버 + 가짜 백엔드 + 이 PC 의 Edge(headless, `playwright-core`)로 12화면 × ko·en 을 1280×820, 어두운 테마로 찍어 `locales/help/img/` 에 쓴다. 앱 실행 파일에는 들어가지 않는다.
- 데모 프로필의 화면 저장소 표시가 있을 때만 화면을 여는 손잡이가 생긴다(평소 실행에는 없다).

## 9. 수용 기준
- H1 왼쪽 위 물음표 → "처음 실행" 항목.
- H2 `프록시 명령` 검색 → 결과 개수, 첫 결과 "프록시와 프록시 명령", 강조.
- H3 설정 > 출력 규칙 > 이 구역 도움말 → 출력 트리거 항목, 닫으면 설정의 출력 규칙.
- H4 언어 Deutsch → 영어 본문과 안내.
- H5 가나다순 → 첫 항목 "개인용·업무용과 업데이트", 다시 열어도 가나다순.
- H6 자주 묻는 질문은 카드 9개 이상.
- H7 그림을 누르면 그림 보기, Esc 는 그림 보기만 닫는다.
- H8 손잡이로 크기를 바꾸고 다시 열면 그 크기, 두 번 누르면 기본 크기.
