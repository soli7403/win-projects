# 우측 패널 — SFTP 탐색기·스니펫

> 작성 방식: 기존 앱 실행 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**.

## 1. 패널 틀

- **SFTP 패널**은 **탭 그룹마다 최대 1개**이며, 그 그룹 작업 영역의 오른쪽에 붙는다. 열기/닫기: 그 그룹 **탭 막대 맨 오른쪽의 폴더 트리 아이콘**(툴팁 "SFTP (Ctrl+Shift+S)", 열려 있으면 눌린 모양), 단축키 Ctrl+Shift+S(포커스 그룹), 칸 우클릭 메뉴 "SFTP 열기"(그 칸에 포커스를 준 뒤 그 칸 그룹의 패널을 연다), 패널 머리 오른쪽 닫기(X). 칸 머리글과 왼쪽 아이콘 묶음에는 SFTP 버튼이 없다.
- 그룹에 탭이 없으면 그 그룹의 SFTP 패널은 보이지 않는다(열림 상태는 기억).
- 왼쪽 가장자리를 끌어 **너비 조절**: 최소 260px, 최대 760px, 기본 340px. 끌기를 마치면 설정(rightPanelWidth)에 저장(두 그룹이 같은 너비를 쓴다).
- 머리: "SFTP"(폴더 트리 아이콘) 제목, 오른쪽 끝 닫기(X).
- **스니펫 패널**은 왼쪽 **서버 목록 열의 아래 절반**에 붙는다(서버 목록과 위아래 반씩). 열기/닫기: 왼쪽 아이콘 묶음의 **스니펫(코드 `<>` 아이콘)** 버튼. 서버 목록이 접혀 있을 때 누르면 서버 목록을 펴면서 스니펫을 연다.

## 2. SFTP 탭

대상은 **그 그룹에서 선택된 탭의 포커스된 칸 세션**이다. 그 그룹의 탭이나 포커스가 바뀌면 그 세션의 목록으로 바뀐다.

### 2.1 상태 안내 문구 (목록 영역 대신 표시)
- 포커스된 세션이 없으면: "세션을 선택하면 해당 서버의 파일이 표시됩니다."
- 세션이 SFTP 불가(SSH 가 아님)이면: "SFTP는 SSH 세션에서만 사용할 수 있습니다." 줄바꿈 "({프로토콜 대문자} 세션)"
- 연결되지 않았으면: "연결되면 파일 목록이 표시됩니다."

### 2.2 도구 막대 (왼쪽→오른쪽)
> 2026-11-12 사용자 요청으로 배치 변경: 작업 버튼은 **패널 머리(제목 줄)** 로 올리고, 아래 줄은 경로 이동만 둔다.

- **제목 줄**: "SFTP"(로컬 터미널이면 "파일") 제목 · (빈 공간) · [새로고침](툴팁 "새로고침", 불러오는 중 아이콘 회전) [새 폴더](툴팁 "새 폴더") [파일 업로드](툴팁 "파일 업로드") [터미널에서 이 폴더로 cd](툴팁 같음) · 닫기(X). 버튼은 작은 아이콘 버튼(22px, 아이콘 14px).
- **경로 줄**: [상위 폴더](툴팁 "상위 폴더") [홈](툴팁 "홈") · 경로 입력창(남는 폭 전부; Enter 로 이동, 맞춤법 검사 끔)

- 처음 열면 `~`(홈)을 불러온다. 이후 세션마다 마지막으로 본 경로를 기억해 다시 포커스될 때 그 경로를 연다.
- 불러온 뒤 경로 입력창은 서버가 알려 준 실제 경로로 바뀌고 선택은 비워진다.
- 상위 폴더: 현재 경로가 `/` 이면 그대로, 아니면 마지막 경로 요소를 뺀 경로(비면 `/`).
- **새 폴더**: 입력 대화상자 "새 폴더 이름" → 비어 있지 않으면 현재 폴더 아래에 만들고 새로 불러온다. 실패하면 오류 토스트.
- **파일 업로드**: 로컬 파일 선택 대화상자 → 현재 폴더로 업로드 → 새로 불러온다. 실패하면 오류 토스트.
- **터미널에서 cd**: 현재 경로를 작은따옴표로 감싸(경로 안 작은따옴표는 `'\''` 로 이스케이프) `cd '경로'` + Enter 를 그 세션에 보내고 터미널에 포커스.
- 업로드가 끝났을 때 그 전송의 원격 경로가 현재 폴더 아래이면 자동으로 새로 불러온다.
- 불러오기 실패 시 목록 위에 빨간 안내 박스(아이콘 + 오류 메시지).

### 2.3 목록
- 머리 줄: (아이콘 칸) 이름 · 크기 · 수정일.
- **목록 항목 필드**: `mode` = 권한 하위 9비트 숫자(예: 0755 = 493), `perm` = 10글자 권한 문자열(`drwxr-xr-x`, 첫 글자 d/l/-). 권한 변경 입력의 초기값은 `mode` 를 8진수 문자열로 바꾼 것(예: `755`).
- 행: 아이콘(폴더=채워진 폴더 아이콘, 이미지 확장자 png·jpg·jpeg·gif·webp·bmp·svg=이미지 아이콘, 그 외=파일 아이콘) · 이름(심볼릭 링크면 이름 뒤 작은 링크 아이콘) · 크기(폴더는 비움; 형식은 ui/dialogs.md §1.5) · 수정일(같은 형식).
- 행 툴팁: 첫 줄 이름, 둘째 줄 `{권한 문자열}  {크기}`.
- 비어 있으면(오류도 없고 불러오는 중도 아닐 때): "빈 폴더입니다. 파일을 여기로 끌어다 놓으면 업로드됩니다."
- **선택**: 클릭=단일 선택(다른 선택 해제), Ctrl+클릭=개별 추가/해제, Shift+클릭=마지막으로 Shift 없이 누른 행부터 현재 행까지 범위 선택(Ctrl 과 함께면 기존 선택에 추가).
- **열기**(더블클릭 또는 Enter, 선택이 1개일 때): 폴더면 그 폴더로 이동, 파일이면 미리보기 대화상자.
- **키보드**(목록에 포커스): Delete=선택 삭제(확인), Backspace=상위 폴더, Enter=열기, Ctrl+A=전체 선택.
- **파일 끌어 놓기 업로드**: 목록 위로 파일을 끌어오면 안내 오버레이 "여기에 놓으면 {현재 경로} 로 업로드". 놓으면 업로드하고 새로 불러온다(경로를 못 얻으면 아무 일 없음). 실패 시 오류 토스트.

### 2.4 행 우클릭 메뉴
우클릭한 행이 현재 선택에 속하면 선택 전체가 대상, 아니면 그 행만 선택하고 그 행이 대상.

| 항목 | 동작 | 비활성 조건 |
|---|---|---|
| 열기(폴더) / 미리보기(파일) | 열기 규칙과 같음. **우클릭한 행 하나**가 대상이며 여러 개를 선택한 상태에서도 항상 활성 | |
| 다운로드... | 폴더 선택 대화상자 후 대상 전체를 다운로드. 완료하면 토스트(ok) "다운로드 완료 → {폴더}"(취소하면 없음). 실패 시 오류 토스트 | |
| 로컬 앱으로 편집 (저장 시 자동 업로드) | 파일을 임시로 내려받아 이 PC의 기본 앱으로 열고, 저장되면 서버로 자동 업로드. 시작하면 정보 토스트 "편집 후 저장하면 서버에 자동 업로드됩니다". 실패 시 오류 토스트 | 폴더이거나 2개 이상 선택 |
| ―구분선― | | |
| 경로를 터미널에 입력 | 대상 경로를 공백으로 이어(필요하면 따옴표 처리) 끝에 공백을 붙여 입력, 터미널 포커스 | |
| 터미널에서 이 폴더로 cd | 폴더 행이면 그 폴더, 파일 행이면 현재 폴더로 `cd` + Enter 입력 | |
| 경로 복사 | 대상 경로를 줄바꿈으로 이어 클립보드에 | |
| ―구분선― | | |
| 이름 바꾸기 | 입력 대화상자 "이름 바꾸기"(현재 이름이 채워짐). 비어 있지 않고 바뀌었으면 같은 폴더 안에서 새 이름으로 변경 후 새로 불러옴. 실패 시 오류 토스트 | 2개 이상 선택 |
| 권한 변경 (현재 {권한 문자열}) | 입력 대화상자 "권한 (8진수, 예: 755)"(현재 권한의 하위 3자리 8진수가 채워짐). `[0-7]{3,4}` 형식일 때만 적용 후 새로 불러옴 | 2개 이상 선택 |
| 삭제 (위험색) | 삭제 규칙(§2.5) | |

경로 따옴표 규칙(터미널에 입력할 때): 공백이나 `'` `"` `$` `` ` `` `\` `(` `)` `&` `;` `|` `<` `>` `*` `?` `!` `#` 가 포함되면 작은따옴표로 감싸고 경로 안의 작은따옴표는 `'\''` 로 바꾼다. 아니면 그대로.

### 2.5 삭제
확인 대화상자: 제목 "삭제", 본문 `"{이름}"을(를) 서버에서 영구 삭제할까요?`(2개 이상이면 `{n}개 항목을(를) …`) + 폴더가 포함되면 " 폴더는 안의 내용까지 모두 삭제됩니다.", 확인 "삭제", 위험. 확인하면 삭제하고 새로 불러온다. 실패 시 오류 토스트.

### 2.6 전송 목록
- 이 세션의 전송이 있을 때 목록 아래에 표시. 최신순 **최대 30개**.
- 머리: "전송" + 오른쪽 링크 [지우기] → 진행 중·대기 중이 아닌 전송(완료·오류·취소)을 목록에서 지운다.
- **전송 상태 값**(백엔드와 프런트가 **이 이름 그대로** 쓴다): `queued`(대기) · `running`(진행) · `done`(완료) · `error`(오류) · `canceled`(취소). 이 앱에는 취소 기능이 없어 백엔드는 `canceled` 를 보내지 않지만 값은 인식해야 하며, 완료·오류가 아닌 상태는 모두 퍼센트로 표시한다.
- 행: 방향 아이콘(업로드 ↑ / 다운로드 ↓), 파일 이름, 상태(완료=초록 체크, 오류=빨간 경고, 그 외=`{퍼센트}%`), 전체 크기, 아래 진행 막대. 퍼센트 = 전송 바이트/전체(전체가 0 이면 완료일 때 100, 아니면 0). 툴팁: 오류가 있으면 오류 메시지, 없으면 원격 경로.

## 3. 미리보기 대화상자 (크게)
- 제목: 파일 이름. 본문: 불러오는 중 "불러오는 중...", 미리보기 불가 "미리보기를 지원하지 않는 파일입니다 (이진 파일 또는 512KB 초과).", 이미지면 이미지(가운데), 텍스트면 고정폭 박스(최대 높이 화면의 60%, 스크롤).
- 바닥: 왼쪽 흐린 글씨로 전체 경로 / 버튼 [경로를 터미널에 입력](대화상자를 닫고 경로+공백 입력 후 터미널 포커스) [로컬 앱으로 편집](성공하면 닫기, 실패 시 오류 토스트) [다운로드](주 버튼; 완료 토스트 "다운로드 완료 → {폴더}").
- 미리보기 가능 조건: 이미지(§2.3 확장자) 또는 텍스트이면서 512KB 이하인 파일.

## 4. 스니펫 탭

- 도구 막대: 검색 입력(플레이스홀더 "스니펫 검색") + [새 스니펫](+ 아이콘, 툴팁 "새 스니펫"). 검색은 "이름 + 본문"에 대해 대소문자 무시 부분 일치.
- 목록: 항목마다 굵은 이름(비면 "(이름 없음)") + 아래 본문 미리보기, 오른쪽 [편집](연필) [삭제](휴지통). 항목 툴팁 "클릭하면 현재 세션에 입력합니다".
- **항목 클릭** → 포커스된 세션에 본문을 입력(behavior/terminal.md §7). 편집·삭제 버튼 클릭은 입력을 일으키지 않는다.
- 검색 결과가 0개일 때(스니펫은 있음)는 **아무 문구 없이 빈 목록**이다.
- 비어 있으면(스니펫 0개): "자주 쓰는 명령을 저장해 두고 클릭 한 번으로 실행하세요." 줄바꿈 "동시 입력이 켜진 탭에서는 모든 패널에 입력됩니다."
- 삭제 확인: 제목 "스니펫 삭제", 본문 `"{이름}"을(를) 삭제할까요?`, 확인 "삭제", 위험.
- **편집 대화상자**(작게): 제목 새로 만들 때 "새 스니펫", 편집 시 "스니펫 편집". 필드 "이름"(플레이스홀더 "예: 로그 보기", 포커스), "명령"(5줄, 도움말 "여러 줄은 순서대로 입력됩니다", 플레이스홀더 `tail -f /var/log/nginx/error.log`), 토글 "입력 후 Enter 실행". 새 스니펫 기본값: 이름·본문 빈 값, 입력 후 Enter 실행 켜짐. [저장]은 **명령이 비어 있으면 비활성**. 저장하면 목록에 추가(편집이면 교체) 후 닫는다.
