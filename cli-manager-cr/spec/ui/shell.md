# 화면 뼈대 — 제목 표시줄·탭·상태 표시줄·시작 화면

> 작성 방식: 기존 앱 실행 관찰 + 열람. 작성일 2026-11-10. 상태: **draft** (치수·색은 ui/tokens.md 와 스크린샷으로 보강 예정).

## 1. 전체 배치

창은 운영체제 기본 프레임(제목 "DariTerm")을 쓰고, **앱 안에는 별도 제목 줄이 없다**. 프레임 아래는 왼쪽부터 **왼쪽 열(아이콘 묶음 + 서버 목록)**, **작업 영역(탭 막대 + 탭 내용)**, **그룹별 SFTP 패널(열려 있을 때만, 그룹 오른쪽)** 이고, 맨 아래가 **상태 표시줄**이다. 서버 목록 너비는 설정(sidebarWidth 260)에 저장되고 경계를 끌어 조절한다.

## 2. 왼쪽 아이콘 묶음과 탭 막대

### 2.0 왼쪽 아이콘 묶음
순서: **서버 목록 토글**(툴팁 "서버 목록 (Ctrl+Shift+L)", 열려 있으면 눌린 모양) · **스니펫**(코드 `<>` 아이콘, 서버 목록 아래에 스니펫 패널 열기/닫기, ui/sftp-snippets.md §1) · **설정**. 잠그기 버튼은 두지 않는다 — 앱 잠금은 상태 표시줄 오른쪽 끝의 "잠금 해제됨"을 눌러 한다(D67).
- 서버 목록이 **열려 있으면** 서버 목록 열의 맨 위에 **가로 한 줄**로 놓인다.
- **접혀 있으면** 작업 영역 왼쪽에 너비 약 38px 의 **세로 막대**가 남고 같은 아이콘이 세로로 쌓인다.

### 2.0.1 탭 막대
탭 막대는 **작업 영역 맨 위에만** 있다(왼쪽 열 위로는 이어지지 않는다). 탭 목록 끝에 + 버튼(툴팁 "새로 연결 (Ctrl+K)", 빠른 접속), **탭 막대 맨 오른쪽에 SFTP(폴더 트리) 버튼** — 그 그룹의 SFTP 패널 열기/닫기(ui/sftp-snippets.md §1). 화면을 나누면 그룹마다 하나씩(§2.3). 탭이 하나도 없으면 탭 막대는 + 버튼만 보이고 아래에 시작 화면이 나온다.

### 2.1 탭

각 탭은 왼쪽부터 다음을 가진다: 상태 점 · 제목 · (동시 입력 중이면 broadcast 아이콘, 경고색) · (칸이 2개 이상이면 칸 수 배지) · 닫기(X) 버튼.

- **제목**: 사용자가 정한 이름이 있으면 그것, 없으면 포커스된 칸 세션의 제목, 그것도 없으면 "세션". 툴팁도 같은 제목.
- **색** (2026-11-20 사용자 결정, D103): 탭 위쪽 가장자리의 **색 막대는 그룹에서 선택된 탭에만** 둔다. 막대 색은 그 탭의 포커스된 칸 세션의 색(서버 색·폴더 색·환경 색), 색이 없으면 강조색이고, 선택된 탭의 배경도 그 색으로 옅게 칠한다(14% 정도의 혼합). 선택되지 않은 탭은 막대 없이, 세션에 색이 있을 때만 배경을 그 색으로 옅게 칠한다(7% 정도). 화면을 나누면 그룹마다 선택된 탭 하나씩에 막대가 있다.
- **상태 점**: 탭 안 칸들의 세션 상태를 합쳐 표시한다.
  - 모든 칸이 연결됨 → 연결됨
  - 일부만 연결됨 → 재접속(경고) 표시
  - 연결된 칸이 없고 접속 중/재접속 중인 칸이 있음 → 접속 중
  - 그 외 오류가 있으면 오류, 아니면 끊김
  - **비활성 탭에 새 출력이 있으면** 상태 점이 "활동" 표시로 바뀐다. 그 탭을 활성화하거나 그 칸에 포커스하면 사라진다.
- **조작**
  - 왼쪽 버튼 누르기: 그 탭 활성화
  - 가운데 버튼 클릭: 그 탭 닫기
  - X 버튼: 닫기(눌러도 탭 활성화는 일어나지 않음)
  - 더블클릭: "탭 이름 변경" 입력창(현재 제목이 채워져 있음). 빈 값으로 확인하면 사용자 이름을 지우고 자동 제목으로 돌아간다. 취소하면 변경 없음.
  - 드래그로 순서 변경: 놓은 위치 탭에 "드래그 오버" 표시가 나타나고, 놓으면 그 위치로 이동
  - 우클릭: 탭 메뉴(아래)

### 2.3 탭 그룹 (화면 나누기, 최대 2개)

작업 영역을 **왼쪽·오른쪽 두 개의 탭 그룹**으로 나눌 수 있다. 나누지 않은 상태가 기본이며, 그룹은 최대 2개다.

- **나누기**: 탭 우클릭 메뉴의 "오른쪽 화면으로 보내기", 또는 탭을 끌어 작업 영역의 오른쪽 절반에 놓는다. 끄는 탭이 작업 영역의 **오른쪽 가장자리**(영역 너비의 10%, 단 최소 100px) 안에 들어가면 오른쪽 절반에 "여기에 놓으면 좌우로 나눕니다" 안내가 나타난다. 탭 막대 위에서는 가장자리라도 띄우지 않는다(탭 순서 바꾸기를 가리지 않게). 안내는 포인터가 오른쪽 절반에 있는 동안 유지되고, 왼쪽 절반으로 가거나 끌기가 어떻게든 끝나면(놓기, Esc 취소, 다른 탭 위·작업 영역 밖·창 밖에 놓기) 사라진다. 사라진 뒤에는 다시 가장자리에 들어가야 나타난다(2026-11-19 사용자 결정, D101·D102). 탭이 1개뿐이면 나눌 수 없다.
- **나뉜 모양**: 작업 영역이 같은 너비의 두 열이 되고, **각 열이 자기 탭 막대를 맨 위에 가지며** 그 아래에 그 그룹에서 선택된 탭의 내용을 바로 보여 준다. 각 열의 탭 막대 끝에는 + 버튼이 있다. 두 열 사이 경계(가운데)를 **끌어서** 좌우 너비 비율을 바꿀 수 있다(각 20~80%, 경계를 더블클릭하면 50:50). 비율은 저장 레이아웃에 함께 저장·복원된다.
- **그룹별 선택**: 두 그룹은 각각 자기 선택 탭을 기억한다. 탭을 누르거나 그 안의 칸을 누르면 그 그룹이 **포커스 그룹**이 되고(열 위쪽에 강조 선), 상태 표시줄·단축키·사이드바에서 서버를 열 때 새 탭은 **포커스 그룹**에 생긴다.
- **옮기기**: 탭을 다른 그룹의 탭 막대(탭 위 또는 빈 곳)로 끌어 놓거나, 탭 우클릭의 "왼쪽/오른쪽 그룹으로 이동"을 쓴다. 옮겨진 탭은 대상 그룹의 선택 탭이 된다. 세션은 끊기지 않는다.
- **합치기**: 한 그룹의 탭이 모두 없어지면(닫거나 옮겨서) 자동으로 나뉨이 풀려 하나가 된다. 탭 우클릭의 "한 화면으로 합치기"는 모든 탭을 왼쪽 그룹으로 합친다.
- **순서 변경·닫기·전환**: 탭 순서 변경, 탭 닫기 후 다음 탭 선택(같은 그룹 안), Ctrl+Tab 류 탭 전환과 Ctrl+Shift+←/→ 이동은 **포커스 그룹 안의 탭**만 대상으로 한다.
- "모든 탭을 한 화면에 바둑판으로"는 나뉨을 풀고 한 탭으로 만든다.
- 저장 레이아웃(data/store.md §5)에 그룹 정보가 함께 저장·복원된다.

## 3. 상태 표시줄

왼쪽: 포커스된 세션이 있으면 다음 항목을 차례로 보여 준다.
1. 상태 점 + 세션 제목 (글자색은 세션 색, 없으면 기본색, 굵게)
2. 접속 대상 문자열 (`user@host:port`, 시리얼은 `COM3@115200` 꼴)
3. 상태 문구: 연결됨 / 접속 중 / 재접속 대기 / 끊김 / 실패. **연결됨이고 접속 시각이 있으면** ` · HH:MM:SS` 형식의 경과 시간을 덧붙이고(1초마다 갱신), 연결됨이 아니고 메시지가 있으면 ` · 메시지`를 덧붙인다.
4. 이 탭이 동시 입력 중이면 "일괄 입력 중" 배지

세션이 없으면 흐린 글자로 "연결된 세션 없음".

오른쪽(차례로, 해당할 때만):
- 새 버전이 있으면 "새 버전 {버전}" (누르면 배포 페이지를 외부 브라우저로 연다, 툴팁 "새 버전 내려받기 페이지 열기")
- 연결된 세션이 SFTP 가능하거나 로컬 세션이면 흐린 글자로 "이미지 붙여넣기 Ctrl+V" (툴팁: 원격이면 "클립보드 이미지를 서버에 올리고 경로를 입력합니다 (Claude Code 등 CLI에서 이미지 첨부)", 로컬이면 "클립보드 이미지를 이 PC에 저장하고 경로를 입력합니다 (Claude Code 등 CLI에서 이미지 첨부)")
- 포커스된 세션의 서버가 저장된 서버이면 그 서버의 인코딩을 대문자로 (예 `UTF-8`)
- 포커스된 터미널의 크기 `열×행` (예 `141×36`)
- 볼트 상태: 열림이면 열린 자물쇠 + "잠금 해제됨"(툴팁 "누르면 앱을 잠급니다", 누르면 잠금), 잠김이면 닫힌 자물쇠 + "앱 잠김"(툴팁 "앱 잠김", 눌러도 동작 없음)

## 4. 시작 화면 (탭이 하나도 없을 때 작업 영역에 표시)

가운데 카드 하나:
- 로고(48px), 제목 "DariTerm"
- 안내 문장: "서버를 더블클릭하거나 **Ctrl+K** 로 바로 연결하세요." (단축키는 키 모양 표기)
- 버튼 4개(가로 나열): **빠른 접속**(주 버튼, 번개 아이콘) · **로컬 터미널**(툴팁 Ctrl+Alt+T) · **새 서버 등록**(서버 편집 대화상자를 최상위 폴더 기준으로 연다) · **PuTTY에서 가져오기**(가져오기 대화상자)
- **최근 서버 격자**: 서버가 하나라도 있으면 표시. 최근 사용 시각(lastUsedAt) 내림차순, 같으면 이름 오름차순으로 **최대 9개**. 카드마다 왼쪽에 색 막대(서버 색·폴더 색·환경 색, 없으면 테두리색), 프로토콜 아이콘, 굵은 이름, 아래에 대상 문자열. 카드를 누르면 새 탭으로 연결.
- 단축키 표: 처음 12개 항목 (behavior/shortcuts.md §4)

## 5. 토스트(알림)

화면 구석에 쌓이는 짧은 알림. 종류 3가지(ok, error, info). 한 번에 **최대 5개**가 보이고 더 오면 가장 오래된 것부터 밀려난다. 자동으로 사라지는 시간: error 6초, 나머지 3.5초.

## 6. 앱 시작 시 흐름(화면 관점)

1. 저장 데이터와 볼트 상태를 읽는 동안 빈 앱 틀만 보인다.
2. 읽기가 끝나면 뼈대가 나타난다. 볼트가 아직 열리지 않았으면 그 위에 잠금 화면(ui/lock.md)이 덮인다.
3. 볼트가 설정되어 있고 잠겨 있으며 "OS 잠금 해제"가 켜져 있고 열린 탭이 없으면, 자동으로 OS 잠금 해제를 한 번 시도한다. 성공하면 잠금 화면이 사라진다.
4. 볼트가 열리면 저장된 탭·분할을 **한 번** 복원한다(설정 restoreLayout 이 켜져 있을 때, behavior/lifecycle.md).
5. 볼트가 열렸고 서버가 하나도 없고 "가져오기 제안"을 아직 한 적이 없으면, PuTTY·ssh config 후보를 검색해서 **후보가 있을 때만** 가져오기 대화상자를 자동으로 연다. 제안 여부는 이 앱 화면 저장소에 "이미 제안함"으로 기록하여 다시 묻지 않는다.
6. 모든 대화상자가 닫히면 포커스를 터미널로 되돌린다.
