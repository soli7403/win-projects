# 사이드바 — 서버 목록

> 작성 방식: 기존 앱 실행 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**.

## 1. 구성 (위→아래)

1. **머리**: 검색 입력(돋보기 아이콘, 플레이스홀더 "서버 검색"), 그 아래 버튼 3개 [+ 서버] [폴더 추가 아이콘 + 폴더] [가져오기]. 가져오기 버튼 툴팁 "PuTTY / SSH config 가져오기".
2. **트리**(스크롤): 즐겨찾기 섹션 → 최근 접속 섹션 → "서버" 섹션(폴더 트리 + 폴더 없는 서버)
3. 오른쪽 가장자리의 **너비 조절 손잡이**: 끌어서 너비 변경. **최소 200px, 최대 520px**. 끌기를 마치면 설정(sidebarWidth)에 저장하고 터미널 크기 재계산을 알린다. 기본 260px.

## 2. 검색

- 입력할 때마다 즉시 필터링. 공백으로 나눈 **모든 낱말**이 "이름 · 주소 · 사용자명 · 태그 · 폴더 이름 · 메모"를 이어 붙인 글자(대소문자 무시)에 포함되어야 일치.
- 검색 중에는 즐겨찾기·최근 섹션을 숨기고, 모든 폴더를 펼친 상태로 보여 주며, 일치 서버가 하나도 없는 폴더는 숨긴다. 폴더 오른쪽의 개수도 일치한 서버 수.
- Enter: 일치한 첫 서버를 새 탭으로 연결. Esc: 검색어 지우기.
- 일치가 없으면 `"{검색어}"와 일치하는 서버가 없습니다`(서버가 1개 이상 있을 때).

## 3. 섹션

- **즐겨찾기**: 검색 중이 아니고 즐겨찾기 서버가 있을 때. 제목 "즐겨찾기"(별 아이콘). 이 섹션의 행은 끌 수 없고 선택 강조도 하지 않는다.
- **최근 접속**: 검색 중이 아니고 **서버가 6개를 넘고**(7개 이상) 최근 사용 기록이 있는 서버가 있을 때. 제목 "최근 접속"(시계 아이콘). 최근 사용 시각 내림차순 **최대 5개**.
- **서버**: 제목 "서버 · {전체 서버 수}"(서버가 0이면 개수 생략). 그 아래 최상위 폴더(정렬 키 오름차순, 같으면 이름 순) → 폴더 없는 서버(또는 소속 폴더가 없어진 서버)(정렬 키 오름차순, 같으면 이름 순).
- 서버가 하나도 없으면 안내: "아직 저장된 서버가 없습니다." 줄바꿈 "**+ 서버**로 추가하거나" 줄바꿈 "**가져오기**로 PuTTY 세션을 불러오세요."

## 4. 폴더 행

- 왼쪽부터: 펼침 화살표(펼침 ▾ / 접힘 ▸) · 폴더 아이콘(펼침이면 열린 폴더) · 굵은 이름 · (환경이 `none` 이 아니면 환경 알약: 그 환경 색의 옅은 배경 + 색 글자) · 포함 서버 개수 · (마우스를 올리면) [폴더 전체 그리드로 열기] 버튼.
- 폴더 아이콘 색: 폴더 색, 없으면 환경 색, 없으면 흐린 색.
- **한 번 클릭하면 접기/펴기**가 토글되고 저장된다. 더블클릭은 아무 동작 없음.
- 하위 구조: 펼침 상태일 때 하위 폴더(같은 정렬 규칙) → 그 폴더의 서버. **들여쓰기는 단계마다 14px**(기본 6px).
- 개수는 하위 폴더까지 합산한 (검색 필터가 적용된) 서버 수.

## 5. 서버 행

- 왼쪽부터: 색 막대 · 프로토콜 아이콘(SSH 터미널, 텔넷 전파, 시리얼 칩, 로컬 터미널 상자) · 이름(이름이 비면 주소) · 흐린 부제(시리얼=장치 경로, 로컬=시작 폴더 또는 `~`, 그 외=주소) · (연결된 세션이 있으면 초록 점 + 2개 이상이면 개수) · (마우스를 올리면) [분할로 연결](오른쪽 분할) [하나 더 연결](새 탭) 버튼.
- **색 규칙**: 서버 자신의 색 → 서버 환경색(`none` 제외) → 소속 폴더의 색/환경색 → 상위 폴더로 올라가며 처음 나오는 것 → 없음.
- **접속 대상 문자열**: 시리얼=장치 경로, 로컬=`로컬 · ` + (시작 폴더, 비면 `~`), 그 외=`[사용자@]주소` (툴팁·상세에서는 `:포트` 추가).
- **툴팁**: 첫 줄 이름, 둘째 줄 접속 대상(포트 포함), 메모가 있으면 셋째 줄.
- **클릭**: 선택 + 그 서버의 열린 세션으로 이동(ui/panes.md §9). **더블클릭**: 열기/이동.
- **선택 동기화**: 포커스된 칸의 세션이 저장된 서버면 사이드바가 그 서버를 자동 선택하고 보이도록 스크롤한다.
- 즐겨찾기·최근 섹션의 행은 선택 강조·끌기가 없다.

## 6. 키보드 (사이드바에 포커스, 선택된 서버가 있을 때)

- Enter: 새 탭으로 연결. **Ctrl+Enter**: 오른쪽 분할로, **Shift+Enter**: 아래 분할로.
- F2: 서버 편집 대화상자.
- Delete: 삭제 확인 후 삭제 (제목 "서버 삭제", 본문 `"{이름}"을(를) 삭제할까요?`, 확인 "삭제", 위험).

| 항목 | 동작 |

| ―구분선― | |

**폴더 삭제 효과**: 그 폴더와 모든 하위 폴더가 삭제되고, 그 안의 서버는 삭제된 폴더의 **상위 폴더**(최상위면 폴더 없음)로 옮겨진다.

## 9. 끌어 놓기 (정리)

- **끌 수 있는 것**: 서버 행(즐겨찾기·최근 섹션 제외), 폴더 행.
- **놓는 곳**: 폴더 행 → 그 폴더로 이동(놓는 동안 폴더 행이 "drop" 강조). 트리의 빈 영역 → 최상위(폴더 없음)로 이동.
- 폴더를 자기 자신이나 **자기 하위 폴더**로 옮기는 것은 무시(순환 방지). 서버가 이미 그 폴더에 있으면 변경 없음.
- 서버를 **칸으로** 끌어 놓는 동작은 ui/panes.md §7.

## 10. 변경 저장

서버·폴더·설정의 변경은 즉시 화면에 반영되고 저장 요청을 보낸다(별도 저장 버튼 없음).
