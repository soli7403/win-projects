# 잠금 화면·최초 설정·복구

> 작성 방식: 기존 앱 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**. 암호 절차는 data/vault.md.

화면 전체(또는 세션 위 오버레이)를 덮는 중앙 카드. 카드 맨 위에 로고. 모드 4개: **잠금 해제 / 최초 설정 / 복구 코드 표시 / 복구 코드로 재설정**. 볼트가 이미 설정되어 있으면 "열기", 아니면 "최초 설정"으로 시작한다. 모드 전환 때 첫 입력창에 포커스.

**오버레이 모드**: 열린 탭이 있는 상태(자동 잠금 등)에서 잠기면 세션 화면 위에 덮는다.

## 1. 잠금 해제

- 제목 "DariTerm 잠김"(자물쇠 아이콘)
- 안내: 오버레이면 "세션은 계속 연결되어 있습니다. 앱 잠금 비밀번호를 입력하면 다시 사용할 수 있습니다.", 아니면 "저장된 서버 계정을 열려면 앱 잠금 비밀번호를 입력하세요."
- 비밀번호 입력창(플레이스홀더 "앱 잠금 비밀번호"), Enter 로 제출
- 오류: "비밀번호가 올바르지 않습니다" — 입력창을 비운다. **잠금 해제 요청이 `false` 가 아니라 오류로 실패하면**(예: 암호화 파일 손상) 오류 줄에 `잠금 해제에 실패했습니다: {오류 메시지}` 를 보이고 입력창은 그대로 둔다.
- 버튼 "열기" — 입력이 비었거나 확인 중이면 비활성. 확인 중 글자는 "확인 중..."
- **볼트 상태의 `osUnlockEnabled` 가 true 일 때만** 추가 버튼(방패 아이콘)을 보인다(`osUnlockAvailable` 은 보지 않음). 버튼: Windows 는 "Windows 로그인으로 열기". 실패하면 오류 "Windows 자동 잠금해제에 실패했습니다"
- 링크 버튼 "비밀번호를 잊으셨나요? 복구 코드로 재설정" → 복구 코드로 재설정 모드(입력값·오류 초기화)

## 2. 최초 설정

- 제목 "DariTerm 처음 설정"
- 안내: "서버 ID·비밀번호·키는 이 앱 잠금 비밀번호로 AES-256 암호화되어 이 PC에만 저장됩니다. 앱 잠금 비밀번호는 어디에도 전송되지 않습니다."
- 입력창 "앱 잠금 비밀번호 (8자 이상)", "비밀번호 확인"
- 비밀번호를 입력하면 **강도 막대**와 "강도: {라벨}" 표시. 점수는 다음 조건을 각각 1점씩 더하고 최대 4로 자른다: 8자 이상 / 12자 이상 / 대문자·소문자 모두 포함 / 숫자 포함 / 영숫자 외 문자 포함. 라벨 0~4 = 매우 약함, 약함, 보통, 강함, 매우 강함. 막대 너비 = (점수+1)×20%, 색 = 점수별 `#ef4444` `#f97316` `#f59e0b` `#22c55e` `#10b981`.
- 제출 시 검사: 8자 미만이면 "8자 이상 입력하세요", 두 값이 다르면 "비밀번호가 일치하지 않습니다"
- 버튼 "앱 잠금 비밀번호 만들기", 진행 중 "암호화 키 생성 중..."
- 성공하면 복구 코드 표시 모드로 간다. 실패하면 오류 메시지 표시.

## 3. 복구 코드 표시

- 제목 "복구 코드"(열쇠 아이콘)
- 안내: "앱 잠금 비밀번호를 잊었을 때 이 코드로만 복구할 수 있습니다. 인쇄하거나 안전한 곳에 적어 두세요. 이 화면을 닫으면 다시 볼 수 없습니다."
- 복구 코드 표시(고정폭 글꼴). 형식: 영숫자 24자를 4자씩 하이픈으로 나눔 (`XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`), 알파벳은 혼동되는 글자(I, O, 0, 1)를 뺀 대문자와 숫자.
- 버튼 "복사" → 클립보드에 복사하고 토스트(ok) "복구 코드를 복사했습니다"
- 체크박스 "복구 코드를 안전한 곳에 저장했습니다" — 체크해야 "시작하기" 버튼 활성
- "시작하기" → 상태를 새로 읽어 앱 진입 (이 시점에 볼트는 열린 상태)

## 4. 복구 코드로 재설정

- 제목 "복구 코드로 비밀번호 다시 정하기"
- 안내: "앱 잠금 비밀번호를 만들 때 받은 24자리 복구 코드와 새 앱 잠금 비밀번호를 입력하세요. 저장된 계정은 그대로 유지됩니다."
- 입력창: 복구 코드(고정폭, 입력하는 즉시 대문자로 변환하되 **하이픈은 자동으로 넣지 않는다** — 제출할 때 하이픈·공백·탭은 백엔드가 제거, 플레이스홀더 "XXXX-XXXX-XXXX-XXXX-XXXX-XXXX"), "새 앱 잠금 비밀번호", "새 비밀번호 확인"
- 제출 검사: 새 비밀번호 8자 미만 "새 비밀번호는 8자 이상이어야 합니다", 불일치 "새 비밀번호가 일치하지 않습니다", 복구 코드 틀림 "복구 코드가 올바르지 않습니다"
- 버튼 "다시 정하기", 링크 "뒤로"(잠금 해제 모드로, 오류 초기화)
- 성공하면 새 비밀번호로 볼트가 열린 상태로 앱에 진입.
