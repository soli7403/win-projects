## 1. 로컬 터미널에서 파일 패널

- 포커스 칸이 **연결된 로컬 터미널**이면 SFTP 패널은 **이 PC 의 파일시스템**을 보여준다. 패널 머리 제목은 "SFTP" 대신 **"파일"**(같은 폴더 트리 아이콘).
- 패널을 쓸 수 있는 세션: 연결된 SSH 세션, 연결된 로컬 터미널. 그 밖(텔넷·시리얼)은 안내 문구 "파일 창은 SSH·로컬 터미널 세션에서만 사용할 수 있습니다." 다음 줄 "(TELNET 세션)" 처럼 프로토콜 대문자.
- 세션이 없을 때 안내: "세션을 선택하면 해당 서버(또는 이 PC)의 파일이 표시됩니다."
- 처음 여는 폴더: 그 로컬 서버 설정의 **시작 폴더**(설정 안 됐거나 폴더가 없으면 사용자 홈). 같은 세션은 마지막으로 본 폴더를 기억한다(SSH 와 같음).
- 홈 버튼: 사용자 홈. 경로 입력칸: Windows 경로(`C:\Users\…`, `D:\`)와 `~`, `~\하위` 를 받는다. 다른 드라이브는 경로 입력칸에 직접 입력한다.
- 상위 폴더 버튼: 드라이브 루트(`C:\`)·`/` 에서는 비활성. Backspace 도 같다.
- 경로 구분자는 이 PC 의 것(Windows `\`)을 쓴다. 새 폴더·이름 바꾸기도 그 구분자로 경로를 만든다.
- 행 우클릭 메뉴 차이 (로컬일 때):
  - "다운로드..." → **"다른 폴더로 복사..."** (폴더 선택 후 복사, 완료 토스트 "복사 완료 → <폴더>")
  - "이 PC 앱으로 편집 (저장하면 자동 업로드)" → **"기본 앱으로 열기"** (파일을 그 자리에서 OS 기본 프로그램으로 연다, 토스트 없음)
  - Windows 에서는 "권한 변경" 항목을 **보이지 않는다**
  - 삭제 확인 문구의 "서버에서" → "이 PC에서"
- 도구 막대 업로드 버튼 툴팁: 로컬이면 "파일 가져오기 (이 폴더로 복사)". 빈 폴더 문구의 "업로드됩니다" → "복사됩니다".
- "경로를 터미널에 입력"·"터미널을 이 폴더로 이동 (cd)": 로컬 Windows 는 공백·`& ( ) ^ % ! ' " ; ,` 가 있으면 **큰따옴표**로 감싼다(SSH 는 기존 규칙).
- 칸 우클릭 메뉴 "SFTP 창 열기" 는 로컬 칸에서 **"파일 창 열기"** 로 보이고 활성화된다.

## 2. 끌어 놓기 복사

### 2.1 끌기 시작
- 파일 패널의 행은 끌 수 있다. 선택된 행을 끌면 **선택된 항목 전부**, 선택 안 된 행을 끌면 그 행만(그 행이 선택된다).

### 2.2 다른 탭으로 옮겨 가기
- 끌고 있는 동안 **탭 막대의 탭** 위에 **0.5초** 머물면 그 탭이 활성 탭이 된다(그 그룹의 파일 패널이 그 탭 포커스 칸의 세션으로 바뀐다). 탭 위에 있는 동안 탭에 점선 테두리(강조색 1px, 안쪽 2px).
- **분할 칸** 위에 0.5초 머물면 그 칸에 포커스(패널이 그 세션으로 바뀜). 빈 칸은 반응하지 않는다.
- 다른 **탭 그룹**의 파일 패널 위로 바로 가져가도 된다.

### 2.3 놓는 위치와 대상 폴더
| 놓은 곳 | 대상 폴더 |
|---|---|
| 폴더 행 | 그 폴더 **안** |
| 파일 행 | 그 파일이 있는 폴더(= 패널의 현재 폴더) |
| 목록 빈 곳 | 패널의 현재 폴더 |
| 탭 막대의 탭 | 그 탭 포커스 칸 세션에서 마지막으로 본 폴더(없으면 시작 폴더) |
| 분할 칸 | 그 칸 세션의 마지막 폴더(없으면 시작 폴더) |

- 목록 위에 있는 동안 기존 놓기 안내 상자를 보이고 문구는 "여기에 놓으면 <대상 폴더> (으)로 복사". 폴더 행 위면 그 행에 점선 테두리 + 선택 배경색.
- 대상 세션이 파일 패널을 쓸 수 없으면(연결 안 됨, 텔넷·시리얼) 토스트(오류) "이 탭에는 복사할 수 없습니다 (연결된 SSH 또는 로컬 터미널만 가능)".
- **무시**(아무 일 없음): 같은 세션의 같은 폴더에 놓음, 끌던 폴더 자신 위에 놓음.
- OS 탐색기에서 끌어 온 파일은 기존대로 업로드(로컬 패널이면 복사)하되, 폴더 행에 놓으면 그 폴더 안으로.

### 2.4 이름 충돌·특수 경우
- 대상 폴더에 같은 이름이 하나라도 있으면 **아무것도 시작하지 않고** 확인 대화상자: 제목 "덮어쓰기", 본문 "대상 폴더에 같은 이름이 있습니다: <이름들>" 다음 줄 "덮어쓸까요?", 위험 버튼 "덮어쓰기". 이름은 최대 5개, 넘으면 " 외 N개". 확인하면 덮어쓰며 시작, 취소하면 끝.
- **같은 파일시스템에서 원래 자리**로 복사하게 되면 새 이름 "이름 (1).확장자"(폴더는 "이름 (1)"), 이미 있으면 (2), (3)…. 확인 없이 진행.
- 폴더를 **자기 자신이나 그 하위**로 복사하면 거부: 토스트(오류) "복사 실패: 폴더를 자기 자신 안으로 복사할 수 없습니다: <이름>".
- 같은 파일시스템 판정: 로컬끼리는 같음. SSH 는 **접속 대상(사용자@호스트:포트)이 같으면 같은 파일시스템**으로 본다(같은 서버를 연 두 탭 사이 복사에서 원본을 자기 자신에 덮어쓰지 않기 위해). Windows·macOS 로컬은 경로 대소문자를 구분하지 않고 비교.
- 대상 폴더가 없으면 토스트(오류) "복사 실패: 대상 폴더가 없습니다: <경로>".

### 2.5 복사 방식
- 복사는 **백그라운드**에서 한다. 놓으면 바로 다음 조작이 가능하다.
- 항상 **바이너리 그대로** 복사한다: 줄바꿈(CRLF/LF)·인코딩 변환 없음. 한 바이트도 바뀌면 안 된다.
- 폴더는 안의 내용까지 재귀 복사. 심볼릭 링크는 따라가서 내용을 복사한다.
- 경로별 방식:
  | 원본 → 대상 | 방식 |
  |---|---|
  | 로컬 → 로컬 | PC 안 복사 |
  | 로컬 → 서버 | 업로드 |
  | 서버 → 로컬 | 다운로드 |
  | 서버 → 서버 (같은 서버 포함) | **이 PC 임시 폴더를 거친다**: 원본 서버에서 임시 폴더로 받기 → 대상 서버로 올리기 → 임시 사본 삭제(성공·실패·취소 모두) |
- 임시 폴더: 설정 "서버 간 복사용 임시 폴더"(§4). 비어 있으면 OS 임시 폴더 아래 `dariterm-transfer`. 작업마다 그 아래 새 하위 폴더를 만들어 쓰고 끝나면 지운다. 만들 수 없으면 작업 실패 "임시 폴더를 만들 수 없습니다 (<경로>): <원인>".
- 한 세션에 대한 전송(업로드·다운로드·복사 작업)은 **세션마다 하나씩 차례로** 한다. 두 세션이 걸린 작업은 두 세션 모두 차례를 기다린다(교착 없이). 기다리는 동안 상태는 "대기 중".
- 끌어 놓기 복사는 파일별 전송 항목을 패널의 전송 목록에 올리지 **않는다**(§3 의 한 줄만).

## 3. 복사 작업 목록 (창 맨 아래)

- 위치: 창 맨 아래, **상태 표시줄 바로 위**, 전체 폭. 작업이 하나도 없으면 보이지 않는다.
- 배경 bg-2, 위 테두리 1px border, 글자 12px.
- 머리 줄(높이 약 20px, 11.5px, text-2): 복사 아이콘(12) + "복사 N개 진행 중"(진행 중이 없으면 "복사 완료") + 끝난 작업이 있으면 " · 끝남 M개", 오른쪽 끝 링크 "끝난 항목 지우기"(끝난 작업 모두 제거).
- 목록: **끌어 놓기 한 번 = 한 줄**(폴더 하나를 끌어도 한 줄, 여러 항목을 한 번에 끌어도 한 줄). 오래된 것이 위. 최대 높이 132px, 넘치면 스크롤.
- 줄(높이 24px, 좌 10px 우 6px 여백, 간격 6px, 호버 시 bg-hover), 왼쪽→오른쪽:
  1. 상태 아이콘 13px: 진행·대기 = 회전 로더, 완료 = 체크(ok 색), 실패 = 경고(danger 색), 취소 = 금지 표시
  2. 이름(굵게, 최대 폭 22%, 말줄임): 첫 항목 이름, 여러 개면 "<첫 이름> 외 N개"
  3. 원본 "<원본 탭 제목>: <원본 폴더>" (text-2, 말줄임, 남는 폭을 대상과 반씩)
  4. 오른쪽 화살표 12px (text-3)
  5. 대상 "<대상 탭 제목>: <대상 폴더>" (같은 모양)
  6. 상태 글(11.5px, text-3):
     - 대기: "대기 중"
     - 진행: "<단계> · <끝난 파일 수>/<전체 파일 수>개 · <보낸 크기>/<전체 크기> · <퍼센트>%"
       - 단계: 크기를 세는 중 "크기 확인 중", 로컬 관련 복사 "복사 중", 서버→서버의 받기 "임시 폴더로 받는 중", 올리기 "대상으로 올리는 중"
       - 크기·퍼센트는 **작업 전체** 기준(폴더 안 모든 파일 합). 서버→서버는 받기+올리기를 합쳐 0→100% 로 한 번 진행하고, 보이는 크기는 원본 크기 기준.
       - 파일 수는 올리기(또는 복사)로 끝난 파일만 센다.
     - 완료: "완료 · <파일 수>개 · <전체 크기>"
     - 취소: "취소됨"
     - 실패: "실패: <원인>" (danger 색, 최대 폭 30% 말줄임)
  7. 진행 막대 90×4px(radius 3, 바탕 bg-3, 채움 accent / 완료 ok / 실패·취소 danger)
  8. 진행·대기 중이면 작은 글자 버튼 **"취소"**(높이 20px, 툴팁 "취소"), 끝났으면 작은 아이콘 버튼 X(12) **목록에서 지우기**(툴팁 "끝난 항목 지우기")
- 줄 툴팁: 이름, 원본, "→ 대상", 서버→서버면 "(이 PC 임시 폴더 경유)", 실패면 원인.
- 진행 갱신은 최소 150ms 간격. 상태가 바뀌면 즉시.
- 창 폭 720px 이하에서는 원본·화살표·대상을 숨긴다.
- 취소: 지금 쓰던 파일은 대상에 중간까지 남을 수 있다(지우지 않는다). 이미 끝난 파일은 그대로.
- 개별 파일이 실패하면 **작업 전체를 멈추고** 실패로 표시한다.
- 작업이 **완료**되면, 그 대상 세션의 패널이 대상 폴더(또는 그 하위)를 보고 있으면 목록을 새로고침한다.

## 4. 설정·데이터

- 설정 화면 "파일 전송" 구획, "서버에 올릴 폴더"와 "오래된 업로드 자동 삭제" 다음에 항목 추가:
  - 이름 **"서버 간 복사용 임시 폴더 (이 PC)"**
  - 고정폭 입력칸(남는 폭) + 오른쪽 작은 버튼 "찾아보기…"(폴더 선택 대화상자, 고르면 입력칸에 채움)
  - 빈 값일 때 자리 표시 "(OS 임시 폴더)\dariterm-transfer"
  - 도움말 "서버→서버 복사는 이 PC 폴더로 먼저 받은 뒤 대상 서버로 올리고, 끝나면 임시 파일을 지웁니다. 비우면 OS 임시 폴더를 씁니다."
  - `~` 는 이 PC 사용자 홈.
- 저장: 설정 키 **`transferTempDir`**, 기본값 빈 문자열 (data/store.md 의 설정 표에 추가).

## 6. 수용 시나리오

1. 로컬 터미널(시작 폴더 `C:\Work`) 창에 포커스 → 창 제목 "파일", 목록이 `C:\Work`.
2. 로컬 패널에서 `C:\` 로 이동 → 상위 폴더 버튼 비활성. 경로칸에 `D:\` 입력 + Enter → D 드라이브 목록.
3. SSH 탭 A 패널에서 `report.pdf` 를 끌어 로컬 탭 위에 0.5초 → 로컬 탭 활성, 로컬 창의 `Downloads` 폴더 행에 놓음 → 맨 아래에 "report.pdf  A: /home/u → 로컬 터미널: C:\…\Downloads" 한 줄, 완료 후 바이트 단위로 원본과 같음.
4. 폴더 `proj`(파일 120개)를 서버 A → 서버 B 로 끌어 놓음 → 줄 하나만 생기고 "임시 폴더로 받는 중 · 0/120개 …" → "대상으로 올리는 중 · n/120개 …" → "완료 · 120개 · <크기>". 임시 폴더에 남은 것이 없음.
5. 같은 폴더를 다시 B 에 놓음 → "덮어쓰기" 확인. 취소 → 아무 일 없음.
6. 파일 행 위에 놓음 → 그 파일이 있는 폴더로 복사(파일을 덮어쓰지 않음).
7. 진행 중 X → "취소됨", 서버→서버면 임시 폴더 정리됨.
8. 두 번 연속 끌어 놓기 → 두 줄. 같은 세션이 걸리면 두 번째는 "대기 중" 이다가 첫 번째가 끝나면 진행.
9. 같은 서버를 연 탭 두 개 사이에서 같은 폴더로 놓음 → 덮어쓰지 않고 "이름 (1)" 로 생김.
10. CRLF·LF·NUL·0xFF 가 섞인 파일을 로컬→서버→서버→로컬로 복사 → 원본과 바이트 동일.
11. 설정에서 임시 폴더를 `E:\tmp` 로 바꾸고 서버→서버 복사 → 진행 중 `E:\tmp` 아래 하위 폴더가 생겼다가 끝나면 사라짐.
12. 텔넷 탭 위에 놓음 → 오류 토스트 "이 탭에는 복사할 수 없습니다 (연결된 SSH 또는 로컬 터미널만 가능)".
