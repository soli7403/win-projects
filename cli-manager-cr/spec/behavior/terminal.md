# 터미널 동작 — 입력·붙여넣기·복사·위험 명령 가드

> 작성 방식: 기존 앱 실행 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**. 터미널 화면 자체는 공개 라이브러리 xterm.js(WebGL 렌더러 우선, 실패 시 DOM 렌더러)를 쓴다.

## 1. 터미널 표시 옵션

설정(data/store.md §4)이 바뀌면 **열려 있는 모든 터미널에 즉시 적용**하고 크기를 다시 맞춘다.

| 항목 | 값 |
|---|---|
| 글꼴·크기·줄 간격 | 설정값 |
| 커서 모양·깜빡임 | 설정값 |
| 스크롤백 | 설정값 |
| 색 | 설정의 터미널 테마(없는 이름이면 `TermGo Dark`) |
| 글자 폭 | 유니코드 11 기준(한글·CJK 전각 폭) |
| 굵은 글씨 | 밝은 색으로 그림 |
| 최소 대비 | 1(보정 없음) |
| 부드러운 스크롤 | 끔 |
| Alt+클릭 | 커서를 그 위치로 이동 |
| 우클릭 | 단어 선택 안 함 |
| 화면 유지 | 다른 탭에 갔다 오거나 칸을 분할·크게 보기·다른 그룹으로 옮겨도 화면 내용·스크롤백이 그대로이고, 안 보이는 동안의 출력도 쌓인다. 세션(칸·탭)을 닫을 때만 버린다 (D57) |
| 입력 포커스 | 탭을 누르거나 서버를 열면(이미 열린 세션으로 옮겨 가는 경우 포함) 그 탭의 포커스 칸 터미널로 바로 입력된다 (D57) |
| 마우스 모드(tmux 등) 중 글자 선택 | Shift+드래그로 선택 |
| 링크 | 터미널 안 URL 은 **Ctrl+클릭**으로 기본 브라우저에서 연다 |
| 벨 | 설정 "경고음"가 켜져 있을 때만 짧은 소리 |

- 터미널 크기(열×행)가 바뀌면 백엔드에 새 크기를 알린다. 숨겨져 있거나 너무 작은(가로·세로 20px 미만) 영역에서는 맞추지 않는다.
- 터미널 입력의 이진 데이터(마우스 보고 등)는 변환 없이 백엔드로 보낸다.
- **출력 수신**: 세션 출력은 해당 터미널에 기록한다. 그 세션이 **현재 활성 탭에 보이지 않는 상태**이면 "활동" 표시를 켠다(탭 점·ui/shell.md §2.1).
- 칸을 옮기거나 확대·복원하면 같은 세션의 터미널 화면 내용이 그대로 유지된다(새로 그리지 않고 옮겨 붙임). 세션이 사라지면 그 터미널을 폐기한다.
- 대화상자가 모두 닫히면 30ms 뒤 포커스된 칸 터미널에 입력 포커스를 준다(모달이 남아 있으면 주지 않는다).

## 2. 키 입력 처리 (Windows)

1. **Shift+Enter**(다른 보조키 없이) + 설정 "Shift+Enter 로 줄바꿈"이 켜져 있으면: 서버로 `ESC` + `CR`(Alt+Enter 와 같은 신호)을 보내고 일반 Enter 는 보내지 않는다.
2. **Ctrl+Shift+C**: 선택이 있으면 클립보드에 복사. 터미널로는 보내지 않는다.
3. **Ctrl+C**(Shift·Alt 없이): **선택이 있으면** 복사하고 선택을 해제하며 터미널로 보내지 않는다. 선택이 없으면 터미널로 전달(중단 신호).
4. **붙여넣기**: Ctrl+Shift+V, Shift+Insert, 그리고 설정 "Ctrl+V로 붙여넣기"가 켜져 있을 때 Ctrl+V → 붙여넣기 흐름(§4). 설정이 꺼져 있으면 Ctrl+V 는 서버로 전달.
5. **Ctrl+Alt+V**: 클립보드 이미지 붙여넣기(§4, 이미지 강제).
6. 앱 단축키(behavior/shortcuts.md)와 Ctrl+Shift+M 은 터미널로 보내지 않는다(Ctrl+Shift+M 은 예약만, 동작 없음). 나머지는 모두 터미널로 전달.
7. **복사**: 선택이 바뀔 때마다 설정 "드래그하면 바로 복사"가 켜져 있고 선택이 비어 있지 않으면 즉시 클립보드에 복사한다.

## 3. 입력 전달과 동시 입력

- 터미널에서 나온 입력은 그 세션의 서버로 전달한다.
- 그 세션이 속한 탭이 **동시 입력**이면 탭 안의 **연결된 모든 세션**(입력이 발생한 세션 포함)으로 같은 입력을 보낸다.

## 4. 붙여넣기 흐름

**(a) 이미지 강제**(Ctrl+Alt+V, 칸 머리글 이미지 버튼, 우클릭 메뉴): 클립보드에 이미지가 있으면 "이미지 올리기"(§5)를 실행, 없으면 정보 토스트 "클립보드에 이미지가 없습니다".

**(b) 일반 붙여넣기**: 클립보드 내용을 읽어 종류별로 처리한다.
1. **파일 목록**이면 → 파일 올리기(§5).
2. **이미지**이면 → 이미지 올리기(§5).
3. **텍스트**가 아니거나 비었으면 → 아무 일 없음.
4. 텍스트이면(끝의 줄바꿈 하나를 뺀 뒤 줄바꿈으로 나눠 줄 수를 센다):
   - **위험 가드**가 켜져 있고(§6) 텍스트가 위험 패턴과 일치하면 확인 대화상자: 제목 "운영 서버 위험 명령 붙여넣기", 본문 `[{세션 제목}] 붙여넣을 내용에 위험한 명령이 있습니다.`, 상세=내용 앞 2000자, 확인 "붙여넣기", 위험. 취소하면 붙여넣지 않고 터미널에 포커스.
   - 아니면 설정 "여러 줄 붙여넣기 전에 묻기"이 켜져 있고 **2줄 이상**이고 **터미널 프로그램이 bracketed paste 모드를 켜지 않았으면** 확인: 제목 "여러 줄 붙여넣기", 본문 `{줄 수}줄을 [{세션 제목}]에 붙여넣습니다. 각 줄이 명령으로 실행될 수 있습니다.`, 상세=내용 앞 2000자, 확인 "붙여넣기"(일반색). 취소하면 붙여넣지 않음.
   - 통과하면 텍스트를 붙여넣는다(터미널의 붙여넣기 기능 사용 — 프로그램이 bracketed paste 를 켰으면 그 표식으로 감싸 전달). 그 뒤 터미널에 포커스.

## 5. 이미지·파일 올리기와 경로 입력

대상 세션 종류에 따라:

- **로컬 세션**: 이미지는 이 PC에 파일로 저장하고 그 경로를, 파일은 원래 경로를 입력한다. 실패하면 오류 토스트(오류 메시지).
- **SSH 연결됨(SFTP 가능)**: 정보 토스트 `{라벨} 서버로 전송 중...` → 서버의 업로드 폴더(설정)에 올림 → 올린 파일의 서버 경로들을 입력 → 성공 토스트 `{라벨} 전송 완료 → {경로, 경로…}`. 실패하면 오류 토스트 `전송 실패: {오류}`.
- **그 외**(연결 안 됨, Telnet·시리얼 등): 파일이면 **올리지 않고** 원래 경로를 입력, 이미지면 오류 토스트 "이미지 전송은 연결된 SSH 세션에서만 가능합니다".
- **라벨**: 클립보드 이미지 = "클립보드 이미지", 파일 1개 = 파일 이름, 여러 개 = `파일 {n}개`.
- **경로 입력 형식**: 설정 "공백이 있는 경로는 따옴표로 감싸기"가 켜져 있으면 공백·특수문자(`'` `"` `$` `` ` `` `\` `(` `)` `&` `;` `|` `<` `>` `*` `?` `!` `#`)가 있는 경로를 작은따옴표로 감싼다(경로 안 `'` → `'\''`). 여러 경로는 공백으로 잇고 **끝에 공백 하나**를 붙인다. 입력은 **붙여넣기 방식(bracketed paste)** 으로 해서, Claude Code 같은 CLI 가 이미지 경로를 끌어다 놓은 파일처럼 처리하게 한다. 입력 후 터미널에 포커스.
- 서버의 업로드 폴더가 없으면 자동으로 만든다. 올리는 파일 이름은 `tg-` 로 시작한다(설정 "오래된 업로드 자동 삭제"의 대상 식별, ui/settings.md §3).

## 6. 운영 서버 위험 명령 가드

**활성 조건**: 설정 "운영 서버 위험 명령 경고"이 켜져 있고, 해당 세션의 환경이 `prod`(운영) 일 때.

**입력 줄 추적**(최선 노력, 터미널이 일반 화면일 때만; 대체 화면(vim 등)에서는 추적하지 않음):
- 인쇄 가능한 문자 입력(공백 이상, 한글 등 포함)은 줄에 덧붙인다.
- Backspace 는 마지막 글자를 지운다.
- Ctrl+C, Ctrl+U 는 줄을 비우고 "알 수 없음" 표시도 해제한다.
- 그 외 제어 입력(방향키, 탭 완성, 히스토리 등)은 줄을 **"알 수 없음"** 으로 표시한다.
- Enter 를 누르면: 줄이 "알 수 없음"이 아니고 비어 있지 않으며 **위험 패턴 중 하나와 일치**(대소문자 무시 정규식, 잘못된 정규식은 건너뜀)하면, Enter 를 **보내지 않고** 확인 대화상자를 띄운다: 제목 "운영 서버 위험 명령", 본문 `[{세션 제목}] 운영 서버에서 실행하려는 명령입니다. 정말 실행할까요?`, 상세=입력한 줄, 확인 "실행"(위험색). 확인하면 Enter 를 (동시 입력 규칙대로) 보내고, 취소하면 아무것도 보내지 않는다. 어느 쪽이든 줄 추적은 초기화되고 터미널에 포커스. **확인 대화상자는 한 번에 하나만** 뜬다(떠 있는 동안의 Enter 는 처리하지 않음).
- 일치하지 않거나 추적할 수 없으면 Enter 는 그대로 전달.

> 한계: 줄 추적은 완벽하지 않다(히스토리·붙여넣기로 만든 줄은 "알 수 없음"으로 통과). 붙여넣기는 §4 에서 별도로 검사한다.

## 7. 스니펫 입력

- 대상: 현재 포커스된 칸의 세션(동시 입력 규칙 적용). 포커스된 세션이 없으면 정보 토스트 "먼저 세션을 선택하세요".
- 본문의 모든 줄바꿈을 CR 로 바꿔 보내고, "입력하고 바로 실행"이 켜져 있으면 끝에 CR 을 더한다. 입력 후 터미널에 포커스.

## 8. OSC 52 (원격 → 로컬 클립보드)

- 설정 "서버의 클립보드 쓰기 허용 (OSC 52)"이 꺼져 있으면 모두 무시.
- 켜져 있으면 **쓰기 요청만** 처리한다: 내용이 비었거나 `?`(읽기 요청)이면 무시(읽기는 항상 거절). base64 로 인코딩된 UTF-8 텍스트를 풀어 **1,000,000자 이하일 때만** 이 PC 클립보드에 쓴다. 잘못된 base64 는 조용히 무시.

## 모든 창 동시 입력 (쇠사슬, 2026-11-12 사용자 요청)

- 왼쪽 위 아이콘 묶음(서버 목록 · 스니펫 · **동시 입력** · 잠그기 · 설정)에 쇠사슬 아이콘. 꺼짐 = 끊어진 쇠사슬(툴팁 "일괄 입력 꺼짐 — 누르면 보이는 모든 창에 같이 입력합니다"), 켜짐 = 이어진 쇠사슬 + 경고색 배경(warn-soft, 아이콘 warn, 툴팁 "일괄 입력 켜짐 — 보이는 모든 창에 같이 입력합니다 (누르면 끄기)").
- 누를 때 토스트(info): 켜면 "일괄 입력을 켰습니다 — 보이는 모든 창에 같이 입력됩니다", 끄면 "일괄 입력을 껐습니다 — 창마다 따로 입력합니다".
- 켜져 있으면 어느 창에서 입력하든(타이핑·Enter·붙여넣기·이미지/파일 붙여넣기 경로 입력 포함) **지금 화면에 보이는 모든 창**에 같은 입력을 보낸다: 탭 그룹마다 선택된 탭의 칸 전부(크게 보기 중이면 그 칸만), 빈 칸 제외. 숨은 탭의 창에는 보내지 않는다.
- 위험 명령 가드(운영 환경)는 그대로 적용되고, 확인하면 대상 모든 창에 Enter 를 보낸다.
- 켜져 있는 동안 대상 창의 칸 머리 제목 오른쪽에 작은 쇠사슬(12px, warn 색).
- 탭 단위 "이 탭의 모든 창에 일괄 입력" 과는 별개이며, 쇠사슬이 켜져 있으면 쇠사슬 규칙이 우선한다.
- 저장하지 않는다: 앱을 시작하면 항상 꺼짐(실수로 여러 서버에 입력하는 것을 막기 위해).
