# 다국어 (화면·안내 문구의 언어)

> 작성 방식: 사용자 요청에 따른 신규 기능(원본 앱에 없음, 결정 D75). 작성일 2026-11-14. 상태: **ready**.

## 1. 지원 언어

10개. 언어 선택 목록에 이 순서·이 이름(그 언어로 쓴 이름)으로 보인다.

| id | 이름 | BCP 47 |
|---|---|---|
| en | English | en |
| ko | 한국어 | ko |
| ja | 日本語 | ja |
| zh | 简体中文 | zh-CN |
| tw | 繁體中文 | zh-TW |
| de | Deutsch | de |
| fr | Français | fr |
| es | Español | es |
| pt | Português (Brasil) | pt-BR |
| ru | Русский | ru |

- 맞는 언어가 없을 때 쓰는 언어(대체 언어)는 **영어**다.
- 명세 문서의 화면 문구는 한국어 원문이다. 다른 언어 문구는 언어 파일(§4)이 정한다.

## 2. 첫 실행 언어 선택

- 설정 `language` 가 비어 있으면(처음 실행, 또는 이 기능 이전 버전에서 올라온 경우) **잠금·처음 설정 화면보다 먼저** 언어 선택 화면을 보인다.
  - 카드 가운데 로고, 제목 "언어를 선택하세요", 안내 "나중에 설정 > 화면 > 언어에서 바꿀 수 있습니다.", 언어 10개(두 줄 격자), [계속].
  - OS 언어(§3)에 맞는 항목이 미리 골라져 있다. 항목을 누르면 화면 문구가 즉시 그 언어로 바뀐다(미리 보기).
  - [계속]을 누르면 `language` 에 저장하고 원래 흐름(잠금 또는 처음 설정)으로 간다.
- 고르기 전에도 화면은 OS 언어로 보인다.

## 3. OS 언어 맞추기

- OS 언어 태그 목록(우선순위 순)을 앞에서부터 보고 **처음 맞는 지원 언어**를 쓴다. 하나도 없으면 영어.
  - Windows: 사용자 표시 언어 목록. macOS: 시스템 언어 목록(AppleLanguages) → LANG. 그 외: LC_ALL → LC_MESSAGES → LANGUAGE → LANG.
  - 백엔드가 맞춘 값을 `app.info` 의 `osLanguage` 로 알려 준다. 비어 있으면 웹뷰 언어(navigator.languages)로 맞춘다.
- 태그 해석: 대소문자 무시, `_` 는 `-` 로, `.` 뒤(인코딩)는 버린다. 첫 부분으로 고르되
  - `zh` 는 `Hant`·`TW`·`HK`·`MO` 가 붙으면 `tw`, 아니면 `zh`.
  - `pt` 는 지역과 관계없이 `pt`.
- 예: `ko-KR`→ko, `zh-Hans-CN`→zh, `zh-Hant-HK`→tw, `pt-PT`→pt, `de_DE.UTF-8`→de, `it-IT`→en, [`it-IT`,`fr-FR`]→fr.

## 4. 언어 파일

- 저장소 루트 `locales/<id>.json` 10개. 평평한 `키 → 문구` 객체. 화면(프런트엔드)과 백엔드 문구(오류·터미널 안내·대화상자 제목·종료 확인)가 같은 파일을 쓴다.
- 기준은 `ko.json` 이다. 다른 언어 파일은 같은 키를 모두 가져야 하고, 빈 문구가 없어야 하며, 자리표시자 `{이름}` 이 같아야 한다(검사 테스트).
- 문구 안의 꾸밈은 `<b>굵게</b>`, `<k>키·입력 예시</k>` 두 가지만 쓴다.
- 어떤 언어에 키가 없으면 영어 → 한국어 → 키 순서로 대신 보인다.
- 문구를 고칠 때는 언어 파일만 고친다(빌드할 때 실행 파일에 들어간다).

## 5. 언어 바꾸기

- 설정 > 화면 맨 위 "언어"(목록 선택). 바꾸면 **즉시** 화면 전체와 백엔드 문구가 그 언어로 바뀐다. 열린 터미널·세션은 그대로 둔다.
- 이미 화면에 찍힌 터미널 안내 줄, 가져오기로 만든 폴더 이름은 바꾸지 않는다.
- 앱이 자동으로 붙인 탭·세션 이름("로컬 터미널")은 저장된 언어와 관계없이 **지금 언어로 보인다**(저장 값은 그대로, 그릴 때만). 사용자가 지은 이름은 그대로.
- 날짜·시각 표시는 그 언어의 형식을 따른다.
- 입력 별칭(빠른 연결의 "로컬"·"터미널", 가져오기 이름 접두 "운영"·"개발" 등)은 언어와 관계없이 그대로 인식한다.
