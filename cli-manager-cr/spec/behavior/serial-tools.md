# 시리얼 도구: HEX 보기·HEX 보내기·XMODEM

> 작성: 2026-11-28, 이 저장소에서 새로 설계한 기능(기존 앱에 없음, D163·D164). 작성 방식: 새 설계.
> 메뉴는 **시리얼 칸의 우클릭 메뉴**에만 둔다("창 다시 연결" 위, 구분선 뒤). 연결된 동안만 누를 수 있다. 백엔드 동작은 세션 종류와 상관없다.

## 1. HEX 보기 (메뉴 "HEX 로 보기" ↔ "글자로 보기")

- 켜면 그때부터 받은 바이트를 글자로 풀지 않고 한 줄 16바이트로 보인다: `41 42 0D 0A ` + 남은 자리 공백 + ` |AB..|`(0x20~0x7E 만 그대로, 나머지 `.`), 줄 끝 CRLF. **받은 조각마다 새 줄**에서 시작한다(장치의 응답 단위가 보이게).
- 이미 화면에 있는 출력은 바꾸지 않는다. 세션 로그에도 HEX 줄로 남는다. HEX 보기 중에는 로그인 스크립트가 출력을 보지 않는다.
- 상태는 세션 정보 `hexView`(켜졌을 때만 실림)로 알리고 메뉴 이름이 바뀐다. 다시 연결해도 유지, 세션을 닫으면 사라진다(저장하지 않는다).
- 키보드 입력은 평소대로 보낸다.

## 2. HEX 보내기 (메뉴 "HEX 보내기…")

- 창 "HEX 보내기": 입력 한 줄(고정폭), 안내 "16진 바이트를 공백·쉼표로 띄우거나 붙여 적습니다. 예: 01 03 00 00 00 0A C5 CD", 아래에 바이트 수("{n}바이트") 또는 오류 문구, [닫기] [보내기]. Enter 도 보내기. 보낸 뒤 창은 열려 있다(같은 값을 되풀이해 보낼 수 있게).
- 입력 규칙: 공백·탭·줄바꿈·`,`·`:`·`;` 는 구분자, 낱말 앞의 `0x`/`0X` 는 뗀다, 한 글자 낱말은 앞에 0 을 붙인다(`A` → `0A`), 구분자 없이 붙은 낱말은 두 글자씩 끊는다(홀수면 오류), 16진이 아닌 글자가 있거나 바이트가 없으면 오류 "16진 바이트가 아닙니다 (예: 01 03 0A FF)".
- 보낸 바이트는 **인코딩을 거치지 않고** 그대로 간다. 파일 전송 중이면 오류 "다른 파일 전송이 진행 중입니다".

## 3. XMODEM (메뉴 "XMODEM 보내기…", "XMODEM-1K 보내기…", "XMODEM 받기…", "XMODEM 전송 취소")

- **보내기**: 파일 하나를 고른다(취소하면 아무것도 안 함). 터미널에 `XMODEM 보내기: {파일} — 장치에서 받기를 시작하세요 (Ctrl+C 로 취소)`. 장치가 받기를 시작하면(`C` = CRC, NAK = 체크섬) 블록을 보낸다. 블록은 128바이트(SOH), "1K" 는 받는 쪽이 CRC 를 고를 때만 1024바이트(STX, 끝의 128바이트 이하 조각은 128 블록). 마지막 블록은 0x1A 로 채우고 EOT 로 끝낸다. 장치가 **60초** 안에 시작하지 않으면 "장치가 XMODEM 전송을 시작하지 않았습니다".
- **받기**: 저장할 파일 이름을 고른다(기본 `xmodem.bin`). `XMODEM 받기: {파일} — 장치에서 보내기를 시작하세요`. `C` 를 3초 간격으로 3번, 그 뒤 NAK(체크섬)를 7번 보낸다(답이 없으면 시작 실패). 받는 동안은 `{파일}.dtpart` 에 쓰고 다 받으면 이름을 바꾼다(실패·취소면 지운다). **마지막 블록 끝의 0x1A 채움은 떼어 낸다**(XMODEM 은 파일 크기를 모른다 — 0x1A 로 끝나는 파일은 그 바이트가 빠진다, 알려진 한계).
- 블록마다 응답·블록 시한 10초, 깨진 블록·시한은 다시 보내 달라고(NAK) 하고 한 블록에 10번 넘게 실패하면 끝낸다. 같은 번호의 블록이 다시 오면(ACK 가 사라진 경우) ACK 만 한다. 번호가 건너뛰면 실패.
- 전송 중에는 받은 바이트를 모두 엔진이 가져가고(화면에 안 나옴) **터미널 입력은 보내지 않는다. Ctrl+C 또는 메뉴 "XMODEM 전송 취소" 는 취소**다(CAN 8개를 보낸다). 장치가 CAN 두 개를 보내면 "장치가 XMODEM 전송을 취소했습니다".
- 진행: 한 줄을 0.25초마다 고쳐 쓴다 `XMODEM 보내는 중: {파일} 12.0 KB / 40.0 KB (30%)`(받기는 전체 크기를 모른다). 끝: `XMODEM 전송 완료: {파일}, {크기}` / "XMODEM 전송을 취소했습니다" / "XMODEM 전송 실패: {까닭}". 연결이 끊기면 전송도 끝난다.
- 한 세션에 전송은 하나(ZMODEM 포함). 이미 전송 중이면 "다른 파일 전송이 진행 중입니다".
- YMODEM·Kermit 은 범위 밖.
