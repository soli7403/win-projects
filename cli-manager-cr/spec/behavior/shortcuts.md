# 단축키와 입력 규칙

> 작성 방식: 기존 앱 관찰 + 열람. 작성일 2026-11-10. 상태: **draft**. 1차 대상은 Windows(결정 D5). macOS 표는 후순위라 제외.

## 1. 일반 규칙

- 단축키는 **물리 키 기준**으로 인식한다. 문자·숫자 키는 키 위치로 판단하므로 한글 입력기가 켜져 있어도 동작한다.
- 인식한 단축키가 실제 동작을 했으면 그 키 입력은 터미널로 전달되지 않는다. 동작하지 않았으면(조건 불충족) 터미널이 받는다.
- **동작하지 않는 상황**: ① 볼트가 설정되어 있고 잠겨 있을 때 ② 대화상자가 열려 있을 때. 예외: **빠른 접속 대화상자가 열려 있을 때는 모든 단축키가 동작**하고, 전체 화면 전환(F11)은 어떤 대화상자가 열려 있어도 동작한다. (설정·서버 편집 등 다른 대화상자가 열려 있으면 F11 외에는 무시)

## 2. Windows 단축키 표

| 키 | 동작 | 조건·세부 |
|---|---|---|
| Ctrl+K | 빠른 접속 열기/닫기 | 이미 열려 있으면 닫는다 |
| Ctrl+Shift+T | 빠른 접속 열기/닫기 | Ctrl+K 와 같은 토글 |
| Ctrl+Shift+N | 빠른 접속 열기/닫기 | Ctrl+K 와 같은 토글 |
| Ctrl+Shift+P | 빠른 접속 열기 | 항상 열기(닫지 않음) |
| Ctrl+Alt+T | 새 로컬 터미널 | 빠른 접속이 열려 있으면 닫고 새 탭에 연다 |
| Ctrl+Shift+W | 포커스된 칸 닫기 | 칸 닫기 규칙은 ui/panes.md |
| Ctrl+Shift+D | 오른쪽 분할 | 포커스된 칸과 같은 서버로 연다 |
| Ctrl+Shift+E | 아래 분할 | 같은 서버로 연다 |
| Ctrl+Shift+Enter | 패널 확대/원복 | 칸이 2개 이상일 때만 |
| Ctrl+Shift+F | 터미널에서 찾기 | 포커스된 칸 대상 |
| Ctrl+Shift+S | SFTP 패널 열기/닫기 | |
| Ctrl+Shift+B | 동시 입력 켜기/끄기 | 칸이 2개 이상일 때만. 켜면 안내 토스트 "일괄 입력 켜짐 — 이 탭의 모든 창에 입력됩니다", 끄면 "일괄 입력 꺼짐" |
| Ctrl+Shift+L | 서버 목록 표시/숨김 | |
| Ctrl+Shift+← / → | 탭을 왼쪽/오른쪽으로 이동 | 끝에서는 아무 동작 없음 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음/이전 탭 | 처음·끝에서 순환 |
| Ctrl+1 ~ Ctrl+8 | 1~8번째 탭으로 | 해당 탭이 없으면 동작 없음 |
| Ctrl+9 | **마지막** 탭으로 | |
| Alt+방향키 | 인접 칸으로 포커스 이동 | 위치 기준 가장 가까운 칸. 없으면 동작 없음 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 글자 크기 +1 / −1 / 14로 초기화 | 범위 8~32, 설정에 저장 |
| F11 | 창 최대화 ↔ 복원 전환(진짜 전체 화면 아님) | 대화상자가 열려 있어도 동작 |

### 터미널 안에서의 붙여넣기·복사 (표시용 안내와 동작)

| 키 | 동작 |
|---|---|
| Ctrl+V | 붙여넣기. 클립보드에 이미지·파일이 있으면 서버(또는 이 PC)에 올리고 경로를 입력 |
| Ctrl+Alt+V | 클립보드 이미지를 서버로 올리고 경로 입력 |
| Ctrl+Shift+C | 복사. 설정 "선택하면 복사"가 켜져 있으면 선택만으로도 복사 |

## 3. 마우스 휠 글자 확대

- 터미널 칸 본문 위에서 **Ctrl 을 누른 채** 휠을 돌리면 글자 크기가 1씩 바뀐다 (위로 돌리면 +1, 아래로 −1, 범위 8~32). 이때 페이지 스크롤·브라우저 확대는 일어나지 않는다.
- 칸 본문 밖에서는 동작하지 않는다.

## 4. 화면에 표시하는 단축키 라벨 (Windows)

| 항목 | 표시 |
|---|---|
| 빠른 접속 / 명령 | Ctrl+K |
| 새 탭(빠른 접속) | Ctrl+Shift+T |
| 새 로컬 터미널 | Ctrl+Alt+T |
| 탭 닫기 | Ctrl+Shift+W |
| 오른쪽 분할 | Ctrl+Shift+D |
| 아래 분할 | Ctrl+Shift+E |
| 패널 이동 | Alt+방향키 |
| 패널 크게 보기 | Ctrl+Shift+Enter |
| 탭 이동 | Ctrl+Tab / Ctrl+1~9 |
| 붙여넣기 | Ctrl+V |
| 클립보드 이미지 → 서버 | Ctrl+Alt+V |
| 복사 | Ctrl+Shift+C / 선택 |
| 터미널에서 찾기 | Ctrl+Shift+F |
| SFTP 패널 | Ctrl+Shift+S |
| 동시 입력 | Ctrl+Shift+B |
| 서버 목록 표시/숨김 | Ctrl+Shift+L |
| 글자 크기 | Ctrl+= / Ctrl+- / Ctrl+0 |
| 빠른 접속에서 오른쪽 분할로 열기 | Ctrl+Enter |

시작 화면과 설정의 "단축키" 표는 위 순서의 항목 이름과 라벨을 그대로 쓴다. 시작 화면은 처음 12개만 보여 주고, 설정 화면은 전체를 보여 준다. 표 항목의 이름은 "빠른 연결 / 명령", "새 탭 (빠른 연결)", "새 로컬 터미널", "탭 닫기", "같은 서버를 오른쪽에", "같은 서버를 아래에", "창 이동", "창 최대화", "탭 이동", "붙여넣기 (이미지·파일 자동 업로드)", "클립보드 이미지 → 서버", "복사", "터미널에서 찾기", "SFTP 창", "일괄 입력", "서버 목록 표시/숨김", "글자 크기" 이다.
