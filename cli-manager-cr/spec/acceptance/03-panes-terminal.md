## 터미널 (behavior/terminal.md)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| T1 | 선택 있음 | Ctrl+C | 복사되고 선택 해제, 서버로 중단 신호는 가지 않는다 |
| T2 | 선택 없음 | Ctrl+C | 서버로 중단 신호 전달 |
| T3 | 설정 "드래그하면 바로 복사" 켜짐 | 드래그로 선택 | 즉시 클립보드에 복사 |
| T4 | 여러 줄(3줄) 텍스트 복사 후 | Ctrl+V | "3줄을 [제목]에 붙여넣습니다…" 확인(앱이 bracketed paste 를 켠 상태가 아닐 때) |
| T5 | 운영 서버 칸 | `rm -rf /tmp/x` 입력 후 Enter | "운영 서버 위험 명령" 확인, 취소하면 아무것도 실행되지 않음 |
| T6 | 같은 상황, 위쪽 화살표로 히스토리 불러온 명령 | Enter | 확인 없이 실행(줄을 알 수 없음) |
| T7 | 개발 서버 칸 | `rm -rf /tmp/x` | 확인 없음 |
| T8 | Shift+Enter | | 서버로 ESC+CR 이 간다(실행되지 않고 줄바꿈) |
| T9 | 클립보드에 PNG 이미지, SSH 칸 | Ctrl+V | "클립보드 이미지 서버로 전송 중..." 후 서버 경로가 입력되고 "전송 완료 → …" |
| T10 | 같은 상황, Telnet 칸 | Ctrl+Alt+V | "이미지 전송은 연결된 SSH 세션에서만 가능합니다" |
| T11 | 원격이 OSC 52 쓰기 요청 | | PC 클립보드에 복사. 읽기 요청(`?`)은 무시 |
| T12 | Ctrl+Shift+F | 검색어 입력 후 Enter/Shift+Enter | 다음/이전 일치로 이동, Esc 로 닫고 터미널 포커스 |
| T13 | Ctrl 누르고 휠 | | 글자 크기 ±1(8~32), 설정에 저장 |
| T14 | 공백이 있는 파일 경로 입력(붙여넣기) | | 작은따옴표로 감싸지고 끝에 공백 |

## 단축키 (behavior/shortcuts.md)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| K1 | 한글 입력기 켜짐 | Ctrl+K | 빠른 접속이 열린다 |
| K2 | 설정 대화상자 열림 | Ctrl+Shift+T | 무시 |
| K3 | 빠른 접속 열림 | Ctrl+Alt+T | 빠른 접속이 닫히고 새 탭에 로컬 셸 |
| K4 | 탭 5개 | Ctrl+9 | 마지막 탭 |
| K5 | 볼트 잠김 | 아무 앱 단축키 | 무시 |
| K6 | 칸 1개 | Ctrl+Shift+B | 동작 없음 |
| K7 | 어떤 대화상자든 | F11 | 창이 최대화/복원 토글 |
| K8 | 설정 > 단축키 "단축키 사용" 끔, 터미널에서 vi 실행 | Ctrl+K, Ctrl+Shift+T, Alt+방향키, F11 | 앱은 반응하지 않고 키가 터미널로 간다. Ctrl+Shift+C 복사·Ctrl+V 붙여넣기는 된다 |
| K9 | "터미널에서 찾기"의 키를 Ctrl+Alt+F 로 바꿈 | Ctrl+Alt+F / Ctrl+Shift+F | 앞의 것은 찾기 막대, 뒤의 것은 아무 일 없음. 칸 메뉴의 찾기 옆에 Ctrl+Alt+F |
| K10 | "터미널에서 찾기"의 키로 Ctrl+K 를 누름 | | 찾기 = Ctrl+K, "빠른 연결 / 명령" = 없음(저장 값 빈 글자), 안내 토스트 |
| K11 | 키를 받는 중 | a (조합 키 없이) / Ctrl+V / Esc | 오류 토스트 후 계속 기다림 / 같음 / 받기 취소(설정 창은 그대로) |
| K12 | 키를 바꾼 뒤 [모두 기본값으로] | | 모든 명령이 기본 키, 저장 값은 빈 표 |
