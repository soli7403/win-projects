## 백업·동기화 (data/sync-backup.md)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| Y1 | 백업 내보내기 | 파일 확인 | `app: termgo`, store 와 vault 가 들어 있음, 기본 이름 `termgo-backup-YYYY-MM-DD.tgbackup` |
| Y2 | 기존 앱의 `.btbackup`(app: brightterm) | 가져오기 | 받아들여지고 볼트는 잠긴 상태, 마스터 비밀번호로 열림 |
| Y3 | app 이 다른 파일 | 가져오기 | "백업 파일이 아닙니다" |
| Y4 | 저장소 주소에 `https://user:pw@host/…` | 동기화 | "저장소 주소에 비밀번호·토큰을 넣지 마세요…" |
| Y5 | 빈 저장소 + 새 데이터 | 동기화 | `termgo-sync.json` 이 올라가고 평문에 서버 주소가 없다 |
| Y6 | 두 PC 가 같은 서버를 각각 수정 | 한 PC 에서 동기화 | 동기화한 PC 의 값이 남는다 |
| Y7 | 한쪽에서 서버를 삭제, 다른 쪽에서 수정 | 동기화 | 삭제가 이긴다 |
| Y8 | 다른 마스터 비밀번호의 볼트가 저장소에 있음 | 동기화 | "저장소의 보관함이 이 PC 의 보관함과 다릅니다" + [저장소의 보관함 받기]/[이 PC 보관함으로 덮어쓰기] |
| Y9 | 볼트 받기에서 비밀번호 틀림 | | `vault-mismatch`, "마스터 비밀번호가 맞지 않거나 취소되었습니다" |
| Y10 | 서버를 수정 | 20초 뒤 | 자동 동기화(설정 켜짐) |
