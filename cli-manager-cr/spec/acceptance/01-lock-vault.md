# 수용 시나리오 1 — 잠금 화면·볼트·자동 잠금

> 형식: 번호 · 사전 조건 · 동작 · 기대 결과. 근거 문서는 괄호. 상태: draft.

## 잠금 화면 (ui/lock.md)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| L1 | 볼트가 없는 첫 실행 | 앱을 시작 | "TermGo 시작하기" 카드가 보이고 "마스터 비밀번호 (8자 이상)" 입력창에 포커스가 있다 |
| L2 | L1 화면 | 비밀번호 `abc` 입력 후 제출 | "8자 이상 입력하세요" 오류, 볼트는 만들어지지 않는다 |
| L3 | L1 화면 | 비밀번호와 확인을 다르게 입력 후 제출 | "비밀번호가 일치하지 않습니다" |
| L4 | L1 화면 | 비밀번호 `Abcdefgh1!x2` 입력 | 강도 "매우 강함", 막대 너비 100%, 색 `#10b981` |
| L5 | 유효한 비밀번호 두 번 입력 후 [볼트 만들기] | | 버튼이 "암호화 키 생성 중..." 이 되었다가 복구 코드 화면(`XXXX-XXXX-…` 24자)으로 바뀐다 |
| L6 | 복구 코드 화면 | 체크박스를 켜지 않고 [시작하기] | 버튼이 비활성이라 진행되지 않는다. 체크 후에는 앱으로 진입 |
| L7 | 볼트가 있고 잠긴 상태 | 틀린 비밀번호 제출 | "비밀번호가 올바르지 않습니다", 입력창이 비워진다 |
| L8 | 열린 탭이 있는 상태에서 잠김 | 화면 확인 | 세션 화면 위에 오버레이로 잠금 카드, 안내 "세션은 계속 연결되어 있습니다…" |
| L9 | 복구 코드 모드 | 소문자로 복구 코드를 입력 | 입력이 즉시 대문자로 바뀐다 |
| L10 | 복구 코드가 맞고 새 비밀번호 8자 이상 | [재설정] | 새 비밀번호로 열림, 저장된 계정이 그대로 있음 |

## 볼트 데이터 (data/vault.md)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| V1 | 새 볼트 | 파일 확인 | `kdf` 가 scrypt N=131072, r=8, p=1, salt 16바이트이고 `wrapped` 에 iv/tag/ct 가 있다 |
| V2 | 계정 저장 후 | `items[]` 확인 | 이름·종류·사용자 이름은 평문, 비밀번호는 iv/tag/ct 안에만 있다 |
| V3 | 같은 마스터 비밀번호 | 기존 앱이 만든 vault.json 열기 | 열린다(양방향 호환) |
| V4 | 비밀번호 변경 | 변경 후 잠그고 새 비밀번호로 해제 | 열리고 항목은 그대로. 이전 비밀번호는 실패 |
| V5 | 비밀번호 변경 후 | 처음 받은 복구 코드로 복구 | 여전히 성공 |
| V6 | 볼트가 잠김 | 계정 비밀 조회 | "볼트가 잠겨 있습니다" 오류, 목록(이름 등)은 조회 가능 |
| V7 | 계정 저장 시 비밀번호 필드를 비워 둠(지정 안 함) | 저장 | 기존 비밀번호가 유지된다 |
| V8 | OS 잠금 해제를 켠 뒤 | 잠금 → "Windows 계정으로 잠금 해제" | 비밀번호 없이 열린다. 백업을 다른 PC 에서 가져오면 이 기능은 꺼진다 |

## 자동 잠금 (behavior/lifecycle.md §2)
| # | 조건 | 동작 | 기대 결과 |
|---|---|---|---|
| A1 | 자동 잠금 1분, 볼트 열림 | 1분 이상 키보드·마우스 입력 없음 | 20초 주기 확인 중 잠기고 잠금 오버레이 |
| A2 | 같은 상태 | 세션 출력만 계속 발생 | 입력이 없으면 잠긴다(출력은 사용으로 치지 않음) |
| A3 | 자동 잠금 0 | 오래 방치 | 잠기지 않는다 |
| A4 | 잠긴 뒤 | 세션 확인 | 연결과 탭은 유지된다 |
| A5 | 자동 잠금 1분 이상(사용 중), Windows 세션 잠금/절전(D6 구현 시) | 잠금 | 볼트가 잠긴다 |
| A6 | 자동 잠금 0(사용 안 함), Windows 세션 잠금/절전 | 잠금 | 볼트는 잠기지 않는다(0 은 이 기능 전체를 끈다) |
