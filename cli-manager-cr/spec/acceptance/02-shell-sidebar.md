## 탭 그룹 (ui/shell.md §2.3)
| # | 상황 | 조작 | 기대 결과 |
|---|---|---|---|
| G1 | 탭 2개, 나뉘지 않음 | 탭 우클릭 → "오른쪽 화면으로 보내기" | 두 열로 나뉘고 각 열이 자기 탭 막대와 선택 탭 내용을 보인다. 제목 표시줄에는 탭 막대가 없다 |
| G2 | 탭 1개 | 탭 우클릭 | "오른쪽 화면으로 보내기"이 비활성 |
| G3 | 나뉨, 오른쪽 탭 2개 | 오른쪽 선택 탭을 왼쪽 탭 막대로 끌어 놓기 | 그 탭이 왼쪽 그룹으로 이동하고 왼쪽의 선택 탭이 된다. 세션 연결 유지 |
| G4 | 나뉨, 오른쪽 탭 1개 | 그 탭을 닫기 | 나뉨이 풀려 하나의 탭 막대로 돌아간다 |
| G5 | 나뉨, 오른쪽 열 선택 | 사이드바에서 서버 열기 | 새 탭이 오른쪽 그룹에 생기고 선택된다 |
| G6 | 나뉨 | Ctrl+Tab | 포커스 그룹 안의 탭만 순환한다 |
| G7 | 나뉨 | 앱 종료 후 다시 실행(레이아웃 복원 켬) | 그룹과 각 그룹의 선택 탭이 복원된다 |
| G8 | 탭 2개, 나뉘지 않음 | 탭을 작업 영역 오른쪽 절반으로 끌기 | "여기에 놓으면 좌우로 나눕니다" 안내가 보이고, 놓으면 G1 과 같다 |
| G9 | 나뉨 | 탭 우클릭 → "한 화면으로 합치기" | 모든 탭이 왼쪽 그룹으로 합쳐진다 |
