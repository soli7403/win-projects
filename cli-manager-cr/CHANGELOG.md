# DariTerm 버전 이력

버전은 `wails.json` 의 `info.productVersion` 한 곳에서 정한다(D82). 스토어 패키지 버전은 끝에 `.0` 을 붙인다(예: 0.2.0 → 0.2.0.0).
스토어 "이 버전의 새로운 기능"에 붙여 넣는 짧은 문구(영어·한국어)는 [docs/store/listing.md](./docs/store/listing.md) 의 각 언어 절 끝에 있다.

## 1.2.0 — 2026-11-28

Microsoft Store 패키지 `DariTerm-1.2.0.0.msix`와 스토어 밖 설치 파일 `DariTerm-1.2.0-amd64-installer.exe`(D161, 배포 안내 [docs/releases/1.2.0.md](./docs/releases/1.2.0.md)). 1.1.0 이후 변경(2026-11-26·27 계획서 docs/import-plans/2026-11-26-1~3, 2026-11-27-1~20). 데이터 파일 형식은 필드만 늘어 1.1.0 에서 덮어 설치하면 그대로 쓴다.

### 새 기능
- 설치 파일로 설치한 DariTerm 도 새 버전을 확인한다 — 공개 릴리스 저장소(`soli7403/dariterm-releases`)의 최신 릴리스를 보고, 새 버전이 있으면 릴리스 페이지를 연다. (D135)
- **포트 포워딩 정보**: 접속 때 터미널 안내가 포워딩마다 한 줄씩(들여쓰기·화살표 맞춤, 실패는 빨강) 나온다. 창 머리글의 `⇄ N` 버튼(또는 칸 우클릭 "포트 포워딩 보기")으로 종류·듣는 주소·대상·상태 표를 보고 복사한다. 상태는 "동작 중", 이어진 연결이 있으면 연결 수까지. (D136·D137·D142·D143)
- **명령 모음 변수**: 명령에 `{{이름}}`·`{{이름:기본값}}` 을 적어 두면 누를 때 값을 묻는 창이 뜨고, 채운 명령이 입력된다(미리 보기). (D138)
- **로그인 스크립트**: 서버 편집 > "자동화" 탭에서 "이 글자가 나오면 → 이것을 입력" 단계를 적어 두면 연결할 때마다 순서대로 실행한다(`sudo su -` 비밀번호, 장비 `enable` 등). `{{password}}` 는 로그인 비밀번호로 바뀐다. (D139)
- **출력 트리거**: 설정 > 새 구역 "출력 규칙"에서, 출력 한 줄에 정한 글자가 나오면 알림·소리·자동 응답을 하게 한다(안 보이는 탭도). 키워드 강조도 이 구역으로 옮겼다. (D140)
- **매크로**: 매크로&명령 모음에 단계별로 출력을 기다려 가며 입력하는 매크로를 만들거나, 창에 치는 입력을 녹화해 만든다(상태 표시줄에 녹화 배지). 명령에는 `명령` 배지. (D141·D143)
- 출력 트리거의 알림이 앱이 뒤에 있을 때 **Windows 알림 센터**에도 뜬다(설정 > 출력 규칙에서 끌 수 있음, 한 번에 맞은 줄은 알림 하나). (D145)
- 매크로도 명령처럼 **일괄 입력 대상 모두**에서 돈다(창마다 자기 출력을 기다리며). (D146)
- 설정 > 단축키에 **매크로 녹화 시작/정지 · 마지막 매크로 다시 실행 · 지금 창의 매크로 중지**(기본 키 없음, 원하는 키를 준다). (D147)
- 로그인 스크립트 단계에 **보관함 값**을 고르면 `su`·`enable` 같은 다른 비밀번호를 평문 없이 보낸다. (D148)
- **서버별 출력 트리거**: 서버 편집 > 자동화 "이 서버의 출력 트리거"에 그 서버에서만 쓰는 규칙을 넣는다(로컬 터미널도). (D149)
- 가져오기: SecureCRT 세션에 로그인 스크립트(로그온 동작)가 있으면 "옮기지 않음"을 알린다(형식 확인 전). (D150)
- 포워딩 정보 창에 포워딩마다 **전송량**(↑ 보낸 · ↓ 받은 바이트, 접속 뒤 누적)과 합계. (D151)
- **프록시 명령(ProxyCommand)**: 서버 편집 > 고급 > 프록시 경유에서 외부 명령(`ssh -W %h:%p bastion`, `ncat`, `cloudflared` 등)의 입출력을 서버까지의 통로로 쓴다. (D152)
- ssh config 가져오기: `ProxyJump a,b` 를 경유 서버 체인(대상 → b → a)으로 잇고, `ProxyCommand` 는 서버의 프록시 명령으로 옮긴다. (D152·D153)
- **도움말 창**: 왼쪽 위 물음표(또는 설정의 "이 구역 도움말")로 기능별 설명 28개를 검색해 본다. 목록 정렬(기능 순서·가나다순), 자주 묻는 질문 카드, 화면 그림(누르면 크게), 창 크기 조절. (D155~D159)
- **세션 전송량**: 창 머리글 오른쪽 버튼들 앞에 그 세션이 보낸 양(↑ 입력)과 받은 양(↓ 출력)을 `↑1.2 K ↓34 M` 처럼 보인다. 세션을 연 뒤 누적, 1초마다 갱신, 마우스를 올리면 정확한 값. 폭이 고정이라 값이 바뀌어도 머리글이 흔들리지 않고, 좁은 창(머리글 360px 이하)에서는 숨는다. (D160)

### 수정
- 스토어판에서 [업데이트 확인] 이 늘 "확인하지 못했습니다" 로 끝나던 문제 — 확인용 PowerShell 이 앱의 패키지 신원 없이 돌던 탓. 업데이트 확인 창(설치)도 같은 까닭으로 함께 고쳐짐. (D134)
- Xshell 파일 선택 창에서 세션 파일(`.xsh`)이 보이지 않던 문제 — 기본 종류를 `*.xts;*.xsh` 로. (D129)
- 로그온 화면을 표시하지 않는 **화면 보호기**에서도 앱이 잠길 수 있던 문제 — Windows 세션의 실제 잠금 상태로 판정한다. (D154)
- 서버 편집 > 자동화의 로그인 스크립트 표에서 "기다릴 글자" 열이 한 글자 폭으로 줄던 문제. (D157)
- **좁은 창에서 머리글의 환경 태그("운영" 등)가 두 줄로 꺾이던 문제**: 태그는 줄지 않고 제목·접속 대상이 먼저 말줄임으로 준다. (D160)

## 1.1.0 — 2026-11-25

Microsoft Store 패키지 `DariTerm-1.1.0.0.msix`(D123-1, 제출 전이라 2026-11-25 변경을 합쳐 다시 만듦 D133). 1.0.0 이후 변경. 계획서는 docs/import-plans/2026-11-23-*.md (14건 + 2026-11-23-1~4 의 4건)와 2026-11-25-1~8. 데이터 파일 형식은 필드만 늘어 1.0.0 에서 덮어 설치하면 그대로 쓴다.

### 새 기능
- **PuTTY 키(.ppk) 그대로 쓰기**: PPK 형식 2·3(RSA·Ed25519·ECDSA, 암호 걸린 키 포함)을 변환 없이 읽는다. 전에 저장해 두고 접속이 안 되던 PPK v2 키도 다시 저장하지 않아도 된다. (D106-2)
- **SSH 에이전트가 Pageant 도 쓴다**: Windows 에서 OpenSSH 에이전트와 실행 중인 Pageant 의 키를 모두 시도한다. Windows 밖은 `SSH_AUTH_SOCK`. (D107-2)
- **시리얼 흐름 제어 RTS/CTS · XON/XOFF** 가 실제로 동작한다(전에는 저장만). 장치가 2초 넘게 받지 못한 입력은 버리고 알려 준다. (D108)
- **동적 포트 포워딩(SOCKS 프록시, `ssh -D`)**: 포워딩 종류 D. 이 PC 의 포트를 SOCKS4/5 프록시로 열어 SSH 서버를 거쳐 나간다. (D109)
- **프록시 경유 접속**: 서버 편집 > 고급 "프록시 경유"(HTTP CONNECT · SOCKS5, 사용자 이름·비밀번호). 방화벽 뒤 회사망에서 접속할 때. (D110)
- **SSH 에이전트 전달(`ssh -A`)**: 서버 편집 > 고급 토글(기본 꺼짐). 서버 안에서 `ssh`·`git` 을 이 PC 의 에이전트 키로. (D111)
- **로그 줄마다 시각**: 설정 > 로그 "로그 줄마다 시각 표시"(기본 꺼짐) — 세션 로그 파일 줄 앞에 `[YYYY-MM-DD HH:mm:ss.SSS]`. (D112)
- **키워드 강조**: 설정 > 화면 "키워드 강조" — `ERROR`·`FAIL` 같은 글자를 고른 색으로 표시(정규식·대소문자·바탕 칠하기). 화면 표시만 바꾼다. (D113)
- **ZMODEM 파일 전송**: SSH·시리얼 터미널에서 서버의 `sz` 로 받고 `rz` 로 올린다. 설정 > 파일에서 받는 폴더·끄기. 실제 lrzsz 와 맞대어 확인했다(15B~40MB 받기·보내기 SHA256 일치). 받는 중 Ctrl+C 로 취소하면 이미 오던 데이터를 버리고 프롬프트로 돌아오고, 서버가 60초 동안 응답하지 않으면 전송만 끝낸다(연결은 유지). tmux·screen 안에서는 전송할 수 없다는 것과 끝내는 방법(Ctrl+X 5번)을 알린다. (D114·D123-2·D125)
- **스토어 설치본의 새 버전 알림**: 스토어에 새 버전이 있으면 상태 표시줄에 알리고, 누르면 Windows 의 업데이트 확인 창을 띄운다. (D115)
- **문자 인코딩 EUC-JP · GBK · Big5** 추가(가져오기도 인식). (D118)
- 잠금 화면에서 Caps Lock 이 켜져 있으면 알려 준다. (D97)
- **설정 > 로그** 구역을 새로 두고 로그 항목을 연결에서 옮겼다. **"ANSI 그대로 저장"**(기본 꺼짐)을 켜면 세션 로그에 색·커서 코드와 CR 을 지우지 않고 남겨 `cat`·`less -R` 로 화면처럼 다시 볼 수 있다. (D120-2)
- 설정 > 로그 "로그 파일 갱신 주기 (초)"(0~5, 기본 2). 기록 중인 로그 파일이 탐색기에 0바이트로 보이던 것이 이 주기마다 갱신된다. (D100)
- **설정 > 단축키** 구역(구역 10개): 앱 단축키 34개의 키를 하나씩 바꾸거나 지우고 기본값으로 되돌린다. 다른 동작이 쓰던 키를 고르면 그 동작의 키는 비워진다. "단축키 사용"을 끄면 앱 단축키가 모두 꺼져 그 키가 터미널(vi·tmux)로 간다. 단축키 표는 "정보"에서 이리로 옮겼다. (D126)
- **Xshell 세션 가져오기**: 서버 가져오기에서 Xshell 내보내기 파일(`.xts`)이나 세션 파일(`.xsh`) 하나를 고르면 폴더 구조·포트 포워딩까지 옮긴다(비밀번호·사용자 키·프록시는 옮기지 않음). 이 PC 에 Xshell 이 있으면 자동으로 찾는다. (D128·D129)
- 서버 목록의 **"즐겨찾기"·"최근 사용" 구역 접기**: 제목을 누르면 접히고, 접은 상태는 저장된다. "서버" 구역 위에 구분선. (D131·D132)

### 개선
- 터미널 찾기에서 현재 항목이 빨강으로 뚜렷하게 보이고 스크롤 막대에 위치가 표시된다. (D96)
- "터미널 출력 기록"을 켜고 끄면 열려 있는 연결에도 곧바로 적용된다. (D99)
- 창 머리글의 최대화·복원 아이콘을 빈 사각형 / 겹친 사각형으로 바꾸고, 크게 보는 중에는 버튼이 켜진 표시가 된다. (D121)
- 탭의 창 수 배지 숫자가 다크·라이트, 세션 색 배경 위에서도 잘 보인다. (D122)
- 서버의 유휴 자동 로그아웃 뒤 자동으로 다시 연결한다. **달라 보이는 점**: 입력 없이 10초 넘게 있다가 서버가 세션을 끝내면 이제 다시 붙는다. `exit` 로 끝내면 전처럼 닫힌다. (D98)
- 텔넷·시리얼이 끊기면 까닭을 함께 보인다: "서버가 연결을 닫았습니다", "네트워크 오류 (…)", "포트가 닫혔습니다 (…)". (D127, KI-009)
- 구성 요소 최신화: Wails 2.17.1(웹뷰 로더 go-webview2 1.0.23), Go 1.27.4, React 19.3.1, x/crypto 0.59.0 등. 화면·데이터 형식 변화 없음. (D124-1)

### 없앤 것
- "바둑판으로"(모든 탭을 한 화면에 / 폴더 서버 모두 열기 / 빠른 연결 명령): 탭당 창 수 한도를 무시해 그 뒤 나누기·열기가 막히던 기능. (D116)
- 서버 우클릭 "열 위치 선택…" 대화상자: 같은 한도를 보지 않던 두 번째 경로. 여는 위치는 새 탭 / 오른쪽 화면 / 아래 창으로 고른다. (D117)

### 수정
- 칸 머리의 돋보기 버튼이 찾기를 열지 않던 문제. (D96)
- 화면을 나눈 상태에서 다른 쪽에 포커스가 있을 때 탭 막대의 + 로 연 세션이 + 가 있는 쪽이 아니라 포커스 쪽에 생기던 문제. (D119)
- **찾기 막대를 연 동안 클립보드가 덮이던 문제**: "선택하면 자동 복사"가 켜져 있으면 찾은 글자가 클립보드에 계속 복사되고, 출력이 이어지면 찾기 강조가 갱신되지 않거나 마우스로 한 선택이 찾은 항목으로 바뀌던 문제. 이제 자동 복사는 마우스로 선택을 끝냈을 때만 하고, 찾은 항목 강조는 출력 중에도 0.1초마다, 스크롤 막대는 최근 줄부터 표시한다. (D120-1, KI-011)
- 명령 모음을 켜면 왼쪽 열이 서버 목록보다 넓어져 화면이 어긋나던 문제. 이제 서버 목록과 명령 모음이 늘 같은 너비이고 함께 바뀐다. (D130)
- **Ctrl+Shift+Tab**(이전 탭)이 동작하지 않던 문제. F11 은 조합 키 없이 누를 때만 창 최대화. (D126)

## 1.0.0 — 2026-11-21

첫 정식 버전(D106-1). Microsoft Store 패키지 `DariTerm-1.0.0.0.msix`, Windows 설치 파일 `DariTerm-1.0.0-amd64-installer.exe`. 0.3.0 이후 변경. 데이터 파일 형식은 그대로라 0.x 에서 덮어 설치하면 서버 목록·계정·설정을 그대로 쓴다. 업무용 라이선스 키는 주 버전 제한이 1 이상이거나 없는 키면 그대로 쓸 수 있다.

### 개선
- **화면 나누기 안내가 너무 빨리 나오던 문제**: 탭을 끌어 작업 영역의 오른쪽 가장자리(너비의 10%, 최소 100px)에 가져갈 때만 "여기에 놓으면 좌우로 나눕니다" 안내가 나온다. 탭 막대 위에서 순서를 바꿀 때는 나오지 않는다. (D102)
- **선택된 탭 표시**: 탭 위쪽 색 막대가 이제 그룹에서 선택된 탭에만 있고 선택을 따라간다. 색이 없는 서버의 탭이면 파란색(강조색) 막대. 선택되지 않은 탭은 서버 색의 옅은 배경만 남는다. **달라 보이는 점**: 색 있는 서버의 선택되지 않은 탭에서 막대가 없어졌다. (D103)

### 수정
- 탭 끌기를 취소하거나 다른 탭 위·창 밖에 놓아도 화면 나누기 점선 상자가 남아 오른쪽 절반을 누를 수 없던 문제. (D101)
- **파일 전송이 중간에 끊기거나 취소되면 대상 파일이 잘린 채 남던 문제**: SFTP 업로드·다운로드·끌어 놓기 복사·편집 저장은 이제 같은 폴더의 임시 이름(`이름.dtpart-xxxxxxxx`)에 쓰고 끝까지 쓴 뒤에만 원래 이름으로 바꾼다. 덮어쓰던 파일은 끊겨도 전 내용 그대로이고, 권한도 유지한다. 네트워크가 끊겨 지우지 못한 `.dtpart-` 파일은 직접 지운다. (D104)
- 폴더에 색·환경을 지정하고 서버에는 지정하지 않으면 터미널 칸 테두리·탭이 폴더 색 대신 파랑으로 나오던 문제. 폴더만 "운영"인 서버도 이제 운영으로 취급해 빨간 테두리와 위험 명령 확인이 뜬다. 사이드바 색 순서도 서버 색 → 서버 환경색 → 폴더로 맞췄다. (D105)

## 0.3.0 — 2026-11-17

Microsoft Store 패키지 `DariTerm-0.3.0.0.msix`, Windows 설치 파일 `DariTerm-0.3.0-amd64-installer.exe`. 0.2.0 이후 변경.

### 개선
- **잠금·오래 둔 뒤 SSH 비밀번호를 다시 묻던 문제**: 화면 보호기·자동 잠금으로 앱이 잠긴 동안 연결이 끊겨도, 그 세션이 처음 접속할 때 쓴 계정으로 창 없이 다시 연결한다(저장하지 않고 입력한 비밀번호 포함, 세션을 닫으면 지움). 그래도 안 되면 비밀번호 창 대신 "앱 잠금을 해제하면 다시 연결합니다" 를 보이고, 잠금을 풀면 곧바로 다시 연결한다. (D94)
- **서버가 끝낸 세션에 다시 붙지 않음**: 서버의 유휴 자동 로그아웃이나 `exit` 로 셸이 끝나면 자동 재접속하지 않고 "서버가 세션을 끝냈습니다" + "Enter 키를 누르면 다시 연결합니다" 를 보인다. 네트워크 끊김은 지금처럼 자동 재접속. **달라 보이는 점**: 전에는 `exit` 뒤에도 2초 뒤 다시 붙었다. (D93)

- **파일 창 정렬**: SFTP·로컬 파일 목록의 머리 줄(이름·크기·수정일)을 누르면 그 순서로 정렬하고, 다시 누르면 방향을 바꾼다. 폴더는 항상 위. 목록을 스크롤해도 머리 줄은 위에 고정된다. (D95)

### 수정
- 아주 빠르게 연달아 보낸 입력(한글 조합 확정 직후의 키, vim·tmux 시작 때의 터미널 응답 등)이 드물게 순서가 바뀌어 서버에 가던 문제. (D92)

## 0.2.0 — 2026-11-16

Microsoft Store 패키지 `DariTerm-0.2.0.0.msix`. 0.1.0 이후 변경.

### 새 기능
- **세션 로그 보관 기간**: 설정 > 연결 > "로그 보관 기간 (일)"(기본 30일, 0 = 지우지 않음). 앱이 시작 10초 뒤와 1시간마다, 값을 바꾸면 곧바로 오래된 로그 파일을 지운다. 기록 중인 파일은 건드리지 않는다. (D90)
- **WebGL 화면 그리기**: 터미널을 GPU 로 그려 많은 출력도 빠르게 보인다. WebGL 을 쓸 수 없는 환경(원격 데스크톱 등)에서는 기존 방식으로 자동 전환. (D84)

### 개선
- **고속 출력이 앱 전체를 느리게 하던 문제**: 한 탭에서 초당 수 MB 를 출력해도 다른 탭의 입력·화면이 평소처럼 반응한다. 화면이 처리한 만큼만 받아 메모리가 늘지 않고, 출력은 버리지 않는다. 안 보이는 탭의 출력은 몰아서 그린다. (D84, KI-008)
- **붙여넣기 지연**: 오른쪽 클릭·Ctrl+V 붙여넣기가 0.3~0.8초 늦던 문제를 고쳤다. (D91, KI-010)
- **SSH 끊김 감지**: 와이파이 전환·VPN 끊김처럼 연결이 조용히 사라져도 "연결 유지" 간격 × 4 안에 끊김을 알아채고 자동 재접속한다. (D86, KI-002)
- **시리얼 로컬 에코**: 장치가 아무것도 보내지 않아도 입력한 글자가 바로 보인다. 흐름 제어 설정이 아직 적용되지 않는다는 안내를 서버 편집 화면에 넣었다. (D87, KI-003)

### 수정
- 같은 서버를 같은 분에 여러 번 열면 세션 로그가 한 파일에 섞이던 문제 — 파일 이름이 초 단위가 되고 겹치면 `-2`, `-3` 을 붙여 세션마다 파일 하나. (D85, KI-001)
- 세션 로그에 `[31m` 같은 색 코드 조각이 남던 문제, 로그 쓰기가 출력을 늦추던 문제. (D88, KI-004)
- 아주 긴 별칭이나 탭·줄바꿈이 든 별칭이면 로그 파일을 못 만들거나 이름이 이상하던 문제. (D88, KI-007)
- 로컬 터미널을 닫을 때 드물게 종료 문구가 엉뚱하거나 잠깐 멈출 수 있던 문제. (D89, KI-005)
- 세션을 닫은 직후 출력·접속 실패 안내가 한두 번 더 오던 문제. (D84, KI-006)
- 실행 파일 속성(자세히)에 제품 이름·회사·저작권이 비어 보이던 문제. (4f6fe26)

### 설정·데이터
- 새 설정 `sessionLogKeepDays`(기본 30). 기존 store.json 은 그대로 읽힌다.
- 로그 파일 이름 규칙이 `{별칭}-{YYYYMMDD-HHmmss}.log` 로 바뀌었다(전: 분 단위). 이미 있던 로그는 그대로 두고, 보관 기간이 지나면 같이 정리된다.
