# DariTerm 사용 설명서

DariTerm 은 서버에 접속해 일하는 사람을 위한 터미널 프로그램입니다. SSH·Telnet·시리얼 장비·내 PC 의 터미널(cmd, PowerShell, WSL)을 한 창에서 탭과 창 나누기로 함께 쓸 수 있고, 서버 비밀번호와 키는 암호화해 내 PC 에만 저장합니다.

> 이 설명서는 버전 1.2.0 기준입니다. English: [user-guide.en.md](./user-guide.en.md)

---

## 1. 설치하기

1. `DariTerm-amd64-installer.exe` 를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누릅니다(아직 코드 서명 전이라 나오는 안내입니다).
2. 관리자 권한을 허용하고, 사용권에 동의한 뒤 [설치]를 누릅니다.
   - 설치 위치: `C:\Program Files\DariTerm`
   - 시작 메뉴와 바탕화면에 **DariTerm** 바로가기가 생깁니다.
3. 지울 때는 **설정 > 앱 > 설치된 앱(프로그램 추가/제거) > DariTerm > 제거**. 서버 목록과 설정은 남아 있어서 다시 설치하면 그대로 이어서 쓸 수 있습니다.

## 2. 처음 실행

처음 실행하면 네 단계를 거칩니다.

1. **언어 선택** — 10개 언어 중에서 고릅니다. Windows 언어가 미리 골라져 있습니다.
2. **사용 용도** — *개인용*(무료, 기한 없음) 또는 *업무용*(30일 무료 평가 후 라이선스 필요). 업무용 라이선스 키가 있으면 여기서 넣어도 됩니다.
3. **앱 잠금 비밀번호 만들기** — 8자 이상. 서버 비밀번호·키를 이 비밀번호로 암호화합니다. 어디에도 보내지 않습니다.
4. **복구 코드 저장** — 24자리 코드가 **한 번만** 보입니다. 인쇄하거나 안전한 곳에 적어 두세요. 비밀번호를 잊었을 때 이 코드로만 되살릴 수 있습니다.

> 💡 PuTTY 나 SecureCRT 를 쓰고 있었다면 저장된 세션을 가져오라고 안내합니다(→ 7장).

## 3. 화면 둘러보기

```
┌───────────┬───────────────────────────────────────────┐
│ 아이콘 줄 │ 탭 막대  [web-01] [db-01] [+]              │
├───────────┼───────────────────────────────────────────┤
│ 서버 목록 │                                           │
│ (사이드바)│            터미널 창 (나눌 수 있음)          │
│           │                                           │
│ 명령 모음 │                                           │
├───────────┴───────────────────────────────────────────┤
│ 상태 표시줄: 연결 상태 · 사용 형태 · 잠금 해제됨        │
└───────────────────────────────────────────────────────┘
```

- **왼쪽 위 아이콘**: 서버 목록 표시/숨김, 명령 모음, 모든 창 일괄 입력, 설정.
- **오른쪽 위 아이콘**: SFTP(파일) 창.
- **창 머리글**: 서버 이름과 접속 대상, 포트 포워딩이 있으면 `⇄ 개수` 버튼. 오른쪽 버튼들 앞의 `↑1.2 K ↓34 M` 은 그 세션의 **전송량**입니다 — ↑ 보낸 것(입력), ↓ 받은 것(출력), 세션을 연 뒤 누적, 1초마다 바뀝니다. 마우스를 올리면 정확한 값이 보이고, 창이 좁으면 숨겨집니다.
- **상태 표시줄 오른쪽 아래 "잠금 해제됨"** 을 누르면 바로 잠깁니다.

## 4. 서버 등록하고 연결하기

### 서버 추가
1. 사이드바 **[서버 추가]**.
2. **일반** 탭: 프로토콜(SSH/Telnet/시리얼/로컬), 표시 이름, 주소, 포트, 사용자 이름.
   - 주소 칸에 `user@10.0.0.11:22` 처럼 넣으면 알아서 나눠 채웁니다.
   - **환경**을 "운영"으로 정하면 빨간 테두리로 표시되고, 위험한 명령 앞에서 한 번 더 묻습니다.
   - 서버에 색·환경을 정하지 않으면 **폴더의 색·환경을 물려받습니다**. 폴더를 "운영"으로 정하면 그 안의 서버도 운영으로 보호됩니다(서버에 다른 환경을 정하면 서버 것이 먼저).
3. **로그인** 탭: 비밀번호 / 키 파일 / SSH 에이전트 / 접속할 때마다 입력 중에서 고릅니다.
4. **[저장하고 연결]**.

### 연결하는 여러 방법
- 사이드바에서 서버를 **더블클릭**.
- **Ctrl+K**(빠른 연결)에서 이름이나 IP 일부를 치고 Enter.
  - 저장하지 않은 서버도 `user@host` 처럼 치면 바로 연결됩니다.
  - `>` 를 치면 명령(새 로컬 터미널, 설정 열기, 테마 전환, 앱 잠그기 등)이 나옵니다.
- **Ctrl+Alt+T**: 내 PC 의 터미널.

### 처음 연결하는 서버
"처음 연결하는 서버입니다" 창과 키 지문이 보입니다. 서버 관리자가 알려 준 값과 같으면 **[믿고 연결]**. 나중에 키가 바뀌면 경고가 뜨니, 이유를 모르면 연결하지 마세요.

### 비밀번호 저장
비밀번호를 물을 때 **"암호화해 저장하고 다음부터 자동 로그인"** 을 체크하면 다음부터 묻지 않습니다.

## 5. 터미널 쓰기

| 하고 싶은 일 | 방법 |
|---|---|
| 복사 | 마우스로 끌어 선택하면 바로 복사됩니다(또는 Ctrl+Shift+C) |
| 붙여넣기 | Ctrl+V 또는 마우스 오른쪽 클릭 |
| **캡처 이미지를 서버로** | 화면을 캡처(복사)한 뒤 터미널에서 **Ctrl+V** → 서버에 올리고 그 경로를 입력해 줍니다. Claude Code 같은 AI CLI 에 이미지를 보여 줄 때 편합니다 |
| 파일 경로 넣기 | 탐색기에서 파일을 터미널로 끌어 놓기 |
| 글자 찾기 | Ctrl+Shift+F |
| 글자 크기 | Ctrl+= 크게, Ctrl+- 작게, Ctrl+0 원래대로 |
| 명령 실행 없이 줄바꿈 | Shift+Enter |

> ⚠️ **운영 서버 보호**: 환경이 "운영"인 서버에서 `rm -rf`, `reboot`, `DROP TABLE` 같은 명령을 치면 바로 실행하지 않고 "정말 실행할까요?" 라고 묻습니다.

## 6. 탭과 창 나누기

| 하고 싶은 일 | 방법 |
|---|---|
| 같은 서버를 옆에 하나 더 | Ctrl+Shift+D (오른쪽), Ctrl+Shift+E (아래) |
| 창 사이 이동 | Alt+방향키 |
| 한 창만 크게 보기 | Ctrl+Shift+Enter |
| 탭 사이 이동 | Ctrl+Tab, Ctrl+1~9 |
| 여러 서버에 같은 명령 | Ctrl+Shift+B (일괄 입력 켜기/끄기) |
| 탭 닫기 | Ctrl+Shift+W |
| 화면을 좌우 둘로 | 탭 우클릭 → "오른쪽 화면으로 보내기", 또는 탭을 끌어 오른쪽 가장자리로 가져가 "여기에 놓으면 좌우로 나눕니다" 가 나오면 놓기 |

지금 보고 있는 탭은 위쪽에 색 막대가 있습니다(서버 색, 없으면 파랑). 다른 탭은 서버 색이 옅게 칠해집니다.

## 7. 다른 프로그램에서 가져오기

사이드바 **[가져오기]** 를 누르면 아래를 찾아 목록으로 보여 줍니다.

- PuTTY 에 저장된 세션
- SecureCRT 세션 폴더(폴더 구조와 포트 포워딩까지) — 다른 위치면 [SecureCRT 폴더 선택]
- Xshell 세션(`.xts` 내보내기 파일 또는 `.xsh` 세션 파일, 폴더·포트 포워딩까지)
- `~/.ssh/config`
- AWS EC2 — [AWS EC2 불러오기] (aws CLI 설정 필요)

원하는 항목을 체크하고 **[n개 가져오기]**. 비밀번호는 가져오지 않으므로, 처음 연결할 때 한 번 입력해 저장하면 됩니다.

## 8. 파일 주고받기 (SFTP)

1. SSH 로 연결한 뒤 **Ctrl+Shift+S**(또는 오른쪽 위 아이콘).
2. 오른쪽에 서버 파일 목록이 나옵니다.
   - **올리기**: 탐색기 파일을 목록에 끌어 놓기
   - **받기·편집**: 파일 우클릭 → 다운로드 / "이 PC 앱으로 편집"(저장하면 자동으로 서버에 올라감)
   - **미리보기**: 파일 더블클릭
   - **정렬**: 목록 위의 이름·크기·수정일을 누르면 그 순서로 정렬, 한 번 더 누르면 반대 순서(폴더는 항상 위)
   - **[터미널을 이 폴더로 이동]**: 지금 보는 폴더로 `cd`
3. **서버에서 서버로 복사**: 한 탭의 파일을 다른 서버 탭으로 끌어 놓으면, 창 맨 아래 복사 목록에서 진행 상황을 볼 수 있습니다.
4. **전송이 끊기거나 취소되면**: 받는 쪽에 같은 이름의 파일이 있었다면 전 내용 그대로 남습니다(전송 중에는 `이름.dtpart-xxxxxxxx` 라는 임시 이름에 쓰고, 끝나야 원래 이름으로 바꿉니다). 네트워크가 끊겨 `.dtpart-` 파일이 남았으면 직접 지워 주세요.

## 9. 명령 모음

자주 쓰는 명령을 저장해 두고 클릭 한 번으로 입력합니다.

1. 사이드바 아래 명령 모음에서 **[새 명령]**.
2. 이름·명령(여러 줄 가능)을 넣고, 바로 실행하려면 "입력하고 바로 실행"을 켭니다.
3. 목록에서 명령을 누르면 지금 창에 입력됩니다. 일괄 입력이 켜진 탭이면 모든 창에 들어갑니다.

## 10. 반복 작업 자동화

| 하고 싶은 일 | 방법 |
|---|---|
| 명령에 값을 그때그때 넣기 | 명령 모음의 명령에 `{{이름}}`·`{{이름:기본값}}` 을 적어 두면 누를 때 값을 묻고, 채운 명령을 미리 보여 줍니다 |
| 출력을 기다려 가며 여러 단계 입력 | 명령 모음 > **매크로**: 단계마다 "이 글자가 나오면 → 이것을 입력". 창에 치는 입력을 **녹화**해 만들 수도 있습니다(상태 표시줄에 녹화 배지). 일괄 입력이 켜진 탭이면 모든 창에서 돕니다 |
| 접속할 때마다 자동으로 | 서버 편집 > **자동화** > 로그인 스크립트: `password:` → `{{password}}` 처럼 적으면 `sudo su -`·장비 `enable` 비밀번호를 대신 넣습니다. 다른 비밀번호는 평문 대신 **보관함 값**을 고르세요 |
| 특정 출력이 나오면 알림 | 설정 > **출력 규칙** > 출력 트리거: `ERROR` 가 나오면 알림·소리·자동 응답. 앱이 뒤에 있으면 Windows 알림 센터에도 뜹니다. 그 서버에서만 쓰려면 서버 편집 > 자동화 |
| 글자에 색 칠하기 | 설정 > 출력 규칙 > 키워드 강조 (화면 표시만 바뀝니다) |

## 11. 포트 포워딩·경유 서버·프록시

- **포트 포워딩**: 서버 편집 > 포트 포워딩 탭. L(내 PC 포트 → 서버 쪽 주소), R(서버 포트 → 내 PC 쪽 주소), D(내 PC 포트를 SOCKS 프록시로). 접속하면 포워딩마다 한 줄씩 안내하고, 창 머리글의 **`⇄ N`** 에서 상태·연결 수·전송량을 봅니다.
- **경유 서버**: 서버 편집 > 고급 > 경유 서버(ProxyJump). ssh config 의 `ProxyJump a,b` 는 가져올 때 경유 서버 체인으로 이어집니다.
- **프록시**: 서버 편집 > 고급 > 프록시 경유 — HTTP CONNECT, SOCKS5, 또는 **프록시 명령**(`ssh -W %h:%p bastion`, `ncat`, `cloudflared` 같은 외부 명령의 입출력을 통로로).
- **에이전트**: 인증 "SSH 에이전트"는 Windows OpenSSH 에이전트와 Pageant 를 모두 씁니다. 서버 안에서 이 PC 의 키를 쓰려면 고급 > 에이전트 전달.

## 12. 터미널로 파일 주고받기 (ZMODEM)

SSH·시리얼 창에서 서버의 `sz 파일` 로 받고 `rz` 로 올립니다. 받는 폴더와 끄기는 설정 > 파일 전송. 받는 중 **Ctrl+C** 로 취소하면 프롬프트로 돌아옵니다. tmux·screen 안에서는 전송할 수 없으니 밖에서 실행하세요.

## 13. SSH 키 만들기와 서버에 등록

비밀번호 대신 키로 로그인하게 바꾸는 순서입니다.

1. 설정 > 보안 > 저장된 계정의 **[SSH 키 만들기]**: 이름, 종류(Ed25519 권장, 오래된 서버는 RSA 4096), 키 암호(선택). 키는 보관함에 암호화되어 저장됩니다.
2. 비밀번호로 접속한 창에서 우클릭 > **공개 키를 이 서버에 등록…** → 키를 고르고 [등록]. 서버의 `~/.ssh/authorized_keys` 에 한 줄이 들어갑니다(이미 있으면 그대로).
3. "다음 접속부터 이 서버에 이 키로 로그인"을 켜 두면 서버 설정도 키 로그인으로 바뀝니다.

키 계정 줄의 [공개 키]로 공개 키 한 줄과 지문을 보고 복사할 수 있습니다(GitHub 등에 붙여 넣기).

## 14. 시리얼 장비: HEX 보기·HEX 보내기·XMODEM

시리얼 창의 우클릭 메뉴에 있습니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 받은 바이트를 16진으로 | **HEX 로 보기** — `01 41 FF  |.A.|` 처럼 한 줄 16바이트. 다시 누르면 글자로 |
| 바이트를 그대로 보내기 | **HEX 보내기…** — `01 03 00 00 00 0A C5 CD` 를 적고 [보내기]. 창이 열려 있어 되풀이해 보낼 수 있습니다 |
| 펌웨어 올리기 | **XMODEM 보내기 / XMODEM-1K 보내기** — 파일을 고른 뒤 장치에서 받기 시작(부트로더 `loadx` 등) |
| 장치에서 파일 받기 | **XMODEM 받기** — 저장 이름을 고른 뒤 장치에서 보내기 시작 |
| 전송 그만두기 | Ctrl+C 또는 "XMODEM 전송 취소" |

## 15. 도움말 창

왼쪽 위 **물음표**(또는 설정의 "이 구역 도움말")를 누르면 기능별 설명을 검색해 볼 수 있습니다. 목록은 기능 순서·가나다순, 자주 묻는 질문 카드, 화면 그림(누르면 크게)이 있고 창 크기를 끌어 바꿀 수 있습니다.

## 16. 안전하게 쓰기

- **자동 잠금**: 15분 동안 입력이 없거나 Windows 를 잠그면 앱이 잠깁니다. 연결은 끊기지 않습니다. 시간은 설정 > 보안에서 바꿉니다.
- **Windows 로그인으로 열기**: 설정 > 보안에서 켜면 비밀번호 대신 Windows 계정으로 엽니다.
- **비밀번호를 잊었을 때**: 잠금 화면 → "복구 코드로 재설정".
- **저장된 계정 정리**: 설정 > 보안 > 저장된 계정.

## 17. 여러 PC 에서 같이 쓰기

- **백업**: 설정 > 백업 → [백업 내보내기]. 다른 PC 에서 [백업 가져오기] 후, 원래 PC 의 앱 잠금 비밀번호로 엽니다.
- **git 동기화**: 설정 > git 동기화에 **비공개** git 저장소 주소를 넣으면, 앱 잠금 비밀번호로 암호화한 파일 하나만 올려 여러 PC 의 서버 목록을 맞춥니다.

## 18. 설정 한눈에

설정(톱니바퀴)은 바꾸는 즉시 저장됩니다.

- **화면**: 언어, 테마(다크/라이트), 터미널 색상, 글꼴, 커서, 창 나누기 최대 개수
- **입력**: 복사·붙여넣기 방식, 여러 줄 붙여넣기 확인, 운영 서버 위험 명령 경고
- **단축키**: 동작마다 키 바꾸기·지우기, 단축키 전체 켜기/끄기
- **출력 규칙**: 출력 트리거, 키워드 강조
- **파일 전송**: 이미지를 올릴 서버 폴더, 오래된 업로드 자동 정리, ZMODEM 받는 폴더
- **연결**: 끊기면 다시 연결, 마지막 화면 배치 복원(앱을 다시 열면 탭·창 나누기·서버를 그대로 다시 엶)
- **로그**: 터미널 출력 기록, 줄마다 시각, ANSI 그대로 저장, 보관 기간
- **git 동기화 / 보안(SSH 키 만들기 포함) / 백업 / 정보**

## 20. 자주 묻는 질문

**Q. 연결이 자꾸 끊겨요.**
설정 > 연결 "연결이 끊기면 다시 연결"이 켜져 있으면 2·4·8·16·30초 간격으로 다시 연결합니다. 멈춘 뒤에는 터미널에서 Enter 를 누르면 다시 연결됩니다.

**Q. 창을 닫아도 서버 작업이 계속 돌았으면 해요.**
서버 편집 > 고급 > **"연결 유지 (tmux)"** 를 켜세요. 서버에 tmux 가 있어야 합니다. 다시 열면 같은 화면으로 돌아옵니다.

**Q. 경유 서버(점프 호스트)를 거쳐야 해요.**
서버 편집 > 고급 > "경유 서버 (ProxyJump)" 에서 저장된 서버를 고르거나 직접 입력하세요.

**Q. 포트 포워딩은요?**
서버 편집 > 포트 포워딩 탭에서 L·R·D(SOCKS) 를 추가합니다(§11).

**Q. 이 세션에서 얼마나 주고받았는지 보고 싶어요.**
창 머리글 오른쪽의 `↑ … ↓ …` 가 세션을 연 뒤 보낸 양(입력)과 받은 양(출력)입니다. 재접속해도 이어서 세고, SFTP·포트 포워딩은 따로 셉니다. 창이 좁아 안 보이면 창을 넓히거나 Ctrl+Shift+Enter 로 그 창만 크게 보세요.

**Q. PuTTY 키(.ppk)를 쓸 수 있나요?**
네. PPK 형식 2·3(암호 걸린 키 포함)을 변환 없이 읽습니다. 새로 만들려면 §13 의 SSH 키 만들기를 쓰세요.

**Q. 내 정보가 어디로 전송되나요?**
아니요. 서버 목록·비밀번호·키·라이선스 확인은 모두 이 PC 안에서만 처리합니다.
