# 02. 업무용 라이선스 서명 비밀키

> 2026-11-14 생성. 결정 D78. **비밀값 자체는 이 문서와 저장소에 넣지 않는다.**

## 무엇을

- Ed25519 키 쌍을 `go run ./tools/licensekey keygen <파일>` 로 만들었다.
- **비밀키 위치**: `%USERPROFILE%\.dariterm-signing\license-ed25519.key` (이 PC, 저장소 밖).
- 공개키는 앱에 들어 있다: `internal/license/license.go` 의 `g_szPublicKey`.

## 반드시 할 일

- 비밀키 파일을 **안전한 곳(암호화된 USB, 비밀번호 관리자 등)에 백업**한다.
  - 잃어버리면: 이미 판 키는 계속 유효하지만 **새 키를 발급할 수 없다**. 새 키 쌍을 만들면 공개키가 바뀌어 새 앱 버전부터만 새 키를 받는다.
  - 새어 나가면: 누구나 키를 만들 수 있다. 새 키 쌍으로 바꾸고 앱을 새로 배포해야 한다.
- 발급 서버를 만들면 이 비밀키를 서버의 비밀 저장소(예: 클라우드 비밀 관리)로 옮기고, PC 의 파일은 백업만 남긴다.

## 시험 발급

```powershell
go run ./tools/licensekey issue "$env:USERPROFILE\.dariterm-signing\license-ed25519.key" -id DT-2026-0001 -org "회사 이름" -seats 5 -ver 1 -exp 2029-11-14
```

출력된 `DT1.…` 한 줄을 앱의 설정 > 정보 > 사용 형태에 붙여 넣는다.

## 발급 대장

- 발급한 키는 `%USERPROFILE%\.dariterm-signing\issued.md`(번호·회사·사용자 수·기한)와 `<ID>.txt`(키 원문)에 남긴다. 고객 정보라 저장소에는 넣지 않는다.
- 번호는 `DT-<연도>-<4자리 일련번호>`. 새로 발급할 때 대장의 마지막 번호 다음을 쓴다.
- 기간제는 `-exp` 를 발급일 + 기간으로 넣는다(만료일 당일까지 유효, spec/behavior/license.md). 기간제는 `-ver 0`(모든 버전)으로 둔다.

## 되돌리기

파일을 지우면 된다(단, 위 "잃어버리면"과 같아진다).
