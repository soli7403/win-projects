## 0. 한 줄 요약

사용자 요청 "설정 옆에 help 버튼을 넣고 기능별 자세한 설명을 추가할 수 있을까?"와 "help에는 검색도 있었으면 좋겠다"에 따라, 왼쪽 위 아이콘 묶음의 **설정 오른쪽에 도움말 버튼**을 두고, 누르면 **왼쪽 검색 칸·항목 목록 + 오른쪽 설명**의 창을 연다. 설명은 기능별 **28개 항목**(이번에 넣은 기능 포함), 검색은 모든 낱말이 든 항목만 제목 우선으로 보이고 본문에서 맞은 곳을 노랗게 강조한다. 설정 화면 왼쪽 아래 **"이 구역 도움말"** 은 그 구역의 설명으로 바로 간다.

## 1. 결정

| 항목 | 결정 | 까닭 |
|---|---|---|
| 버튼 자리 | 왼쪽 위 아이콘 묶음, 설정 오른쪽(물음표 동그라미) | 사용자가 말한 자리 |
| 설정과의 연결 | 설정 왼쪽 아래 "이 구역 도움말" → 설정을 닫고 도움말을 그 구역의 항목으로, 도움말을 닫으면 설정이 같은 구역으로 다시 열림 | 모달 둘을 겹치면 Esc 한 번에 둘 다 닫힌다(모달마다 창 전체의 Esc 를 듣는다) |
| 본문 저장 | `locales/help/<언어>.md` — 작은 마크다운 | 표·목록이 많은 긴 글이라 json 한 줄 문구로는 고치기 어렵다. "화면 문구는 locales 아래에만"(D75)은 지킨다 |
| 언어 | **ko·en 두 개**를 썼다. 그 밖의 8개 언어는 영어 본문 + 안내 "이 언어의 도움말이 아직 없어 영어로 보여 드립니다." | 본문이 언어마다 2만 자 안팎이라 이번 범위에서 빼고 결정에 남긴다. 창의 화면 문구(제목·검색·안내 7개)는 10개 언어 |
| 내용의 바탕 | 사용 설명서(docs/manual/user-guide.*)를 기능별로 나누고, 이번(D145~D154)과 그전 기능(ZMODEM·키워드 강조·로그·가져오기 등)을 더했다. 화면 이름은 `ko.json`·`en.json` 의 실제 문구로 맞췄다 | 설명서는 순서대로 읽는 글이고 도움말은 찾아 읽는 글이다 |
| 검색 | 모든 낱말(AND), 대소문자 무시, 제목에 있으면 100점 + 본문 횟수, 같으면 원래 순서. 목록에 미리 보기 두 줄. Enter 는 첫 결과 | 몇 글자만 쳐도 원하는 항목이 맨 위에 오게 |
| 강조 | 제목·목록·본문의 글자 안에서 낱말을 `<mark>`(경고색 바탕) | |
| 단축키 | 주지 않는다 | F1 은 mc·htop 등 터미널 프로그램이 쓴다 |
| 새 의존성 | 없다(마크다운 해석을 직접 작게 만들었다) | 쓰는 형식이 몇 가지뿐이다. 외부 HTML 을 그리지 않으므로 HTML 삽입 걱정도 없다(모두 React 요소) |
| 대안 | 웹 문서 링크 — 기각(오프라인·사내망에서 못 연다). 설정 위에 겹쳐 띄우기 — 기각(Esc 문제) | |

### 3.1 읽기·검색 — `frontend/src/lib/help.ts` (새 파일)

| 함수 | 하는 일 |
|---|---|
| `parseHelp(src)` | 주석을 버리고 줄 단위로 읽어 항목(`{id, title, blocks, haystack}`)을 만든다. 블록: `h`·`p`·`ul`/`ol`(하위 한 단계)·`table`(둘째 줄 구분선 건너뜀)·`note`·`code`. `haystack` 은 제목+본문에서 `**`·`` ` `` 를 뺀 소문자 |
| `searchTerms(q)` | 공백으로 나눈 소문자 낱말 |
| `searchHelp(topics, q)` | §1 의 점수·순서, 미리 보기(첫 낱말 앞 30자부터 90자) |
| `markParts(text, terms)` | 정규식 특수 문자를 이스케이프해 낱말로 쪼갠 `[글, 맞음]` 배열 |
| `helpFor(lang)` | `import.meta.glob('../../../locales/help/*.md', { eager: true, query: '?raw', import: 'default' })` 로 묶은 본문에서 그 언어(없으면 en → ko)를 골라 읽고 캐시. `fallback` 을 함께 돌려준다 |
| `SETTINGS_HELP_TOPIC` | 설정 구역 → 항목 id (spec/ui/help.md §3) |

```ts
export function searchHelp(topics: readonly HelpTopic[], query: string): HelpHit[] {
  const terms = searchTerms(query);
  if (terms.length === 0) return [];
  const hits: (HelpHit & { order: number })[] = [];
  topics.forEach((topic, order) => {
    if (!terms.every((w) => topic.haystack.includes(w))) return;
    const title = topic.title.toLowerCase();
    let score = 0;
    for (const w of terms) {
      if (title.includes(w)) score += 100;
      score += topic.haystack.split(w).length - 1;
    }
    … 미리 보기
    hits.push({ topic, score, snippet, order });
  });
  hits.sort((a, b) => b.score - a.score || a.order - b.order);
  return hits.map(({ topic, score, snippet }) => ({ topic, score, snippet }));
}
```
