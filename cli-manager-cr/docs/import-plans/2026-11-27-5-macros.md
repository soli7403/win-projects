# 매크로 — 여러 입력을 출력을 기다려 가며 보낸다, 녹화

**작성**: 2026-11-27 · **상태**: 코드·자동 테스트·빌드 완료(D141, 같은 날 패널 이름과 종류 배지 D143 — §3). 앱 화면에서의 확인은 수동 검증으로 남음(§H) · **대상**: cli-manager-cr(DariTerm) · **Known issue**: 없음
**관련**: 명령 모음(D55·D130), 2번 문서(변수), 4번 문서(출력 감시). 명세 [spec/behavior/terminal.md](../../spec/behavior/terminal.md) §11, [spec/ui/sftp-snippets.md](../../spec/ui/sftp-snippets.md) §4.4, [spec/data/store.md](../../spec/data/store.md) §7
**적용 순서**: 2026-11-27 의 5번째(마지막). 2·4번 문서의 파일을 쓴다.

---

## 0. 한 줄 요약

명령 모음에 **매크로**를 둘 수 있다. 매크로는 단계의 목록이고, 단계마다 **앞 입력의 결과가 나온 뒤에** 다음 입력을 보낸다. 창에 치는 입력을 **녹화**해 만들 수도 있다.

| | 명령 | 매크로 |
|---|---|---|
| 보내는 방식 | 여러 줄을 한꺼번에 | 한 단계씩, 출력을 기다려서 |
| 기다림 | 없음 | 단계마다 "기다릴 글자"(없으면 출력이 0.5초 조용해질 때까지) |
| 대상 | 일괄 입력이면 모든 창 | 지금 창 하나 |
| 만드는 법 | 직접 적기 | 직접 적기 또는 녹화 |

## 1. 배경

2026-11-27 사용자 요청("권장 순서대로 구현")의 넷째 항목. 명령 모음은 고정된 글자를 한 번에 보내기만 해서, `sudo -i` 뒤에 비밀번호 질문이 뜨기 전에 다음 줄이 가 버리는 일을 막을 길이 없었다. 원본 앱에 없던 기능이라 명세도 이번에 새로 썼다.

## 2. 설계 결정

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 저장하는 곳 | 명령 모음 항목에 `steps` 를 더한다(따로 목록을 두지 않는다) | 동기화·백업·병합이 항목 단위라 그대로 따라간다. `steps` 를 모르는 옛 버전에서는 `body`(단계를 줄마다 이은 것)가 평범한 명령으로 보인다 |
| 화면 | 명령과 같은 목록, 배지 `매크로 N단계`(D143: 명령에도 초록 배지 `명령`, 패널 이름은 "매크로&명령 모음") | 탭을 나누면 좁은 왼쪽 열에서 한 번 더 눌러야 한다. 검색이 함께 된다 |
| 기다림(글자 없음) | 출력이 0.5초 조용해지면 보냄, 길어도 10초 | 프롬프트 모양을 몰라도 대개 맞는다. 녹화한 매크로가 손대지 않아도 돌게 한다 |
| 기다림(글자 있음) | 앞 단계를 **보낸 뒤의** 출력에서 찾음, 30초 시한 | 화면에 남아 있던 옛 글자에 맞지 않게 |
| 첫 단계 | 기다릴 글자가 없으면 바로 | 누르자마자 반응해야 한다 |
| 실행하는 곳 | 프런트(출력 감시는 4번 문서의 `outputHub`) | 사용자가 눌러 시작하고 진행 상태를 화면에 보인다. 로그인 스크립트와 달리 접속 직후의 경합이 없다 |
| 대상 | 포커스된 창 하나, 창마다 한 번에 하나 | 창마다 출력이 달라 기다림이 따로 돌아야 한다. 여러 창 동시 실행은 필요해지면 더한다 |
| 제어 문자 | `\x03`·`\e`·`\t`·`\r`·`\n`·`\\` 로 적는다 | 편집 칸에 넣고 고칠 수 있어야 한다(Ctrl+C, 방향키) |
| 녹화 범위 | 사용자가 **직접 친** 입력만. Enter 마다 한 단계 | 명령 모음·자동 응답이 보낸 것, 터미널의 자동 응답이 섞이지 않게 |
| 녹화의 백스페이스 | 그 줄에 친 글자를 지운다 | 오타를 고친 흔적이 매크로에 남지 않게 |
| 녹화 표시 | 명령 모음의 버튼 + **상태 표시줄의 빨간 배지** | 패널을 닫아도 녹화 중임이 보이고 멈출 수 있어야 한다(비밀번호가 기록될 수 있다) |
| 단축키 | 주지 않는다. 빠른 연결의 `>` 명령에 "매크로 녹화 시작/정지" | 앱 단축키가 이미 34개라 vi·tmux 와 겹치는 키가 는다. 필요한 사람은 나중에 설정에서 받게 할 수 있다 |
| 운영 서버 | 위험 명령 패턴에 맞는 단계가 있으면 실행 전에 확인 | 붙여넣기와 같은 규칙 |

알려 둘 것:
- 매크로는 평문으로 저장된다. 녹화 시작 토스트와 녹화한 편집 창에 비밀번호를 치지 말라고 적었다.
- 녹화한 단계에는 "기다릴 글자"가 비어 있다(0.5초 조용함으로 넘어간다). 오래 걸리는 명령 뒤의 단계는 편집 창에서 기다릴 글자를 넣는 편이 안전하다.
- 전체 화면 프로그램(vim 등) 안의 글자는 기다릴 글자로 잡히지 않는다(조용함으로는 넘어간다).

## 3. 추가: 패널 이름과 종류 배지 (2026-11-27, D143)

사용자 지시: "아이콘 설명도 '명령 모음'도 '매크로&명령 모음'으로 바꿔 주고, 매크로 옆의 '매크로 1단계'처럼 명령에 '명령'으로 다른 색으로 표시해줘."

- 왼쪽 아이콘(`<>`)의 툴팁과 패널 이름: "명령 모음" → **"매크로&명령 모음"**(문구 키 `shell.snippets`, 10개 언어).
- 목록의 명령 항목에 배지 **`명령`**(초록, 클래스 `snip-badge cmd`). 매크로 배지(강조색)와 모양은 같고 색만 다르다. 문구 키 `snip.badge`.
- 바꾼 파일: `frontend/src/screens/SnippetsPanel.tsx`, `frontend/src/styles/rightpanel.css`, `locales/*.json`, 테스트 `Automation.test.tsx`(1개 추가), 명세 `spec/ui/sftp-snippets.md` §4.4.

### `frontend/src/lib/macro.ts` — 새 파일 (전체)

```ts
// 매크로의 순수 계산: 제어 문자 적기·읽기, 녹화한 입력을 단계로 나누기, 출력에서 글자 기다리기.
// 근거: spec/behavior/terminal.md §11 (D141). 실행·녹화 상태는 state/macros.ts.
import type { MacroStep, Snippet } from '../ipc/types';
import { OutputLines } from './outputLines';

/** 매크로 하나의 최대 단계 수. */
export const MACRO_STEP_MAX = 50;
/** 기다릴 글자가 나오기를 기다리는 최대 시간(ms). 넘으면 매크로를 멈춘다. */
export const MACRO_EXPECT_TIMEOUT_MS = 30_000;
/** 기다릴 글자가 없는 단계: 출력이 이만큼(ms) 조용하면 다음 입력을 보낸다. */
export const MACRO_QUIET_MS = 500;
/** 출력이 계속 이어져도 이만큼(ms) 지나면 다음 입력을 보낸다. */
export const MACRO_QUIET_MAX_MS = 10_000;
/** 기다릴 글자를 찾는 최근 출력의 최대 길이. */
const TAIL_MAX = 4000;

export function newMacroStep(p: Partial<MacroStep> = {}): MacroStep {
  return { id: `ms-${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 7)}`, expect: '', send: '', enter: true, ...p };
}

/** 이 항목이 매크로인지(단계가 하나라도 있는지). */
export function isMacro(s: Snippet): s is Snippet & { steps: MacroStep[] } {
  return Array.isArray(s.steps) && s.steps.length > 0;
}

/** 저장할 단계: 보낼 것이 없는 단계(글자도 Enter 도 없음)는 빼고, 최대 개수까지만. */
export function cleanSteps(steps: readonly MacroStep[]): MacroStep[] {
  return steps.filter((s) => s.send !== '' || s.enter).slice(0, MACRO_STEP_MAX);
}

/** 매크로를 목록·검색·옛 버전에서 보일 한 덩어리 글로: 단계의 보낼 글자를 줄마다. */
export function macroBody(steps: readonly MacroStep[]): string {
  return steps.map((s) => s.send).join('\n');
}

/** 입력 글자를 편집할 수 있는 글로 적는다: 제어 문자는 `\xNN`, ESC 는 `\e`, 탭은 `\t`, 역슬래시는 `\\`. */
export function escapeKeys(raw: string): string {
  let out = '';
  for (const ch of raw) {
    const code = ch.codePointAt(0) ?? 0;
    if (ch === '\\') out += '\\\\';
    else if (code === 0x1b) out += '\\e';
    else if (code === 0x09) out += '\\t';
    else if (code === 0x0d) out += '\\r';
    else if (code === 0x0a) out += '\\n';
    else if (code < 0x20 || code === 0x7f) out += `\\x${code.toString(16).padStart(2, '0')}`;
    else out += ch;
  }
  return out;
}

/** escapeKeys 의 반대. 모르는 `\?` 는 글자 그대로 둔다. */
export function unescapeKeys(text: string): string {
  return text.replace(/\\(x[0-9a-fA-F]{2}|[etrn\\])/g, (_m, g: string) => {
    if (g === 'e') return '\x1b';
    if (g === 't') return '\t';
    if (g === 'r') return '\r';
    if (g === 'n') return '\n';
    if (g === '\\') return '\\';
    return String.fromCharCode(parseInt(g.slice(1), 16));
  });
}

/** 터미널이 서버의 질의에 스스로 답하는 입력(장치 속성·커서 위치·포커스 알림). 사용자가 친 것이 아니므로 녹화하지 않는다. */
const AUTO_REPLY = /^\x1b\[(?:[?>]?[\d;]*[cRn]|[IO])$/;

/**
 * 사용자가 친 입력을 단계로 모은다. Enter 마다 한 단계(보낸 뒤 Enter)가 되고,
 * 백스페이스는 그 줄에 친 마지막 글자를 지운다(지울 글자가 없으면 그대로 적는다).
 */
export class MacroRecorder {
  private steps: MacroStep[] = [];
  /** 지금 줄에 친 것(글자 단위. 제어 문자도 한 칸). */
  private line: string[] = [];

  feed(data: string): void {
    if (!data || AUTO_REPLY.test(data)) return;
    // 방향키 같은 ESC 시퀀스는 한 덩어리로 넣는다(백스페이스가 반쪽만 지우지 않게).
    if (data.startsWith('\x1b') && data.length > 1 && !data.includes('\r')) {
      this.line.push(data);
      return;
    }
    for (const ch of data) {
      if (ch === '\r') {
        this.flush(true);
      } else if (ch === '\n') {
        // 붙여넣기의 LF 는 CR 로 이미 왔다고 보고 버린다
      } else if ((ch === '\x7f' || ch === '\b') && this.line.length > 0 && isPrintable(this.line[this.line.length - 1])) {
        this.line.pop();
      } else {
        this.line.push(ch);
      }
    }
  }

  private flush(enter: boolean): void {
    if (this.steps.length >= MACRO_STEP_MAX) {
      this.line = [];
      return;
    }
    const send = escapeKeys(this.line.join(''));
    this.line = [];
    if (send === '' && !enter) return;
    this.steps.push(newMacroStep({ send, enter }));
  }

  /** 지금까지 모은 단계 수(진행 표시용). */
  count(): number {
    return this.steps.length + (this.line.length > 0 ? 1 : 0);
  }

  /** 녹화를 끝내고 단계를 돌려준다. Enter 없이 남은 입력은 Enter 를 붙이지 않는 단계가 된다. */
  finish(): MacroStep[] {
    this.flush(false);
    const out = this.steps;
    this.steps = [];
    return out;
  }
}

function isPrintable(s: string): boolean {
  return s.length > 0 && !s.startsWith('\x1b') && (s.codePointAt(0) ?? 0) >= 0x20 && s !== '\x7f';
}

/** 출력에서 글자를 기다리는 데 쓰는 최근 출력(ANSI 를 지운 글). 대소문자는 구분하지 않는다. */
export class OutputTail {
  private lines = new OutputLines();
  private done = '';
  private partial = '';
  /** 지금 줄에서 이미 버린 앞부분의 길이(reset 뒤에 같은 줄이 이어질 때 다시 보지 않게). */
  private skip = 0;
  /** 줄 모으개가 들고 있는 지금 줄 전체의 길이. */
  private rawPartial = 0;

  feed(chunk: string): void {
    const r = this.lines.feed(chunk);
    for (const line of r.lines) {
      this.done += `${line.slice(this.skip)}\n`;
      this.skip = 0;
    }
    if (this.done.length > TAIL_MAX) this.done = this.done.slice(this.done.length - TAIL_MAX);
    this.rawPartial = r.partial.length;
    if (this.skip > this.rawPartial) this.skip = 0; // 줄을 처음부터 다시 썼다(CR)
    this.partial = r.partial.slice(this.skip);
  }

  /** 지금까지의 출력에 needle 이 있으면 지금까지의 출력을 버리고 true. */
  consume(needle: string): boolean {
    const hay = (this.done + this.partial).toLowerCase();
    if (hay.indexOf(needle.toLowerCase()) < 0) return false;
    this.reset();
    return true;
  }

  /** 지금까지의 출력을 버린다(입력을 보낸 직후: 그 뒤의 출력만 기다린다). */
  reset(): void {
    this.done = '';
    this.partial = '';
    this.skip = this.rawPartial;
  }
}
```

```ts
import { create } from 'zustand';
import { getBackend } from '../ipc/backend';
import type { MacroStep } from '../ipc/types';
import {
  MACRO_EXPECT_TIMEOUT_MS, MACRO_QUIET_MAX_MS, MACRO_QUIET_MS, MacroRecorder, OutputTail, unescapeKeys,
} from '../lib/macro';
import { emitAppInput, onInput, onOutput } from '../lib/outputHub';
import { fillVars } from '../lib/snippetVars';
import { focusedSessionId, focusTerminal, notifyNoFocus } from '../lib/termSend';
import { relabel, t } from '../i18n';
import { useApp } from './app';
import { useUi } from './ui';
import { useWorkspace } from './workspace';

export interface MacroRun {
  /** 실행 중인 매크로(명령 모음 항목)의 id 와 이름. */
  macroId: string;
  name: string;
  /** 지금 기다리는 단계(0부터)와 전체 단계 수. */
  step: number;
  total: number;
}

interface MacroState {
  /** 세션 id → 그 세션에서 실행 중인 매크로. 세션마다 하나만 돈다. */
  running: Record<string, MacroRun>;
  /** 녹화 중인 세션과 지금까지 모은 단계 수. 녹화는 한 번에 하나만. */
  recording: { sessionId: string; count: number } | null;
  /** 방금 끝난 녹화의 단계. 명령 모음 패널이 가져가 편집 창을 연다(가져가면 null). */
  recorded: MacroStep[] | null;
}

export const useMacros = create<MacroState>(() => ({ running: {}, recording: null, recorded: null }));

interface Job {
  steps: MacroStep[];
  values: Record<string, string>;
  index: number;
  tail: OutputTail;
  /** 지금 단계의 시한(기다릴 글자) 또는 조용함 타이머. */
  timer: ReturnType<typeof setTimeout> | null;
  /** 조용함을 기다리기 시작한 때(상한 계산). */
  quietSince: number;
}

const jobs = new Map<string, Job>();
let recorder: MacroRecorder | null = null;

function setRun(sessionId: string, run: MacroRun | null): void {
  useMacros.setState((s) => {
    const running = { ...s.running };
    if (run) running[sessionId] = run;
    else delete running[sessionId];
    return { running };
  });
}

function clearTimer(job: Job): void {
  if (job.timer) clearTimeout(job.timer);
  job.timer = null;
}

function finish(sessionId: string, toast?: { kind: 'ok' | 'error' | 'info'; text: string }): void {
  const job = jobs.get(sessionId);
  if (!job) return;
  clearTimer(job);
  jobs.delete(sessionId);
  setRun(sessionId, null);
  if (toast) useApp.getState().pushToast(toast);
}

function nameOf(sessionId: string): string {
  return useMacros.getState().running[sessionId]?.name ?? '';
}

/** 지금 단계의 입력을 보내고 다음 단계로 간다. */
function sendStep(sessionId: string, job: Job): void {
  clearTimer(job);
  const info = useWorkspace.getState().sessions[sessionId]?.info;
  if (!info || info.state !== 'connected') {
    finish(sessionId, { kind: 'error', text: t('macro.disconnected', { name: nameOf(sessionId) }) });
    return;
  }
  const step = job.steps[job.index];
  const text = unescapeKeys(fillVars(step.send, job.values)) + (step.enter ? '\r' : '');
  job.tail.reset(); // 보낸 뒤의 출력만 다음 단계의 조건으로 본다
  if (text) {
    getBackend().termInput(sessionId, text);
    emitAppInput(sessionId, text);
  }
  job.index++;
  if (job.index >= job.steps.length) {
    finish(sessionId, { kind: 'ok', text: t('macro.done', { name: nameOf(sessionId) }) });
    return;
  }
  const cur = useMacros.getState().running[sessionId];
  if (cur) setRun(sessionId, { ...cur, step: job.index });
  armStep(sessionId, job);
}

/** 지금 단계의 기다림을 건다: 기다릴 글자가 있으면 시한, 없으면 출력이 조용해지기를 기다린다. */
function armStep(sessionId: string, job: Job): void {
  clearTimer(job);
  const step = job.steps[job.index];
  if (step.expect) {
    if (job.tail.consume(step.expect)) {
      sendStep(sessionId, job);
      return;
    }
    job.timer = setTimeout(() => {
      finish(sessionId, {
        kind: 'error',
        text: t('macro.timeout', { name: nameOf(sessionId), text: step.expect, sec: Math.round(MACRO_EXPECT_TIMEOUT_MS / 1000) }),
      });
    }, MACRO_EXPECT_TIMEOUT_MS);
    return;
  }
  job.quietSince = Date.now();
  job.timer = setTimeout(() => sendStep(sessionId, job), MACRO_QUIET_MS);
}

function onSessionOutput(sessionId: string, text: string): void {
  const job = jobs.get(sessionId);
  if (!job) return;
  job.tail.feed(text);
  const step = job.steps[job.index];
  if (step.expect) {
    if (job.tail.consume(step.expect)) sendStep(sessionId, job);
    return;
  }
  // 출력이 왔다: 조용함을 다시 잰다. 다만 상한을 넘겼으면 더 기다리지 않는다.
  clearTimer(job);
  const left = MACRO_QUIET_MAX_MS - (Date.now() - job.quietSince);
  job.timer = setTimeout(() => sendStep(sessionId, job), Math.max(0, Math.min(MACRO_QUIET_MS, left)));
}

/**
 * 매크로를 세션에서 실행한다. 첫 단계는 기다릴 글자가 없으면 바로 보낸다.
 * 그 세션에서 이미 매크로가 돌고 있으면 실행하지 않고 false.
 */
export function runMacro(sessionId: string, macroId: string, name: string, steps: readonly MacroStep[], values: Record<string, string> = {}): boolean {
  if (steps.length === 0) return false;
  if (jobs.has(sessionId)) {
    useApp.getState().pushToast({ kind: 'info', text: t('macro.busy') });
    return false;
  }
  const info = useWorkspace.getState().sessions[sessionId]?.info;
  if (!info || info.state !== 'connected') {
    useApp.getState().pushToast({ kind: 'info', text: t('macro.needConnected') });
    return false;
  }
  const job: Job = { steps: [...steps], values, index: 0, tail: new OutputTail(), timer: null, quietSince: Date.now() };
  jobs.set(sessionId, job);
  setRun(sessionId, { macroId, name: name || relabel(info.title), step: 0, total: steps.length });
  if (job.steps[0].expect) armStep(sessionId, job);
  else sendStep(sessionId, job);
  return true;
}

/** 실행 중인 매크로를 멈춘다(사용자가 [중지]). */
export function stopMacro(sessionId: string): void {
  if (!jobs.has(sessionId)) return;
  finish(sessionId, { kind: 'info', text: t('macro.stopped', { name: nameOf(sessionId) }) });
}

/** 지금 창의 입력을 녹화하기 시작한다. 이미 녹화 중이면 false. */
export function startRecording(sessionId: string): boolean {
  if (recorder) return false;
  recorder = new MacroRecorder();
  useMacros.setState({ recording: { sessionId, count: 0 } });
  return true;
}

/** 녹화를 끝내고 모은 단계를 돌려준다. 녹화 중이 아니면 빈 배열. */
export function stopRecording(): MacroStep[] {
  const r = recorder;
  recorder = null;
  useMacros.setState({ recording: null });
  return r ? r.finish() : [];
}

/**
 * 매크로 녹화 시작/정지(명령 모음 패널·상태 표시줄·빠른 연결의 명령이 부른다).
 * 시작: 지금 창의 입력을 모으기 시작한다. 정지: 모은 단계가 있으면 명령 모음 패널을 열어 편집 창을 띄우게 한다.
 */
export function toggleRecording(): void {
  const push = useApp.getState().pushToast;
  if (useMacros.getState().recording) {
    const steps = stopRecording();
    if (steps.length === 0) {
      push({ kind: 'info', text: t('macro.recordEmpty') });
      return;
    }
    const ui = useUi.getState();
    ui.setSnippetsOpen(true);
    if (!ui.sidebarOpen) ui.toggleSidebar();
    useMacros.setState({ recorded: steps });
    return;
  }
  const sid = focusedSessionId();
  if (!sid) {
    notifyNoFocus();
    return;
  }
  if (startRecording(sid)) {
    push({ kind: 'info', text: t('macro.recordStarted') });
    focusTerminal();
  }
}

/** 앱 시작 때 한 번 건다. 돌려준 함수는 구독을 끊는다. */
export function startMacros(): () => void {
  const offs = [
    onOutput(onSessionOutput),
    onInput((sessionId, data, fromUser) => {
      // 녹화는 사용자가 직접 친 입력만 모은다(명령 모음·자동 응답이 보낸 것은 빼고).
      const rec = useMacros.getState().recording;
      if (!fromUser || !recorder || !rec || rec.sessionId !== sessionId) return;
      recorder.feed(data);
      const count = recorder.count();
      if (count !== rec.count) useMacros.setState({ recording: { sessionId, count } });
    }),
    // 세션이 닫히면 그 세션의 실행·녹화를 끝낸다.
    useWorkspace.subscribe((s) => {
      for (const sid of [...jobs.keys()]) if (!s.sessions[sid]) finish(sid);
      const rec = useMacros.getState().recording;
      if (rec && !s.sessions[rec.sessionId]) stopRecording();
    }),
  ];
  return () => {
    offs.forEach((off) => off());
    resetMacrosForTest();
  };
}

/** 테스트용: 실행·녹화 상태를 모두 버린다. */
export function resetMacrosForTest(): void {
  for (const job of jobs.values()) clearTimer(job);
  jobs.clear();
  recorder = null;
  useMacros.setState({ running: {}, recording: null, recorded: null });
}
```

```tsx
      return;

    const st = useApp.getState().store?.settings;
    const info = useWorkspace.getState().sessions[sid]?.info;
    const text = previewOf(s, values);
    if (st?.guardDangerousOnProd && info?.env === 'prod' && matchesDangerous(text, st.dangerousPatterns ?? DANGEROUS_PATTERNS)) {
      const ok = await confirm({
        title: t('run.dangerTitle'),
        body: t('run.dangerBody', { name: relabel(info.title) }),
        detail: text.slice(0, 2000),
        okText: t('run.ok'),
        danger: true,
      });
      if (!ok) return;
    }
    if (runMacro(sid, s.id, s.name || t('snip.noName'), s.steps, values)) focusTerminal();
  };

  const onRun = (s: Snippet) => {
    // 보낼 창이 없으면 값을 묻기 전에 알린다.
    if (!focusedSessionId()) {
      notifyNoFocus();
      return;
    }
    // 변수가 있으면 값을 먼저 묻는다 (terminal.md §7.1).
    if (varsOf(s).length > 0) {
      setAsking(s);
      return;
    }
    void execute(s, {});
  };

  const onRunWith = (s: Snippet, values: Record<string, string>) => {
    rememberValues(s.id, values);
    setAsking(null);
    void execute(s, values);
  };

        </button>

          <Plus size={15} />
        </button>
      </div>

      {snippets.length === 0 ? (
        <div className="snip-empty">
          <div>{t('snip.empty')}</div>

        </div>
      ) : (
        <div className="snip-list">
          {shown.map((s) => {
            const macro = isMacro(s);
            const run = macro ? runOf(s) : undefined;
            return (
              <div
                key={s.id}
                className="snip-item"
                title={macro ? t('macro.runTitle') : t('snip.runTitle')}
                role="button"
                tabIndex={0}
                onClick={() => onRun(s)}
                onKeyDown={(e) => {
                  if (e.key === 'Enter') onRun(s);
                }}
              >
                <div className="snip-main">
                  <div className="snip-name">
                    {s.name || t('snip.noName')}
                    {/* 종류 배지: 매크로는 강조색, 명령은 초록 — 한 목록에 섞여 있어도 한눈에 가려진다 (D143). */}

                    {run ? t('macro.running', { step: run[1].step + 1, total: run[1].total }) : macro ? s.steps.map((x) => x.send).join(' ⏎ ') : s.body}
                  </div>
                </div>
                <div className="snip-actions">
                  {run ? (
                    <button
                      className="icon-btn small"
                      title={t('macro.stop')}
                      aria-label={t('macro.stop')}
                      onClick={(e) => {
                        e.stopPropagation();
                        stopMacro(run[0]);
                      }}
                    >
                      <Square size={13} />
                    </button>
                  ) : (
                    <>
                      <button
                        className="icon-btn small"
                        title={t('common.edit')}
                        aria-label={t('common.edit')}
                        onClick={(e) => {
                          e.stopPropagation();
                          setEditing({ kind: macro ? 'macro' : 'command', item: s, isNew: false });
                        }}
                      >
                        <Pencil size={13} />
                      </button>
                      <button className="icon-btn small" title={t('common.delete')} aria-label={t('common.delete')} onClick={(e) => void onDelete(s, e)}>
                        <Trash2 size={13} />
                      </button>
                    </>
                  )}
                </div>
              </div>
            );
          })}
        </div>
      )}

      {asking && (
        <VarsDialog
          title={asking.name || t('snip.noName')}
          vars={varsOf(asking)}
          initial={initialValues(asking.id, varsOf(asking))}
          preview={(values) => previewOf(asking, values)}
          onCancel={() => setAsking(null)}
          onRun={(values) => onRunWith(asking, values)}
        />
      )}

      {editing?.kind === 'command' && (
        <SnippetEditor initial={editing.item} isNew={editing.isNew} onCancel={() => setEditing(null)} onSave={(d) => void onSaved(d)} />
      )}
      {editing?.kind === 'macro' && (
        <MacroEditor initial={editing.item} isNew={editing.isNew} recorded={editing.recorded} onCancel={() => setEditing(null)} onSave={(d) => void onSaved(d)} />
      )}
    </div>
  );
}
```

```diff
+## 10. 출력 트리거 (2026-11-27, D140)
+
+원본 앱에 없던 기능이다. 터미널 출력에 정해 둔 글자가 나오면 알림·소리·자동 응답을 한다.

+- **규칙**: 설정 `triggerRules`(설정 > 출력 규칙 > 출력 트리거). 찾을 글자(`pattern`), 정규식(`regex`), 대소문자 구분(`caseSensitive`, 기본 구분 안 함), 할 일 세 가지 — 알림(`notify`), 소리(`sound`), 자동 응답(`replyOn` + `reply` + `replyEnter`), 사용 여부(`enabled`). 꺼진 규칙·빈 글자·틀린 정규식·할 일이 하나도 없는 규칙은 쓰지 않는다. **30개**까지.
+- **대상**: 열려 있는 모든 세션. 안 보이는 탭의 출력도 본다.
+- **줄 단위로 찾는다**(§10.1 의 글자만 남긴 줄). 줄바꿈으로 **끝난 줄**은 곧바로 살피고, 줄바꿈 없이 멈춘 줄(`Continue? [y/N] ` 같은 프롬프트)은 출력이 **0.3초** 조용해진 뒤에 살핀다.
+- **반복 제한**: 한 줄에서 규칙마다 한 번(멈춘 줄에서 실행한 규칙은 그 줄이 끝나도 다시 실행하지 않는다). 같은 규칙은 한 세션에서 **1초에 한 번**.
+- **실행하지 않는 곳**: 전체 화면 프로그램(대체 화면: vim·less·htop) 안의 글자. **입력을 보낸 줄**(사용자가 친 글자, 명령 모음·매크로·자동 응답이 보낸 글자)의 에코 — 그 줄이 끝날 때까지 살피지 않는다(`grep error` 를 치는 동안 `error` 규칙이 울리지 않게). 터미널이 스스로 보내는 응답(ESC 로 시작)은 입력으로 세지 않는다.
+- **알림**: 정보 토스트 `{세션 제목}: {맞은 줄}`(줄은 120자까지, 넘으면 `…`).
+- **소리**: 터미널 벨과 같은 짧은 소리(설정의 "벨 소리"와 무관하게 낸다). 한 번에 여러 규칙이 맞아도 한 번만.
+- **자동 응답**: 그 세션(글자가 나온 세션 하나)에 `reply` 를 입력하고, `replyEnter` 면 뒤에 CR. `reply` 가 비고 `replyEnter` 만 켜져 있으면 Enter 만 보낸다. 세션이 연결됨일 때만.
+  - **운영 서버**(세션 환경 `prod`)에는 설정 "운영 서버 위험 명령 확인"(`guardDangerousOnProd`)이 켜져 있는 동안 **보내지 않고** 정보 토스트 `{세션 제목}: 운영 서버라 자동 응답을 보내지 않았습니다`.
+  - **끝없는 반복 막기**: 같은 규칙의 자동 응답이 한 세션에서 **10초에 5번**을 넘으면 그 세션에서 그 규칙을 끄고(앱을 다시 켜거나 세션을 다시 열 때까지) 오류 토스트 `{세션 제목}: 자동 응답이 너무 자주 반복돼 이 연결에서는 껐습니다`. 넘은 그 응답은 보내지 않는다.
+- 화면 표시·세션 로그·서버로 가는 다른 입력은 바꾸지 않는다.
+
+### 10.1 출력을 글자만 남긴 줄로 바꾸기
+
+출력 트리거와 매크로(§11)가 함께 쓴다. 터미널 화면(xterm)과는 따로, 백엔드가 보낸 출력 묶음을 그대로 받아 계산한다.
+
+- ANSI 제어 시퀀스(CSI, OSC — BEL 또는 ST 로 끝남, 그 밖의 ESC 두 글자)를 지운다. 묶음이 시퀀스 중간에서 잘려도 다음 묶음과 이어서 본다.
+- `\n` 으로 줄이 끝난다(`\r\n` 은 줄바꿈 하나). `\r` 뒤에 줄바꿈이 아닌 글자가 오면 그 줄을 처음부터 다시 쓴 것으로 본다(진행 막대). 백스페이스는 마지막 글자를 지우고, 탭은 빈칸, 그 밖의 제어 문자는 버린다.
+- 대체 화면에 들어가 있는 동안(`CSI ? 47|1047|1049 h` ~ `l`)의 글자는 버린다.
+- 한 줄은 **2000자**까지만 모은다(넘으면 앞을 버린다).

+## 11. 매크로 (2026-11-27, D141)
+
+원본 앱에 없던 기능이다. 여러 입력을 **출력을 기다려 가며** 차례로 보낸다. 명령 모음의 한 종류다(data/store.md §7 `steps`).
+
+- **단계**: `expect`(기다릴 글자), `send`(보낼 글자), `enter`(Enter 붙이기). 보낼 것이 없는 단계(글자도 Enter 도 없음)는 저장할 때 뺀다. **50단계**까지.
+- **실행**: 포커스된 칸의 세션 **하나**에서 돈다(동시 입력 대상이 아니다). 연결됨이 아니면 정보 토스트 "연결된 창에서만 매크로를 실행할 수 있습니다". 그 세션에서 이미 매크로가 돌고 있으면 "이 창에서 이미 매크로가 실행 중입니다".
+  - 변수(§7.1)가 있으면 먼저 값을 묻는다.
+  - 운영 서버(환경 `prod`)이고 설정 "운영 서버 위험 명령 확인"이 켜져 있으며 단계의 보낼 글자가 위험 명령 패턴에 맞으면, 실행 전에 §6 과 같은 확인 창을 띄운다(상세에 전체 단계).
+- **기다림**: 단계의 `expect` 가 있으면 **앞 단계를 보낸 뒤의 출력**(§10.1 의 글자만 남긴 글, 대소문자 구분 없음)에 그 글자가 나온 뒤에 보낸다. **30초** 안에 안 나오면 멈추고 오류 토스트 `매크로 "{이름}": "{글자}" 을(를) 30초 동안 기다렸지만 나오지 않아 멈췄습니다`. `expect` 가 비면 출력이 **0.5초** 조용해진 뒤에 보낸다(출력이 그치지 않아도 **10초**가 지나면 보낸다). **첫 단계**는 `expect` 가 없으면 바로 보낸다.
+- **보낼 글자**: 변수를 채운 뒤, `\xNN`(16진 두 자리) · `\e`(ESC) · `\t` · `\r` · `\n` · `\\` 를 그 글자로 바꾼다. 모르는 `\?` 는 그대로 둔다. `enter` 면 끝에 CR.
+- **끝**: 마지막 단계를 보내면 성공 토스트 `매크로 "{이름}" 완료`. 도는 동안 연결이 끊기면 `매크로 "{이름}": 연결이 끊겨 멈췄습니다`. 사용자가 [중지]를 누르면 `매크로 "{이름}" 을(를) 중지했습니다`. 세션을 닫으면 조용히 끝난다.
+- **녹화**: [매크로 녹화]를 누르면 그때 포커스된 세션에 **사용자가 직접 친 입력**을 모은다(명령 모음·자동 응답이 보낸 입력, 터미널이 스스로 보내는 응답은 빼고). 한 번에 하나만 녹화한다.
+  - Enter 마다 한 단계(`enter` 켜짐)가 된다. 백스페이스는 그 줄에 친 마지막 글자를 지운다(지울 글자가 없으면 `\x7f` 로 적는다). 제어 문자·방향키는 위의 표기로 적는다. 녹화한 단계의 `expect` 는 비어 있다(편집 창에서 넣는다).
+  - 정지하면 Enter 없이 남은 입력은 `enter` 꺼진 단계가 되고, 모은 단계로 새 매크로 편집 창이 열린다(명령 모음 패널이 닫혀 있으면 연다). 모은 것이 없으면 정보 토스트 "기록된 입력이 없어 매크로를 만들지 않았습니다".
+  - 녹화 중인 세션을 닫으면 녹화는 버려진다.
+- **보안**: 매크로는 store.json 에 평문으로 남는다. 녹화를 시작할 때와 녹화한 편집 창에서 비밀번호를 치지 말라고 알린다.
```
