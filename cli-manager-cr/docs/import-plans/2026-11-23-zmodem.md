## 0. 한 줄 요약

터미널에서 서버의 `sz 파일` 을 실행하면 그 파일이 이 PC 로 받아지고, `rz` 를 실행하면 파일 선택 창이 떠서 고른 파일이 서버로 올라간다. SFTP 를 쓸 수 없는 곳(경유 서버를 여러 번 거친 셸, `sudo`·`su` 로 바꾼 계정, 시리얼 장비)에서 쓰는 방법이다. SSH 와 시리얼 세션에서 동작한다.

```
$ sz report.tar.gz
rz
● ZMODEM 받는 중: report.tar.gz 45% (1.2 MB / 2.6 MB) · Ctrl+C 취소      ← 같은 줄을 고쳐 쓴다
● 받음: report.tar.gz (2.6 MB) → C:\Users\me\Downloads\report.tar.gz
● ZMODEM 전송 완료: 파일 1개, 2.6 MB
$
```

## 1. 배경

- 파일 전송은 SFTP 패널뿐이었다. SFTP 는 "이 앱이 직접 SSH 로 붙은 서버"에만 된다. 그 서버 안에서 `ssh 다른서버` 로 넘어갔거나 `sudo -i` 로 계정을 바꿨으면 그 자리의 파일은 SFTP 로 닿지 않는다. 시리얼 장비도 SFTP 가 없다.
- ZMODEM 은 **지금 보고 있는 터미널 흐름 그 자체**로 파일을 실어 보내므로 어디까지 들어가 있든 된다. SecureCRT·Xshell 을 쓰던 사람이 가장 먼저 찾는 기능이다.

| 받는 폴더 | 설정 `zmodemDownloadDir`, 비면 다운로드 폴더 | 파일마다 묻지 않는다 |
| 파일 이름 | 서버가 준 이름에서 **경로를 떼고**, 금지 문자를 바꾸고, 장치 이름을 피한다(`SafeFileName`) | 서버가 `../../x` 나 `C:\Windows\x` 를 주어도 받는 폴더 밖에 쓰지 않는다 |
| 같은 이름 | 덮어쓰지 않고 ` (2)`, ` (3)` | 실수로 지우지 않는다 |
| 쓰는 방식 | `<이름>.dtpart` 에 쓰고 다 받으면 이름 바꾸기 | 받다 만 파일이 온전한 파일처럼 보이지 않게(D104 와 같은 생각) |
| 보낼 파일 | 파일 선택 창(여러 개). 취소하면 전송 취소 | rz 는 무엇을 받을지 모른다 |

| 보내는 조각 | 1024바이트, 256조각(약 256KB)마다 확인(ZACK)을 기다린다 | 1024 는 모든 구현이 받는다. 확인을 기다리는 자리에서만 상대의 "다시 보내라"(ZRPOS)를 읽는다 |
| 이스케이프 | 제어 문자(0x00~0x1f, 0x7f, 0x80~0x9f, 0xff)를 모두 | 터미널 계층이 건드릴 수 있는 문자를 하나도 그대로 보내지 않는다. 크기는 평균 25% 쯤 는다 |
| CRC | 상대가 CRC-32 를 쓸 수 있다고 하면 CRC-32, 아니면 CRC-16. 받을 때는 둘 다 | 규격대로 |
| 오류 복구 | CRC 불일치면 그 위치부터 다시 요청(ZRPOS). 전송 하나에 10번까지 | SSH 위에서는 사실상 일어나지 않지만 시리얼에서는 일어난다 |
| 다시 맞추는 동안 | 상대가 이미 보낸 데이터를 버리는 중에 헤더처럼 보이다 만 것은 오류로 세지 않는다(`bResync`) | 버리는 데이터가 수백 KB 일 수 있고 그 안에 우연히 헤더 모양이 있다(구현 중 테스트로 발견, §G) |
| 시간 제한 | **없다** | 연결의 읽기에 시한을 걸 수 없는 구조다. 서버 프로그램이 응답 없이 멈추면 Ctrl+C 로 푼다(알려진 한계) |
| 진행 표시 | 터미널 안에 한 줄을 고쳐 쓴다(0.25초에 한 번). 그 줄은 로그에 남기지 않는다 | 따로 창을 만들지 않는다. 로그는 CR 을 지우므로 진행 줄이 한 줄로 길게 붙는다 |
| 적용 프로토콜 | SSH, 시리얼 | 로컬 터미널(ConPTY)은 이진 데이터를 바꾼다. 텔넷은 이진 방식을 협상하지 않아 CR 등이 바뀔 수 있다 |
| 끄기 | 설정 `zmodemEnabled`(기본 켜짐) | 출력에 우연히 시작 표시가 나오는 환경을 위해 |

### 2.3 검증의 한계 (중요)

이 PC 에는 WSL 도, lrzsz 도 없다. **실제 `sz`·`rz` 와는 한 번도 맞대어 보지 못했다.** 자동 테스트는 이 패키지의 보내는 쪽과 받는 쪽을 서로 맞물려 돌린다 — 같은 규격 이해에서 나온 두 쪽이 "서로 맞는다"는 것까지만 보증한다.

밖의 기준으로 확인한 것은 하나다: lrzsz 가 실제로 보내는 시작 헤더 세 가지(`**\x18B00000000000000\r\x8a\x11`, rz 의 `**\x18B0100000023be50\r\x8a\x11`, `**\x18B0800000000022d\r\x8a`)와 이 구현이 만든 헤더가 **바이트 단위로 같다**(`TestHexHeadersMatchLrzsz`). 16진 헤더의 모양·CRC-16·값의 순서가 맞다는 뜻이다. 이진 헤더, 데이터 조각, 파일 정보의 모양은 규격 문서를 따랐을 뿐 실물과 대조하지 못했다.

→ **§H 수동 검증 1~3번을 가장 먼저 해야 한다.** 안 되면 `zmodemEnabled` 를 끄면 전과 같은 동작이다.

```go
// ZMODEM 파일 전송을 세션에 잇는다 (spec/behavior/zmodem.md, D114).
// 읽기 루프가 출력에서 시작 표시를 찾으면, 전송이 끝날 때까지 연결의 읽기·쓰기를 ZMODEM 엔진에 넘긴다.
// 그동안 터미널 입력은 서버로 보내지 않는다(Ctrl+C 만 전송 취소로 쓴다).

// ZmodemHooks 는 세션이 ZMODEM 전송에 쓰는 앱 쪽 기능이다. nil 이면 이 세션은 ZMODEM 을 쓰지 않는다.
type ZmodemHooks struct {
	// Enabled 는 지금 ZMODEM 이 켜져 있는지다 (설정 zmodemEnabled). 시작 표시를 볼 때마다 묻는다.
	Enabled func() bool

	DownloadDir func() string
	// PickFiles 는 보낼 파일을 고르는 대화상자를 띄운다. 취소하면 빈 목록이다.
	PickFiles func() ([]string, error)
}

const (
	// g_cdurZmodemProgress 는 진행 표시를 고쳐 쓰는 최소 간격이다.
	g_cdurZmodemProgress = 250 * time.Millisecond
	// g_cszZmodemTempSuffix 는 받는 중인 파일 이름 뒤에 붙는 꼬리다. 다 받으면 떼어 낸다.
	g_cszZmodemTempSuffix = ".dtpart"
	// g_ciZmodemNameMaxRunes 는 저장하는 파일 이름의 최대 길이다.
	g_ciZmodemNameMaxRunes = 200
	// g_ciZmodemNameMaxTries 는 같은 이름이 있을 때 번호를 붙여 보는 최대 횟수다.
	g_ciZmodemNameMaxTries = 1000

// zmodemOn 은 이 세션에서 ZMODEM 시작 표시를 살필지다.
func (pSession *Session) zmodemOn() bool {
	pHooks := pSession.cfg.Zmodem
	return pHooks != nil && (pHooks.Enabled == nil || pHooks.Enabled())
}

// cancelZmodem 은 진행 중인 전송을 취소한다: 엔진에 알리고 상대에게 중단 바이트열을 보낸다.
func (pSession *Session) cancelZmodem(conn Transport) {
	if pSession.zCancel.Swap(true) {
		return // 이미 취소했다
	}
	_ = conn.Write(zmodem.AbortSequence())
}

// runZmodem 은 전송 하나를 끝까지 돌린다. 읽기 루프 고루틴에서 부른다.
// 돌려주는 바이트는 ZMODEM 이 아닌 것으로 남은 출력(화면으로 보낸다), 오류는 연결이 끊겼을 때만 nil 이 아니다.
func (pSession *Session) runZmodem(conn Transport, kind zmodem.Kind, bEngine []byte) ([]byte, error) {
	pSession.zCancel.Store(false)
	pSession.zActive.Store(true)
	defer pSession.zActive.Store(false)

	pHooks := pSession.cfg.Zmodem
	bSending := kind == zmodem.KindRemoteAccepts
	pView := &zmodemView{pSession: pSession, bSending: bSending}
	opts := zmodem.Options{Cancelled: pSession.zCancel.Load, Progress: pView.onProgress}

	var result zmodem.Result
	var errRun error
	if bSending {
		result, errRun = zmodem.Send(conn, bEngine, func() ([]zmodem.FileSource, error) {
			pSession.writeOutput(noticeLine(i18n.T("be.zm.pick")))
			if pHooks.PickFiles == nil {
				return nil, nil
			}
			slPaths, errPick := pHooks.PickFiles()
			if errPick != nil {
				return nil, errPick
			}
			return zmodemSources(slPaths), nil
		}, opts)
	} else {
		szDir := ""
		if pHooks.DownloadDir != nil {
			szDir = pHooks.DownloadDir()
		}
		pView.szDir = szDir
		result, errRun = zmodem.Receive(conn, bEngine, &zmodemSink{szDir: szDir, pView: pView}, opts)
	}

	var errStream *zmodem.StreamError
	switch {
	case errRun == nil:
		pSession.writeOutput(noticeLine(i18n.T("be.zm.done", "n", result.Files, "size", formatBytes(result.Bytes))))
	case errors.Is(errRun, zmodem.ErrNotZmodem):
		// 시작 표시처럼 보였을 뿐이다: 아무 안내 없이 읽은 바이트를 화면으로 되돌린다.
	case errors.As(errRun, &errStream):
		return result.Leftover, errStream.Err
	case errors.Is(errRun, zmodem.ErrCancelled):
		pView.endLine()
		pSession.writeOutput(noticeLine(i18n.T("be.zm.cancelled")))
	case errors.Is(errRun, zmodem.ErrRemoteCancelled):
		pView.endLine()
		pSession.writeOutput(noticeLine(i18n.T("be.zm.remoteCancelled")))
	default:
		pView.endLine()
		pSession.writeOutput(noticeLine(i18n.T("be.zm.failed", "error", errRun)))
	}
	return result.Leftover, nil
}

// noticeLine 은 터미널 안내 한 줄(청록 ●)을 만든다.
func noticeLine(szText string) string {
	return "\r\x1b[2K\x1b[36m● " + szText + "\x1b[0m\r\n"
}

// formatBytes 는 바이트 수를 읽기 쉬운 단위로 적는다 (1024 단위).
func formatBytes(i64Bytes int64) string {
	const fUnit = 1024.0
	fValue := float64(i64Bytes)
	switch {
	case i64Bytes < 0:
		return "?"
	case fValue < fUnit:
		return strconv.FormatInt(i64Bytes, 10) + " B"
	case fValue < fUnit*fUnit:
		return fmt.Sprintf("%.1f KB", fValue/fUnit)
	case fValue < fUnit*fUnit*fUnit:
		return fmt.Sprintf("%.1f MB", fValue/(fUnit*fUnit))
	default:
		return fmt.Sprintf("%.2f GB", fValue/(fUnit*fUnit*fUnit))
	}
}

// zmodemView 는 전송 진행을 터미널에 보인다. 진행률은 한 줄을 고쳐 쓰고(로그에는 남기지 않는다),
// 파일 하나가 끝나면 결과 한 줄을 남긴다.
type zmodemView struct {
	pSession  *Session
	bSending  bool
	szDir     string
	tLastDraw time.Time
	bLineOpen bool   // 진행 줄을 그려 둔 상태 (끝낼 때 줄을 바꿔야 한다)
	szSavedAs string // 받은 파일이 저장된 경로 (zmodemSink 가 알려 준다)
}

func (pView *zmodemView) onProgress(ev zmodem.Progress) {
	szName := displayName(ev.Name)
	switch ev.State {
	case zmodem.G_ciStateStart:
		pView.tLastDraw = time.Time{}
	case zmodem.G_ciStateData:
		if time.Since(pView.tLastDraw) < g_cdurZmodemProgress {
			return
		}
		pView.tLastDraw = time.Now()
		szKey := "be.zm.receiving"
		if pView.bSending {
			szKey = "be.zm.sending"
		}
		szAmount := formatBytes(ev.Done)
		if ev.Total > 0 {
			szAmount = strconv.FormatInt(ev.Done*100/ev.Total, 10) + "% (" + formatBytes(ev.Done) + " / " + formatBytes(ev.Total) + ")"
		}
		// 진행 줄은 화면에만 보낸다: 로그에는 CR 이 지워져 한 줄로 길게 붙기 때문이다.
		pView.pSession.batcher.Add("\r\x1b[2K\x1b[36m● " + i18n.T(szKey, "name", szName, "amount", szAmount) + "\x1b[0m")
		pView.bLineOpen = true
	case zmodem.G_ciStateDone:
		pView.bLineOpen = false
		if pView.bSending {
			pView.pSession.writeOutput(noticeLine(i18n.T("be.zm.sent", "name", szName, "size", formatBytes(ev.Done))))
		} else {
			pView.pSession.writeOutput(noticeLine(i18n.T("be.zm.received", "name", szName, "size", formatBytes(ev.Done), "path", pView.szSavedAs)))
		}
	case zmodem.G_ciStateSkipped:
		pView.pSession.writeOutput(noticeLine(i18n.T("be.zm.skipped", "name", szName)))
	}
}

// endLine 은 그려 둔 진행 줄이 있으면 지운다 (취소·실패 안내를 그 자리에 쓰기 위해).

		pView.pSession.batcher.Add("\r\x1b[2K")
		pView.bLineOpen = false
	}

// SafeFileName 은 서버가 준 파일 이름을 이 PC 에 저장할 이름으로 다듬는다.
// 경로는 떼어 내고(폴더 밖에 쓰지 못하게), 금지·제어 문자는 `_` 로 바꾸고, 끝의 공백·점을 지우고,
// 장치 이름은 앞에 `_` 를 붙이고, 길이를 줄이고, 비면 "zmodem-file" 로 한다.
func SafeFileName(szName string) string {
	if iCut := strings.LastIndexAny(szName, `/\`); iCut >= 0 {
		szName = szName[iCut+1:]
	}
	szOut := strings.Trim(g_reFileNameBad.ReplaceAllString(szName, "_"), " .")
	if slRunes := []rune(szOut); len(slRunes) > g_ciZmodemNameMaxRunes {
		szOut = strings.Trim(string(slRunes[:g_ciZmodemNameMaxRunes]), " .")
	}
	if szOut == "" {
		return "zmodem-file"
	}
	szStem, _, _ := strings.Cut(szOut, ".")
	if g_mReservedNames[strings.ToUpper(szStem)] {
		szOut = "_" + szOut
	}
	return szOut
}

// uniquePath 는 szDir 안에서 아직 없는 경로를 찾는다: "이름.확장자" → "이름 (2).확장자" → …
// 받는 중인 임시 파일(.dtpart)이 있는 이름도 쓰는 중으로 본다.
func uniquePath(szDir string, szName string) (string, error) {
	szExt := filepath.Ext(szName)
	szStem := strings.TrimSuffix(szName, szExt)
	for iSeq := 1; iSeq <= g_ciZmodemNameMaxTries; iSeq++ {
		szTry := szName
		if iSeq >= 2 {
			szTry = szStem + " (" + strconv.Itoa(iSeq) + ")" + szExt
		}
		szPath := filepath.Join(szDir, szTry)
		_, errFinal := os.Lstat(szPath)
		_, errTemp := os.Lstat(szPath + g_cszZmodemTempSuffix)
		if errors.Is(errFinal, os.ErrNotExist) && errors.Is(errTemp, os.ErrNotExist) {
			return szPath, nil
		}
	}
	return "", i18n.NewError("be.zm.noName")
}

// zmodemSink 는 받은 파일을 폴더에 저장한다. 받는 동안은 "<이름>.dtpart" 에 쓰고 다 받으면 이름을 바꾼다.
// 같은 이름이 있으면 덮어쓰지 않고 번호를 붙인다.
type zmodemSink struct {
	szDir string
	pView *zmodemView
}

func (pSink *zmodemSink) Accept(info zmodem.FileInfo) (zmodem.FileWriter, error) {
	if pSink.szDir == "" {
		return nil, i18n.NewError("be.zm.noDir")
	}
	if errMkdir := os.MkdirAll(pSink.szDir, 0o755); errMkdir != nil {
		return nil, errMkdir
	}
	szPath, errPath := uniquePath(pSink.szDir, SafeFileName(info.Name))
	if errPath != nil {
		return nil, errPath
	}
	pFile, errOpen := os.OpenFile(szPath+g_cszZmodemTempSuffix, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o644)
	if errOpen != nil {
		return nil, errOpen
	}
	return &zmodemFile{pFile: pFile, szPath: szPath, tModTime: info.ModTime, pView: pSink.pView}, nil
}

// zmodemFile 은 받는 파일 하나다.
type zmodemFile struct {
	pFile    *os.File
	szPath   string // 다 받은 뒤의 최종 경로
	tModTime time.Time
	pView    *zmodemView
}

func (pOut *zmodemFile) Write(bData []byte) (int, error) {
	return pOut.pFile.Write(bData)
}

// Commit 은 파일을 닫고 최종 이름으로 바꾼다. 그사이 같은 이름이 생겼으면 번호를 붙인 새 이름으로 한다.
func (pOut *zmodemFile) Commit() error {
	szTemp := pOut.szPath + g_cszZmodemTempSuffix
	if errClose := pOut.pFile.Close(); errClose != nil {
		_ = os.Remove(szTemp)
		return errClose
	}
	szFinal := pOut.szPath
	if _, errStat := os.Lstat(szFinal); errStat == nil {
		// 받는 동안 다른 프로그램이 같은 이름을 만들었다: 덮어쓰지 않는다.
		_ = os.Rename(szTemp, szTemp+".tmp") // 임시 이름을 비켜 두어야 uniquePath 가 원래 이름을 다시 고르지 않는다
		szTemp += ".tmp"
		szNew, errPath := uniquePath(filepath.Dir(szFinal), filepath.Base(szFinal))
		if errPath != nil {
			_ = os.Remove(szTemp)
			return errPath
		}
		szFinal = szNew
	}
	if errRename := os.Rename(szTemp, szFinal); errRename != nil {
		_ = os.Remove(szTemp)
		return errRename
	}
	if !pOut.tModTime.IsZero() {
		_ = os.Chtimes(szFinal, time.Now(), pOut.tModTime)
	}
	if pOut.pView != nil {
		pOut.pView.szSavedAs = szFinal
	}
	return nil
}

// Abort 는 받다 만 파일을 닫고 지운다.
func (pOut *zmodemFile) Abort() {
	_ = pOut.pFile.Close()
	_ = os.Remove(pOut.szPath + g_cszZmodemTempSuffix)
}

// zmodemSources 는 고른 경로들을 보낼 파일 목록으로 바꾼다. 폴더와 읽을 수 없는 항목은 뺀다.
func zmodemSources(slPaths []string) []zmodem.FileSource {
	var slOut []zmodem.FileSource
	for _, szPath := range slPaths {
		info, errStat := os.Stat(szPath)
		if errStat != nil || !info.Mode().IsRegular() {
			continue
		}
		szOpen := szPath
		slOut = append(slOut, zmodem.FileSource{
```

```go
package zmodem

// Kind 는 출력에서 찾은 ZMODEM 시작 표시의 종류다.
type Kind int

const (
	KindNone          Kind = iota // 시작 표시 없음
	KindRemoteSends               // 서버가 보내려 한다(ZRQINIT, 서버에서 sz 실행) → 이쪽은 받는다
	KindRemoteAccepts             // 서버가 받으려 한다(ZRINIT, 서버에서 rz 실행) → 이쪽은 보낸다
)

// g_cszStartPrefix 는 16진 헤더의 앞부분이다: ZPAD ZPAD ZDLE 'B' '0'. 그 뒤 글자가 '0' 이면 ZRQINIT, '1' 이면 ZRINIT 다.
const g_cszStartPrefix = "**\x18B0"

// Detector 는 세션 출력 흐름에서 ZMODEM 시작 표시를 찾는다.
// 표시가 출력 묶음 경계에 걸쳐 와도 찾는다(앞 묶음에서 맞춘 글자 수를 기억한다).
// 표시 앞의 출력은 그대로 화면으로 보내야 하므로, 앞 묶음에 걸친 표시의 앞 글자('*' 등)는 이미 화면으로 나간 뒤다.
type Detector struct {
	iMatched int // 지금까지 맞춘 g_cszStartPrefix 의 글자 수
}

// Feed 는 출력 묶음 하나를 살핀다.
// 시작 표시가 없으면 (bData, KindNone, nil) 을 돌려준다.
// 있으면 표시 앞부분, 종류, 그리고 엔진에 넘길 바이트(다시 만든 표시 6바이트 + 묶음의 나머지)를 돌려준다.
func (pDetector *Detector) Feed(bData []byte) (bBefore []byte, kind Kind, bEngine []byte) {
	for iIndex, bOne := range bData {
		if pDetector.iMatched == len(g_cszStartPrefix) {
			pDetector.iMatched = 0
			if bOne == '0' || bOne == '1' {
				kind = KindRemoteSends
				if bOne == '1' {
					kind = KindRemoteAccepts
				}
				iStart := iIndex - len(g_cszStartPrefix) // 표시가 이 묶음에서 시작한 자리 (앞 묶음에 걸쳤으면 음수)
				if iStart < 0 {
					iStart = 0
				}
				bEngine = append([]byte(g_cszStartPrefix), bData[iIndex:]...)
				return bData[:iStart], kind, bEngine
			}
		}
		switch {
		case bOne == g_cszStartPrefix[pDetector.iMatched]:
			pDetector.iMatched++
		case bOne == '*':
			// "***" 처럼 별이 이어지면 마지막 두 개가 표시의 앞부분일 수 있다.
			if pDetector.iMatched >= 2 {
				pDetector.iMatched = 2
			} else {
				pDetector.iMatched = 1
			}
		default:
			pDetector.iMatched = 0
		}
	}
	return bData, KindNone, nil
}

// Reset 은 맞추던 상태를 지운다 (연결이 바뀌었을 때).
func (pDetector *Detector) Reset() {
	pDetector.iMatched = 0
}
```

```go
package zmodem

import (
	"encoding/binary"
	"hash/crc32"
)

// Stream 은 전송 계층이다 (세션의 연결). Read 는 받은 바이트를, Write 는 보낼 바이트를 다룬다.
type Stream interface {
	Read(bBuf []byte) (int, error)
	Write(bData []byte) error
}

// Options 는 전송 하나의 선택 사항이다.
type Options struct {
	// Cancelled 는 사용자가 취소했는지 알려 준다. nil 이면 취소할 수 없다.
	Cancelled func() bool
	// Progress 는 진행 상황을 알린다. nil 이면 알리지 않는다.
	Progress func(ev Progress)
}

// Progress 는 진행 상황 알림 하나다.
type Progress struct {
	Name  string
	Done  int64
	Total int64 // 모르면 -1
	State int   // G_ciStateStart · G_ciStateData · G_ciStateDone · G_ciStateSkipped
}

// 진행 상태.
const (
	G_ciStateStart = iota
	G_ciStateData
	G_ciStateDone
	G_ciStateSkipped
)

// engine 은 전송 하나의 상태다: 읽기 버퍼, 취소 확인, 오류 횟수.
type engine struct {
	stream  Stream
	opts    Options
	bIn     []byte // 읽어 둔 바이트
	iIn     int    // bIn 에서 다음에 읽을 자리
	bKeep   bool   // true 면 읽은 바이트를 버리지 않고 쌓는다 (첫 헤더가 아니면 통째로 되돌리기 위해)
	iCanRun int    // 연달아 받은 CAN(0x18) 수
	iErrors int
	// bResync 는 오류 뒤 ZRPOS 를 보내고 상대의 새 ZDATA 를 기다리는 중이라는 뜻이다. 그동안 흘러오는 것은
	// 이미 버리기로 한 데이터라, 그 안에서 헤더처럼 보이다 만 것들은 오류로 세지 않는다(ZRPOS 를 보낼 때 한 번 셌다).
	bResync bool
	arrRead [32 * 1024]byte
}

func newEngine(stream Stream, bInitial []byte, opts Options) *engine {
	return &engine{stream: stream, opts: opts, bIn: append([]byte(nil), bInitial...), bKeep: true}
}

func (pEngine *engine) cancelled() bool {
	return pEngine.opts.Cancelled != nil && pEngine.opts.Cancelled()
}

func (pEngine *engine) progress(szName string, i64Done int64, i64Total int64, iState int) {
	if pEngine.opts.Progress != nil {
		pEngine.opts.Progress(Progress{Name: szName, Done: i64Done, Total: i64Total, State: iState})
	}
}

// readByte 는 바이트 하나를 읽는다. 버퍼가 비면 연결에서 읽는다.
// 사용자가 취소했으면 ErrCancelled, CAN 이 5개 이어지면 ErrRemoteCancelled 다.
func (pEngine *engine) readByte() (byte, error) {
	for pEngine.iIn >= len(pEngine.bIn) {
		if pEngine.cancelled() {
			return 0, ErrCancelled
		}
		nRead, errRead := pEngine.stream.Read(pEngine.arrRead[:])
		if nRead > 0 {
			if pEngine.bKeep {
				pEngine.bIn = append(pEngine.bIn, pEngine.arrRead[:nRead]...)
			} else {
				pEngine.bIn = append(pEngine.bIn[:0], pEngine.arrRead[:nRead]...)
				pEngine.iIn = 0
			}
		}
		if errRead != nil && nRead == 0 {
			return 0, &StreamError{Err: errRead}
		}
		if pEngine.cancelled() {
			// 취소한 뒤에 도착한 것은 전송 중이던 데이터다: 화면으로 되돌리지 않고 버린다.
			pEngine.bIn, pEngine.iIn = pEngine.bIn[:0], 0
			return 0, ErrCancelled
		}
	}
	bOne := pEngine.bIn[pEngine.iIn]
	pEngine.iIn++
	if bOne == g_cbZdle {
		pEngine.iCanRun++
		if pEngine.iCanRun >= 5 {
			return 0, ErrRemoteCancelled
		}
	} else {
		pEngine.iCanRun = 0
	}
	return bOne, nil
}

// unreadByte 는 방금 읽은 바이트 하나를 되돌린다.
func (pEngine *engine) unreadByte() {
	if pEngine.iIn > 0 {
		pEngine.iIn--
	}
}

// leftover 는 읽어 두었지만 쓰지 않은 바이트다. 전송이 끝난 뒤 화면 출력으로 되돌린다.
func (pEngine *engine) leftover() []byte {
	return append([]byte(nil), pEngine.bIn[pEngine.iIn:]...)
}

func (pEngine *engine) write(bData []byte) error {
	if errWrite := pEngine.stream.Write(bData); errWrite != nil {
		return &StreamError{Err: errWrite}
	}
	return nil
}

func (pEngine *engine) sendHex(bType byte, arrData [4]byte) error {
	return pEngine.write(encodeHexHeader(bType, arrData))
}

// noteError 는 오류 하나를 센다. 한도를 넘으면 ErrProtocol 이다.
func (pEngine *engine) noteError() error {
	pEngine.iErrors++
	if pEngine.iErrors > g_ciErrorMax {
		return ErrProtocol
	}
	return nil
}

// readEscaped 는 이스케이프를 푼 바이트 하나를 읽는다. 데이터 조각의 끝 표시를 만나면 bEnd 에 그 표시를 넣어 돌려준다.
// 흐름 제어 문자(XON·XOFF)는 건너뛴다.
func (pEngine *engine) readEscaped() (bOne byte, bEnd byte, err error) {
	for {
		bRaw, errRead := pEngine.readByte()
		if errRead != nil {
			return 0, 0, errRead
		}
		switch bRaw {
		case g_cbXon, g_cbXoff, g_cbXon | 0x80, g_cbXoff | 0x80:
			continue
		case g_cbZdle:
		default:
			return bRaw, 0, nil
		}
		bNext, errNext := pEngine.readByte()
		if errNext != nil {
			return 0, 0, errNext
		}
		switch {
		case bNext == g_cbZcrce || bNext == g_cbZcrcg || bNext == g_cbZcrcq || bNext == g_cbZcrcw:
			return 0, bNext, nil
		case bNext == g_cbZrub0:
			return 0x7f, 0, nil
		case bNext == g_cbZrub1:
			return 0xff, 0, nil
		case bNext&0x60 == 0x40:
			return bNext ^ 0x40, 0, nil
		default:
			return 0, 0, ErrProtocol
		}
	}
}

// readEscapedN 은 이스케이프를 푼 바이트 iCount 개를 읽는다. 그 사이에 끝 표시가 나오면 오류다.
func (pEngine *engine) readEscapedN(iCount int) ([]byte, error) {
	bOut := make([]byte, 0, iCount)
	for len(bOut) < iCount {
		bOne, bEnd, errRead := pEngine.readEscaped()
		if errRead != nil {
			return nil, errRead
		}
		if bEnd != 0 {
			return nil, ErrProtocol
		}
		bOut = append(bOut, bOne)
	}
	return bOut, nil
}

func hexValue(bDigit byte) (byte, bool) {
	switch {
	case bDigit >= '0' && bDigit <= '9':
		return bDigit - '0', true
	case bDigit >= 'a' && bDigit <= 'f':
		return bDigit - 'a' + 10, true
	case bDigit >= 'A' && bDigit <= 'F':
		return bDigit - 'A' + 10, true
	}
	return 0, false
}

// tryHeaderBody 는 형식 글자(A·B·C) 뒤의 헤더 본문을 읽는다. CRC 가 맞지 않거나 모양이 틀리면 bOk=false 다.
func (pEngine *engine) tryHeaderBody(bFormat byte) (hdr header, bOk bool, err error) {
	hdr.bFormat = bFormat
	var bBody []byte
	switch bFormat {
	case g_cbZhex:
		bBody = make([]byte, 0, 7)
		for iIndex := 0; iIndex < 7; iIndex++ {
			bHigh, errHigh := pEngine.readByte()
			if errHigh != nil {
				return hdr, false, errHigh
			}
			bLow, errLow := pEngine.readByte()
			if errLow != nil {
				return hdr, false, errLow
			}
			bHighValue, bHighOk := hexValue(bHigh)
			bLowValue, bLowOk := hexValue(bLow)
			if !bHighOk || !bLowOk {
				return hdr, false, nil
			}
			bBody = append(bBody, bHighValue<<4|bLowValue)
		}
		if crc16(bBody[:5]) != binary.BigEndian.Uint16(bBody[5:]) {
			return hdr, false, nil
		}
		// 16진 헤더 뒤의 CR LF 를 먹는다 (LF 는 8번째 비트가 서 있을 수 있다). XON 은 다음 헤더를 찾을 때 건너뛴다.
		bCr, errCr := pEngine.readByte()
		if errCr != nil {
			return hdr, false, errCr
		}
		if bCr == '\r' || bCr == 0x8d {
			bLf, errLf := pEngine.readByte()
			if errLf != nil {
				return hdr, false, errLf
			}
			if bLf != '\n' && bLf != 0x8a {
				pEngine.unreadByte()
			}
		} else {
			pEngine.unreadByte()
		}
	case g_cbZbin:
		bRead, errRead := pEngine.readEscapedN(7)
		if errRead == ErrProtocol {
			return hdr, false, nil
		}
		if errRead != nil {
			return hdr, false, errRead
		}
		if crc16(bRead[:5]) != binary.BigEndian.Uint16(bRead[5:]) {
			return hdr, false, nil
		}
		bBody = bRead
	case g_cbZbin32:
		bRead, errRead := pEngine.readEscapedN(9)
		if errRead == ErrProtocol {
			return hdr, false, nil
		}
		if errRead != nil {
			return hdr, false, errRead
		}
		if crc32.ChecksumIEEE(bRead[:5]) != binary.LittleEndian.Uint32(bRead[5:]) {
			return hdr, false, nil
		}
		bBody = bRead
	default:
		return hdr, false, nil
	}
	hdr.bType = bBody[0]
	copy(hdr.arrData[:], bBody[1:5])
	return hdr, true, nil
}

// readFirstHeader 는 시작 표시로 본 자리에서 헤더 하나를 읽는다. 헤더가 아니면 읽은 것을 모두 되돌려 놓고 ErrNotZmodem 이다.
func (pEngine *engine) readFirstHeader() (header, error) {
	defer func() { pEngine.bKeep = false }()
	for _, bWant := range []byte{g_cbZpad, g_cbZpad, g_cbZdle, g_cbZhex} {
		bOne, errRead := pEngine.readByte()
		if errRead != nil {
			return header{}, errRead
		}
		if bOne != bWant {
			pEngine.iIn = 0
			return header{}, ErrNotZmodem
		}
	}
	hdr, bOk, errBody := pEngine.tryHeaderBody(g_cbZhex)
	if errBody != nil {
		return header{}, errBody
	}
	if !bOk {
		pEngine.iIn = 0
		return header{}, ErrNotZmodem
	}
	// 헤더가 맞다: 여기까지 읽은 부분은 더 되돌릴 일이 없다.
	pEngine.bIn = append([]byte(nil), pEngine.bIn[pEngine.iIn:]...)
	pEngine.iIn = 0
	return hdr, nil
}

// readHeader 는 다음 헤더를 찾을 때까지 읽는다. 헤더 사이의 다른 바이트는 버린다.
// 깨진 헤더는 오류로 세고 계속 찾는다. 헤더 없이 너무 많이 버리면 ErrProtocol 이다.
func (pEngine *engine) readHeader() (header, error) {
	iGarbage := 0
	for {
		bOne, errRead := pEngine.readByte()
		if errRead != nil {
			return header{}, errRead
		}
		if bOne != g_cbZpad {
			iGarbage++
			if iGarbage > g_ciGarbageMax {
				return header{}, ErrProtocol
			}
			continue
		}
		for bOne == g_cbZpad {
			if bOne, errRead = pEngine.readByte(); errRead != nil {
				return header{}, errRead
			}
		}
		if bOne != g_cbZdle {
			continue
		}
		bFormat, errFormat := pEngine.readByte()
		if errFormat != nil {
			return header{}, errFormat
		}
		if bFormat != g_cbZbin && bFormat != g_cbZhex && bFormat != g_cbZbin32 {
			continue
		}
		hdr, bOk, errBody := pEngine.tryHeaderBody(bFormat)
		if errBody != nil {
			return header{}, errBody
		}
		if !bOk {
			if !pEngine.bResync {
				if errCount := pEngine.noteError(); errCount != nil {
					return header{}, errCount
				}
			}
			continue
		}
		if hdr.bType == g_cbZcan || hdr.bType == g_cbZabort {
			return header{}, ErrRemoteCancelled
		}
		return hdr, nil
	}
}

// readSubpacket 은 데이터 조각 하나를 읽는다. CRC 종류는 앞선 헤더의 형식을 따른다(CRC-32 는 'C' 헤더 뒤에서만).
// CRC 가 맞지 않으면 bOk=false 다.
func (pEngine *engine) readSubpacket(bCrc32 bool) (bData []byte, bEnd byte, bOk bool, err error) {
	for {
		bOne, bEndMark, errRead := pEngine.readEscaped()
		if errRead == ErrProtocol {
			return nil, 0, false, nil
		}
		if errRead != nil {
			return nil, 0, false, errRead
		}
		if bEndMark != 0 {
			bEnd = bEndMark
			break
		}
		if len(bData) >= g_ciSubpacketMax {
			return nil, 0, false, nil
		}
		bData = append(bData, bOne)
	}
	if bCrc32 {
		bCrc, errCrc := pEngine.readEscapedN(4)
		if errCrc == ErrProtocol {
			return nil, 0, false, nil
		}
		if errCrc != nil {
			return nil, 0, false, errCrc
		}
		uiWant := crc32.Update(crc32.ChecksumIEEE(bData), crc32.IEEETable, []byte{bEnd})
		return bData, bEnd, uiWant == binary.LittleEndian.Uint32(bCrc), nil
	}
	bCrc, errCrc := pEngine.readEscapedN(2)
	if errCrc == ErrProtocol {
		return nil, 0, false, nil
	}
	if errCrc != nil {
		return nil, 0, false, errCrc
	}
	uiWant := crc16(append(append([]byte(nil), bData...), bEnd))
	return bData, bEnd, uiWant == binary.BigEndian.Uint16(bCrc), nil
}
```

```go
// Package zmodem 은 ZMODEM 파일 전송 프로토콜을 구현한다 (spec/behavior/zmodem.md, D114).
// 서버에서 sz 를 실행하면 받는 쪽(Receive), rz 를 실행하면 보내는 쪽(Send)이 된다.
// 형식은 공개 규격(Chuck Forsberg, "The ZMODEM Inter Application File Transfer Protocol")을 따른다.
// 전송 계층(SSH·시리얼)과 파일 저장 방식은 인터페이스로 받아 이 패키지는 프로토콜만 다룬다.
package zmodem

import (
	"encoding/binary"
	"errors"
	"hash/crc32"
)

// 프레임을 이루는 특수 바이트.
const (
	g_cbZpad   = '*'  // 헤더 앞의 채움 문자
	g_cbZdle   = 0x18 // 이스케이프 문자 (CAN 과 같은 값)
	g_cbZbin   = 'A'  // 이진 헤더, CRC-16
	g_cbZhex   = 'B'  // 16진 헤더, CRC-16
	g_cbZbin32 = 'C'  // 이진 헤더, CRC-32
	g_cbXon    = 0x11
	g_cbXoff   = 0x13
	g_cbZrub0  = 'l' // ZDLE 뒤에서 0x7f 를 뜻한다
	g_cbZrub1  = 'm' // ZDLE 뒤에서 0xff 를 뜻한다
)

// 헤더 종류.
const (
	G_cbZrqinit  = 0  // 보내는 쪽의 시작 요청 (sz 가 처음 보낸다)
	G_cbZrinit   = 1  // 받는 쪽의 준비 알림 (rz 가 처음 보낸다)
	g_cbZsinit   = 2  // 보내는 쪽의 초기 설정
	g_cbZack     = 3  // 확인
	g_cbZfile    = 4  // 파일 정보
	g_cbZskip    = 5  // 이 파일 건너뛰기
	g_cbZnak     = 6  // 마지막 헤더를 못 읽음
	g_cbZabort   = 7  // 전송 중단
	g_cbZfin     = 8  // 세션 끝
	g_cbZrpos    = 9  // 이 위치부터 다시 보내라
	g_cbZdata    = 10 // 데이터가 뒤따른다
	g_cbZeof     = 11 // 파일 끝
	g_cbZferr    = 12 // 파일 읽기·쓰기 오류
	g_cbZcrc     = 13 // 파일 CRC 요청·응답
	g_cbZcan     = 16 // CAN 여러 개로 중단됨
	g_cbZfreecnt = 17 // 남은 저장 공간 요청
)

// 데이터 조각(subpacket)의 끝 표시. ZDLE 뒤에 온다.
const (
	g_cbZcrce = 'h' // 프레임 끝, 헤더가 뒤따른다
	g_cbZcrcg = 'i' // 프레임이 이어진다, 응답 없음
	g_cbZcrcq = 'j' // 프레임이 이어진다, ZACK 을 기대한다
	g_cbZcrcw = 'k' // 프레임 끝, ZACK 을 기대한다
)

// ZRINIT 의 능력 표시(ZF0).
const (
	g_cbCanFdx  = 0x01 // 동시에 보내고 받을 수 있다
	g_cbCanOvIo = 0x02 // 디스크에 쓰는 동안에도 받을 수 있다
	g_cbCanFc32 = 0x20 // CRC-32 를 쓸 수 있다
)

// 한도.
const (
	// G_ciSubpacketBytes 는 보낼 때 데이터 조각 하나의 크기다. 모든 구현이 받는 1024 로 둔다.
	G_ciSubpacketBytes = 1024
	// g_ciSubpacketMax 는 받을 때 받아들이는 조각의 최대 크기다 (lrzsz 는 8192 까지 보낸다).
	g_ciSubpacketMax = 16 * 1024
	// g_ciAckEvery 는 보낼 때 몇 조각마다 확인(ZACK)을 기다릴지다. 약 256KB 마다 한 번.
	g_ciAckEvery = 256
	// g_ciGarbageMax 는 헤더를 기다리는 동안 버릴 수 있는 바이트 수다. 넘으면 상대가 ZMODEM 을 끝낸 것으로 본다.
	// 오류 뒤 다시 맞추는 동안에는 상대가 이미 보낸 데이터(확인 주기 하나 분량)를 통째로 버려야 하므로 넉넉히 둔다.
	g_ciGarbageMax = 4 * 1024 * 1024
	// g_ciErrorMax 는 전송 하나에서 참는 오류(CRC 불일치 등) 횟수다.
	g_ciErrorMax = 10
)

// 오류.
var (
	// ErrCancelled 는 이쪽(사용자)이 전송을 취소했을 때의 오류다.
	ErrCancelled = errors.New("zmodem: cancelled")
	// ErrRemoteCancelled 는 상대가 전송을 중단했을 때의 오류다.
	ErrRemoteCancelled = errors.New("zmodem: cancelled by the remote side")
	// ErrProtocol 은 상대의 응답이 규격과 맞지 않거나 오류가 너무 많을 때의 오류다.
	ErrProtocol = errors.New("zmodem: protocol error")
	// ErrNotZmodem 은 시작 표시처럼 보였지만 ZMODEM 헤더가 아니었을 때의 오류다 (화면 출력으로 되돌린다).
	ErrNotZmodem = errors.New("zmodem: not a zmodem header")
)

// StreamError 는 전송 계층(연결)에서 난 읽기·쓰기 오류를 감싼다. 호출자는 연결 끊김으로 처리한다.
type StreamError struct {
	Err error
}

func (pErr *StreamError) Error() string { return pErr.Err.Error() }
func (pErr *StreamError) Unwrap() error { return pErr.Err }

// header 는 헤더 하나다: 종류와 4바이트 값(위치 또는 플래그), 그리고 받은 형식(뒤따르는 데이터의 CRC 종류를 정한다).
type header struct {
	bType   byte
	arrData [4]byte
	bFormat byte
}

// pos 는 헤더 값을 파일 위치(리틀 엔디언)로 읽는다.
func (hdr header) pos() int64 {
	return int64(binary.LittleEndian.Uint32(hdr.arrData[:]))
}

// posData 는 파일 위치를 헤더 값으로 만든다.
func posData(i64Pos int64) [4]byte {
	var arrData [4]byte
	binary.LittleEndian.PutUint32(arrData[:], uint32(i64Pos))
	return arrData
}

// crc16 은 CRC-16/XMODEM(다항식 0x1021, 초기값 0)을 계산한다.
func crc16(bData []byte) uint16 {
	var uiCrc uint16
	for _, bOne := range bData {
		uiCrc ^= uint16(bOne) << 8
		for iBit := 0; iBit < 8; iBit++ {
			if uiCrc&0x8000 != 0 {
				uiCrc = uiCrc<<1 ^ 0x1021
			} else {
				uiCrc <<= 1
			}
		}
	}
	return uiCrc
}

// appendEscaped 는 bData 를 ZDLE 이스케이프해 bOut 에 붙인다.
// 제어 문자(0x00~0x1f, 0x80~0x9f)는 모두 이스케이프한다 — 터미널 계층이 건드릴 수 있는 문자를 하나도 그대로 보내지 않는다.
func appendEscaped(bOut []byte, bData []byte) []byte {
	for _, bOne := range bData {
		switch {
		case bOne == 0x7f:
			bOut = append(bOut, g_cbZdle, g_cbZrub0)
		case bOne == 0xff:
			bOut = append(bOut, g_cbZdle, g_cbZrub1)
		case bOne&0x60 == 0:
			bOut = append(bOut, g_cbZdle, bOne^0x40)
		default:
			bOut = append(bOut, bOne)
		}
	}
	return bOut
}

const g_cszHexDigits = "0123456789abcdef"

// encodeHexHeader 는 16진 헤더를 만든다: ZPAD ZPAD ZDLE 'B' + 16진 14자 + CR LF(8번째 비트를 세운 LF) [+ XON].
// ZACK 과 ZFIN 뒤에는 XON 을 붙이지 않는다.
func encodeHexHeader(bType byte, arrData [4]byte) []byte {
	bBody := []byte{bType, arrData[0], arrData[1], arrData[2], arrData[3]}
	uiCrc := crc16(bBody)
	bBody = append(bBody, byte(uiCrc>>8), byte(uiCrc))
	bOut := []byte{g_cbZpad, g_cbZpad, g_cbZdle, g_cbZhex}
	for _, bOne := range bBody {
		bOut = append(bOut, g_cszHexDigits[bOne>>4], g_cszHexDigits[bOne&0x0f])
	}
	bOut = append(bOut, '\r', 0x8a)
	if bType != g_cbZack && bType != g_cbZfin {
		bOut = append(bOut, g_cbXon)
	}
	return bOut
}

// encodeBinHeader 는 이진 헤더를 만든다. bCrc32 면 CRC-32('C'), 아니면 CRC-16('A').
func encodeBinHeader(bType byte, arrData [4]byte, bCrc32 bool) []byte {
	bBody := []byte{bType, arrData[0], arrData[1], arrData[2], arrData[3]}
	if bCrc32 {
		bBody = binary.LittleEndian.AppendUint32(bBody, crc32.ChecksumIEEE(bBody))
		return appendEscaped([]byte{g_cbZpad, g_cbZdle, g_cbZbin32}, bBody)
	}
	uiCrc := crc16(bBody)
	bBody = append(bBody, byte(uiCrc>>8), byte(uiCrc))
	return appendEscaped([]byte{g_cbZpad, g_cbZdle, g_cbZbin}, bBody)
}

// appendSubpacket 은 데이터 조각 하나를 bOut 에 붙인다: 이스케이프한 데이터 + ZDLE 끝 표시 + CRC(데이터와 끝 표시에 대한).
func appendSubpacket(bOut []byte, bData []byte, bEnd byte, bCrc32 bool) []byte {
	bOut = appendEscaped(bOut, bData)
	bOut = append(bOut, g_cbZdle, bEnd)
	if bCrc32 {
		uiCrc := crc32.Update(crc32.ChecksumIEEE(bData), crc32.IEEETable, []byte{bEnd})
		return appendEscaped(bOut, binary.LittleEndian.AppendUint32(nil, uiCrc))
	}
	uiCrc := crc16(append(append([]byte(nil), bData...), bEnd))
	return appendEscaped(bOut, []byte{byte(uiCrc >> 8), byte(uiCrc)})
}

// AbortSequence 는 상대에게 전송 중단을 알리는 바이트열이다: CAN 8개 + 백스페이스 8개.
func AbortSequence() []byte {
	return []byte{0x18, 0x18, 0x18, 0x18, 0x18, 0x18, 0x18, 0x18, 8, 8, 8, 8, 8, 8, 8, 8}
}
```

```go
package zmodem

import (
	"strconv"
	"strings"
	"time"
)

// FileInfo 는 상대가 보내려는 파일의 정보다 (ZFILE 헤더의 데이터).
type FileInfo struct {
	Name    string    // 상대가 준 이름 그대로 (경로가 붙어 있을 수 있다 — 받는 쪽이 다듬는다)
	Size    int64     // 모르면 -1
	ModTime time.Time // 모르면 zero
}

// FileWriter 는 받는 파일 하나를 쓰는 곳이다.
type FileWriter interface {
	Write(bData []byte) (int, error)
	// Commit 은 파일을 다 받았을 때 부른다 (닫고 최종 이름으로 확정).
	Commit() error
	// Abort 는 받다가 그만둘 때 부른다 (닫고 지운다).
	Abort()
}

// Sink 는 받은 파일을 저장하는 쪽이다.
type Sink interface {
	// Accept 는 파일 하나를 받을지 정한다. (nil, nil) 이면 그 파일을 건너뛴다. 오류면 전송 전체를 중단한다.
	Accept(info FileInfo) (FileWriter, error)
}

// Result 는 전송 결과다.
type Result struct {
	Files    int    // 다 주고받은 파일 수
	Skipped  int    // 건너뛴 파일 수
	Bytes    int64  // 주고받은 바이트 수
	Leftover []byte // ZMODEM 이 아닌 것으로 남은 바이트 (화면 출력으로 되돌린다)
}

// Receive 는 서버가 보내는 파일들을 받는다. bInitial 은 Detector 가 돌려준 바이트(시작 표시 포함)다.
// 시작 표시가 실제 헤더가 아니면 ErrNotZmodem 과 함께 읽은 바이트를 Leftover 로 돌려준다.
// 실패하면(취소 포함) 상대에게 중단을 알린다. 연결 오류(*StreamError)는 그대로 돌려준다.
func Receive(stream Stream, bInitial []byte, sink Sink, opts Options) (Result, error) {
	pEngine := newEngine(stream, bInitial, opts)
	var result Result
	hdr, errFirst := pEngine.readFirstHeader()
	if errFirst == nil && hdr.bType != G_cbZrqinit {
		errFirst = ErrNotZmodem
	}
	if errFirst != nil {
		result.Leftover = pEngine.leftover()
		return result, errFirst
	}
	errRun := pEngine.receiveLoop(sink, &result)
	result.Leftover = pEngine.leftover()
	if errRun != nil {
		if _, bStream := errRun.(*StreamError); !bStream && errRun != ErrRemoteCancelled {
			_ = stream.Write(AbortSequence())
		}
	}
	return result, errRun
}

// sendRinit 는 받을 준비가 됐음을 알린다: 버퍼 크기 0(끊김 없이 받음), 능력 = 양방향·디스크 중 수신·CRC-32.
func (pEngine *engine) sendRinit() error {
	return pEngine.sendHex(G_cbZrinit, [4]byte{0, 0, 0, g_cbCanFdx | g_cbCanOvIo | g_cbCanFc32})
}

// receiveLoop 는 파일 사이의 헤더를 처리한다: ZFILE 이면 파일을 받고, ZFIN 이면 끝낸다.
func (pEngine *engine) receiveLoop(sink Sink, pResult *Result) error {
	if errSend := pEngine.sendRinit(); errSend != nil {
		return errSend
	}
	for {
		hdr, errHeader := pEngine.readHeader()
		if errHeader != nil {
			return errHeader
		}
		switch hdr.bType {
		case G_cbZrqinit:
			if errSend := pEngine.sendRinit(); errSend != nil {
				return errSend
			}
		case g_cbZsinit:
			// 보내는 쪽의 초기 설정(주의 끌기 문자열): 읽고 확인만 한다.
			_, _, bOk, errData := pEngine.readSubpacket(hdr.bFormat == g_cbZbin32)
			if errData != nil {
				return errData
			}
			bReply := byte(g_cbZack)
			if !bOk {
				bReply = g_cbZnak
			}
			if errSend := pEngine.sendHex(bReply, [4]byte{1, 0, 0, 0}); errSend != nil {
				return errSend
			}
		case g_cbZfreecnt:
			if errSend := pEngine.sendHex(g_cbZack, [4]byte{0xff, 0xff, 0xff, 0x7f}); errSend != nil {
				return errSend
			}
		case g_cbZfile:
			bInfo, _, bOk, errData := pEngine.readSubpacket(hdr.bFormat == g_cbZbin32)
			if errData != nil {
				return errData
			}
			if !bOk {
				if errCount := pEngine.noteError(); errCount != nil {
					return errCount
				}
				if errSend := pEngine.sendHex(g_cbZnak, [4]byte{}); errSend != nil {
					return errSend
				}
				continue
			}
			if errFile := pEngine.receiveFile(parseFileInfo(bInfo), sink, pResult); errFile != nil {
				return errFile
			}
		case g_cbZfin:
			if errSend := pEngine.sendHex(g_cbZfin, [4]byte{}); errSend != nil {
				return errSend
			}
			pEngine.eatOverAndOut()
			return nil
		default:
			// 이 자리에서 뜻이 없는 헤더(늦게 온 ZDATA·ZEOF 등)는 넘긴다.
		}
	}
}

// eatOverAndOut 은 상대가 마지막에 보내는 "OO" 를 먹는다. 이미 버퍼에 있을 때만 본다 —
// 없으면 기다리지 않는다(다음 출력과 함께 오면 화면에 "OO" 두 글자가 보일 수 있다).
func (pEngine *engine) eatOverAndOut() {
	// 16진 헤더 뒤의 XON 이 남아 있으면 먼저 넘긴다.
	for pEngine.iIn < len(pEngine.bIn) && pEngine.bIn[pEngine.iIn] == g_cbXon {
		pEngine.iIn++
	}
	if pEngine.iIn+1 < len(pEngine.bIn) && pEngine.bIn[pEngine.iIn] == 'O' && pEngine.bIn[pEngine.iIn+1] == 'O' {
		pEngine.iIn += 2
	}
}

// parseFileInfo 는 ZFILE 데이터를 푼다: "이름\0크기 수정시각(8진) 모드(8진) …\0".
func parseFileInfo(bInfo []byte) FileInfo {
	info := FileInfo{Size: -1}
	szName, szRest, _ := strings.Cut(string(bInfo), "\x00")
	info.Name = szName
	szRest, _, _ = strings.Cut(szRest, "\x00")
	slFields := strings.Fields(szRest)
	if len(slFields) >= 1 {
		if i64Size, errSize := strconv.ParseInt(slFields[0], 10, 64); errSize == nil && i64Size >= 0 {
			info.Size = i64Size
		}
	}
	if len(slFields) >= 2 {
		if i64Time, errTime := strconv.ParseInt(slFields[1], 8, 64); errTime == nil && i64Time > 0 {
			info.ModTime = time.Unix(i64Time, 0)
		}
	}
	return info
}

// receiveFile 은 파일 하나를 받는다. 저장하는 쪽이 건너뛰라고 하면 ZSKIP 을 보낸다.
func (pEngine *engine) receiveFile(info FileInfo, sink Sink, pResult *Result) error {
	writer, errAccept := sink.Accept(info)
	if errAccept != nil {
		return errAccept
	}
	if writer == nil {
		pResult.Skipped++
		pEngine.progress(info.Name, 0, info.Size, G_ciStateSkipped)
		return pEngine.sendHex(g_cbZskip, [4]byte{})
	}
	pEngine.progress(info.Name, 0, info.Size, G_ciStateStart)
	i64Pos, errData := pEngine.receiveData(info, writer)
	if errData != nil {
		writer.Abort()
		return errData
	}
	if errCommit := writer.Commit(); errCommit != nil {
		return errCommit
	}
	pResult.Files++
	pResult.Bytes += i64Pos
	pEngine.progress(info.Name, i64Pos, info.Size, G_ciStateDone)
	return pEngine.sendRinit() // 다음 파일(ZFILE) 또는 끝(ZFIN)을 기다린다
}

// receiveData 는 파일 내용을 받는다. 받은 길이를 돌려준다.
// CRC 가 틀리거나 위치가 어긋나면 ZRPOS 로 지금 위치부터 다시 보내 달라고 한다.
func (pEngine *engine) receiveData(info FileInfo, writer FileWriter) (int64, error) {
	var i64Pos int64
	if errSend := pEngine.sendHex(g_cbZrpos, posData(0)); errSend != nil {
		return 0, errSend
	}
	for {
		hdr, errHeader := pEngine.readHeader()
		if errHeader != nil {
			return i64Pos, errHeader
		}
		switch hdr.bType {
		case g_cbZdata:
			if hdr.pos() != i64Pos&0xffffffff {
				if pEngine.bResync {
					continue // 다시 맞추는 중: 버리는 데이터 안에서 우연히 맞은 헤더이거나 옛 프레임이다
				}
				if errCount := pEngine.noteError(); errCount != nil {
					return i64Pos, errCount
				}
				pEngine.bResync = true
				if errSend := pEngine.sendHex(g_cbZrpos, posData(i64Pos)); errSend != nil {
					return i64Pos, errSend
				}
				continue
			}
			pEngine.bResync = false
			bFrameDone := false
			for !bFrameDone {
				bData, bEnd, bOk, errData := pEngine.readSubpacket(hdr.bFormat == g_cbZbin32)
				if errData != nil {
					return i64Pos, errData
				}
				if !bOk {
					if errCount := pEngine.noteError(); errCount != nil {
						return i64Pos, errCount
					}
					pEngine.bResync = true
					if errSend := pEngine.sendHex(g_cbZrpos, posData(i64Pos)); errSend != nil {
						return i64Pos, errSend
					}
					break
				}
				if len(bData) > 0 {
					if _, errWrite := writer.Write(bData); errWrite != nil {
						_ = pEngine.sendHex(g_cbZferr, [4]byte{})
						return i64Pos, errWrite
					}
					i64Pos += int64(len(bData))
					pEngine.progress(info.Name, i64Pos, info.Size, G_ciStateData)
				}
				switch bEnd {
				case g_cbZcrcw:
					bFrameDone = true
					fallthrough
				case g_cbZcrcq:
					if errSend := pEngine.sendHex(g_cbZack, posData(i64Pos)); errSend != nil {
						return i64Pos, errSend
					}
				case g_cbZcrce:
					bFrameDone = true
				}
			}
		case g_cbZeof:
			if hdr.pos() == i64Pos&0xffffffff {
				pEngine.bResync = false
				return i64Pos, nil
			}
			if pEngine.bResync {
				continue // 다시 맞추는 중에 온 옛 ZEOF: 이미 ZRPOS 를 보냈으니 새 ZDATA 를 기다린다
			}
			// 위치가 다른 ZEOF 는 놓친 데이터가 있다는 뜻이다: 지금 위치부터 다시 받는다.
			if errCount := pEngine.noteError(); errCount != nil {
				return i64Pos, errCount
			}
			pEngine.bResync = true
			if errSend := pEngine.sendHex(g_cbZrpos, posData(i64Pos)); errSend != nil {
				return i64Pos, errSend
			}
		case g_cbZfile:
			// 우리 ZRPOS 를 못 받고 ZFILE 을 다시 보냈다: 데이터는 읽어 버리고 ZRPOS 를 다시 보낸다.
			if _, _, _, errData := pEngine.readSubpacket(hdr.bFormat == g_cbZbin32); errData != nil {
				return i64Pos, errData
			}
			if errSend := pEngine.sendHex(g_cbZrpos, posData(i64Pos)); errSend != nil {
				return i64Pos, errSend
			}
		case g_cbZfin:
			return i64Pos, ErrRemoteCancelled // 파일 중간에 세션을 끝냈다
		default:
		}
	}
}
```

```go
package zmodem

import (
	"hash/crc32"
	"io"

	"time"
)

// FileSource 는 보낼 파일 하나다.
type FileSource struct {
	Name    string // 상대에게 알릴 이름 (경로 없이 파일 이름만)
	Size    int64
	ModTime time.Time
	// Open 은 내용을 읽을 곳을 연다. 상대가 중간부터 다시 달라고 할 수 있어 위치를 옮길 수 있어야 한다.
	Open func() (io.ReadSeekCloser, error)
}

// G_durStaleRinit 은 ZFILE 을 보낸 뒤 이 시간 안에 온 ZRINIT 을 "밀려 있던 것"으로 보는 창이다.
// 파일을 고르는 동안 rz 가 ZRINIT 을 여러 번 다시 보내는데, 그것들에 ZFILE 로 일일이 답하지 않기 위해서다.
// 창이 지난 뒤의 ZRINIT 은 상대가 ZFILE 을 받지 못한 것이므로 ZFILE 을 다시 보낸다. 시험에서 줄일 수 있게 변수다.
var G_durStaleRinit = 2 * time.Second

// Send 는 서버(rz)로 파일들을 보낸다. bInitial 은 Detector 가 돌려준 바이트(시작 표시 포함)다.
// fnPick 은 시작 표시가 진짜 ZRINIT 임을 확인한 뒤 불러 보낼 파일을 고르게 한다(빈 목록이면 취소).
// 실패하면(취소 포함) 상대에게 중단을 알린다. 연결 오류(*StreamError)는 그대로 돌려준다.
func Send(stream Stream, bInitial []byte, fnPick func() ([]FileSource, error), opts Options) (Result, error) {
	pEngine := newEngine(stream, bInitial, opts)
	var result Result
	hdr, errFirst := pEngine.readFirstHeader()
	if errFirst == nil && hdr.bType != G_cbZrinit {
		errFirst = ErrNotZmodem
	}
	if errFirst != nil {
		result.Leftover = pEngine.leftover()
		return result, errFirst
	}
	bCrc32 := hdr.arrData[3]&g_cbCanFc32 != 0
	slFiles, errPick := fnPick()
	errRun := errPick
	if errRun == nil && (len(slFiles) == 0 || pEngine.cancelled()) {
		errRun = ErrCancelled // 고르지 않았거나, 고르는 동안 취소했다
	}
	if errRun == nil {
		errRun = pEngine.sendLoop(slFiles, bCrc32, &result)
	}
	result.Leftover = pEngine.leftover()
	if errRun != nil {
		if _, bStream := errRun.(*StreamError); !bStream && errRun != ErrRemoteCancelled {
			_ = stream.Write(AbortSequence())
		}
	}
	return result, errRun
}

// sendLoop 는 파일을 차례로 보내고 세션을 끝낸다.
func (pEngine *engine) sendLoop(slFiles []FileSource, bCrc32 bool, pResult *Result) error {
	for iIndex, file := range slFiles {
		if errFile := pEngine.sendFile(file, len(slFiles)-iIndex, bCrc32, pResult); errFile != nil {
			return errFile
		}
	}
	// 끝: ZFIN 을 보내고 상대의 ZFIN 을 받은 뒤 "OO"(over and out)를 보낸다.
	if errSend := pEngine.sendHex(g_cbZfin, [4]byte{}); errSend != nil {
		return errSend
	}
	for {
		hdr, errHeader := pEngine.readHeader()
		if errHeader != nil {
			return errHeader
		}
		if hdr.bType == g_cbZfin {
			return pEngine.write([]byte("OO"))
		}
	}
}

// fileHeaderFrame 은 ZFILE 헤더와 파일 정보 데이터를 만든다. 변환 방식은 이진(ZCBIN)이다.
func fileHeaderFrame(file FileSource, iFilesLeft int, bCrc32 bool) []byte {
	szInfo := file.Name + "\x00" + strconv.FormatInt(file.Size, 10) + " " +
		strconv.FormatInt(file.ModTime.Unix(), 8) + " 100644 0 " + strconv.Itoa(iFilesLeft) + " " + strconv.FormatInt(file.Size, 10) + "\x00"
	bFrame := encodeBinHeader(g_cbZfile, [4]byte{0, 0, 0, 1}, bCrc32)
	return appendSubpacket(bFrame, []byte(szInfo), g_cbZcrcw, bCrc32)
}

// sendFile 은 파일 하나를 보낸다: ZFILE → (ZRPOS 를 받으면) ZDATA … ZEOF → ZRINIT.
func (pEngine *engine) sendFile(file FileSource, iFilesLeft int, bCrc32 bool, pResult *Result) error {
	reader, errOpen := file.Open()
	if errOpen != nil {
		return errOpen
	}
	defer reader.Close()
	bFileFrame := fileHeaderFrame(file, iFilesLeft, bCrc32)
	if errSend := pEngine.write(bFileFrame); errSend != nil {
		return errSend
	}
	tFileSent := time.Now()
	pEngine.progress(file.Name, 0, file.Size, G_ciStateStart)
	// ZFILE 에 대한 답을 기다린다.
	var i64Pos int64
	for bWaiting := true; bWaiting; {
		hdr, errHeader := pEngine.readHeader()
		if errHeader != nil {
			return errHeader
		}
		switch hdr.bType {
		case g_cbZrpos:
			i64Pos = hdr.pos()
			bWaiting = false
		case g_cbZskip:
			pResult.Skipped++
			pEngine.progress(file.Name, 0, file.Size, G_ciStateSkipped)
			return nil
		case G_cbZrinit:
			if time.Since(tFileSent) < G_durStaleRinit {
				continue // 파일을 고르는 동안 밀려 있던 ZRINIT
			}
			fallthrough
		case g_cbZnak:
			if errCount := pEngine.noteError(); errCount != nil {
				return errCount
			}
			if errSend := pEngine.write(bFileFrame); errSend != nil {
				return errSend
			}
			tFileSent = time.Now()
		case g_cbZcrc:
			// 상대가 이미 가진 파일과 같은지 보려고 파일 전체의 CRC-32 를 묻는다.
			uiCrc, errCrc := fileCrc32(reader)
			if errCrc != nil {
				return errCrc
			}
			if errSend := pEngine.sendHex(g_cbZcrc, posData(int64(uiCrc))); errSend != nil {
				return errSend
			}
		case g_cbZfin:
			return ErrRemoteCancelled
		default:
		}
	}
	for {
		i64End, errData := pEngine.sendData(file, reader, i64Pos, bCrc32)
		if errData != nil {
			return errData
		}
		if i64End >= 0 {
			// 상대가 중간 위치부터 다시 달라고 했다.
			i64Pos = i64End
			continue
		}
		break
	}
	pResult.Files++
	pResult.Bytes += file.Size
	pEngine.progress(file.Name, file.Size, file.Size, G_ciStateDone)
	return nil
}

// fileCrc32 는 파일 전체의 CRC-32 를 계산하고 읽는 위치를 처음으로 되돌린다.
func fileCrc32(reader io.ReadSeeker) (uint32, error) {
	if _, errSeek := reader.Seek(0, io.SeekStart); errSeek != nil {
		return 0, errSeek
	}
	hasher := crc32.NewIEEE()
	if _, errCopy := io.Copy(hasher, reader); errCopy != nil {
		return 0, errCopy
	}
	_, errSeek := reader.Seek(0, io.SeekStart)
	return hasher.Sum32(), errSeek
}

// sendData 는 i64Pos 부터 파일 끝까지 보내고 ZEOF 뒤의 답을 기다린다.
// 다 끝났으면 -1, 상대가 다른 위치부터 다시 달라고 했으면 그 위치를 돌려준다.
func (pEngine *engine) sendData(file FileSource, reader io.ReadSeeker, i64Pos int64, bCrc32 bool) (int64, error) {
	if _, errSeek := reader.Seek(i64Pos, io.SeekStart); errSeek != nil {
		return -1, errSeek
	}
	if errSend := pEngine.write(encodeBinHeader(g_cbZdata, posData(i64Pos), bCrc32)); errSend != nil {
		return -1, errSend
	}
	bChunk := make([]byte, G_ciSubpacketBytes)
	bFrame := make([]byte, 0, G_ciSubpacketBytes*2+16)
	iSinceAck := 0
	for {
		if pEngine.cancelled() {
			return -1, ErrCancelled
		}
		nRead, errRead := io.ReadFull(reader, bChunk)
		bLast := errRead == io.EOF || errRead == io.ErrUnexpectedEOF
		if errRead != nil && !bLast {
			return -1, errRead
		}
		iSinceAck++
		bEnd := byte(g_cbZcrcg)
		switch {
		case bLast:
			bEnd = g_cbZcrce
		case iSinceAck >= g_ciAckEvery:
			bEnd = g_cbZcrcq
		}
		bFrame = appendSubpacket(bFrame[:0], bChunk[:nRead], bEnd, bCrc32)
		if errSend := pEngine.write(bFrame); errSend != nil {
			return -1, errSend
		}
		i64Pos += int64(nRead)
		pEngine.progress(file.Name, i64Pos, file.Size, G_ciStateData)
		if bLast {
			break
		}
		if bEnd == g_cbZcrcq {
			// 확인을 기다린다: ZACK 이면 계속, ZRPOS 면 그 위치부터 다시.
			iSinceAck = 0
			for bWaiting := true; bWaiting; {
				hdr, errHeader := pEngine.readHeader()
				if errHeader != nil {
					return -1, errHeader
				}
				switch hdr.bType {
				case g_cbZack:
					bWaiting = false
				case g_cbZrpos:
					if errCount := pEngine.noteError(); errCount != nil {
						return -1, errCount
					}
					return hdr.pos(), nil
				case g_cbZskip:
					return -1, nil
				case g_cbZfin:
					return -1, ErrRemoteCancelled
				default:
				}
			}
		}
	}
	if errSend := pEngine.write(encodeBinHeader(g_cbZeof, posData(i64Pos), bCrc32)); errSend != nil {
		return -1, errSend
	}
	for {
		hdr, errHeader := pEngine.readHeader()
		if errHeader != nil {
			return -1, errHeader
		}
		switch hdr.bType {
		case G_cbZrinit, g_cbZskip:
			return -1, nil // 파일을 다 받았다 (다음 파일 또는 끝)
		case g_cbZrpos:
			if errCount := pEngine.noteError(); errCount != nil {
				return -1, errCount
			}
			return hdr.pos(), nil
		case g_cbZfin:
			return -1, ErrRemoteCancelled
		default: // ZACK 등은 넘긴다
		}
	}
}
```

```go
// linkTransport 는 앱 쪽 연결(Transport)이고, 반대쪽 끝(remote)은 서버 흉내가 쓴다.
type linkTransport struct {
	chToApp    chan []byte
	chToRemote chan []byte
	chClosed   chan struct{}
	onceClose  sync.Once
	bRest      []byte
}

func newLinkTransport() *linkTransport {
	return &linkTransport{chToApp: make(chan []byte, 100000), chToRemote: make(chan []byte, 100000), chClosed: make(chan struct{})}
}

func (pLink *linkTransport) Read(bBuf []byte) (int, error) {
	select {
	case bData := <-pLink.chToApp:
		return copy(bBuf, bData), nil // 시험에서는 한 번에 32KB 이하로만 보낸다
	case <-pLink.chClosed:
		return 0, io.EOF
	}
}

func (pLink *linkTransport) Write(bData []byte) error {
	pLink.chToRemote <- append([]byte(nil), bData...)
	return nil
}
func (pLink *linkTransport) Resize(iCols int, iRows int) error { return nil }
func (pLink *linkTransport) Close() error {
	pLink.onceClose.Do(func() { close(pLink.chClosed) })
	return nil
}

	pLink *linkTransport
	bRest []byte
}

func (pEnd *remoteEnd) Read(bBuf []byte) (int, error) {
	if len(pEnd.bRest) == 0 {
		select {
		case bData := <-pEnd.pLink.chToRemote:
			pEnd.bRest = bData
		case <-pEnd.pLink.chClosed:
			return 0, io.EOF
		}
	}
	nCopy := copy(bBuf, pEnd.bRest)
	pEnd.bRest = pEnd.bRest[nCopy:]
	return nCopy, nil
}

func (pEnd *remoteEnd) Write(bData []byte) error {
	for len(bData) > 0 {
		nPart := len(bData)
		if nPart > 8192 {
			nPart = 8192
		}
		pEnd.pLink.chToApp <- append([]byte(nil), bData[:nPart]...)
		bData = bData[nPart:]
	}
	return nil
}

// remoteSz 는 서버에서 sz 를 실행한 것처럼 군다: 시작 헤더를 보내고 앱의 ZRINIT 을 기다려 파일을 보낸다.
func remoteSz(pLink *linkTransport, slFiles []zmodem.FileSource) error {
	pEnd := &remoteEnd{pLink: pLink}
	_ = pEnd.Write([]byte("rz\r" + g_cszTestZrqinit))
	var detector zmodem.Detector
	bBuf := make([]byte, 4096)
	for {
		nRead, errRead := pEnd.Read(bBuf)
		if errRead != nil {
			return errRead
		}
		if _, kind, bEngine := detector.Feed(bBuf[:nRead]); kind == zmodem.KindRemoteAccepts {
			_, errSend := zmodem.Send(pEnd, bEngine, func() ([]zmodem.FileSource, error) { return slFiles, nil }, zmodem.Options{})
			return errSend
		}
	}
}

func openZmodemSession(t *testing.T, pLink *linkTransport, pHooks *ZmodemHooks) (*Session, *eventRecorder) {
	t.Helper()
	rec := &eventRecorder{}
	pManager := NewManager(rec.emit)
	cfg := sshConfig(func(func(string)) (Transport, error) { return pLink, nil }, false)
	cfg.Zmodem = pHooks
	info, errOpen := pManager.Open(cfg)
	if errOpen != nil {
		t.Fatal(errOpen)
	}
	t.Cleanup(func() { pManager.Close(info.M_szId) })
	pSession, _ := pManager.Get(info.M_szId)
	waitUntil(t, func() bool { return pSession.Snapshot().M_szState == G_cszStateConnected }, time.Second)
	// 시험에서는 프런트가 없으므로 출력 확인(ack)을 대신해 준다 (출력 흐름 제어에 막히지 않게).
	chStop := make(chan struct{})
	t.Cleanup(func() { close(chStop) })
	go func() {
		for {
			select {
			case <-chStop:
				return
			case <-time.After(5 * time.Millisecond):
				pSession.AckOutput(1000)
			}
		}
	}()
	return pSession, rec
}

func TestZmodemUploadSendsPickedFiles(t *testing.T) {

	iBefore int
	iPos    int

func (pReader *holdReader) Read(bBuf []byte) (int, error) {

	}
	pReader.iPos += len(bBuf)
	return len(bBuf), nil
}

}
```

```go
// chanPipe 는 한 방향의 바이트 흐름이다. 쓰기는 막히지 않고(넉넉한 버퍼), 닫으면 읽기가 EOF 다.
type chanPipe struct {
	chData   chan []byte
	bRest    []byte
	onceDone sync.Once
	chDone   chan struct{}
}

func newChanPipe() *chanPipe {
	return &chanPipe{chData: make(chan []byte, 100000), chDone: make(chan struct{})}
}

func (pPipe *chanPipe) write(bData []byte) error {
	select {
	case <-pPipe.chDone:
		return io.ErrClosedPipe
	default:
	}
	pPipe.chData <- append([]byte(nil), bData...)
	return nil
}

func (pPipe *chanPipe) read(bBuf []byte) (int, error) {
	if len(pPipe.bRest) == 0 {
		select {
		case bData := <-pPipe.chData:
			pPipe.bRest = bData
		case <-pPipe.chDone:
			select {
			case bData := <-pPipe.chData:
				pPipe.bRest = bData
			default:
				return 0, io.EOF
			}
		}
	}
	nCopy := copy(bBuf, pPipe.bRest)
	pPipe.bRest = pPipe.bRest[nCopy:]
	return nCopy, nil
}

func (pPipe *chanPipe) close() { pPipe.onceDone.Do(func() { close(pPipe.chDone) }) }

// endpoint 는 양방향 연결의 한쪽 끝이다 (Stream). fnTamper 가 있으면 보내는 바이트를 고칠 수 있다.
type endpoint struct {
	pIn      *chanPipe
	pOut     *chanPipe
	fnTamper func(bData []byte) []byte
}

func (pEnd *endpoint) Read(bBuf []byte) (int, error) { return pEnd.pIn.read(bBuf) }
func (pEnd *endpoint) Write(bData []byte) error {
	if pEnd.fnTamper != nil {
		bData = pEnd.fnTamper(append([]byte(nil), bData...))
	}
	return pEnd.pOut.write(bData)
}

	pAtoB, pBtoA := newChanPipe(), newChanPipe()
	return &endpoint{pIn: pBtoA, pOut: pAtoB}, &endpoint{pIn: pAtoB, pOut: pBtoA}
}

// memSink 는 받은 파일을 메모리에 담는다.
type memSink struct {
	mtxData   sync.Mutex
	mapFiles  map[string][]byte
	mapInfo   map[string]FileInfo
	slAborted []string
	szSkip    string // 이 이름은 건너뛴다
	errAccept error
}

type memWriter struct {
	pSink  *memSink
	szName string
	bData  bytes.Buffer
}

func (pWriter *memWriter) Write(bData []byte) (int, error) { return pWriter.bData.Write(bData) }
func (pWriter *memWriter) Commit() error {
	pWriter.pSink.mtxData.Lock()
	defer pWriter.pSink.mtxData.Unlock()
	pWriter.pSink.mapFiles[pWriter.szName] = pWriter.bData.Bytes()
	return nil
}
func (pWriter *memWriter) Abort() {
	pWriter.pSink.mtxData.Lock()
	defer pWriter.pSink.mtxData.Unlock()
	pWriter.pSink.slAborted = append(pWriter.pSink.slAborted, pWriter.szName)
}

func newMemSink() *memSink {
	return &memSink{mapFiles: map[string][]byte{}, mapInfo: map[string]FileInfo{}}
}

func (pSink *memSink) Accept(info FileInfo) (FileWriter, error) {
	if pSink.errAccept != nil {
		return nil, pSink.errAccept
	}
	pSink.mtxData.Lock()
	pSink.mapInfo[info.Name] = info
	pSink.mtxData.Unlock()
	if info.Name == pSink.szSkip {
		return nil, nil
	}
	return &memWriter{pSink: pSink, szName: info.Name}, nil
}

func TestDetectorAcrossChunksAndStars(t *testing.T) {

		_, kindFirst, _ := detector.Feed(bAll[:iCut])

		}
	}
}

	}

		pEngine := newEngine(pRemote, nil, Options{})

		_ = pEngine.sendHex(G_cbZrinit, [4]byte{0, 0, 0, g_cbCanFdx | g_cbCanOvIo}) // CRC-32 없음
		var result Result
		for {
			hdr, errHeader := pEngine.readHeader()
			if errHeader != nil {
				return
			}
			switch hdr.bType {
			case g_cbZfile:
				bInfo, _, _, _ := pEngine.readSubpacket(hdr.bFormat == g_cbZbin32)
				_ = pEngine.receiveFile(parseFileInfo(bInfo), sink, &result)
			case g_cbZfin:

			}
		}
	}()
	if _, errSend := appSend(t, pApp, []FileSource{memSource("c16.bin", bData)}, Options{}); errSend != nil {

	}
	if bSawBin32.Load() {

	}
	if !bytes.Equal(sink.mapFiles["c16.bin"], bData) {
```

### `spec/behavior/zmodem.md` — 새 파일 (전체)

```markdown
# ZMODEM 파일 전송 (sz · rz)

> 작성 방식: 새 기능의 동작 정의(기존 앱에 없던 기능이라 관찰 대상이 없다). 통신 형식은 공개 규격(Chuck Forsberg, "The ZMODEM Inter Application File Transfer Protocol")을 따른다. 작성일 2026-11-23, 결정 D114. 상태: **ready**.

## 1. 무엇을 하는가

터미널에서 서버의 `sz 파일` 을 실행하면 그 파일을 이 PC 로 받고, `rz` 를 실행하면 이 PC 에서 고른 파일을 서버로 보낸다. SFTP 를 쓸 수 없는 곳(경유 서버를 여러 번 거쳐 들어간 셸, `sudo`·`su` 로 바꾼 계정, 시리얼로 붙은 장비)에서 쓰는 방법이다. 서버에 `lrzsz` 같은 ZMODEM 프로그램이 있어야 한다.

## 2. 적용 범위

- **SSH 와 시리얼 세션**에서만 동작한다.
- **로컬 터미널**은 하지 않는다(가상 터미널이 이진 데이터를 바꾼다). **텔넷**도 하지 않는다(이진 전송 방식을 협상하지 않아 데이터가 바뀔 수 있다).
- 설정 `zmodemEnabled`(기본 켜짐)가 꺼져 있으면 아무 일도 하지 않고, 서버가 보낸 시작 표시가 그대로 화면에 나온다.
- tmux 안에서는 tmux 가 이진 데이터를 다시 그리므로 대개 동작하지 않는다(알려진 한계).

## 3. 시작

- 세션 출력에 **시작 표시**가 나타나면 전송을 시작한다. 시작 표시는 16진 헤더의 앞부분 `* * 0x18 B 0` 다음에 `0`(서버가 보내려 함, `sz`) 또는 `1`(서버가 받으려 함, `rz`)이 오는 것이다. 표시가 출력 묶음 경계에 걸쳐 와도 찾는다.
- 표시 **앞의 출력은 그대로 화면에 보낸다**(`sz` 가 먼저 찍는 `rz` 글자 등).
- 표시처럼 보였지만 뒤가 올바른 헤더가 아니면(검사값 불일치) 전송하지 않고 읽은 바이트를 화면 출력으로 되돌린다.
- 전송이 시작되면 끝날 때까지 **그 연결의 입출력을 전송에만 쓴다**: 서버가 보낸 바이트는 화면에 나오지 않고, **터미널 입력은 서버로 보내지 않는다**(전송 데이터에 섞이지 않게). 일괄 입력으로 들어온 입력도 같다.

## 4. 받기 (서버에서 `sz`)

- 저장 폴더: 설정 `zmodemDownloadDir`. 비면 OS 의 다운로드 폴더(`~/Downloads`). `~` 로 시작하면 홈으로 바꾼다. 폴더가 없으면 만든다.
- **파일 이름**은 서버가 준 이름을 다듬어 쓴다: 경로는 떼고 파일 이름만(폴더 밖에 쓰지 못하게), `\ / : * ? " < > |` 와 제어 문자는 `_`, 끝의 공백·점 제거, 200자까지, 비면 `zmodem-file`, Windows 장치 이름(`CON`, `NUL`, `COM1` 등)은 앞에 `_`.
- **같은 이름이 있으면 덮어쓰지 않는다**: `이름 (2).확장자`, `이름 (3).확장자` … 로 저장한다.
- 받는 동안은 `<이름>.dtpart` 에 쓰고, **다 받은 뒤에만** 최종 이름으로 바꾼다. 취소·실패·끊김이면 `.dtpart` 파일을 지운다(끊겨서 지우지 못하면 남는다).
- 서버가 수정 시각을 알려 주면 받은 파일의 수정 시각을 그 값으로 맞춘다.
- 여러 파일(`sz a b c`)을 차례로 받는다.

## 5. 보내기 (서버에서 `rz`)

- 파일 선택 대화상자(제목 "ZMODEM으로 보낼 파일 선택", 여러 개 선택 가능)를 띄운다. 그 전에 터미널에 안내 "ZMODEM 보내기: 보낼 파일을 고르세요 (취소하면 전송을 그만둡니다)".
- 고르지 않고 닫으면 전송을 취소하고 서버의 `rz` 를 끝낸다.
- 폴더와 읽을 수 없는 항목은 빼고 보낸다. 서버에는 경로 없이 **파일 이름만** 알린다.
- 서버가 같은 이름을 이미 갖고 있어 건너뛰라고 하면 그 파일은 건너뛴다.
- 파일 선택 대화상자가 없는 OS(Windows 가 아닌 곳)에서는 보내기를 할 수 없다(취소로 끝난다). 받기는 된다.

## 6. 진행 표시와 안내 (터미널 안, 청록색 `●`)

| 때 | 문구 |
|---|---|
| 전송 중(0.25초에 한 번 같은 줄을 고쳐 씀) | `ZMODEM 받는 중: {이름} {백분율}% ({받은 크기} / {전체 크기}) · Ctrl+C 취소` / `ZMODEM 보내는 중: …` |
| 파일 하나를 다 받음 | `받음: {이름} ({크기}) → {저장된 경로}` |
| 파일 하나를 다 보냄 | `보냄: {이름} ({크기})` |
| 건너뜀 | `건너뜀: {이름}` |
| 모두 끝남 | `ZMODEM 전송 완료: 파일 {n}개, {크기}` |
| 사용자가 취소 | `ZMODEM 전송을 취소했습니다` |
| 서버가 중단 | `서버 쪽에서 ZMODEM 전송을 중단했습니다` |
| 그 밖의 실패 | `ZMODEM 전송 실패: {오류}` |

- 전체 크기를 모르면 백분율 없이 받은 크기만 보인다.
- 크기 단위는 B · KB · MB · GB(1024 단위).
- **전송 중인 줄은 세션 로그에 남기지 않는다.** 나머지 안내 줄은 로그에도 남는다.
- 파일 이름의 제어 문자는 `_` 로 바꿔 보인다.

## 7. 취소

- 전송 중에 터미널에서 **Ctrl+C** 를 누르면 취소한다: 서버에 중단 신호(CAN 8개)를 보내고, 받던 파일은 지운다.
- 취소한 뒤 도착한 전송 데이터는 화면에 내보내지 않고 버린다. 그 뒤의 출력(셸 프롬프트)부터 다시 화면에 나온다.
- 세션을 닫거나 연결이 끊기면 전송도 끝난다(끊김 처리는 보통 세션과 같다 — 자동 재접속 규칙 적용).
- **시간 제한은 없다**: 서버 쪽 프로그램이 응답 없이 멈추면 전송 상태로 남으므로 Ctrl+C 로 풀어야 한다(알려진 한계).

## 8. 오류 복구와 한도

- 받은 데이터의 검사값이 맞지 않으면 그 위치부터 다시 보내 달라고 요청해 이어 받는다. 전송 하나에서 이런 오류가 **10번**을 넘으면 실패로 끝낸다.
- 보낼 때는 데이터를 **1024바이트 조각**으로 보내고 **256조각(약 256KB)마다** 서버의 확인을 기다린다. 서버가 다른 위치부터 다시 달라고 하면 그 위치부터 다시 보낸다.
- 서버가 CRC-32 를 쓸 수 있다고 알리면 CRC-32 로, 아니면 CRC-16 으로 보낸다. 받을 때는 둘 다 받는다.
- 보낼 때 제어 문자(0x00~0x1f, 0x7f, 0x80~0x9f, 0xff)는 모두 바꿔서(이스케이프) 보낸다.
- 4GB 를 넘는 파일은 보장하지 않는다(규격의 위치 값이 32비트다).
- 이어받기(끊긴 전송을 중간부터 다시)는 하지 않는다: 항상 처음부터 받는다.
```

| 1 | lrzsz 가 있는 리눅스 서버(SSH)에서 `sz /etc/hostname` | 진행 줄 → `받음: hostname (…) → …\Downloads\hostname` → `ZMODEM 전송 완료`. 파일 내용이 서버와 같다. 프롬프트가 다시 나온다 |
| 2 | 같은 서버에서 수십 MB 이진 파일을 `sz` → 서버와 이 PC 에서 `sha256sum`·`certutil -hashfile` 비교 | 해시가 같다 |
| 3 | 같은 서버에서 `rz` → 파일 2개(하나는 수 MB 이진) 선택 → 서버에서 해시 비교 | 두 파일이 현재 폴더에 생기고 해시가 같다 |
| 4 | `rz` → 선택 창 취소 | `ZMODEM 전송을 취소했습니다`, 서버의 rz 가 끝나고 프롬프트 |
| 5 | 큰 파일을 받는 중 Ctrl+C | 전송이 멈추고 `.dtpart` 가 지워진다. 화면에 이진 쓰레기가 쏟아지지 않는다. 그 뒤 입력이 정상 |
| 6 | 큰 파일을 받는 중 글자를 친다 | 전송이 깨지지 않는다 |
| 7 | 경유 서버 → 서버 A → `ssh B` 로 넘어간 셸에서 `sz`·`rz` | 된다(이 기능을 만든 이유) |
| 8 | `sz a b c`(여러 파일), 같은 파일을 두 번 | 차례로 받는다 / 두 번째는 ` (2)` |
| 9 | 시리얼 장비(lrzsz 또는 장비 자체의 ZMODEM) | 된다. 로컬 에코가 켜진 포트는 꺼야 한다 |
| 10 | tmux 안에서 `sz` | 대개 안 된다(알려진 한계). 화면에 글자가 나오면 Ctrl+C 또는 서버에서 Ctrl+X 여러 번 |
| 11 | 설정 > 파일 전송에서 ZMODEM 을 끄고 `sz` | 전송하지 않고 서버가 보낸 글자가 화면에 나온다 |
| 12 | 받는 폴더를 다른 폴더로 바꾸고 `sz` | 그 폴더에 저장된다 |

## I. 영향 범위·회귀 위험

| 영역 | 위험 | 대비 |
|---|---|---|
| 모든 SSH·시리얼 세션의 출력 경로 | 읽은 묶음마다 `Detector.Feed` 가 한 번 훑는다(바이트마다 비교 한두 번) | 부하는 재 보지 않았다. 고속 출력에서 눈에 띄면 `zmodemEnabled` 를 끈다 |
| 우연한 시작 표시 | 출력에 `**\x18B00` + 올바른 CRC 의 16진 14자가 나와야 전송으로 넘어간다. 이진 파일을 `cat` 하면 드물게 나올 수 있다 | 헤더 CRC 가 틀리면 화면으로 되돌린다. 넘어가 버렸으면 Ctrl+C |
| 서버가 준 파일 이름 | 경로를 떼고 다듬는다 | `TestSafeFileName`, `TestZmodemDownloadSavesFile` |
| 화면 조작 | 진행 줄의 파일 이름에서 제어 문자를 뺀다 | `displayName` |
| 멈춘 전송 | 시간 제한이 없어 Ctrl+C 를 눌러야 풀린다. 그동안 그 세션의 입력은 서버로 가지 않는다 | 진행 줄에 "Ctrl+C 취소"를 늘 보인다 |
| 일괄 입력 | 전송 중인 세션은 일괄 입력도 받지 않는다(다른 세션에는 간다) | 의도한 동작 |
| 세션 닫기·끊김 | 엔진이 연결 오류로 끝나고 보통의 끊김 처리로 간다. `.dtpart` 는 지운다 | `TestReceiveStreamError` |
| 텔넷·로컬 | 훅이 nil 이라 아무 일도 하지 않는다 | `TestZmodemDisabledPassesThrough` |
| 4GB 넘는 파일 | 위치 값이 32비트라 보장하지 않는다 | 명세에 명시 |
