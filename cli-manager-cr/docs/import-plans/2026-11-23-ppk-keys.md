## 0. 한 줄 요약

PuTTY 의 개인 키 파일(`.ppk`)을 **변환 없이** 쓸 수 있게 했다. 전에는 화면이 "PPK v2 지원"이라고 안내했지만 실제로는 어떤 PPK 도 읽지 못했고(§1), v3 는 화면에서 막고 PuTTYgen 으로 변환하라고 안내했다.

| | 전 | 후 |
|---|---|---|
| PPK 형식 2 | 화면은 받지만 접속할 때 "개인 키를 읽을 수 없습니다" | 읽는다 |
| PPK 형식 3 (PuTTY 0.75 이후 기본) | 화면에서 막고 변환 안내 | 읽는다 |
| 암호 걸린 PPK | — | "키 암호 입력"을 묻고(최대 3번) 읽는다 |

## 1. 배경 (원인)

- 키를 읽는 곳은 [internal/sshconn/auth.go](../../internal/sshconn/auth.go) `keyLoader` 하나이고, `x/crypto/ssh` 의 `ParsePrivateKey` 를 그대로 불렀다. 이 함수는 OpenSSH·PEM 만 읽는다. PPK 를 읽는 코드는 저장소 어디에도 없었다.
- 프런트는 [frontend/src/lib/hostForm.ts](../../frontend/src/lib/hostForm.ts) `isPpkV3` 로 v3 만 막았고, v2 는 통과시켜 볼트에 저장했다. 저장된 v2 키는 접속할 때 실패했다.
- 명세([spec/ui/host-editor.md](../../spec/ui/host-editor.md) §1.2)의 도움말 "PuTTY PPK v2 지원"과 구현이 달랐던 것이다.

## 2. 설계 결정

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 읽는 위치 | 백엔드(`internal/sshconn/ppk.go`), 접속할 때 | 볼트에는 사용자가 준 키 글자를 그대로 둔다. 저장 형식을 바꾸지 않으므로 이미 저장된 PPK v2 키도 곧바로 쓸 수 있다 |
| 진입점 | `ParseKey` / `ParseKeyWithPassphrase` — PPK 면 직접, 아니면 `x/crypto/ssh` | `keyLoader` 의 흐름(암호 필요 → 최대 3번 묻기)을 그대로 쓴다 |
| 암호 필요 표시 | `*ssh.PassphraseMissingError` 를 돌려준다 | `keyLoader` 가 이 오류를 보고 암호를 묻는다(기존 코드 그대로) |
| 틀린 암호 | 무결성 값(MAC) 불일치 `ErrPpkMac` | PPK 는 복호화 결과를 MAC 으로 확인한다. `keyLoader` 는 어떤 오류든 다시 묻는다 |
| 키 종류 | RSA, Ed25519, ECDSA P-256/384/521 | Go 표준 라이브러리로 만들 수 있는 것. DSA 는 뺐다(서버들이 더는 받지 않는다) |
| 형식 3 의 키 유도 | Argon2id, Argon2i | `x/crypto/argon2` 가 제공하는 것. PuTTYgen 기본값은 Argon2id. Argon2d 는 라이브러리에 없어 오류로 안내 |
| 조작된 파일 대비 | Argon2 메모리 ≤ 1GiB, 반복 ≤ 1000, 병렬 ≤ 255 | 파일이 주는 값으로 메모리를 다 쓰게 하지 못하도록 |
| 새 의존성 | 없음 | `x/crypto` 는 이미 쓰고 있다(고지 파일 변경 없음) |
| 프런트 | v3 차단(`isPpkV3`, `PPK_V3_MESSAGE`) 삭제, 도움말 문구 변경 | 더는 막을 이유가 없다 |

### 2.1 PPK 파일 형식 요약 (PuTTY 공개 문서 부록 "PPK file format")

```
PuTTY-User-Key-File-3: ssh-ed25519        ← 형식 번호와 키 종류
Encryption: aes256-cbc | none
Comment: …
Public-Lines: N   + base64 N줄            ← 공개 부분
Key-Derivation: Argon2id                  ← 형식 3 이고 암호가 있을 때만 (아래 4줄 포함)
Argon2-Memory / Argon2-Passes / Argon2-Parallelism / Argon2-Salt
Private-Lines: N  + base64 N줄            ← 개인 부분(암호가 있으면 AES-256-CBC 암호문)
Private-MAC: 16진
```

| | 형식 2 | 형식 3 |
|---|---|---|
| 암호 키 | SHA-1(0x00000000‖암호) ‖ SHA-1(0x00000001‖암호) 의 앞 32바이트, IV 0 | Argon2(암호, 솔트) 80바이트 → 암호 키 32 · IV 16 · MAC 키 32 |
| MAC 키 | SHA-1("putty-private-key-file-mac-key" ‖ 암호) | 위의 MAC 키 32바이트. 암호가 없으면 빈 값 |
| MAC | HMAC-SHA-1 | HMAC-SHA-256 |
| MAC 대상 | 키 종류 · 암호화 · 주석 · 공개 부분 · (복호화한) 개인 부분을 각각 "길이 4바이트 + 내용"으로 이어 붙인 것 | 같음 |

### 2.2 검증의 한계 (중요)

이 PC 에는 PuTTYgen 이 없어 **PuTTYgen 이 만든 실제 파일로는 확인하지 못했다.** 자동 테스트는 테스트 코드 안에 따로 짠 "PPK 쓰는 쪽"이 만든 파일을 읽는다. 쓰는 쪽과 읽는 쪽이 같은 형식 이해에서 나왔으므로 이 테스트는 "서로 맞는다"까지만 보증한다. 다른 구현(npm `ppk-to-openssh`)으로 교차 확인하려 했으나 실행 권한이 없어 하지 못했다. → §H 수동 검증 1·2번이 이 공백을 메운다.

## 0.3.0 — 2026-11-17

Microsoft Store 패키지 `DariTerm-0.3.0.0.msix`, Windows 설치 파일 `DariTerm-0.3.0-amd64-installer.exe`. 0.2.0 이후 변경.

### 개선
- **잠금·오래 둔 뒤 SSH 비밀번호를 다시 묻던 문제**: 화면 보호기·자동 잠금으로 앱이 잠긴 동안 연결이 끊겨도, 그 세션이 처음 접속할 때 쓴 계정으로 창 없이 다시 연결한다(저장하지 않고 입력한 비밀번호 포함, 세션을 닫으면 지움). 그래도 안 되면 비밀번호 창 대신 "앱 잠금을 해제하면 다시 연결합니다" 를 보이고, 잠금을 풀면 곧바로 다시 연결한다. (D94)
- **서버가 끝낸 세션에 다시 붙지 않음**: 서버의 유휴 자동 로그아웃이나 `exit` 로 셸이 끝나면 자동 재접속하지 않고 "서버가 세션을 끝냈습니다" + "Enter 키를 누르면 다시 연결합니다" 를 보인다. 네트워크 끊김은 지금처럼 자동 재접속. **달라 보이는 점**: 전에는 `exit` 뒤에도 2초 뒤 다시 붙었다. (D93)

- **파일 창 정렬**: SFTP·로컬 파일 목록의 머리 줄(이름·크기·수정일)을 누르면 그 순서로 정렬하고, 다시 누르면 방향을 바꾼다. 폴더는 항상 위. 목록을 스크롤해도 머리 줄은 위에 고정된다. (D95)

### 수정
- 아주 빠르게 연달아 보낸 입력(한글 조합 확정 직후의 키, vim·tmux 시작 때의 터미널 응답 등)이 드물게 순서가 바뀌어 서버에 가던 문제. (D92)

## 0.2.0 — 2026-11-16

Microsoft Store 패키지 `DariTerm-0.2.0.0.msix`. 0.1.0 이후 변경.

### 새 기능
- **세션 로그 보관 기간**: 설정 > 연결 > "로그 보관 기간 (일)"(기본 30일, 0 = 지우지 않음). 앱이 시작 10초 뒤와 1시간마다, 값을 바꾸면 곧바로 오래된 로그 파일을 지운다. 기록 중인 파일은 건드리지 않는다. (D90)
- **WebGL 화면 그리기**: 터미널을 GPU 로 그려 많은 출력도 빠르게 보인다. WebGL 을 쓸 수 없는 환경(원격 데스크톱 등)에서는 기존 방식으로 자동 전환. (D84)

### 개선
- **고속 출력이 앱 전체를 느리게 하던 문제**: 한 탭에서 초당 수 MB 를 출력해도 다른 탭의 입력·화면이 평소처럼 반응한다. 화면이 처리한 만큼만 받아 메모리가 늘지 않고, 출력은 버리지 않는다. 안 보이는 탭의 출력은 몰아서 그린다. (D84, KI-008)
- **붙여넣기 지연**: 오른쪽 클릭·Ctrl+V 붙여넣기가 0.3~0.8초 늦던 문제를 고쳤다. (D91, KI-010)
- **SSH 끊김 감지**: 와이파이 전환·VPN 끊김처럼 연결이 조용히 사라져도 "연결 유지" 간격 × 4 안에 끊김을 알아채고 자동 재접속한다. (D86, KI-002)
- **시리얼 로컬 에코**: 장치가 아무것도 보내지 않아도 입력한 글자가 바로 보인다. 흐름 제어 설정이 아직 적용되지 않는다는 안내를 서버 편집 화면에 넣었다. (D87, KI-003)

### 수정
- 같은 서버를 같은 분에 여러 번 열면 세션 로그가 한 파일에 섞이던 문제 — 파일 이름이 초 단위가 되고 겹치면 `-2`, `-3` 을 붙여 세션마다 파일 하나. (D85, KI-001)
- 세션 로그에 `[31m` 같은 색 코드 조각이 남던 문제, 로그 쓰기가 출력을 늦추던 문제. (D88, KI-004)
- 아주 긴 별칭이나 탭·줄바꿈이 든 별칭이면 로그 파일을 못 만들거나 이름이 이상하던 문제. (D88, KI-007)
- 로컬 터미널을 닫을 때 드물게 종료 문구가 엉뚱하거나 잠깐 멈출 수 있던 문제. (D89, KI-005)
- 세션을 닫은 직후 출력·접속 실패 안내가 한두 번 더 오던 문제. (D84, KI-006)
- 실행 파일 속성(자세히)에 제품 이름·회사·저작권이 비어 보이던 문제. (4f6fe26)

### 설정·데이터
- 새 설정 `sessionLogKeepDays`(기본 30). 기존 store.json 은 그대로 읽힌다.
- 로그 파일 이름 규칙이 `{별칭}-{YYYYMMDD-HHmmss}.log` 로 바뀌었다(전: 분 단위). 이미 있던 로그는 그대로 두고, 보관 기간이 지나면 같이 정리된다.

// PuTTY 개인 키 파일(PPK) 읽기 (protocols.md §2.2 1번, D106).
// 형식 2(SHA-1 기반)와 형식 3(Argon2 + HMAC-SHA-256)을 읽는다. 형식은 PuTTY 공개 문서(부록 C "PPK file format")를 따른다.

// g_cszPpkHeader 는 PPK 파일 첫 줄의 머리다. 뒤에 형식 번호(2 또는 3)가 붙는다.
const g_cszPpkHeader = "PuTTY-User-Key-File-"

// g_ciPpkArgonMemoryMaxKiB 는 받아들이는 Argon2 메모리 상한(KiB)이다. 조작된 파일이 메모리를 다 쓰게 하지 못하도록 막는다.
const g_ciPpkArgonMemoryMaxKiB = 1024 * 1024

// g_ciPpkArgonPassesMax 는 받아들이는 Argon2 반복 횟수 상한이다.
const g_ciPpkArgonPassesMax = 1000

// PPK 읽기 오류.
var (
	// ErrPpkMac 은 무결성 검사(MAC)가 맞지 않을 때의 오류다. 키 암호가 틀렸거나 파일이 손상됐다.
	ErrPpkMac = errors.New("ppk: wrong passphrase or corrupted key file (MAC mismatch)")
	// ErrPpkFormat 은 파일 모양이 PPK 가 아닐 때의 오류다.
	ErrPpkFormat = errors.New("ppk: malformed key file")
)

// IsPpk 는 키 내용이 PuTTY PPK 형식인지 본다.
func IsPpk(bKey []byte) bool {
	return bytes.HasPrefix(bytes.TrimLeft(bKey, " \t\r\n\uFEFF"), []byte(g_cszPpkHeader))
}

// ParseKey 는 개인 키를 읽는다. PPK 면 직접 읽고, 그 밖(OpenSSH·PEM)은 x/crypto/ssh 에 맡긴다.
// 암호가 걸린 키면 *ssh.PassphraseMissingError 를 돌려준다.
func ParseKey(bKey []byte) (ssh.Signer, error) {
	if IsPpk(bKey) {
		return parsePpk(bKey, nil)
	}
	return ssh.ParsePrivateKey(bKey)
}

// ParseKeyWithPassphrase 는 암호가 걸린 개인 키를 읽는다.
func ParseKeyWithPassphrase(bKey []byte, bPassphrase []byte) (ssh.Signer, error) {
	if IsPpk(bKey) {
		return parsePpk(bKey, bPassphrase)
	}
	return ssh.ParsePrivateKeyWithPassphrase(bKey, bPassphrase)
}

// ppkFile 은 PPK 파일을 줄 단위로 읽은 결과다.
type ppkFile struct {
	iVersion     int
	szAlgorithm  string
	szEncryption string
	szComment    string
	bPublic      []byte
	bPrivate     []byte // 암호화돼 있으면 암호문
	bMac         []byte
	szKdf        string
	iMemoryKiB   int
	iPasses      int
	iParallel    int
	bSalt        []byte
}

// readPpk 는 PPK 본문을 필드로 나눈다. 줄바꿈은 LF·CRLF·CR 을 모두 받는다.
func readPpk(bKey []byte) (*ppkFile, error) {
	szText := strings.TrimLeft(string(bKey), " \t\r\n\uFEFF")
	szText = strings.ReplaceAll(strings.ReplaceAll(szText, "\r\n", "\n"), "\r", "\n")
	slLines := strings.Split(szText, "\n")
	pFile := &ppkFile{}
	for iLine := 0; iLine < len(slLines); iLine++ {
		szName, szValue, bFound := strings.Cut(slLines[iLine], ": ")
		if !bFound {
			if strings.TrimSpace(slLines[iLine]) == "" {
				continue
			}
			return nil, ErrPpkFormat
		}
		switch {
		case strings.HasPrefix(szName, g_cszPpkHeader):
			iVersion, errVersion := strconv.Atoi(strings.TrimPrefix(szName, g_cszPpkHeader))
			if errVersion != nil {
				return nil, ErrPpkFormat
			}
			pFile.iVersion = iVersion
			pFile.szAlgorithm = strings.TrimSpace(szValue)
		case szName == "Encryption":
			pFile.szEncryption = strings.TrimSpace(szValue)
		case szName == "Comment":
			pFile.szComment = szValue
		case szName == "Public-Lines", szName == "Private-Lines":
			iCount, errCount := strconv.Atoi(strings.TrimSpace(szValue))
			if errCount != nil || iCount < 0 || iLine+iCount >= len(slLines) {
				return nil, ErrPpkFormat
			}
			bBlob, errBlob := base64.StdEncoding.DecodeString(strings.Join(slLines[iLine+1:iLine+1+iCount], ""))
			if errBlob != nil {
				return nil, ErrPpkFormat
			}
			if szName == "Public-Lines" {
				pFile.bPublic = bBlob
			} else {
				pFile.bPrivate = bBlob
			}
			iLine += iCount
		case szName == "Private-MAC":
			bMac, errMac := hex.DecodeString(strings.TrimSpace(szValue))
			if errMac != nil {
				return nil, ErrPpkFormat
			}
			pFile.bMac = bMac
		case szName == "Key-Derivation":
			pFile.szKdf = strings.TrimSpace(szValue)
		case szName == "Argon2-Memory":
			pFile.iMemoryKiB, _ = strconv.Atoi(strings.TrimSpace(szValue))
		case szName == "Argon2-Passes":
			pFile.iPasses, _ = strconv.Atoi(strings.TrimSpace(szValue))
		case szName == "Argon2-Parallelism":
			pFile.iParallel, _ = strconv.Atoi(strings.TrimSpace(szValue))
		case szName == "Argon2-Salt":
			bSalt, errSalt := hex.DecodeString(strings.TrimSpace(szValue))
			if errSalt != nil {
				return nil, ErrPpkFormat
			}
			pFile.bSalt = bSalt
		}
	}
	if pFile.iVersion == 0 || pFile.szAlgorithm == "" || len(pFile.bPublic) == 0 || len(pFile.bPrivate) == 0 || len(pFile.bMac) == 0 {
		return nil, ErrPpkFormat
	}
	return pFile, nil
}

// parsePpk 는 PPK 를 읽어 서명자를 만든다. 암호가 걸려 있는데 bPassphrase 가 nil 이면 *ssh.PassphraseMissingError 다.
func parsePpk(bKey []byte, bPassphrase []byte) (ssh.Signer, error) {
	pFile, errRead := readPpk(bKey)
	if errRead != nil {
		return nil, errRead
	}
	if pFile.iVersion != 2 && pFile.iVersion != 3 {
		return nil, fmt.Errorf("ppk: unsupported file format version %d", pFile.iVersion)
	}
	bEncrypted := false
	switch pFile.szEncryption {
	case "none":
	case "aes256-cbc":
		bEncrypted = true
	default:
		return nil, fmt.Errorf("ppk: unsupported encryption %q", pFile.szEncryption)
	}
	if bEncrypted && bPassphrase == nil {
		return nil, &ssh.PassphraseMissingError{}
	}
	if !bEncrypted {
		bPassphrase = nil // 암호가 없는 키에 준 암호는 쓰지 않는다
	}
	bCipherKey, bIv, bMacKey, fnHash, errKeys := ppkKeys(pFile, bEncrypted, bPassphrase)
	if errKeys != nil {
		return nil, errKeys
	}
	bPrivate := pFile.bPrivate
	if bEncrypted {
		if len(bPrivate) == 0 || len(bPrivate)%aes.BlockSize != 0 {
			return nil, ErrPpkFormat
		}
		block, errCipher := aes.NewCipher(bCipherKey)
		if errCipher != nil {
			return nil, errCipher
		}
		bPlain := make([]byte, len(bPrivate))
		cipher.NewCBCDecrypter(block, bIv).CryptBlocks(bPlain, bPrivate)
		bPrivate = bPlain
	}
	// MAC: 알고리즘·암호화·주석·공개 부분·(복호화한) 개인 부분을 각각 길이를 앞세운 문자열로 이어 붙인 것.
	mac := hmac.New(fnHash, bMacKey)
	for _, bPart := range [][]byte{[]byte(pFile.szAlgorithm), []byte(pFile.szEncryption), []byte(pFile.szComment), pFile.bPublic, bPrivate} {
		var arrLength [4]byte
		binary.BigEndian.PutUint32(arrLength[:], uint32(len(bPart)))
		mac.Write(arrLength[:])
		mac.Write(bPart)
	}
	if !hmac.Equal(mac.Sum(nil), pFile.bMac) {
		return nil, ErrPpkMac
	}
	anyKey, errBuild := ppkBuildKey(pFile.szAlgorithm, pFile.bPublic, bPrivate)
	if errBuild != nil {
		return nil, errBuild
	}
	return ssh.NewSignerFromKey(anyKey)
}

// ppkKeys 는 형식에 맞는 암호 키·IV·MAC 키와 MAC 해시를 만든다.
func ppkKeys(pFile *ppkFile, bEncrypted bool, bPassphrase []byte) (bCipherKey []byte, bIv []byte, bMacKey []byte, fnHash func() hash.Hash, err error) {
	if pFile.iVersion == 2 {
		// 형식 2: 암호 키 = SHA-1(0x00000000 ‖ 암호) ‖ SHA-1(0x00000001 ‖ 암호) 의 앞 32바이트, IV 는 0.
		// MAC 키 = SHA-1("putty-private-key-file-mac-key" ‖ 암호), MAC 은 HMAC-SHA-1.
		macSeed := sha1.New()
		macSeed.Write([]byte("putty-private-key-file-mac-key"))
		macSeed.Write(bPassphrase)
		if bEncrypted {
			var bStretched []byte
			for iSeq := byte(0); iSeq < 2; iSeq++ {
				h := sha1.New()
				h.Write([]byte{0, 0, 0, iSeq})
				h.Write(bPassphrase)
				bStretched = h.Sum(bStretched)
			}
			bCipherKey = bStretched[:32]
			bIv = make([]byte, aes.BlockSize)
		}
		return bCipherKey, bIv, macSeed.Sum(nil), sha1.New, nil
	}
	// 형식 3: 암호가 없으면 MAC 키는 빈 값. 있으면 Argon2 로 80바이트를 만들어 암호 키 32 · IV 16 · MAC 키 32 로 나눈다.
	if !bEncrypted {
		return nil, nil, []byte{}, sha256.New, nil
	}
	if pFile.iMemoryKiB <= 0 || pFile.iMemoryKiB > g_ciPpkArgonMemoryMaxKiB ||
		pFile.iPasses <= 0 || pFile.iPasses > g_ciPpkArgonPassesMax ||
		pFile.iParallel <= 0 || pFile.iParallel > 255 || len(pFile.bSalt) == 0 {
		return nil, nil, nil, nil, ErrPpkFormat
	}
	var bDerived []byte
	switch pFile.szKdf {
	case "Argon2id":
		bDerived = argon2.IDKey(bPassphrase, pFile.bSalt, uint32(pFile.iPasses), uint32(pFile.iMemoryKiB), uint8(pFile.iParallel), 80)
	case "Argon2i":
		bDerived = argon2.Key(bPassphrase, pFile.bSalt, uint32(pFile.iPasses), uint32(pFile.iMemoryKiB), uint8(pFile.iParallel), 80)
	default:
		// Argon2d 는 쓰는 라이브러리(x/crypto/argon2)에 없다. PuTTYgen 기본값은 Argon2id 다.
		return nil, nil, nil, nil, fmt.Errorf("ppk: unsupported key derivation %q", pFile.szKdf)
	}
	return bDerived[:32], bDerived[32:48], bDerived[48:80], sha256.New, nil
}

// ppkReader 는 SSH 형식(길이 4바이트 + 내용)의 값을 차례로 읽는다.
type ppkReader struct {
	bRest []byte
	bBad  bool
}

func (pReader *ppkReader) bytes() []byte {
	if pReader.bBad || len(pReader.bRest) < 4 {
		pReader.bBad = true
		return nil
	}
	uiLength := binary.BigEndian.Uint32(pReader.bRest[:4])
	if uint64(uiLength) > uint64(len(pReader.bRest)-4) {
		pReader.bBad = true
		return nil
	}
	bOut := pReader.bRest[4 : 4+uiLength]
	pReader.bRest = pReader.bRest[4+uiLength:]
	return bOut
}

func (pReader *ppkReader) mpint() *big.Int {
	return new(big.Int).SetBytes(pReader.bytes())
}

// ppkBuildKey 는 공개·개인 부분으로 Go 개인 키를 만든다 (RSA·Ed25519·ECDSA P-256/384/521).
func ppkBuildKey(szAlgorithm string, bPublic []byte, bPrivate []byte) (any, error) {
	pub := &ppkReader{bRest: bPublic}
	priv := &ppkReader{bRest: bPrivate}
	if string(pub.bytes()) != szAlgorithm {
		return nil, ErrPpkFormat
	}
	switch szAlgorithm {
	case "ssh-rsa":
		pE, pN := pub.mpint(), pub.mpint()
		pD, pP, pQ := priv.mpint(), priv.mpint(), priv.mpint()
		if pub.bBad || priv.bBad || !pE.IsInt64() || pE.Int64() <= 0 || pE.Int64() > 1<<31-1 {
			return nil, ErrPpkFormat
		}
		pKey := &rsa.PrivateKey{PublicKey: rsa.PublicKey{N: pN, E: int(pE.Int64())}, D: pD, Primes: []*big.Int{pP, pQ}}
		if errValidate := pKey.Validate(); errValidate != nil {
			return nil, errValidate
		}
		pKey.Precompute()
		return pKey, nil
	case "ssh-ed25519":
		bPub, bSeed := pub.bytes(), priv.bytes()
		if pub.bBad || priv.bBad || len(bPub) != ed25519.PublicKeySize || len(bSeed) != ed25519.SeedSize {
			return nil, ErrPpkFormat
		}
		key := ed25519.NewKeyFromSeed(bSeed)
		if !bytes.Equal(key.Public().(ed25519.PublicKey), bPub) {
			return nil, ErrPpkFormat
		}
		return &key, nil
	case "ecdsa-sha2-nistp256", "ecdsa-sha2-nistp384", "ecdsa-sha2-nistp521":
		var curve elliptic.Curve
		switch szAlgorithm {
		case "ecdsa-sha2-nistp256":
			curve = elliptic.P256()
		case "ecdsa-sha2-nistp384":
			curve = elliptic.P384()
		default:
			curve = elliptic.P521()
		}
		_ = pub.bytes() // 곡선 이름
		bPoint := pub.bytes()
		pD := priv.mpint()
		iSize := (curve.Params().BitSize + 7) / 8
		if pub.bBad || priv.bBad || len(pD.Bytes()) > iSize {
			return nil, ErrPpkFormat
		}
		pKey, errKey := ecdsa.ParseRawPrivateKey(curve, pD.FillBytes(make([]byte, iSize)))
		if errKey != nil {
			return nil, errKey
		}
		bGot, errPoint := pKey.PublicKey.Bytes()
		if errPoint != nil || !bytes.Equal(bGot, bPoint) {
			return nil, ErrPpkFormat
		}
		return pKey, nil
	default:
		return nil, fmt.Errorf("ppk: unsupported key type %q", szAlgorithm)
	}
}

			t.Fatal(errD)
		}
		return "ecdsa-sha2-" + szCurve,
			ppkString([]byte("ecdsa-sha2-"+szCurve), []byte(szCurve), bPoint),
			ppkString(ppkMpint(new(big.Int).SetBytes(bD)))
	}
	t.Fatalf("모르는 키 종류 %T", anyKey)
	return "", nil, nil
}

func ppkWrap64(bBlob []byte) []string {
	szAll := base64.StdEncoding.EncodeToString(bBlob)
	var slLines []string
	for len(szAll) > 64 {
		slLines = append(slLines, szAll[:64])
		szAll = szAll[64:]
	}
	return append(slLines, szAll)
}

// encodePpkForTest 는 PPK 형식 2 또는 3 파일을 만든다. szPassphrase 가 비면 암호 없는 키다.
func encodePpkForTest(t *testing.T, iVersion int, anyKey any, szComment string, szPassphrase string, szNewline string) []byte {
	t.Helper()
	szAlgorithm, bPublic, bPrivate := ppkBlobsForTest(t, anyKey)
	szEncryption := "none"
	var slKdf []string
	var bMacKey, bCipherKey, bIv []byte
	if szPassphrase != "" {
		szEncryption = "aes256-cbc"
		for len(bPrivate)%aes.BlockSize != 0 {
			bPrivate = append(bPrivate, byte(len(bPrivate))) // 채움 값은 아무 값이나 된다
		}
	}
	fnHash := sha256.New
	if iVersion == 2 {
		fnHash = sha1.New
		seed := sha1.New()
		seed.Write([]byte("putty-private-key-file-mac-key"))
		seed.Write([]byte(szPassphrase))
		bMacKey = seed.Sum(nil)
		if szPassphrase != "" {
			h0, h1 := sha1.Sum(append([]byte{0, 0, 0, 0}, szPassphrase...)), sha1.Sum(append([]byte{0, 0, 0, 1}, szPassphrase...))
			bCipherKey = append(h0[:], h1[:]...)[:32]
			bIv = make([]byte, 16)
		}
	} else if szPassphrase != "" {
		bSalt := make([]byte, 16)
		_, _ = rand.Read(bSalt)
		bDerived := argon2.IDKey([]byte(szPassphrase), bSalt, 3, 1024, 1, 80)
		bCipherKey, bIv, bMacKey = bDerived[:32], bDerived[32:48], bDerived[48:]
		slKdf = []string{"Key-Derivation: Argon2id", "Argon2-Memory: 1024", "Argon2-Passes: 3", "Argon2-Parallelism: 1", "Argon2-Salt: " + hex.EncodeToString(bSalt)}
	}
	mac := hmac.New(fnHash, bMacKey)
	mac.Write(ppkString([]byte(szAlgorithm), []byte(szEncryption), []byte(szComment), bPublic, bPrivate))
	bStored := bPrivate
	if szPassphrase != "" {
		block, _ := aes.NewCipher(bCipherKey)
		bStored = make([]byte, len(bPrivate))
		cipher.NewCBCEncrypter(block, bIv).CryptBlocks(bStored, bPrivate)
	}
	slPub, slPriv := ppkWrap64(bPublic), ppkWrap64(bStored)
	slLines := []string{
		fmt.Sprintf("PuTTY-User-Key-File-%d: %s", iVersion, szAlgorithm),
		"Encryption: " + szEncryption,
		"Comment: " + szComment,
		fmt.Sprintf("Public-Lines: %d", len(slPub)),
	}
	slLines = append(slLines, slPub...)
	slLines = append(slLines, slKdf...)
	slLines = append(slLines, fmt.Sprintf("Private-Lines: %d", len(slPriv)))
	slLines = append(slLines, slPriv...)
	slLines = append(slLines, "Private-MAC: "+hex.EncodeToString(mac.Sum(nil)), "")
	return []byte(strings.Join(slLines, szNewline))
}
