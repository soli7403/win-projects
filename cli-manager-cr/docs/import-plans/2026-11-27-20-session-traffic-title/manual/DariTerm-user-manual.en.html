USER MANUAL & OPERATION GUIDE

DariTerm User Manual

Multi-protocol terminal and SFTP client — what happens in each situation
Version 1.0.0 (2026-11-21) · Publisher: YangHun Lee · 16 areas + shortcut appendix
Each table reads "situation → what you do → what the app does". Screenshots use sample data.

1. Install and first launch

Install with the Windows installer. The first launch takes four steps: language → usage → app lock password → recovery code. The recovery code is shown only once, so keep it somewhere safe.

#SituationWhat you doWhat the app does
1-1First installRun DariTerm-amd64-installer.exeAsks for administrator rights, then shows the installer in your Windows language (10 languages, English otherwise) → license agreement → install folder (default C:\Program Files\DariTerm) → install. Installs WebView2 if missing. Adds Start menu and desktop shortcuts and an Installed apps entry (publisher YangHun Lee).
1-2App running during install/uninstallRun the installer"DariTerm is running" → close it and click [Retry], or [Cancel]. A silent install (/S) cancels right away.
1-3First launchStart the app① Language (Windows language preselected, preview on click) → ② Usage (Personal/Business, optional key) → ③ Setup (app lock password, 8+ characters, strength meter) → ④ Recovery code (24 characters, shown only here; tick "I saved the recovery code somewhere safe" → [Get started]) → start screen.
1-4After first launch—If there are no servers yet and PuTTY saved sessions or ~/.ssh/config exist, the Import servers window opens once automatically (not asked again).
1-5No tabs open—Start screen: [Quick connect] [Local terminal] [Add server] [Import from PuTTY] and a table of 12 shortcuts.
1-6UninstallInstalled apps → DariTermRemoves the program folder and shortcuts. Server list, settings and encrypted accounts (%APPDATA%\DariTerm\data) are kept.

2. App lock (protects server passwords and keys)

Server passwords and keys are encrypted with the app lock password and stored only on this PC. Locking keeps your sessions connected and just covers the screen.

#SituationWhat you doWhat the app does
2-1App start—Lock screen "DariTerm is locked". Enter the app lock password → [Unlock].
2-2Unlock with WindowsSettings > Security "Unlock with Windows sign-in" onThe lock screen shows [Unlock with Windows account] (DPAPI).
2-3Stepping away—Locks automatically after 15 minutes without input (setting, 0 = off) or when Windows locks/sleeps. Connected sessions stay open (the lock screen covers them). If SSH drops while locked, the session reconnects with the credentials it first signed in with, without asking; if that is not enough it shows "Will reconnect when you unlock the app." and reconnects as soon as you unlock.
2-4Lock nowClick "Unlocked" in the status bar, or Quick connect > Lock appLocks immediately.
2-5Wrong password—"The password is incorrect".
2-6Forgot password[Forgot the password? Reset with recovery code]24-character recovery code + new password → saved accounts are kept.
2-7Change passwordSettings > Security > Change app lock passwordCurrent, new, confirm → "Changed".
2-8Manage saved accountsSettings > Security > Saved accountsType (password/key) and servers using each account, [Rename], delete (those servers ask again on next connection).

4. Connecting

Double-click a saved server, or press Ctrl+K and type part of a name or IP. Unsaved servers can be reached directly by typing user@host.

#SituationWhat you doWhat the app does
4-1Saved serverDouble-click / Enter / Quick connectConnects in a new tab. The terminal shows "● Connecting to name (target)...".
4-2Quick connectCtrl+KType a name, IP or user@host:port. Each word is matched against name > address > folder·tags > user > scattered letters, up to 50 results. Enter = new tab, Ctrl+Enter = split right, Shift+Enter = split down.
4-3Unsaved serverType user@1.2.3.4 in Quick connect"Connect now: … (Connect once without saving)".
4-4CommandsType > in Quick connectNew local terminal · Add server · New folder · Import · Open settings · Switch theme · Tile all tabs · Lock app.
4-5Shell on this PCCtrl+Alt+T, start screen [Local terminal]cmd, PowerShell, WSL, etc. (shell and start folder can be set on a local server). If the start folder is missing it opens in the home folder and says so.
4-6Serial deviceProtocol SerialPort, speed, data bits, parity, stop bits, flow control, Enter key value, local echo.
4-7TelnetProtocol TelnetPort 23.
4-8Choose where to openRight-click a server "Choose where to open…"Shows the pane layout of open tabs: [Here] on an empty pane, arrows to split a pane in a direction, or [Open in new tab].
4-9Jump serverAdvanced > pick a jump server or "Enter manually…"Connects through it ("Connecting via jump server …"). An overly long chain is an error.
4-10Port forwardingAdd L/R rows in the Port forwarding tabAfter connecting: "Forwarding A → B". On failure: "Port forwarding L3307 failed: …".
4-11Connection failed—"Connection failed: " + a plain reason (refused port, timeout, host name not found, network unreachable, authentication failed, …).

Local: saves it on this PC and types the path. Telnet/serial: "Images can only be sent in a connected SSH session".

6-6Dangerous command on productionOn a Production server, type rm -rf, reboot, DROP TABLE, … and press EnterEnter is held and "Dangerous command on production — Run it anyway?" appears → [Run] / [Cancel]. Pastes are checked too. Patterns are edited in Settings > Input.

6-8Font sizeCtrl+= / Ctrl+- / Ctrl+08–32; Ctrl+0 resets to 14. Saved in settings.

6-11Log outputSettings > Logs "Log terminal output" on (off by default)Open connections start saving output to text files from that moment, new connections from the start. Turning it off stops recording. [Open log folder]. With "Keep ANSI codes" on (off by default) the log keeps color and cursor codes exactly as received.
6-12Pane context menuRight-click a paneClear screen, Select all, Copy, Paste, Paste image, Find, Same server to the right/below, Open SFTP (file) panel, Reconnect, Close pane.

Esc, dropping elsewhere or dragging back to the left half removes the hint. Drag the divider to resize.

8. Working with files

Press Ctrl+Shift+S (or the top-right icon) to open the file panel: SFTP for SSH sessions, this PC's files for local terminals. Drag between tabs to copy server to server.

#SituationWhat you doWhat the app does
8-1Browse server filesCtrl+Shift+S / top-right iconSFTP panel: files of the current pane's SSH session (name, size, modified; click a column header to sort, again to reverse, folders stay on top, header stays visible). Parent folder, home, path field, refresh, new folder, upload, [Move terminal to this folder (cd)].
8-2Local terminal filesSame shortcut in a local session"Files" panel: this PC's start folder.
8-3File context menu—Open/Preview · Download (local: copy to another folder) · Edit with an app on this PC (auto-upload on save) · Type path into terminal · cd · Copy path · Rename · Change permissions (not on local Windows) · Delete (permanent-delete confirmation).
8-4PreviewDouble-click a fileText and images up to 512 KB. Otherwise "Preview is not available for this file".
8-5UploadDrag files from Explorer onto the SFTP list"Drop here to upload to …" → progress in the transfer list. While writing, DariTerm writes to name.dtpart-xxxxxxxx in the same folder and renames it when done — if the transfer drops or is cancelled, an existing file with the same name keeps its old content and permissions. A .dtpart- file left behind by a network drop must be deleted by hand (downloads, copies and edit-and-save work the same way).
8-6Server → server copyDrag from one tab's SFTP list to another server's tab (terminal or list)Asks before overwriting the same names. Copies through a temp folder on this PC (Settings > File transfer) and deletes the temp files afterwards. The copy list at the bottom shows phase, progress, [Cancel], [Clear finished]. A folder cannot be copied into itself.
8-7Clean up old uploadsSettings > File transferDeletes uploads starting with dt- after N days (default 7, 0 = off).

10. Importing from other apps

Click Import in the sidebar to list PuTTY saved sessions, SecureCRT session folders and ~/.ssh/config. Passwords are not imported.

#SituationWhat you doWhat the app does
10-1Open ImportSidebar [Import], Quick connect > Import, start screenFinds PuTTY saved sessions (registry), SecureCRT session folders and ~/.ssh/config and lists them.
10-2ChooseTick items, select allName, address, type, source, key file. "Target folder name" (default "PuTTY import"; names starting with prod-/stg-/dev- get that environment).
10-3SecureCRT elsewhere[Choose SecureCRT folder]Reads a Config folder copied from another PC too, keeping folder structure and port forwarding.
10-3aXshell[Choose Xshell export file]Reads sessions (name, folder structure, host, port, user, notes, encoding, port forwarding) from an .xts file made with [File > Export] in Xshell, or from a single session file (.xsh). Names given to forwarding rules go into the server notes. If Xshell is installed on this PC its sessions are listed automatically. Passwords, user keys, proxies and serial sessions are not imported.
10-4AWS[Load AWS EC2]All regions via your aws CLI credentials. Private IPs go through a bastion in the same VPC as the jump server; keys from ~/.ssh/<key name>.pem.
10-5Import[Import N]"Imported N servers (M keys saved encrypted)". Passwords are not imported (enter once on first connection).

11. Sync and backup across PCs

#SituationWhat you doWhat the app does
11-1Turn on git syncSettings > git sync: a private repository addressUploads one file encrypted with the app lock password. git authentication uses this PC's git setup (SSH keys, credential helper). Addresses with passwords or tokens are refused.
11-2Automatic sync—On unlock, about 20 seconds after a change, and every 10 minutes. [Sync now]. "Last sync: …".
11-3Data differs from another PC—"The encrypted data in the repository differs from this PC" → [Get repository data] (new PC) / [Overwrite with this PC's data].

11-5Restore[Import backup]Confirms "Your current server list and credentials will be replaced" → the app locks; unlock with the app lock password of the PC that made the backup.

12. Disconnects and keeping sessions

#SituationWhat the app does
12-1Connection drops"Disconnected: …", then reconnects at 2, 4, 8, 16, 30 s, up to 5 times (setting). Serial does not reconnect automatically.
12-1aServer ended the sessionWhen you end the shell yourself (exit, logout — there was input within the last 10 s, or the connection was under 10 s old), DariTerm does not log back in; it shows "The server ended the session." + "Press Enter to reconnect." When the server ends an idle session (idle auto-logout, an admin closing it, a server restart), it reconnects automatically like a dropped connection.
12-2Reconnecting gave up"Press Enter to reconnect." → Enter reconnects immediately. The pane header [Reconnect] does the same.
12-3First connection failedNo automatic reconnect; the error is shown.
12-4Keep session with tmuxServer Advanced "Keep session (tmux)": programs on the server keep running after you close the pane or app, and reopening reattaches to the same screen. Without tmux it says so and works normally. On local Windows, WSL shells only.
12-5Local shell exits"Shell exited" → Enter starts a new shell.
