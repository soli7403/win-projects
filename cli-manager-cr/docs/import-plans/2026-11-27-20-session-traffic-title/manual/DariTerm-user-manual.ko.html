USER MANUAL & OPERATION GUIDE

DariTerm 사용자 매뉴얼

멀티 프로토콜 터미널·SFTP 통합 클라이언트 — 상황별 동작 안내
기준 버전: 1.0.0 (2026-11-21) · 게시자: YangHun Lee · 구성: 16개 영역 + 단축키 부록
각 표는 "상황 → 하는 일 → 앱 동작" 순서입니다. 화면 그림의 서버 이름·주소 등 개인 정보는 흐리게 처리했습니다.

1. 설치·첫 실행

Windows 설치 파일로 설치하고, 처음 실행하면 언어 선택 → 사용 용도 → 앱 잠금 비밀번호 → 복구 코드의 4단계를 거칩니다. 복구 코드는 이 화면에서 한 번만 보이므로 꼭 따로 보관하세요.

#상황하는 일앱 동작
1-1처음 설치DariTerm-amd64-installer.exe 실행관리자 권한을 묻고, Windows 언어로 설치 화면(10개 언어, 없으면 영어) → 사용권 동의 → 설치 위치(기본 C:\Program Files\DariTerm) → 설치. WebView2 가 없으면 함께 설치. 시작 메뉴·바탕화면 바로가기와 프로그램 추가/제거 등록(게시자 YangHun Lee).
1-2앱이 켜진 채 설치·제거설치 파일 실행"DariTerm 이 실행 중입니다" → 닫고 [다시 시도], 또는 [취소]. 조용히 설치(/S)면 바로 취소.
1-3처음 실행앱 실행① 언어 선택(Windows 언어가 미리 골라짐, 누르면 바로 미리 보기) → ② 사용 용도(개인용/업무용, 키 입력 선택) → ③ 처음 설정(앱 잠금 비밀번호 8자 이상, 강도 표시) → ④ 복구 코드(24자리, 이 화면에서만 보임, "안전한 곳에 저장했습니다" 체크 후 [시작하기]) → 시작 화면.
1-4처음 실행 뒤—서버가 하나도 없고 PuTTY 저장 세션이나 ~/.ssh/config 가 있으면 서버 가져오기 창을 한 번 자동으로 연다(다시 묻지 않음).
1-5탭이 하나도 없음—시작 화면: [빠른 연결] [로컬 터미널] [새 서버 등록] [PuTTY에서 가져오기], 단축키 표 12개.
1-6제거프로그램 추가/제거 → DariTerm프로그램 폴더·바로가기 삭제. 서버 목록·설정·암호화 계정(%APPDATA%\DariTerm\data)은 남는다.

2. 앱 잠금 (서버 비밀번호·키 보호)

서버 비밀번호와 키는 앱 잠금 비밀번호로 암호화해 이 PC 에만 저장합니다. 잠가도 연결된 세션은 끊기지 않고 잠금 화면만 위에 덮입니다.

#상황하는 일앱 동작
2-1앱 시작—잠금 화면 "DariTerm 잠김". 앱 잠금 비밀번호 → [열기].
2-2Windows 계정으로 열기설정 > 보안 "Windows 로그인으로 열기" 켬잠금 화면에 [Windows 계정으로 잠금 해제] (DPAPI).
2-3잠깐 자리 비움—입력 없이 15분(설정, 0=끔) 또는 Windows 잠금·절전이면 자동 잠금. 연결된 세션은 끊지 않는다(잠금 화면이 위에 덮임). 잠긴 동안 SSH 가 끊기면 그 세션이 처음 쓴 계정으로 창 없이 다시 연결하고, 그래도 안 되면 "앱 잠금을 해제하면 다시 연결합니다" 를 보이고 잠금을 풀면 곧바로 다시 연결한다.
2-4직접 잠그기상태 표시줄 "잠금 해제됨" 클릭, 또는 빠른 연결 > 앱 잠그기즉시 잠금.
2-5비밀번호 틀림—"비밀번호가 올바르지 않습니다".
2-6비밀번호 잊음[비밀번호를 잊으셨나요? 복구 코드로 재설정]24자리 복구 코드 + 새 비밀번호 → 저장된 계정은 그대로.
2-7비밀번호 바꾸기설정 > 보안 > 앱 잠금 비밀번호 변경현재·새·확인 입력 → "변경했습니다".
2-8저장된 계정 관리설정 > 보안 > 저장된 계정계정별 종류(비밀번호/키), 쓰는 서버, [이름] 바꾸기, 삭제(쓰는 서버는 다음 연결 때 다시 묻는다).

3. 서버 등록·정리 (사이드바)

사이드바에서 서버와 폴더를 정리합니다. 환경을 "운영"으로 정한 서버는 빨간 테두리로 표시되고, 위험한 명령 앞에서 한 번 더 묻습니다.

#상황하는 일앱 동작
3-1서버 추가사이드바 [서버 추가] / 폴더 우클릭 "여기에 서버 추가"서버 편집: 일반(프로토콜 SSH·Telnet·시리얼·로컬, 표시 이름, 주소·포트·사용자, 폴더, 태그, 환경, 색, 메모) · 로그인(SSH: 비밀번호/키 파일/SSH 에이전트/매번 입력, 이 서버에만 저장 또는 저장된 계정 공유) · 고급(경유 서버, tmux 세션 유지, 연결 후 명령, 인코딩, 터미널 종류, 연결 확인 간격) · 포트 포워딩(L/R). [저장] / [저장하고 연결].
3-2주소 칸에 user@host:22입력사용자·호스트·포트로 나눠 채운다.
3-3앱이 잠긴 채 비밀번호 저장[저장]"앱이 잠겨 있어 비밀번호를 저장할 수 없습니다".
3-4PPK v3 키키 파일 선택"PPK v3 키는 PuTTYgen → Conversions → Export OpenSSH key 로 변환해 주세요". OpenSSH·PEM·PPK v2 는 됨(키 내용은 암호화 저장).
3-5폴더 만들기·정리[폴더 추가], 폴더 우클릭(새 하위 폴더·폴더 수정·삭제)폴더 환경을 정하면 안의 서버가 그 색을 물려받는다. 삭제: 비어 있으면 바로, 서버가 있으면 [서버까지 삭제]/[아니오(폴더만 삭제, 서버는 위로)]/[취소].
3-6환경 표시서버·폴더 환경 = 운영/검증/부하 테스트/개발/네트워크 장비색 막대·알약으로 표시. 운영은 빨간 테두리 + 위험 명령 확인(6-6). 서버에 색·환경이 없으면 폴더(위 폴더까지) 것을 물려받는다 — 색 순서는 서버 색 → 서버 환경색 → 폴더 색 → 폴더 환경색. 폴더만 운영이어도 그 안의 서버는 운영으로 보호된다. 탭 위쪽 색 막대는 선택된 탭에만(색이 없으면 파랑), 다른 탭은 서버 색의 옅은 배경만.
3-7찾기사이드바 "서버 찾기"이름·주소·태그로 거른다. 없으면 "…와 일치하는 서버가 없습니다".
3-8즐겨찾기·최근서버 우클릭 "즐겨찾기에 추가"목록 위 "즐겨찾기", "최근 사용" 구역. 구역 제목을 누르면 폴더처럼 접히고, 접어 둔 상태는 저장돼 다시 열어도 그대로다.
3-9옮기기서버·폴더를 끌어 다른 폴더에 놓기정렬·이동, 바로 저장.
3-10여러 개 선택Ctrl+클릭 / Shift+클릭"서버 n개 선택" 막대. 끌어서 폴더로 옮기기, 우클릭 "삭제 (n개)".
3-11서버 우클릭—새 탭으로 열기 · 오른쪽 화면에 열기 · 아래 창으로 열기 · 열 위치 선택… · 수정(F2) · 복사본 만들기 · 즐겨찾기 · 접속 주소 복사 · 삭제.
3-12폴더 전체 열기폴더 우클릭 "폴더 서버 모두 바둑판으로 열기"한 탭에 바둑판으로. 16대 넘으면 먼저 확인.
3-13사이드바 감추기Ctrl+Shift+L, 왼쪽 위 아이콘표시/숨김. 너비는 경계를 끌어 조절(저장).

4. 연결하기

저장된 서버를 더블클릭하거나, Ctrl+K 빠른 연결에서 이름·IP 일부를 입력해 연결합니다. 저장하지 않은 서버는 user@host 형식으로 바로 연결할 수 있습니다.

#상황하는 일앱 동작
4-1저장된 서버더블클릭 / Enter / 빠른 연결새 탭에서 연결. 터미널에 "● 이름 (대상) 연결 중..." 안내 줄.
4-2빠른 연결Ctrl+K이름·IP·user@host:port 입력. 낱말별로 이름 > 주소 > 폴더·태그 > 사용자 > 흩어진 글자 순으로 찾아 최대 50개. Enter=새 탭, Ctrl+Enter=오른쪽 나누기, Shift+Enter=아래 나누기.
4-3저장 안 한 서버빠른 연결에 user@1.2.3.4"바로 연결: …(저장하지 않고 한 번만 연결)".
4-4명령빠른 연결에 >새 로컬 터미널·새 서버·새 폴더·가져오기·설정·테마 전환·모든 탭 바둑판·앱 잠그기.
4-5이 PC 의 셸Ctrl+Alt+T, 시작 화면 [로컬 터미널]cmd·PowerShell·WSL 등(로컬 서버 등록 시 셸·시작 폴더 지정). 시작 폴더가 없으면 홈에서 열고 안내.
4-6시리얼 장비프로토콜 시리얼포트·속도·데이터 비트·패리티·정지 비트·흐름 제어·Enter 값·로컬 에코.
4-7텔넷프로토콜 Telnet포트 23.
4-8어디에 열지 고르기서버 우클릭 "열 위치 선택…"열린 탭들의 칸 배치가 보이고, 빈 칸 [여기에] 또는 칸의 상·하·좌·우 화살표로 나눠 열기, [새 탭으로 열기].
4-9경유 서버(점프)고급 > 경유 서버 선택 또는 "직접 입력…"경유 서버를 거쳐 연결("경유 서버 … 를 거쳐 연결 중..."). 체인이 너무 길면 오류.
4-10포트 포워딩포트 포워딩 탭에 L/R 줄 추가연결 뒤 "포워딩 A → B" 안내. 실패하면 "포트 포워딩 L3307 실패: …".
4-11연결 실패—"연결 실패: " + 쉬운 원인(포트 거부·응답 시간 초과·호스트 이름 없음·네트워크 도달 불가·인증 실패 등).

5. 인증·보안 확인 (연결 중에 묻는 창)

#상황앱 동작
5-1처음 연결하는 서버"처음 연결하는 서버입니다" + 키 지문 → [믿고 연결] / [연결 취소]. 믿으면 저장.
5-2서버 키가 바뀜"경고: 서버의 호스트 키가 바뀌었습니다"(중간자 공격 가능성 경고) + 새·옛 지문 → [위험을 알고 새 키로 연결] / [연결 취소].
5-3비밀번호 필요"비밀번호 입력" + 암호화해 저장하고 다음부터 자동 로그인. 틀리면 다시 묻는다.
5-4추가 인증(OTP 등)서버가 묻는 문구 그대로 입력 창.
5-5키 파일 암호"키 암호 입력".
5-6사용자 이름 없음"사용자 이름 입력".

6. 터미널 쓰기

#상황하는 일앱 동작
6-1복사마우스로 드래그 / Ctrl+Shift+C"드래그하면 바로 복사"가 켜져 있으면(기본) 선택만으로 복사(PuTTY 방식).
6-2붙여넣기Ctrl+V / 마우스 오른쪽 클릭글자를 붙여넣는다. Ctrl+V 를 끄면 Ctrl+V 는 서버로 가고 Ctrl+Shift+V 로 붙여넣는다. 오른쪽 클릭을 끄면 메뉴가 뜬다(Shift+오른쪽 클릭은 늘 메뉴).
6-3여러 줄 붙여넣기2줄 이상 붙여넣기"여러 줄 붙여넣기 — n줄을 [세션]에 붙여넣습니다" 확인(설정으로 끔).
6-4캡처 이미지 보내기이미지를 복사한 뒤 Ctrl+V (또는 Ctrl+Alt+V)SSH: 서버 업로드 폴더(기본 ~/.dariterm/uploads, 없으면 만듦)에 dt-… 이름으로 올리고 경로를 터미널에 입력 → Claude Code 같은 CLI 가 이미지로 읽는다. 로컬: 이 PC 에 저장하고 경로 입력. 텔넷·시리얼: "이미지 전송은 연결된 SSH 세션에서만 가능합니다".
6-5파일 경로 넣기탐색기 파일을 복사 후 Ctrl+V, 또는 터미널에 끌어 놓기SSH 는 올리고 경로 입력, 그 외는 원래 경로 입력. 공백 있는 경로는 따옴표로 감쌈(설정).
6-6운영 서버에서 위험 명령환경=운영 서버에서 rm -rf, reboot, DROP TABLE 등 입력 후 EnterEnter 를 바로 보내지 않고 "운영 서버 위험 명령 — 정말 실행할까요?" → [실행]/[취소]. 붙여넣을 때도 검사. 패턴은 설정 > 입력에서 고침.
6-7찾기Ctrl+Shift+F찾기 막대 [이전] [다음] [닫기].
6-8글자 크기Ctrl+= / Ctrl+- / Ctrl+08~32, 0 은 14 로. 설정에 저장.
6-9여러 줄 입력(Claude Code 등)Shift+Enter실행하지 않고 줄만 바꿈(설정, 기본 켬).
6-10서버가 클립보드에 씀tmux·vim 등이 OSC 52 로 복사이 PC 클립보드에 넣는다(설정, 읽기 요청은 늘 거부).
6-11출력 기록설정 > 로그 "터미널 출력 기록" 켬(기본 꺼짐)켜면 열려 있는 연결도 그때부터, 새 연결은 처음부터 텍스트 파일로 저장. 끄면 기록을 멈춤. [로그 폴더 열기]. "ANSI 그대로 저장"을 켜면(기본 꺼짐) 색·커서 이동 코드를 지우지 않고 받은 그대로 남긴다.
6-12화면 비우기·전체 선택칸 우클릭화면 비우기, 전체 선택, 복사, 붙여넣기, 이미지 붙여넣기, 찾기, 같은 서버를 오른쪽에/아래에, SFTP(파일) 창 열기, 재연결, 창 닫기.

7. 탭·창 나누기

한 탭 안에서 창을 나누고, 일괄 입력을 켜면 여러 창에 같은 명령을 한 번에 보낼 수 있습니다. 왼쪽 위 쇠사슬 아이콘은 보이는 모든 창, Ctrl+Shift+B 는 지금 탭의 창들이 대상입니다.

#상황하는 일앱 동작

8. 파일 다루기

Ctrl+Shift+S(또는 오른쪽 위 아이콘)로 파일 창을 엽니다. SSH 세션은 SFTP, 로컬 터미널은 이 PC 의 파일이 보이며, 탭 사이로 끌어 놓아 서버 간 복사도 할 수 있습니다.

#상황하는 일앱 동작
8-1서버 파일 보기Ctrl+Shift+S / 오른쪽 위 아이콘SFTP 창: 지금 창의 SSH 세션 파일 목록(이름·크기·수정일, 머리 줄을 눌러 정렬·다시 누르면 반대, 폴더는 항상 위, 머리 줄 고정). 상위 폴더·홈·경로 입력·새로고침·새 폴더·업로드·[터미널을 이 폴더로 이동(cd)].
8-2로컬 터미널 파일로컬 세션에서 같은 단축키"파일" 창: 이 PC 의 시작 폴더 목록.
8-3파일 우클릭—열기/미리보기 · 다운로드(로컬: 다른 폴더로 복사) · 이 PC 앱으로 편집(저장하면 자동 업로드) · 경로를 터미널에 입력 · cd · 경로 복사 · 이름 바꾸기 · 권한 바꾸기(Windows 로컬 제외) · 삭제(영구 삭제 확인).
8-4미리보기파일 더블클릭텍스트·이미지(512KB 이하) 미리보기. 그 외 "미리보기를 지원하지 않는 파일입니다".
8-5올리기탐색기 파일을 SFTP 목록에 끌어 놓기"여기에 놓으면 … 로 업로드" → 전송 목록에 진행 표시. 쓰는 동안은 같은 폴더의 이름.dtpart-xxxxxxxx 에 쓰고 끝나면 원래 이름으로 바꾼다 — 중간에 끊기거나 취소해도 같은 이름의 기존 파일은 전 내용 그대로, 권한도 유지. 네트워크가 끊겨 못 지운 .dtpart- 파일은 직접 지운다(다운로드·복사·편집 저장도 같음).
8-6서버 → 서버 복사한 탭의 SFTP 목록에서 끌어 다른 탭(서버)의 터미널이나 목록에 놓기같은 이름이 있으면 덮어쓰기 확인. 이 PC 임시 폴더를 거쳐 복사(설정 > 파일 전송), 끝나면 임시 파일 삭제. 창 맨 아래 복사 목록에 단계·진행률·[취소]·[끝난 항목 지우기]. 폴더를 자기 안으로는 복사 못 함.
8-7오래된 업로드 정리설정 > 파일 전송dt- 로 시작하는 업로드를 n일(기본 7, 0=끔) 뒤 삭제.

#상황하는 일앱 동작

아래는 기본 키다. 설정 > 단축키에서 명령마다 키를 바꾸거나 지울 수 있고, "단축키 사용"을 끄면 앱 단축키 전체가 꺼져 그 키들이 터미널(서버)로 간다(vi·tmux 와 키가 겹칠 때). 다른 동작이 쓰던 키를 고르면 그 동작의 키는 비워진다. 붙여넣기·복사 키는 바꿀 수 없고 꺼도 동작한다.
