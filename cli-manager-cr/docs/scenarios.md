## 1. 설치·첫 실행

| # | 상황 | 하는 일 | 앱 동작 |
|---|---|---|---|
| 1-1 | 처음 설치 | `DariTerm-amd64-installer.exe` 실행 | 관리자 권한을 묻고, Windows 언어로 설치 화면(10개 언어, 없으면 영어) → 사용권 동의 → 설치 위치(기본 `C:\Program Files\DariTerm`) → 설치. WebView2 가 없으면 함께 설치. 시작 메뉴·바탕화면 바로가기와 프로그램 추가/제거 등록(게시자 YangHun Lee). |
| 1-2 | 앱이 켜진 채 설치·제거 | 설치 파일 실행 | "DariTerm 이 실행 중입니다" → 닫고 [다시 시도], 또는 [취소]. 조용히 설치(/S)면 바로 취소. |
| 1-3 | 처음 실행 | 앱 실행 | ① **언어 선택**(Windows 언어가 미리 골라짐, 누르면 바로 미리 보기) → ② **사용 용도**(개인용/업무용, 키 입력 선택) → ③ **처음 설정**(앱 잠금 비밀번호 8자 이상, 강도 표시) → ④ **복구 코드**(24자리, 이 화면에서만 보임, "안전한 곳에 저장했습니다" 체크 후 [시작하기]) → 시작 화면. |
| 1-4 | 처음 실행 뒤 | — | 서버가 하나도 없고 PuTTY 저장 세션이나 `~/.ssh/config` 가 있으면 **서버 가져오기 창을 한 번 자동으로 연다**(다시 묻지 않음, shell §6). |
| 1-5 | 탭이 하나도 없음 | — | 시작 화면: [빠른 연결] [로컬 터미널] [새 서버 등록] [PuTTY에서 가져오기], 단축키 표 12개. |
| 1-6 | 제거 | 프로그램 추가/제거 → DariTerm | 프로그램 폴더·바로가기 삭제. **서버 목록·설정·암호화 계정(`%APPDATA%\DariTerm\data`)은 남는다.** |

## 2. 앱 잠금 (서버 비밀번호·키 보호)

| # | 상황 | 하는 일 | 앱 동작 |
|---|---|---|---|
| 2-1 | 앱 시작 | — | 잠금 화면 "DariTerm 잠김". 앱 잠금 비밀번호 → [열기]. |
| 2-2 | Windows 계정으로 열기 | 설정 > 보안 "Windows 로그인으로 열기" 켬 | 잠금 화면에 [Windows 계정으로 잠금 해제] (DPAPI). |
| 2-3 | 잠깐 자리 비움 | — | 입력 없이 15분(설정, 0=끔) 또는 Windows 잠금·절전이면 자동 잠금. **연결된 세션은 끊지 않는다**(잠금 화면이 위에 덮임). 잠긴 동안 SSH 가 끊기면 그 세션이 처음 쓴 계정으로 창 없이 다시 연결하고, 그래도 안 되면 "앱 잠금을 해제하면 다시 연결합니다" 를 보이고 잠금을 풀면 곧바로 다시 연결한다. |
| 2-4 | 직접 잠그기 | 상태 표시줄 "잠금 해제됨" 클릭, 또는 빠른 연결 `> 앱 잠그기` | 즉시 잠금. |
| 2-5 | 비밀번호 틀림 | — | "비밀번호가 올바르지 않습니다". |
| 2-6 | 비밀번호 잊음 | [비밀번호를 잊으셨나요? 복구 코드로 재설정] | 24자리 복구 코드 + 새 비밀번호 → 저장된 계정은 그대로. |
| 2-7 | 비밀번호 바꾸기 | 설정 > 보안 > 앱 잠금 비밀번호 변경 | 현재·새·확인 입력 → "변경했습니다". |
| 2-8 | 저장된 계정 관리 | 설정 > 보안 > 저장된 계정 | 계정별 종류(비밀번호/키), 쓰는 서버, [이름] 바꾸기, 삭제(쓰는 서버는 다음 연결 때 다시 묻는다). |

## 3. 서버 등록·정리 (사이드바)

| # | 상황 | 하는 일 | 앱 동작 |
|---|---|---|---|
| 3-1 | 서버 추가 | 사이드바 [서버 추가] / 폴더 우클릭 "여기에 서버 추가" | 서버 편집: **일반**(프로토콜 SSH·Telnet·시리얼·로컬, 표시 이름, 주소·포트·사용자, 폴더, 태그, 환경, 색, 메모) · **로그인**(SSH: 비밀번호/키 파일/SSH 에이전트/매번 입력, 이 서버에만 저장 또는 저장된 계정 공유) · **고급**(경유 서버, tmux 세션 유지, 연결 후 명령, 인코딩, 터미널 종류, 연결 확인 간격) · **포트 포워딩**(L/R). [저장] / [저장하고 연결]. |
| 3-2 | 주소 칸에 `user@host:22` | 입력 | 사용자·호스트·포트로 나눠 채운다. |
| 3-3 | 앱이 잠긴 채 비밀번호 저장 | [저장] | "앱이 잠겨 있어 비밀번호를 저장할 수 없습니다". |
| 3-4 | PPK v3 키 | 키 파일 선택 | "PPK v3 키는 PuTTYgen → Conversions → Export OpenSSH key 로 변환해 주세요". OpenSSH·PEM·PPK v2 는 됨(키 내용은 암호화 저장). |
| 3-5 | 폴더 만들기·정리 | [폴더 추가], 폴더 우클릭(새 하위 폴더·폴더 수정·삭제) | 폴더 환경을 정하면 안의 서버가 그 색을 물려받는다. 삭제: 비어 있으면 바로, 서버가 있으면 [서버까지 삭제]/[아니오(폴더만 삭제, 서버는 위로)]/[취소]. |
| 3-6 | 환경 표시 | 서버·폴더 환경 = 운영/검증/부하 테스트/개발/네트워크 장비 | 색 막대·알약으로 표시. **운영**은 빨간 테두리 + 위험 명령 확인(6-6). 서버에 색·환경이 없으면 폴더(위 폴더까지) 것을 물려받는다 — 색 순서는 서버 색 → 서버 환경색 → 폴더 색 → 폴더 환경색. 폴더만 운영이어도 그 안의 서버는 운영으로 보호된다. 탭 위쪽 색 막대는 선택된 탭에만(색이 없으면 파랑), 다른 탭은 서버 색의 옅은 배경만. |
| 3-7 | 찾기 | 사이드바 "서버 찾기" | 이름·주소·태그로 거른다. 없으면 "…와 일치하는 서버가 없습니다". |
| 3-8 | 즐겨찾기·최근 | 서버 우클릭 "즐겨찾기에 추가" | 목록 위 "즐겨찾기", "최근 사용" 구역. |
| 3-9 | 옮기기 | 서버·폴더를 끌어 다른 폴더에 놓기 | 정렬·이동, 바로 저장. |
| 3-10 | 여러 개 선택 | Ctrl+클릭 / Shift+클릭 | "서버 n개 선택" 막대. 끌어서 폴더로 옮기기, 우클릭 "삭제 (n개)". |
| 3-11 | 서버 우클릭 | — | 새 탭으로 열기 · 오른쪽 화면에 열기 · 아래 창으로 열기 · 열 위치 선택… · 수정(F2) · 복사본 만들기 · 즐겨찾기 · 접속 주소 복사 · 삭제. |
| 3-12 | 폴더 전체 열기 | 폴더 우클릭 "폴더 서버 모두 바둑판으로 열기" | 한 탭에 바둑판으로. 16대 넘으면 먼저 확인. |
| 3-13 | 사이드바 감추기 | Ctrl+Shift+L, 왼쪽 위 아이콘 | 표시/숨김. 너비는 경계를 끌어 조절(저장). |

## 4. 연결하기

| # | 상황 | 하는 일 | 앱 동작 |
|---|---|---|---|
| 4-1 | 저장된 서버 | 더블클릭 / Enter / 빠른 연결 | 새 탭에서 연결. 터미널에 "● 이름 (대상) 연결 중..." 안내 줄. |
| 4-2 | 빠른 연결 | Ctrl+K | 이름·IP·`user@host:port` 입력. 낱말별로 이름 > 주소 > 폴더·태그 > 사용자 > 흩어진 글자 순으로 찾아 최대 50개. Enter=새 탭, Ctrl+Enter=오른쪽 나누기, Shift+Enter=아래 나누기. |
| 4-3 | 저장 안 한 서버 | 빠른 연결에 `user@1.2.3.4` | "바로 연결: …(저장하지 않고 한 번만 연결)". |
| 4-4 | 명령 | 빠른 연결에 `>` | 새 로컬 터미널·새 서버·새 폴더·가져오기·설정·테마 전환·모든 탭 바둑판·앱 잠그기. |
| 4-5 | 이 PC 의 셸 | Ctrl+Alt+T, 시작 화면 [로컬 터미널] | cmd·PowerShell·WSL 등(로컬 서버 등록 시 셸·시작 폴더 지정). 시작 폴더가 없으면 홈에서 열고 안내. |
| 4-6 | 시리얼 장비 | 프로토콜 시리얼 | 포트·속도·데이터 비트·패리티·정지 비트·흐름 제어·Enter 값·로컬 에코. |
| 4-7 | 텔넷 | 프로토콜 Telnet | 포트 23. |
| 4-8 | 어디에 열지 고르기 | 서버 우클릭 "열 위치 선택…" | 열린 탭들의 칸 배치가 보이고, 빈 칸 [여기에] 또는 칸의 상·하·좌·우 화살표로 나눠 열기, [새 탭으로 열기]. |
| 4-9 | 경유 서버(점프) | 고급 > 경유 서버 선택 또는 "직접 입력…" | 경유 서버를 거쳐 연결("경유 서버 … 를 거쳐 연결 중..."). 체인이 너무 길면 오류. |
| 4-10 | 포트 포워딩 | 포트 포워딩 탭에 L/R 줄 추가 | 연결 뒤 "포워딩 A → B" 안내. 실패하면 "포트 포워딩 L3307 실패: …". |
| 4-11 | 연결 실패 | — | "연결 실패: " + 쉬운 원인(포트 거부·응답 시간 초과·호스트 이름 없음·네트워크 도달 불가·인증 실패 등). |

## 5. 인증·보안 확인 (연결 중에 묻는 창)

| # | 상황 | 앱 동작 |

| 5-1 | 처음 연결하는 서버 | "처음 연결하는 서버입니다" + 키 지문 → [믿고 연결] / [연결 취소]. 믿으면 저장. |
| 5-2 | 서버 키가 바뀜 | "경고: 서버의 호스트 키가 바뀌었습니다"(중간자 공격 가능성 경고) + 새·옛 지문 → [위험을 알고 새 키로 연결] / [연결 취소]. |

| 5-4 | 추가 인증(OTP 등) | 서버가 묻는 문구 그대로 입력 창. |
| 5-5 | 키 파일 암호 | "키 암호 입력". |
| 5-6 | 사용자 이름 없음 | "사용자 이름 입력". |

## 6. 터미널 쓰기

| # | 상황 | 하는 일 | 앱 동작 |
|---|---|---|---|
| 6-1 | 복사 | 마우스로 드래그 / Ctrl+Shift+C | "드래그하면 바로 복사"가 켜져 있으면(기본) 선택만으로 복사(PuTTY 방식). |
| 6-2 | 붙여넣기 | Ctrl+V / 마우스 오른쪽 클릭 | 글자를 붙여넣는다. Ctrl+V 를 끄면 Ctrl+V 는 서버로 가고 Ctrl+Shift+V 로 붙여넣는다. 오른쪽 클릭을 끄면 메뉴가 뜬다(Shift+오른쪽 클릭은 늘 메뉴). |
| 6-3 | 여러 줄 붙여넣기 | 2줄 이상 붙여넣기 | "여러 줄 붙여넣기 — n줄을 [세션]에 붙여넣습니다" 확인(설정으로 끔). |
| 6-4 | 캡처 이미지 보내기 | 이미지를 복사한 뒤 Ctrl+V (또는 Ctrl+Alt+V) | SSH: 서버 업로드 폴더(기본 `~/.dariterm/uploads`, 없으면 만듦)에 `dt-…` 이름으로 올리고 **경로를 터미널에 입력** → Claude Code 같은 CLI 가 이미지로 읽는다. 로컬: 이 PC 에 저장하고 경로 입력. 텔넷·시리얼: "이미지 전송은 연결된 SSH 세션에서만 가능합니다". |
| 6-5 | 파일 경로 넣기 | 탐색기 파일을 복사 후 Ctrl+V, 또는 터미널에 끌어 놓기 | SSH 는 올리고 경로 입력, 그 외는 원래 경로 입력. 공백 있는 경로는 따옴표로 감쌈(설정). |
| 6-6 | 운영 서버에서 위험 명령 | 환경=운영 서버에서 `rm -rf`, `reboot`, `DROP TABLE` 등 입력 후 Enter | Enter 를 바로 보내지 않고 "운영 서버 위험 명령 — 정말 실행할까요?" → [실행]/[취소]. 붙여넣을 때도 검사. 패턴은 설정 > 입력에서 고침. |
| 6-7 | 찾기 | Ctrl+Shift+F | 찾기 막대 [이전] [다음] [닫기]. |
| 6-8 | 글자 크기 | Ctrl+= / Ctrl+- / Ctrl+0 | 8~32, 0 은 14 로. 설정에 저장. |
| 6-9 | 여러 줄 입력(Claude Code 등) | Shift+Enter | 실행하지 않고 줄만 바꿈(설정, 기본 켬). |
| 6-10 | 서버가 클립보드에 씀 | tmux·vim 등이 OSC 52 로 복사 | 이 PC 클립보드에 넣는다(설정, 읽기 요청은 늘 거부). |
| 6-11 | 출력 기록 | 설정 > 로그 "터미널 출력 기록" 켬(기본 꺼짐) | 켜면 열려 있는 연결도 그때부터, 새 연결은 처음부터 텍스트 파일로 저장. 끄면 기록을 멈춤. [로그 폴더 열기]. "ANSI 그대로 저장"을 켜면(기본 꺼짐) 색·커서 이동 코드를 지우지 않고 받은 그대로 남긴다. |
| 6-12 | 화면 비우기·전체 선택 | 칸 우클릭 | 화면 비우기, 전체 선택, 복사, 붙여넣기, 이미지 붙여넣기, 찾기, 같은 서버를 오른쪽에/아래에, SFTP(파일) 창 열기, 재연결, 창 닫기. |

## 7. 탭·창 나누기
