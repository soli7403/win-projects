# DariTerm 1.1.0 배포 안내 (Windows · Microsoft Store)

**패키지 만든 날**: 2026-11-23 · **결정**: D123 · **이전 버전**: 1.0.0 (2026-11-21)
**관련**: [CHANGELOG.md](../../CHANGELOG.md) 1.1.0 · 스토어 문구 [store/listing.md](../store/listing.md) · 스토어 제출 절차 [store/README.md](../store/README.md) §3 · MSIX 빌드 [host-settings/03_msix.md](../host-settings/03_msix.md)

1.0.0 다음 기능 버전이다. 새 설정 항목과 동작이 바뀐 점(D98 유휴 로그아웃 뒤 재연결, D116·D117 메뉴 삭제)이 있어 1.0.1 이 아니라 1.1.0 으로 정했다(import-1118-features 계획서 §7 권장). 데이터 파일은 필드만 늘어 1.0.0 에서 올려도 서버 목록·계정·설정을 그대로 쓴다.

---

## 1. 배포 파일

`build\dist\` 에 있다(저장소에는 넣지 않는다).

| 파일 | 크기 | SHA256 | 누구에게 |
|---|---|---|---|
| `DariTerm-1.1.0.0.msix` | 6,260,981 바이트 | `6C234F9EEAAD3135B35B8DF064056DF3012A314BE06B1A099F459158CB60F8AD` | Microsoft Store 제출용 (Partner Center 에 올림) |

- 패키지 신원: Name `YangHunLee.DariTerm`, Publisher `CN=0AEF544B-0B89-41A6-861B-39FF4DB0031F`, Version `1.1.0.0`, x64 (1.0.0.0 보다 크므로 스토어가 업데이트로 받는다).
- 서명 없음 — 정상이다. 스토어가 제출을 받을 때 서명한다. 이 파일을 직접 설치하지 않는다.
- **스토어 밖 설치 파일은 이번에 만들지 않았다.** 필요하면 `mingw32-make installer` (버전은 wails.json 의 1.1.0) → `build\dist\DariTerm-1.1.0-amd64-installer.exe`.

만든 방법(2026-11-23, 이 PC):

```
mingw32-make msix VERSION=1.1.0   # wails.json 1.0.0 → 1.1.0, 앱 빌드, MSIX
```

빌드 전 검증: `go vet ./...`, `go test ./...` 전부 통과, 프런트 `tsc --noEmit` 통과, `vitest` 49개 파일 311개 테스트 통과. (`-race` 는 이 PC 에 cgo 컴파일러가 없어 돌리지 않았다.)

### 2.1 사용자가 달라졌다고 느낄 수 있는 점

- 서버가 **입력 없이 10초 넘게 있다가** 세션을 끝내면(유휴 자동 로그아웃 등) 이제 자동으로 다시 붙는다. `exit` 로 끝내면 전처럼 닫힌다.
- 탭·폴더 우클릭의 "바둑판으로", 서버 우클릭의 "열 위치 선택…"이 없다.
- 로그 설정은 "연결"이 아니라 새 **"로그"** 구역에 있다.
- "선택하면 자동 복사"는 마우스로 선택을 끝냈을 때 한 번 복사한다(찾기가 바꾼 선택은 복사하지 않는다).
- 스토어 설치본은 새 버전이 나오면 상태 표시줄에 알린다(자동 확인을 끄지 않았다면).

## 3. 배포 절차 (남은 일 — 사용자가 직접)

외부로 나가는 일이라 사용자가 한다(공통 규칙 §8).

- [ ] **수동 확인**(아래 §4)을 `build\bin\dariterm.exe` 로 해 본다. 특히 ZMODEM 은 실제 lrzsz 와 한 번도 맞대어 보지 않았다.
- [ ] **Microsoft Store**: Partner Center > DariTerm > 제출 업데이트 → 패키지에 `DariTerm-1.1.0.0.msix` 를 올리고 이전 패키지(1.0.0.0)는 제거 → Store 목록의 "이 버전의 새로운 기능" 에 [listing.md](../store/listing.md) 의 영어·한국어 1.1.0 문구 → 제출. 1.0.0 제출(Submission 3)이 아직 인증 중이면 끝날 때까지 기다린다. 결과는 [store/README.md](../store/README.md) §5 제출 이력의 "결과" 칸에 적는다.
- [ ] 커밋(버전 / 기능 / 문서)과 push.
