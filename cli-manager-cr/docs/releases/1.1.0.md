# DariTerm 1.1.0 배포 안내 (Windows · Microsoft Store)

**패키지 만든 날**: 2026-11-25 (처음 만든 날 2026-11-23, 제출 전이라 다시 만듦) · **결정**: D123-1 · D133 · **이전 버전**: 1.0.0 (2026-11-21)
**관련**: [CHANGELOG.md](../../CHANGELOG.md) 1.1.0 · 스토어 문구 [store/listing.md](../store/listing.md) · 스토어 제출 절차 [store/README.md](../store/README.md) §3 · MSIX 빌드 [host-settings/03_msix.md](../host-settings/03_msix.md)

1.0.0 다음 기능 버전이다. 새 설정 항목과 동작이 바뀐 점(D98 유휴 로그아웃 뒤 재연결, D116·D117 메뉴 삭제)이 있어 1.0.1 이 아니라 1.1.0 으로 정했다(import-1118-features 계획서 §7 권장). 데이터 파일은 필드만 늘어 1.0.0 에서 올려도 서버 목록·계정·설정을 그대로 쓴다.

**2026-11-25 다시 만든 까닭**: 2026-11-23 에 만든 패키지를 스토어에 아직 올리지 않았다. 그 사이 고친 것(2026-11-25 계획서 8건, 구성 요소 최신화)을 버전을 올리지 않고 1.1.0 에 합쳤다(D133). 2026-11-23 의 패키지(SHA256 `6C234F9E…60F8AD`)는 덮어썼으니 **올리지 않는다**.

### 2.1 사용자가 달라졌다고 느낄 수 있는 점

- 서버가 **입력 없이 10초 넘게 있다가** 세션을 끝내면(유휴 자동 로그아웃 등) 이제 자동으로 다시 붙는다. `exit` 로 끝내면 전처럼 닫힌다.
- 탭·폴더 우클릭의 "바둑판으로", 서버 우클릭의 "열 위치 선택…"이 없다.
- 설정 구역이 10개가 됐다: 로그 설정은 "연결"이 아니라 **"로그"** 에, 단축키 표는 "정보"가 아니라 **"단축키"** 에 있다.
- "선택하면 자동 복사"는 마우스로 선택을 끝냈을 때 한 번 복사한다(찾기가 바꾼 선택은 복사하지 않는다).
- **F11** 은 조합 키 없이 누를 때만 창을 최대화한다(전에는 Ctrl+F11·Shift+F11 도 됐다).
- 텔넷·시리얼 끊김 안내 문구가 "연결이 종료되었습니다" 대신 까닭(예: "서버가 연결을 닫았습니다", "네트워크 오류 (…)")을 보인다.
- 스토어 설치본은 새 버전이 나오면 상태 표시줄에 알린다(자동 확인을 끄지 않았다면).
