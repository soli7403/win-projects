**패키지 만든 날**: 2026-11-28 (같은 날 SSH 키·시리얼 도구를 넣어 다시 만듦, D166) · **결정**: D161 · D166 · **이전 버전**: 1.1.0 (2026-11-25, 스토어 인증 끝남)

### 2.1 사용자가 달라졌다고 느낄 수 있는 점

- 설정의 "키워드 강조"가 "화면"에서 새 구역 **"출력 규칙"** 으로 옮겨 갔다(출력 트리거와 함께).
- 서버 편집에 **"자동화"** 탭이 생겼다(로그인 스크립트·이 서버의 출력 트리거).
- 창 머리글 오른쪽에 `↑ … ↓ …` 전송량이 보인다(좁은 창에서는 숨음). 포워딩이 있는 SSH 창에는 `⇄ N` 버튼.
- 왼쪽 위에 도움말(?) 버튼이 생겼다.
- 설정 > 보안의 저장된 계정에 [SSH 키 만들기], 키 계정에 [공개 키] 버튼이 생겼다. SSH 창 우클릭에 "공개 키를 이 서버에 등록…".
- 시리얼 창 우클릭에 HEX·XMODEM 항목이 생겼다.
- 화면 보호기가 켜져도 Windows 가 실제로 잠기지 않았으면 앱도 잠기지 않는다.
