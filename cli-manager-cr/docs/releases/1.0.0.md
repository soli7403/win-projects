# DariTerm 1.0.0 배포 안내 (Windows)

**배포일**: 2026-11-21 · **결정**: D106 · **이전 버전**: 0.3.0 (2026-11-17)
**관련**: [CHANGELOG.md](../../CHANGELOG.md) 1.0.0 · 스토어 문구 [store/listing.md](../store/listing.md) · 스토어 제출 절차 [store/README.md](../store/README.md) §3 · 설치 파일 빌드 [host-settings/01_installer-build.md](../host-settings/01_installer-build.md) · MSIX 빌드 [host-settings/03_msix.md](../host-settings/03_msix.md)

DariTerm 의 첫 정식 버전이다. 0.3.0 다음 번호를 0.4.0 이 아니라 1.0.0 으로 정했다(D106). 데이터 파일 형식과 화면 흐름은 0.x 와 같다.

---

## 1. 배포 파일

`build\dist\` 에 있다(저장소에는 넣지 않는다).

| 파일 | 크기 | SHA256 | 누구에게 |
|---|---|---|---|
| `DariTerm-1.0.0.0.msix` | 5,936,011 바이트 | `9D57F0D4B6D5B2BE1B5685B16A05A4B117FF1941EE346D1B4398F9D7A3EB481E` | Microsoft Store 제출용 (Partner Center 에 올림) |
| `DariTerm-1.0.0-amd64-installer.exe` | 7,607,081 바이트 | `449BFE886D3D2CC75CFC9183356E596DFD53B1EE4B4A699698110CE9874EDD8F` | 스토어 밖에서 받는 사람 (NSIS 설치 파일, 64비트) |
| `DariTerm-1.0.0-amd64-installer.zip` | 7,566,070 바이트 | `F9956B7F63222230A45A18E31FA5E1AC7FB7316CB1507511719072B1FEEC37FF` | 위 설치 파일을 zip 으로 묶은 것 (메일·메신저가 .exe 를 막을 때) |

받은 사람이 파일이 온전한지 확인하는 명령:

```powershell
Get-FileHash .\DariTerm-1.0.0-amd64-installer.exe -Algorithm SHA256
```

만든 방법(2026-11-21, 이 PC):

```
make msix VERSION=1.0.0   # wails.json 0.3.0 → 1.0.0, 앱 빌드, MSIX
make installer            # 같은 버전으로 설치 파일
```

빌드 전 검증: `go vet ./...`, `go test -race ./...` 전부 통과, 프런트 `tsc --noEmit` 통과, `vitest` 39개 파일 249개 테스트 통과.

### 1.1 서명

| 파일 | 서명 | 뜻 |
|---|---|---|
| MSIX | 없음 | 정상이다. 스토어가 제출을 받을 때 서명한다. 이 파일을 직접 설치하지 않는다 |
| 설치 파일 | 없음(코드 서명 인증서 없음) | 내려받아 실행하면 Windows SmartScreen 이 "Windows의 PC 보호" 를 띄울 수 있다. [추가 정보] → [실행]. 받는 사람에게 미리 알린다 |

## 2. 0.3.0 이후 바뀐 것

자세한 내용은 [CHANGELOG.md](../../CHANGELOG.md) 1.0.0 과 각 계획서([import-plans](../import-plans/)).

| 구분 | 내용 | 결정 |
|---|---|---|
| 개선 | 화면 나누기 안내는 탭을 작업 영역 **오른쪽 가장자리**(너비의 10%, 최소 100px)로 끌 때만 나온다 | D102 |
| 개선 | 탭 위쪽 색 막대가 **선택된 탭에만** 있고 선택을 따라간다(색 없는 서버는 파랑) | D103 |
| 수정 | 탭 끌기를 취소해도 점선 상자가 남아 오른쪽 절반을 누를 수 없던 문제 | D101 |
| 수정 | SFTP 전송이 끊기거나 취소되면 대상 파일이 잘린 채 남던 문제 — 임시 이름 `이름.dtpart-xxxxxxxx` 에 쓰고 끝나면 바꾼다 | D104 |
| 수정 | 폴더에 지정한 색·환경을 서버가 물려받지 않던 문제(터미널 테두리가 파랑) | D105 |

### 2.1 사용자가 달라졌다고 느낄 수 있는 점

- **"운영" 폴더 안의 서버**는 서버 자체에 환경이 없어도 이제 운영으로 취급된다. 빨간 테두리·"운영" 배지가 붙고, 위험 명령(`rm -rf` 등)을 칠 때 확인 창이 뜬다. 운영이 아닌 서버라면 서버 편집에서 환경을 "개발" 등으로 지정한다("기본"은 지정 안 함이라 폴더 값을 따른다).
- 색이 있는 서버라도 **선택되지 않은 탭에는 색 막대가 없다**(옅은 배경색만).
- SFTP 로 전송하는 동안 대상 폴더에 `.dtpart-` 파일이 잠깐 보인다. 네트워크가 끊겨 남은 것은 직접 지운다.
- 서버·폴더의 색·환경을 바꾸면 사이드바는 곧바로 바뀌지만, 이미 열린 세션은 다시 열어야 반영된다.

## 3. 설치와 업그레이드

| 경우 | 방법 | 데이터 |
|---|---|---|
| 새로 설치 (설치 파일) | 설치 파일 실행 → 관리자 권한 → 설치 화면. WebView2 가 없으면 함께 설치 | — |
| 0.x 설치 파일 판에서 올리기 | **DariTerm 을 닫고** 1.0.0 설치 파일을 실행해 덮어 설치. 켜진 채면 "DariTerm 이 실행 중입니다" 가 나온다 | `%APPDATA%\DariTerm\data` 그대로 사용 (서버 목록·계정·설정 유지) |
| 스토어 판 | 스토어가 자동 업데이트 (인증 통과·게시 뒤) | 그대로 |
| 제거 | 프로그램 추가/제거 → DariTerm | 사용자 데이터는 남는다 |

- 한 PC 에 스토어 판과 설치 파일 판을 함께 두지 않는다([store/README.md](../store/README.md) §4).
- **업무용 라이선스 키**: 키의 주 버전 제한이 1 이상이거나 제한이 없으면 그대로 쓸 수 있다. 0.x 에서 쓰던 키를 다시 넣을 필요는 없다.
- 업데이트 확인 기능은 지금 꺼져 있다(D80). 설치 파일 판 사용자에게는 새 버전을 직접 알려야 한다.

## 5. 배포 전 수동 확인 (자동 테스트로 못 본 것)

`build\bin\dariterm.exe` 또는 설치한 1.0.0 으로 한다. 자세한 표는 각 계획서의 수동 검증 절.

| # | 확인 | 기대 | 자세히 |
|---|---|---|---|
| 1 | 설정 > 정보의 버전 | `1.0.0` | — |
| 2 | 탭을 끌어 탭 막대 위·왼쪽을 지나 오른쪽 가장자리로 | 가장자리에 들어갈 때만 "여기에 놓으면 좌우로 나눕니다". Esc·다른 탭 위에 놓기면 사라짐 | [2026-11-19 계획서](../import-plans/2026-11-19-tab-split-hint-stuck.md) §7.2 |
| 3 | 색 있는/없는 서버 탭을 섞어 차례로 누름 | 색 막대가 선택한 탭만 따라감 | [2026-11-20 탭 색](../import-plans/2026-11-20-active-tab-color-bar.md) §7.2 |
| 4 | 보라 폴더 안의 색 없는 서버, "운영" 폴더 안의 환경 없는 서버를 엶 | 각각 보라 테두리 / 빨간 테두리 + 위험 명령 확인 | 같은 문서 §B7.2 |
| 5 | 큰 파일 덮어쓰기 업로드 중 취소·네트워크 끊기 | 서버의 기존 파일 내용 그대로 | [2026-11-20 SFTP](../import-plans/2026-11-20-sftp-temp-name-write.md) §8.2 |
| 6 | 0.3.0 을 설치한 PC 에 1.0.0 덮어 설치 | 서버 목록·계정·설정이 그대로 | — |

리눅스 서버에서만 볼 수 있는 SFTP 권한 유지·심볼릭 링크(같은 문서 §8.2 의 7~10)는 Windows 자동 테스트에서 건너뛰었다.
