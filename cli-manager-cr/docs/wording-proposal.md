# 문구 바꾸기 (D60 — 2026-11-13 적용됨)

> **D67 (2026-11-14) 갱신**: 아래 표의 "보관함" 문구는 앱 잠금 용어로 다시 바뀌었다 — 잠금 해제됨 / 앱 잠김 / 앱 잠그기 / 암호화해 저장 / 마스터 비밀번호 만들기 / 저장소 데이터 받기 / 이 PC 데이터로 덮어쓰기. "바로 잠그기" 버튼은 없앴다. 상세는 decisions.md D67. 이어서 D68 에서 "마스터 비밀번호"도 **앱 잠금 비밀번호**로 바꿨다.

> **상태: 사용자 승인 후 적용됨.** 아래 표는 적용 기록이다. 예외: 서버 메뉴 "즐겨찾기" → "즐겨찾기에 추가", 사이드바 버튼 "서버"·"폴더" → "서버 추가"·"폴더 추가"는 같은 글자가 다른 곳에도 있어 손으로 바꿨다. AWS 가져오기 설명의 "배스천"은 AWS 용어라 남겼다.

> 작성 2026-11-13. 목적: 원본 앱과 메뉴·용어 표현을 다르게 하되, 뜻은 같고 일반적으로 쓰는 말로.
> 기준: 지금 DariTerm 화면 문구(명세 `spec/` 를 통해 원본 문구를 그대로 옮긴 것). 원본 코드는 열지 않음.
> **승인 전에는 코드를 바꾸지 않는다.** 표에서 고칠 곳은 "제안" 칸을 직접 고치거나 말로 알려 주면 반영한다.

## 0. 원칙

- **바꾸는 것**: 메뉴·버튼·제목·설정 항목 이름·툴팁, 그리고 앱 고유의 용어(볼트, 스니펫, 동시 입력, 점프 호스트 등).
- **유지하는 것**: 어느 앱에서나 쓰는 표준 동작 단어 — 삭제, 취소, 확인, 저장, 닫기, 복사, 붙여넣기, 열기, 찾기, 새로고침, 다운로드, 업로드, 이름 바꾸기, 가져오기, 내보내기, 설정, 세션, 탭, 폴더, 서버, SSH/SFTP 같은 기술 용어. 이것들을 억지로 바꾸면 오히려 쓰기 어렵다.
- **긴 설명 문장**(도움말·토스트): 이번에는 안에 든 용어만 아래 용어 사전대로 바뀐다. 문장 전체를 새로 쓰는 것은 2단계로 따로 한다(원하면).
- 단축키, 동작, 화면 배치는 바꾸지 않는다.
