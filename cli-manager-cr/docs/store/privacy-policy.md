## English

Last updated: November 14, 2026

DariTerm is a terminal application developed by YangHun Lee.

**What DariTerm stores.** Server addresses, user names, session settings, and — if you choose to save them — passwords and private keys. All of this is stored only on your PC. Passwords and keys are stored encrypted and locked with your app lock password.

**What DariTerm sends.** DariTerm connects only to the servers and devices you configure (SSH, Telnet, SFTP, serial). If you use "Load AWS EC2" import, it queries AWS with your own aws CLI credentials. It does not send usage data, analytics, crash reports or any personal information to the developer or to third parties. It does not show ads.

**Backups.** Backup files are written only where you choose. If you turn on synchronization to a Git repository you specify, your settings are sent to that repository only.

**License keys.** A business license key is checked on your PC. It is not sent anywhere.

**Your control.** You can delete servers and saved credentials in the app at any time. Uninstalling the Microsoft Store version removes the data it created.

## 한국어

최종 수정: 2026년 11월 14일

DariTerm 은 YangHun Lee 가 만든 터미널 앱입니다.

**저장하는 정보.** 서버 주소, 사용자 이름, 세션 설정, 그리고 사용자가 저장을 고른 경우 비밀번호와 개인 키. 모두 사용자 PC 안에만 저장합니다. 비밀번호와 키는 암호화해 저장하고 앱 잠금 비밀번호로 잠급니다.

**보내는 정보.** DariTerm 은 사용자가 설정한 서버와 장치(SSH, 텔넷, SFTP, 시리얼)에만 접속합니다. "AWS EC2 불러오기"를 쓰면 사용자의 aws CLI 자격 증명으로 AWS 에 조회합니다. 사용 기록, 분석 정보, 오류 보고, 개인정보를 개발자나 제3자에게 보내지 않습니다. 광고가 없습니다.

**백업.** 백업 파일은 사용자가 고른 곳에만 씁니다. 사용자가 지정한 Git 저장소 동기화를 켜면 설정이 그 저장소로만 보내집니다.

**라이선스 키.** 업무용 라이선스 키는 PC 안에서 확인하며 어디로도 보내지 않습니다.

**삭제.** 서버와 저장한 접속 정보는 앱에서 언제든 지울 수 있습니다. Microsoft Store 판을 제거하면 그 판이 만든 데이터가 지워집니다.
