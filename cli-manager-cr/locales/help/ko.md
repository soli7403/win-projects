## 처음 실행 {#start}

DariTerm 은 서버에 접속해 일하는 사람을 위한 터미널 프로그램입니다. SSH·텔넷·시리얼·이 PC 의 터미널을 탭과 창으로 나눠 씁니다.

1. **언어 선택** — 처음 켜면 화면 언어를 고릅니다. 나중에 설정 > 화면에서 바꿀 수 있습니다.
2. **사용 형태** — 개인용인지 업무용인지 고릅니다.
3. **앱 잠금 비밀번호** — 서버 비밀번호·키를 암호화하는 비밀번호입니다. 잊으면 저장한 비밀번호를 되살릴 수 없으니 잘 기억하세요.
4. **서버 추가** — 사이드바의 [서버 추가]로 첫 서버를 등록하거나, 다른 프로그램에서 가져옵니다.

> 모든 데이터는 이 PC 에만 저장됩니다. 다른 PC 와 맞추려면 git 동기화나 백업을 씁니다.

## 화면 둘러보기 {#screen}

- **사이드바**: 서버 목록(폴더·즐겨찾기·최근 사용)과 검색. 왼쪽 위 아이콘 묶음에 서버 목록, 매크로&명령 모음, 설정, 도움말 버튼이 있습니다.
- **탭 막대**: 연결마다 탭 하나. 탭 안을 여러 창으로 나눌 수 있습니다.
- **창 머리글**: 서버 이름과 접속 대상. 포트 포워딩이 있으면 `⇄ N` 버튼이 보입니다. 오른쪽 버튼들 앞의 `↑1.2 K ↓34 M` 은 이 세션의 **전송량**(↑ 보낸 것 = 입력, ↓ 받은 것 = 출력, 세션을 연 뒤 누적)이고 1초마다 바뀝니다. 창이 좁으면 숨겨집니다.
- **상태 표시줄**: 지금 창의 연결 상태와 연결 시간, 사용 형태, 매크로 녹화 배지, 오른쪽 끝의 "잠금 해제됨"(누르면 바로 잠급니다).

![처음 화면 — 사이드바의 서버 목록과 매크로&명령 모음](screen.png)

## 서버 등록하기 {#servers}

1. 사이드바 **[서버 추가]** (또는 폴더 우클릭 > 여기에 서버 추가).
2. **일반** 탭: 표시 이름, 프로토콜(SSH·텔넷·시리얼·로컬), 주소와 포트, 폴더, 색과 환경(운영·개발 등).
3. **인증** 탭(SSH): 비밀번호, 키 파일, SSH 에이전트, 또는 매번 묻기.
   - 비밀번호와 키는 보관함에 암호화해 저장합니다.
   - 여러 서버가 같은 계정을 쓰면 "공유 계정"으로 한 번만 저장합니다.
4. **고급** 탭: 경유 서버, 프록시 경유, 에이전트 전달, 연결 유지 신호, 인코딩, 연결 후 실행할 명령, 연결 유지 (tmux).
5. **포트 포워딩** 탭(SSH), **자동화** 탭(로그인 스크립트·이 서버의 출력 트리거).
6. **[저장]** 또는 **[저장하고 연결]**.

![서버 편집 > 일반 탭](servers.png)

서버를 끌어 다른 폴더로 옮기거나, 여러 개를 Ctrl·Shift 로 골라 한꺼번에 옮기고 지울 수 있습니다. 즐겨찾기·최근 사용 구역은 제목을 눌러 접습니다.

## 연결하기 {#connect}

- 서버를 **두 번 누르면** 새 탭으로 연결합니다.
- **Ctrl+K**(빠른 연결): 서버 이름을 몇 글자 치고 Enter. `user@host:port` 를 바로 쳐서 저장하지 않은 서버에도 연결합니다. `>` 로 시작하면 명령 목록입니다.
- **Ctrl+Alt+T**: 이 PC 의 터미널.
- 연결이 끊기면 설정 > 연결 "연결이 끊기면 다시 연결"에 따라 2·4·8·16·30초 간격으로 다시 연결합니다. 멈춘 뒤에는 그 창에서 Enter 를 누르면 다시 연결합니다. 끊긴 까닭은 터미널에 한 줄로 나옵니다.

![빠른 연결(Ctrl+K)](connect.png)

## 로그인과 서버 키 확인 {#auth}

- **처음 연결하는 서버**는 키 지문을 보여 줍니다. 서버 관리자가 알려 준 값과 같으면 [믿고 연결]. 나중에 키가 바뀌면 경고가 뜨니, 이유를 모르면 연결하지 마세요.
- 비밀번호를 물으면 [저장]을 켜 두면 다음부터 묻지 않습니다.
- 키 파일은 OpenSSH 형식과 PuTTY 키(`.ppk`, 형식 2·3)를 그대로 읽습니다. 암호가 걸린 키는 처음 한 번 암호를 묻습니다.
- 서버가 추가 질문(OTP 등)을 하면 그때마다 입력 창이 뜹니다.

## 보관함과 앱 잠금 {#vault}

서버 비밀번호·키·경유 서버와 프록시 계정은 **보관함**에 앱 잠금 비밀번호로 암호화해 저장합니다.

![설정 > 보안 — 자동 잠금과 저장된 계정](vault.png)

- **자동 잠금**: 설정 > 보안 > 자동 잠금(분). 그 시간 동안 입력이 없거나, **Windows 를 잠그거나**, 절전하면 앱을 잠급니다. 연결은 끊기지 않습니다. 0이면 끕니다.
- Windows 잠금은 **Windows 세션의 잠금 상태**로 판단합니다. 그래서 화면 보호기가 떠 있어도 Windows 가 실제로 잠기지 않았으면("다시 시작할 때 로그온 화면 표시"를 끈 화면 보호기) 앱도 잠그지 않습니다. 유휴 시간 조건은 그대로 적용됩니다.
- **Windows 로그인으로 열기**: 설정 > 보안에서 켜면 비밀번호 대신 Windows 계정으로 엽니다.
- **저장된 계정**: 설정 > 보안에서 저장된 비밀번호·키를 보고 이름을 바꾸거나 지웁니다.
- 잠금 비밀번호를 바꿔도 저장한 내용은 그대로입니다.

## 터미널 쓰기 {#terminal}

- **복사**: 마우스로 고르면 바로 복사됩니다(설정 > 입력에서 끌 수 있음). **붙여넣기**: Ctrl+V 또는 오른쪽 클릭.
- **찾기**: Ctrl+Shift+F. 위·아래로 옮겨 가며 맞은 곳을 보여 줍니다.
- **글자 크기**: Ctrl+= / Ctrl+- / Ctrl+0.
- 그림을 붙여 넣으면 서버의 임시 폴더로 올리고 그 경로를 입력합니다.
- **운영 서버**(환경 "운영")에서 위험한 명령(`rm -rf` 등)을 붙여 넣거나 Enter 를 누르면 한 번 더 묻습니다. 설정 > 입력에서 패턴을 고칩니다.

## 탭과 창 나누기 {#tabs}

| 하고 싶은 일 | 방법 |
|---|---|
| 같은 서버를 오른쪽에 | Ctrl+Shift+D |
| 같은 서버를 아래에 | Ctrl+Shift+E |
| 창 하나만 크게 | Ctrl+Shift+Enter |
| 창 사이 옮기기 | Alt+방향키 |
| 일괄 입력(탭의 모든 창에 같은 입력) | Ctrl+Shift+B |
| 탭 옮기기 | Ctrl+Shift+← / → 또는 끌기 |

- 탭에 창이 여러 개면 탭에 창 수 배지가 붙습니다.
- 설정 > 화면 "마지막 화면 배치 복원"을 켜면 다음에 켤 때 탭과 창 배치를 되살립니다.

## 경유 서버(점프 호스트) {#jump}

방화벽 안의 서버는 경유 서버를 거쳐 연결합니다. 서버 편집 > 고급 > **경유 서버**에서 등록된 서버를 고르거나 직접 입력합니다.

- 경유 서버에도 경유 서버를 정하면 여러 단계를 차례로 거칩니다.
- 연결 중에는 "경유 서버 … 경유 중..." 줄이 단계마다 나옵니다.
- ssh config 를 가져오면 `ProxyJump a,b` 를 그대로 단계로 잇습니다(가져오기 참고).

## 프록시와 프록시 명령 {#proxy}

서버 편집 > 고급 > **프록시 경유**에서 고릅니다. 경유 서버가 있으면 맨 바깥 서버(이 PC 가 직접 연결하는 서버)의 프록시만 씁니다.

![서버 편집 > 고급 — 프록시 명령](proxy.png)

- **HTTP 프록시(CONNECT)**, **SOCKS5 프록시**: 주소·포트, 필요하면 사용자 이름과 비밀번호(보관함에 `{표시 이름} 프록시` 로 저장).
- **프록시 명령 (ProxyCommand)**: 서버까지의 통로를 외부 명령의 입출력으로 만듭니다. OpenSSH 의 ProxyCommand 와 같습니다.
  - `%h` 는 서버 주소, `%p` 는 포트, `%r` 은 사용자 이름, `%%` 는 `%` 로 바뀝니다.
  - 명령 프롬프트(cmd)에서 실행한 것과 같으며, 그 프로그램이 이 PC 에 설치돼 있어야 합니다.
  - 20초 안에 응답이 없으면 명령을 끝냅니다. 실패하면 명령이 남긴 오류의 끝부분을 보여 줍니다.

```
ssh -W %h:%p bastion
ncat --proxy proxy.example.com:8080 %h %p
```

## 포트 포워딩 {#forward}

서버 편집 > **포트 포워딩** 탭에서 추가합니다.

![서버 편집 > 포트 포워딩 탭](forward.png)

| 종류 | 뜻 |
|---|---|
| L (로컬) | 이 PC 의 포트로 들어온 연결을 서버 쪽 주소로 보냅니다 |
| R (원격) | 서버의 포트로 들어온 연결을 이 PC 쪽 주소로 보냅니다 |
| D (동적) | 이 PC 의 포트를 SOCKS 프록시로 엽니다 |

- 연결하면 터미널에 포워딩마다 한 줄씩 결과가 나옵니다. 실패한 줄은 빨갛게 보입니다.
- 창 머리글의 `⇄ N` 버튼(또는 창 우클릭 > 포트 포워딩 보기)을 누르면 종류·듣는 주소·대상·상태 표가 뜹니다. 상태는 "동작 중"이고, 이어진 연결이 있으면 연결 수가 붙습니다.
- **전송량**: 포워딩마다 보낸(↑)·받은(↓) 양을 접속한 뒤부터 누적해 보입니다. [새로고침]으로 다시 읽습니다.

## 에이전트와 키 파일 (SSH) {#agent}

- **SSH 에이전트**: 인증을 "SSH 에이전트"로 고르면 Windows 의 OpenSSH 에이전트와 실행 중인 Pageant 의 키를 모두 시도합니다. Windows 밖에서는 `SSH_AUTH_SOCK` 을 씁니다.
- **에이전트 전달**(`ssh -A`): 서버 편집 > 고급의 토글(기본 꺼짐). 서버 안에서 `ssh`·`git` 을 이 PC 의 에이전트 키로 씁니다. 믿을 수 있는 서버에서만 켜세요.
- 키 파일은 OpenSSH 형식과 PuTTY `.ppk` 를 변환 없이 읽습니다.

## SSH 키 만들기와 서버에 등록 {#ssh-keys}

비밀번호 대신 키로 로그인하게 바꾸는 순서입니다.

1. **설정 > 보안 > 저장된 계정**의 [SSH 키 만들기]: 이름, 종류(Ed25519 권장, 오래된 서버는 RSA 4096), 키 암호(선택)를 넣고 [만들기]. 키는 보관함에 암호화되어 저장됩니다.
2. 비밀번호로 서버에 접속한 창에서 우클릭 > **공개 키를 이 서버에 등록…** → 키를 고르고 [등록]. 서버의 `~/.ssh/authorized_keys` 에 한 줄이 들어갑니다(이미 있으면 그대로).
3. "다음 접속부터 이 서버에 이 키로 로그인"을 켜 두면 서버 설정도 키 로그인으로 바뀝니다.

- 키 계정 줄의 [공개 키]로 공개 키 한 줄과 지문을 보고 복사할 수 있습니다(다른 서버·GitHub 등에 붙여 넣기).
- 등록은 서버에서 `sh` 로 실행합니다. Windows OpenSSH 서버처럼 `sh` 가 없으면 공개 키를 복사해 직접 넣으세요.

## 연결 유지 (tmux) {#tmux}

서버 편집 > 고급 > **연결 유지 (tmux)** 를 켜면 서버의 tmux 세션 안에서 작업합니다. 창을 닫거나 연결이 끊겨도 서버의 작업은 계속 돌고, 다시 연결하면 그 화면으로 돌아옵니다.

- 세션 이름을 비우면 서버 이름으로 정합니다.
- 서버에 tmux 가 설치돼 있어야 합니다. 이 PC 의 터미널은 WSL 셸에서만 됩니다.

## 시리얼 연결 {#serial}

장비 콘솔(라우터·스위치 등)에 USB-시리얼로 연결합니다. 서버 편집에서 프로토콜을 **시리얼**로 고르고 포트(COM3 등)를 고릅니다.

- 속도(기본 9600), 데이터 비트, 패리티, 정지 비트, 흐름 제어(없음·RTS/CTS·XON/XOFF), Enter 로 보낼 글자, 로컬 에코.
- 장치가 2초 넘게 받지 못한 입력은 버리고 알려 줍니다.

## 시리얼 HEX 보기·HEX 보내기·XMODEM {#serial-tools}

시리얼 창의 우클릭 메뉴에 있습니다(연결된 동안).

- **HEX 로 보기**: 받은 바이트를 `01 41 FF  |.A.|` 처럼 16진과 글자로 보입니다(한 줄 16바이트, 받은 조각마다 새 줄). 다시 누르면 "글자로 보기".
- **HEX 보내기…**: `01 03 00 00 00 0A C5 CD` 처럼 적은 바이트를 그대로 보냅니다(띄어 써도, 붙여 써도, `0x01,0x03` 도 됩니다). 창은 열려 있어 같은 값을 되풀이해 보낼 수 있습니다.
- **XMODEM 보내기 / XMODEM-1K 보내기**: 파일을 고른 뒤 장치에서 받기를 시작하세요(부트로더의 `loadx` 등). 1K 는 1024바이트 블록이라 빠릅니다(장치가 CRC 를 쓸 때만).
- **XMODEM 받기**: 저장할 이름을 고른 뒤 장치에서 보내기를 시작하세요. 마지막 블록 끝의 채움(0x1A)은 떼어 냅니다.
- 전송 중에는 키 입력이 장치로 가지 않습니다. **Ctrl+C** 나 "XMODEM 전송 취소"로 그만둡니다.

## 파일 전송 (SFTP) {#sftp}

SSH 창에서 **Ctrl+Shift+S** 로 SFTP 창을 엽니다.

- 서버 폴더를 오가며 파일을 끌어다 놓아 올리고, 끌어내 받습니다.
- 받는 폴더·임시 폴더·올린 임시 파일 정리 기간은 설정 > 파일 전송.
- 터미널의 지금 폴더로 SFTP 를 맞추거나, SFTP 폴더로 터미널을 `cd` 할 수 있습니다.

## 터미널로 파일 받기·보내기 (ZMODEM) {#zmodem}

SSH·시리얼 터미널에서 서버의 `sz 파일` 로 받고 `rz` 로 올립니다.

- 받는 폴더와 끄기는 설정 > 파일 전송.
- 받는 중 Ctrl+C 로 취소할 수 있고, 서버가 60초 동안 응답하지 않으면 전송만 끝냅니다(연결은 유지).
- tmux·screen 안에서는 전송할 수 없습니다. 멈췄으면 Ctrl+X 를 5번 누르세요.

## 명령 모음과 변수 {#snippets}

자주 쓰는 명령을 **매크로&명령 모음**(왼쪽 위 `<>` 아이콘)에 저장해 두고 누르면 입력합니다. 목록의 명령에는 초록 **명령** 배지가 붙습니다.

- [새 명령]: 이름, 명령(여러 줄 가능), Enter 붙이기.
- 일괄 입력이 켜진 탭이면 그 탭의 모든 창에 입력합니다.
- **변수**: 명령에 `{{이름}}` 이나 `{{이름:기본값}}` 을 적으면, 누를 때 값을 묻는 창이 뜨고 채운 명령이 입력됩니다.

```
systemctl restart {{서비스}} --no-block {{옵션:-q}}
```

> `{{.Names}}` 처럼 점으로 시작하거나 `\{{…}}` 로 적은 것은 변수가 아닙니다. 지난 값은 앱이 켜져 있는 동안만 기억합니다.

## 매크로 {#macros}

매크로는 단계의 목록입니다. 앞 입력의 결과를 기다렸다가 다음 입력을 보냅니다. 목록에서 **파랑 "매크로 N단계"** 배지가 붙은 항목입니다.

![매크로&명령 모음 — 파랑 배지가 매크로](macros.png)

- **만들기**: [새 매크로]. 단계마다 *기다릴 글자*(비우면 출력이 0.5초 조용해질 때까지, 길어도 10초)와 *보낼 글자*, Enter 여부. 기다릴 글자가 30초 안에 나오지 않으면 멈춥니다.
- **녹화**: [매크로 녹화](동그라미)를 누르고 터미널에 평소처럼 입력한 뒤 다시 눌러 멈춥니다. Enter 마다 한 단계가 됩니다. 녹화 중에는 상태 표시줄에 빨간 배지가 보입니다.
- **실행**: 목록에서 누르면 지금 창에서 실행합니다. **일괄 입력이 켜진 탭이면 그 탭의 연결된 모든 창에서 따로따로 실행**합니다(창마다 자기 출력을 기다립니다). 이미 매크로가 도는 창은 건너뜁니다.
- **단축키**: 설정 > 단축키의 "매크로 녹화 시작/정지", "마지막 매크로 다시 실행", "지금 창의 매크로 중지"에 키를 줄 수 있습니다(기본 키 없음).
- 제어 문자는 `\x03`(Ctrl+C), `\e`, `\t`, `\r`, `\n`, `\\` 로 적습니다.

> 매크로는 암호화되지 않고 저장됩니다. 녹화할 때 비밀번호를 치지 마세요.

## 로그인 스크립트 {#login-script}

접속하자마자 하는 입력(`sudo su -`, 장비의 `enable` 등)을 자동으로 합니다. 서버 편집 > **자동화** 탭.

![서버 편집 > 자동화 — 로그인 스크립트와 이 서버의 출력 트리거](login-script.png)

- 단계마다 *기다릴 글자*와 *보낼 글자*. 서버 출력에 기다릴 글자가 나오면 보낼 글자 + Enter 를 보내고 다음 단계로 갑니다. 기다릴 글자가 비면 바로 보냅니다. 대소문자는 구분하지 않습니다.
- 접속할 때마다(재접속 포함) 처음부터 한 번씩 실행합니다. 한 단계가 20초 안에 넘어가지 않거나 직접 입력하면 멈춥니다.
- `{{password}}` 는 그 서버에 로그인할 때 쓴 비밀번호로 바뀝니다(SSH 비밀번호 로그인일 때).
- **보관함 값**: `su`·`enable` 처럼 로그인과 다른 비밀번호는 그 단계의 [보관함 값]에서 보관함 항목을 고르세요. 보낼 글자에 비밀번호를 적지 않아도 되고, 파일에는 항목 이름표만 남습니다.
- 고급 탭의 "연결 후 실행할 명령"은 스크립트가 끝까지 간 뒤에 실행됩니다.

## 키워드 강조 {#highlight}

설정 > **출력 규칙** > 키워드 강조. `ERROR`·`FAIL` 같은 글자를 고른 색으로 보여 줍니다.

- 규칙마다 찾을 글자(정규식 가능), 대소문자, 색, 바탕 칠하기.
- 화면 표시만 바꿉니다. 로그 파일에는 영향이 없습니다.

## 출력 트리거 {#triggers}

출력에 특정 글자가 나오면 알림·소리·자동 응답을 합니다. 보이지 않는 탭의 출력도 살핍니다.

![설정 > 출력 규칙 — 출력 트리거와 Windows 알림](triggers.png)

- **모든 연결의 규칙**: 설정 > 출력 규칙 > 출력 트리거.
- **이 서버의 규칙**: 서버 편집 > 자동화 > "이 서버의 출력 트리거". 그 서버에 연결한 창에서만 쓰고, 설정의 규칙과 함께 동작합니다. 서버를 저장할 때 함께 저장됩니다.
- 규칙마다: 찾을 글자(정규식 가능), 대소문자, **알림**, **소리**, **자동 응답**(보낼 글자, Enter).
- **Windows 알림**: 앱이 뒤에 있으면 알림이 Windows 알림 센터에도 뜹니다. 설정 > 출력 규칙의 "앱이 뒤에 있으면 Windows 알림도 띄우기"로 끕니다.
- 직접 입력하는 줄의 에코와 vim 같은 전체 화면 프로그램 안은 살피지 않습니다. 같은 규칙은 1초에 한 번만 실행합니다.
- 운영 서버에는 자동 응답을 보내지 않고 알립니다. 자동 응답이 10초에 5번 넘게 반복되면 그 연결에서 그 규칙을 끕니다.

## 세션 로그 {#log}

설정 > **로그**에서 켭니다.

![설정 > 로그](log.png)

- 터미널 출력을 연결마다 텍스트 파일(`{표시 이름}-{날짜-시각}.log`)로 남깁니다. [로그 폴더 열기]로 위치를 엽니다.
- 줄마다 시각 붙이기, ANSI 그대로 저장(색까지), 내려 쓰기 주기, 보관 기간(지난 파일 자동 삭제).
- 켜면 이미 열린 연결도 그때부터 기록합니다.

## 다른 프로그램에서 가져오기 {#import}

사이드바 메뉴 > **서버 가져오기**.

- **PuTTY**(레지스트리), **SecureCRT**(세션 폴더), **Xshell**(내보내기 파일 `.xts`·세션 파일 `.xsh`), **ssh config**(`~/.ssh/config`), **AWS EC2**(aws CLI).
- 폴더 구조·포트 포워딩·키 파일을 옮깁니다. 비밀번호는 옮기지 않습니다.
- ssh config 의 **ProxyJump** 는 여러 단계(`ProxyJump a,b`)를 경유 서버 단계로 잇고, **ProxyCommand** 는 서버의 프록시 명령으로 옮깁니다.
- SecureCRT 의 로그인 스크립트(로그온 동작)는 아직 옮기지 않고 알려 줍니다.
- 이미 있는 서버와 같아 보이는 후보는 처음에 선택이 꺼져 있습니다.

## 동기화와 백업 {#sync}

- **git 동기화**: 설정 > git 동기화. 서버 목록·보관함을 암호화한 파일로 내 git 저장소(비공개 권장)에 올리고 받아 여러 PC 를 맞춥니다.
- **백업**: 설정 > 백업. 파일 하나로 내보내고 가져옵니다. 가져올 때 지금 목록과 합치거나 바꿉니다.
- 매크로·명령 모음·출력 규칙도 함께 옮겨집니다.

## 자주 묻는 질문 {#faq}

질문마다 칸 하나로 나눠 두었습니다. 찾는 낱말을 검색 칸에 치면 그 낱말이 든 항목만 보입니다.

Q: 연결이 자꾸 끊겨요.
설정 > 연결 "연결이 끊기면 다시 연결"을 켜 두세요. 서버 편집 > 고급의 연결 유지 신호(keepalive) 간격을 줄이면 방화벽이 끊는 것을 막을 수 있습니다. 끊긴 까닭은 터미널에 나옵니다.

Q: 창을 닫아도 서버 작업이 계속 돌았으면 해요.
서버 편집 > 고급 > 연결 유지 (tmux).

Q: 다른 탭의 빌드가 끝나면 알고 싶어요.
출력 트리거에 `BUILD SUCCESS` 같은 글자를 넣고 알림을 켜세요. 앱이 뒤에 있으면 Windows 알림으로도 옵니다.

Q: `su -` 비밀번호를 자동으로 넣고 싶어요.
로그인 스크립트에서 기다릴 글자 `password` 단계의 [보관함 값]에 su 비밀번호 항목을 고르세요. 보낼 글자에 비밀번호를 적지 않아도 되고 파일에 평문으로 남지 않습니다.

Q: 회사 프록시 뒤라 SSH 가 안 돼요.
서버 편집 > 고급 > 프록시 경유에서 HTTP/SOCKS5 를 고르거나, 회사에서 쓰는 터널 프로그램(`ssh -W`, `cloudflared` 등)이 있으면 프록시 명령으로 지정하세요. `%h` 는 서버 주소, `%p` 는 포트, `%r` 은 사용자 이름으로 바뀝니다.

Q: 포트 포워딩으로 얼마나 주고받았는지 보고 싶어요.
창 머리글의 `⇄ N` 버튼을 누르면 포워딩마다 보낸·받은 양(접속한 뒤 누적)이 보입니다.

Q: 이 세션에서 얼마나 주고받았는지 보고 싶어요.
창 머리글 오른쪽의 `↑ … ↓ …` 가 세션을 연 뒤 보낸 양(입력)과 받은 양(출력)입니다. 마우스를 올리면 정확한 값이 보입니다. 재접속해도 이어서 세고, SFTP·포트 포워딩은 따로 셉니다. 창이 좁으면(머리글 360px 이하) 보이지 않으니 창을 넓히거나 한 창만 크게(Ctrl+Shift+Enter) 보세요.

Q: 화면 보호기만 떠도 앱이 잠겨요.
앱은 Windows 가 실제로 잠겼을 때만 따라 잠급니다. 그래도 잠기면 설정 > 보안 > 자동 잠금(분)을 확인하세요. 입력이 없는 시간으로도 잠깁니다.

Q: PPK 키가 안 읽혀요.
암호를 확인하세요. 안 되면 PuTTYgen > Conversions > Export OpenSSH key 로 바꿔 주세요.

Q: 내 정보가 어디로 전송되나요?
아니요. 서버 목록·비밀번호·키·라이선스 확인은 모두 이 PC 안에서만 처리합니다(git 동기화를 켜면 암호화한 파일만 내 저장소로 올라갑니다).
