## Context

- 사용자 요청: "배포하려면 영어 필수. 10개 국어. 처음 실행할 때 고르고, 기본은 윈도우 언어, 맞는 게 없으면 영어." + "언어를 따로 파일로 빼서 그것만 수정하면 되도록."
- 결정(D75, 권장안): en(기본·대체), ko, ja, zh(简体), tw(繁體), de, fr, es, pt(Brasil), ru.
- **언어 파일**: 저장소 루트 `locales/<id>.json` (평평한 키 → 문구). 기준은 `ko.json`(키 목록·TS 타입 MsgId). 프런트(`frontend/src/i18n/index.ts`, import.meta.glob)와 백엔드(`locales/locales.go` embed → `internal/i18n`)가 같은 파일을 쓴다. 문구 수정은 json 만.
- 코드: `t('area.key', { name })` (프런트, `useT()` 훅), `i18n.T("area.key", "name", v)` / `i18n.Errorf(id, err)` (Go). 자리표시자 `{이름}`.
- 언어 바꾸기: App 이 useLang 구독 → 전체 다시 그림(React.memo 없음). settings.language ''=첫 실행 언어 선택(LanguagePicker). OS 언어 = app.info.osLanguage(Go i18n.Match(DetectOS)) → navigator.
- 검사: `frontend/src/i18n/i18n.test.ts` — 10개 파일 키·자리표시자 일치, 화면 코드에 한국어 하드코딩 없음(주석 제외). **이 테스트의 실패 목록 = 남은 작업 목록.**
- **작업 도구(스크래치패드, 세션 한정)**: `scratchpad/i18n/areas/*.mjs` (`{ key: [ko,en,ja,zh,tw,de,fr,es,pt,ru] }`) → `node scratchpad/i18n/merge.mjs <repo>/cli-manager-cr/locales` 가 json 에 덧붙여 합친다. 스크래치패드가 없어져도 json 이 원본이므로 json 을 직접 고치면 된다.
