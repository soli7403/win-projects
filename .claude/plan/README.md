# plan/ — 계획 문서 보관소

Claude 가 만든 **구현 계획(plan)** 을 여기에 둔다.

## 컨벤션

- 파일명: `<YYYY-MM-DD>-<slug>.md`
- WIP 와의 차이:
  - **plan/** = 착수 전 설계·전략 문서 (무엇을 왜 어떻게 할지)
  - **wip/** = 실행 중 단계별 진행·체크포인트 (지금 어디까지 했는지)
  - 큰 작업은 plan 으로 설계 → wip 으로 실행하는 2단계가 자연스럽다.
- 완료된 plan 은 코드/커밋으로 확정된 뒤 삭제 (히스토리는 git 이 보관).

## SKIP

단순 질문 / 단발 수정 / 1~2단계 trivial 작업은 plan 파일을 만들지 않는다.
